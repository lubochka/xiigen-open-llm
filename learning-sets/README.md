## Соглашение об именовании наборов

Экспортируемые наборы данных именуются так:

```
<домен>_<тип-модели>_<номер>_<размер>_<дата>.json
```

Например: `tr-en_student_001_1000_2026-10-25.json`. Промежуточные рабочие папки партий именуются по потоку и запуску: `<OBJECTIVE>/<профиль>/<RUN_ID>/` (например, `TR07-OMISSION/ru-en/M001/`).

## Стадии партии

1. **candidate** — сгенерирован draft.jsonl, пройдена только структурная проверка (`batches.py check`, статус STRUCTURE_ONLY). Смысл не проверен, качество не установлено.
2. **accepted** — пройдены blind + независимое смысловое review + `batches.py accept`; файл accepted.jsonl. Статус `DATA_REVIEWED_NOT_NATIVE_TRAIN_READY`.
3. **export** — `batches.py export` по принятым партиям; обменный формат `INTERCHANGE_FORMAT_ONLY`, не нативный вход обучения.

Обучение (training) — отдельная стадия вне этого дерева подготовки и в этих папках не запускалось.
