ОРАКУЛ P65: допуск проверенного человеком противопоставления в обучение
------------------------------------------------------------------------------

Фактически измеренные доли общих слов продуктовой мерой:
  противопоставление против истории: 0.8333 (порог 0.70)
  дубликат против истории:           1.0000
  совсем другая строка:              0.0000
  слова истории:          ['важный', 'доступен', 'уже', 'файл', 'этот']
  слова противопоставления: ['важный', 'доступен', 'не', 'уже', 'файл', 'этот']
  слова дубликата:        ['важный', 'доступен', 'уже', 'файл', 'этот']

  доля общих слов у противопоставления                           ожидалось=0.8333 факт=0.8333 OK
  доля общих слов у дубликата                                    ожидалось=1.0 факт=1.0 OK

------------------------------------------------------------------------------
ПАНЕЛЬ 1. Решение о допуске по трём строкам: кто решил и чем кончилось
------------------------------------------------------------------------------

  Прежняя логика (старая перегрузка, тот же продуктовый код):
    P65-t02   Этот важный файл уже не доступен   -> правило общих слов: отвергнут
    P65-t03   Этот важный файл уже доступен!     -> правило общих слов: отвергнут
    P65-t04   Открой красную папку               -> правило общих слов: ДОПУЩЕН

  Новая логика (перегрузка с историей и паспортом):
    P65-t02   -> исключение по паспорту: ДОПУЩЕН (0.8333, паспорт действителен)
    P65-t03   -> правило общих слов: отвергнут (1.0000, паспорта на этого кандидата нет)
    P65-t04   -> правило общих слов: пропущен (0.0000)

  прежняя логика допустила                                       ожидалось=['P65-t04'] факт=['P65-t04'] OK
  новая логика допустила                                         ожидалось=['P65-t02', 'P65-t04'] факт=['P65-t02', 'P65-t04'] OK
  порядок кандидатов сохранён                                    ожидалось=['P65-t02', 'P65-t04'] факт=['P65-t02', 'P65-t04'] OK

------------------------------------------------------------------------------
ПАНЕЛЬ 2. Переходы «верно/неверно» по задаче допуска
------------------------------------------------------------------------------

  Правильный исход по задаче: противопоставление — допустить (новый закон),
  дубликат — отвергнуть (нового закона нет), другая строка — допустить.

  строка    прежде       теперь       переход
  P65-t02   неверно      верно        стало верно
  P65-t03   верно        верно        было и осталось верно
  P65-t04   верно        верно        было и осталось верно

  прежде верных: 2 из 3; теперь верных: 3 из 3
  стало верно: ['P65-t02']
  осталось неверно: нет
  стало неверно (потери): нет

  прежде верных решений о допуске                                ожидалось=2 факт=2 OK
  теперь верных решений о допуске                                ожидалось=3 факт=3 OK
  ни одно верное решение не потеряно                             ожидалось=[] факт=[] OK

ПАНЕЛЬ 3. Боевой вызывающий: сколько строк прошло и сколько уроков обучено
------------------------------------------------------------------------------

  Постановка как в плане: история обучения — один урок; новая партия —
  противопоставление и дубликат; порог и разбиение на слова не меняются.

  плечо A (без паспорта): отфильтровано строк=0, обучено уроков единиц=3

  отфильтрованные строки плеча A                                 ожидалось=0 факт=0 OK
  отфильтрованные строки плеча B                                 ожидалось=1 факт=1 OK
  уроки единиц плеча A                                           ожидалось=3 факт=3 OK
  уроки единиц плеча B                                           ожидалось=6 факт=6 OK
  дубликат отвергнут в обоих плечах                              ожидалось=True факт=True OK

ПАНЕЛЬ 5. Чувствительность к прежней логике
------------------------------------------------------------------------------

  Прежняя логика здесь не копия: это тот же продуктовый путь, вызванный
  без паспорта. Утверждения новой панели на нём не выполняются.

  решения, которые различаются между прежней и новой логикой: ['P65-t02']
  различие ровно в одной строке                                  ожидалось=['P65-t02'] факт=['P65-t02'] OK
  утверждение «противопоставление допущено» ложно на прежней логике ожидалось=False факт=False OK
  утверждение «противопоставление допущено» верно на новой логике ожидалось=True факт=True OK
