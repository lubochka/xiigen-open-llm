**Where in the code.** No code anchor: this is industry context, not a capability of `llm_mvp_core`. This answer deliberately cites no `file:line`, and none is invented here.

**Orchestration.** None — there is no orchestration path for an external adoption statistic. The project's orchestration (the `OrchestratorFacade` pipeline) is unrelated to industry survey figures.

**Honesty boundary.** The adoption statistics are external context and are NOT re-attributed to this project; the repository neither generates nor validates them. The only honest connection is illustrative: this project is one concrete instance of the local / from-scratch style of AI-assisted development that the broader adoption numbers describe — the numbers stay external context.
