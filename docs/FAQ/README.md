# FAQ — LlmFromScratch and current AI trends

This FAQ maps 15 current (2025-2026) AI trends onto what this repository actually
does. Each answer follows the same shape: a short trend intro, how this project
relates, where in the code it lives (`file:line` references), the orchestration
path, and an honest boundary that separates real trained/implemented mechanisms
from scaffolding, stubs, and deterministic gates. Every code reference is verified
against the current tree.

An extra note on the licensing choice (`AGPL-3.0-only`) is included on top of the
15 topics.
