## Required Standard for Every Target

Every future document must include:

- simple PlantUML or Mermaid UML importable to draw.io;
- per-connection branch examples/simulations and expected results;
- no-code algorithms in Russian with actual class, method/function, parameters, input DTO and output DTO;
- where the logic sits in the code;
- short important code quotations with exact file/line references and explanations;
- test/e2e/QA mapping;
- honest status for skeleton/bootstrap/partial/legacy;
- explicit anti-false-done checks: no stubs, JSON-only evidence, PowerShell reports, smoke reports or deterministic shortcuts may be accepted as real code, real algorithm, trained unit or phase done.
