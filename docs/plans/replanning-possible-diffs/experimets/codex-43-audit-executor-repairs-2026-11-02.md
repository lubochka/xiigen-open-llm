Правило полезного эффекта сохраняется в каждом передаваемом задании: любое измеренное улучшение полезного показателя — успех именно показателя/домена, рост accuracy не обязателен, ухудшения показаны рядом. Pure repair PASS не является новым улучшением обучения. Правильный raw false отрицательного случая может означать PASS контроля после сравнения с frozen expected; finalizer использует check_passed и полный заранее заданный required set.

Перед передачей автор извлекает именно копируемый quote/fence/inline-блок и читает его как отдельное задание. Внутри должны остаться self path, полный стек 120 §1, роли 40 §2, применимость 42/43, текущий этап, own good/bad, default model, русский отчёт, STOP/NEXT и полномочия. Ожидание одного handle требуется только при отдельно разрешённом запуске; оно не является командой запустить что-либо в документной фазе. При противоречии исправляется оперативное ядро, а не добавляется ещё один верхний дисклеймер.
