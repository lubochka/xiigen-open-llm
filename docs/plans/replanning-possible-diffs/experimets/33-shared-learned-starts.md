От донора не требуется уже иметь все11sharedfiles: generation/tokenizer, исходные raw данные, source/provenance и shared manifest разрешено оформить по точно назначенным входам без Train/Forward/Generate. data.material берётся из saved material либо детерминированно выводится исходным tokenizer/carrier из exact inputs без модели; во втором случае origin=derived_for_export, не историческое measured material. Неизвестные исторические поля=null с причиной; отсутствие обязательного provenance/identity — отказ. Отсутствующие native optimizer/RNG/qualification не восстанавливать по seed или догадке: EXPORT_INCOMPLETE_SOURCE, без автоматического Prepare.

Prepare использует ровно назначенную producer-host source closure, исходную A semantics и existing typed common helper. В H512 — PrepareLearnedStartAsync внутри copied ContinuousLearning; H64/SILU/CS — common branch собственного Program. Future internal mode `--prepare-shared <absoluteSharedRoot> --owner-nonce <nonce>` обязан принимать только назначенную family и не запускать A/B. Это явно новый authored interface, не заявление о наличии. Старый полный Run-With-Learning-Signal/Run.ps1 не вызывается для подготовки shared, поскольку он мог бы продолжить arms.

Единственный global family owner резервирует sharedroot/execution.claim через CreateNew до build/constructor/load/Forward, затем study.claim до native common. Nonce/PID/start связывают child с owner; child не создаёт второй rootclaim. Для source host действует согласованный owner, прямой child без nonce отказывает. Никакого обхода consumed/active через sharedroot: LC Prepare запрещён, остальные future source hosts проверяются до выдачи. Один script handle ожидается по31; background handle не terminal result. Normal wait не лимитируется двумя быстрыми snapshots; второй monitor/waiter и auto results-NN не создаются.

Consumer проверяет COMPLETE/qualification/полные identities до своего вмешательства, фиксирует bundle path+digest в своём study и восстанавливает A/B из одних bytes. Readback не добавляет Forward ради hashes; A0/B0 уже назначенные scoring calls сохраняются. Missing bundle оставляет задачу OPEN и конкретное family prerequisite; исполнитель не выбирает другой donor и не платит1000/400 автоматически. Прямой STOP/NEXT немедленен.
