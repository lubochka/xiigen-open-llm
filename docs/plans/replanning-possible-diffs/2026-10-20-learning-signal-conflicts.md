В RMS итог 16 readouts: 8 TRAIN плюс 8 прежних EXAM.

## Исправление запуска и конфликтов внутри карточек

Во всех справочных и конкретных карточках закреплено: полностью записать/закрыть script → один последовательный launch, не Promise/parallel для зависимых действий. Ранняя защита действует до build/Train. При неизвестном исходе наблюдать тот же process/session ID; не запускать вторую копию, не удалять partial/raw/claim, не выбирать третий каталог. Найденный output не заменяет exit receipt. Терминальные IDs не выданы за OS PID.

Документный review исправил конкретные ошибки первоначального нового протокола: RMS использует `UTF8(Prompt+Answer)` без LF; N63I оценивает T1/T2/Three/Four/Pos, а Long получает NOT_SCORED_OVER_CONTEXT без Forward; RMS wrapper не делает внешний build. У существующих scorer сохранены исходные знак и разрядность: N63I double loss, N63C native float mean logP с прежним NLL=-logP. Новые rank/exact вычисляются из тех же logits, а не вторым вызовом модели. Это содержательные исправления документа, не выполненные native проверки.
