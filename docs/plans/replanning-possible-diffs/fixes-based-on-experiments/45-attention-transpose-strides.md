## 3. Математическое обоснование и границы

Пусть \(X\in\mathbb R^{B\times A\times C\times D}\) хранится подряд. Source index и destination index:

\[
i=(((bA+a)C+c)D+d),\qquad
j=(((bC+c)A+a)D+d).
\]

Последовательное деление \(i\) на \(D,C,A\) единственным образом восстанавливает \(d,c,a,b\), поскольку размеры положительны. Это та же перестановка, которую общий код вычисляет через массив координат. Она взаимно однозначна: каждый source элемент записан ровно один раз, каждый destination элемент заполнен ровно один раз; округления float отсутствуют, поскольку переносится уже существующее значение.

В векторной записи \(y=Px\), где \(P\) — permutation matrix. Тогда \(P^{-1}=P^\top\), \(\nabla_x L=P^\top\nabla_yL\). Перестановка двух осей обратно даёт именно этот pullback. Для двух использований \(x\) вклады **складываются**, поэтому test с двумя branches необходим: одной проверки формы недостаточно.

Это прямое доказательство адресации для данного кода. Общую математическую основу даёт [Proposition 9.4, chain rule](https://github.com/lubochka/xiigen-planning/blob/d7b1704fd681fe0855afeb08ca5234433b5f9f6c/llm%20mvp/math-theory/giansalvo-transformer-vol1/source/0312-0317-ch09-motor-taxonomy-and-related-work.md#proposition-9-4); связь с раскладкой голов — [Theorem 9.11](https://github.com/lubochka/xiigen-planning/blob/d7b1704fd681fe0855afeb08ca5234433b5f9f6c/llm%20mvp/math-theory/giansalvo-transformer-vol1/source/0325-0329-ch09-headwise-recursion-and-score-motors.md#theorem-9-11), с [проверкой размерностей в заметке 89](https://github.com/lubochka/xiigen-planning/blob/d7b1704fd681fe0855afeb08ca5234433b5f9f6c/llm%20mvp/math-theory/giansalvo-transformer-vol1/notes/89-qkv-paths-and-headwise-pullback.md). Эти утверждения не доказывают ускорение, новое выученное правило или независимость голов.

Экономия временных coordinate arrays имеет порядок \(O(N)\) за вызов; размер result \(O(N)\) и градиенты не исчезают. В эксперименте снижение выделений объяснено точно. В будущем интеграционном тесте допустим любой измеренный полезный ресурсный выигрыш при соблюдении математических и учебных контрактов; исторические −8,67% не являются жёстким порогом.
