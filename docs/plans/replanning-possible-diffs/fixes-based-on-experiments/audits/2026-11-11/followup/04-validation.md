## Публикация

Каждая публикация строится поверх свежего branch head с проверенным base blob. Ветки обновляются с expected SHA и force=false. Параллельные итоги d9fc/3fb, DRAFT6a/merge05caa и новая доска45cd22 сохранены. Все15 баз изменяемых core файлов повторно сверены на45cd22 и совпали с подготовленными основаниями. Подготовленные blob hashes сверяются с Git tree до обновления ref; результат читается по созданному commit SHA. Эти проверки публикации не означают сборку или native tests.

Промежуточные commits: core 8322da46 и 0b2cca56; planning 405e7e5b. Planning checkpoint уже прочитан по commit с точным совпадением всех четырёх файлов. Окончательный core commit и closing planning note фиксируются после создания commit; собственный ещё не существовавший SHA не выдумывается.
