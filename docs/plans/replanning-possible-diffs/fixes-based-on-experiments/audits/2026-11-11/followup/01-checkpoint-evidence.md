## Как повторить

В checkout, где исходные файлы совпадают с [manifest](source-manifest.json), выполнить:

```bash
python docs/plans/replanning-possible-diffs/fixes-based-on-experiments/audits/2026-11-11/followup/recompute_product_measurements.py --core . --output /tmp/xiigen-audit-followup-new-result.json
```

Выходной путь должен ещё не существовать. Скрипт проверяет исходные blob до расчёта, повторно сверяет байты после него и создаёт результат без перезаписи. Если исходники изменились, он отказывает по SHA, а не приписывает старый вывод новой версии. Опубликованный [результат](product-recomputation.json) не является местом для следующего прогона.

В среде аудита отсутствуют .NET SDK и PowerShell. Новых native запусков, production model calls и научных опытов — **0**. Предложенные продуктовые ремонты этим сохранением не реализованы. Следующая публикация добавит завершённый evidence review, карту F/B, точные критерии приёмки и изменения рабочих карточек.
