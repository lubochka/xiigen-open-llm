- KR: проверять настоящий writer→import→TrainableRoutingFlow, score/gap guards по отдельности и полный payload provenance. Ручные keywords не заменяют learned payload.
- HCL/SVD: Run вызывает тот же training core/reader, что тесты. Настоящий Run имеет собственный budget; исторический HCL7/152/16 всё ещё отдельная незакрытая панель, его нельзя объявить заменённым1000token smoke.
- ATS/CS/RRD/MB: scalar formula и несимметричные upstream нужны для арифметики; learned S0/full state нужны для квалификации обучения. Нельзя выбрать одно вместо другого.
