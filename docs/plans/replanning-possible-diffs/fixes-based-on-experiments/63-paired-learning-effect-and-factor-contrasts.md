## 4. Точный расчёт и математическое основание

Для каждой пары i и matched точки t: `f_i(t)=correct_i(t)/denominator_i(t)`. Панельное значение — **macro mean по назначенным парам**, затем `Δ(t)=mean_i f_left,i(t)−mean_i f_right,i(t)`. Для margin тот же порядок агрегации, отдельный столбец. Не заменять macro на pooled `Σcorrect/Σdenominator`: длины ответов различны. Не смешивать no-separator historical профиль с SFT/LF профилем 62; его правильность не измерялась этими dose-curves.

Выход: число matched точек, полное объявленное окно, missing/duplicate/rejected points, mean/min/max Δ, positive/negative/zero counts, знак mean, majority sign и majority fraction. Zero учитывается в общем знаменателе; не удалять неудобные точки, не менять окно и epsilon после просмотра результата. Majority fraction — доля самого частого **ненулевого** знака среди всех matched точек; при равенстве positive/negative записать `tie`, не выбрать направление. Отдельно показать agreement со знаком mean: он в общем случае не обязан совпадать с majority. Эти величины не являются p-value, доверительным интервалом или вероятностью обобщения.

Для finite matched ряда алгебраически:

`Var(left−right) = Var(left) + Var(right) − 2 Cov(left,right)`.

Поэтому большие колебания обоих уровней могут сокращаться в разности. Формула не требует независимости и не доказывает её. Наблюдения соседних учебных шагов коррелированы; статистическую значимость и эффективное число независимых опытов из 121 точек не выводить. Детерминированный replay — отдельный контракт. Ни 97%, ни 100% из этих источников не назначаются универсальным порогом production admission.

Чтение несовместимых arm/pair/phase/profile/maps не даёт численного сравнения. Если нет траектории, helper возвращает `trajectory_not_measured` и сохраняет валидные endpoint-показатели. `0/0` не превращается в нулевую accuracy. Restore/retention gold остаётся заданным до воздействия по 57/62.
