## Что считается успехом

Любое измеренное улучшение полезного показателя считается успехом **по этому показателю и указанной теме/профилю**. Рост точности не обязателен. В той же строке сохраняются ухудшения других показателей. Это не автоматический вывод о пригодности изменения для всех доменов или о разрешении на его включение.

Измеряемый код обязан участвовать в обучении, подготовке его данных, восстановлении используемого состояния либо получении проверяемого результата. Для каждого плана указан такой вызов. Только проверка наличия файлов, числа методов, изменения весов или успешного build не заменяет измерение обучения. Необученный Student с `0→0` правильных токенов не становится успешным учебным опытом из-за небольшого движения margin. Сохранённые ресурсные наблюдения таких попыток не удаляются; они отдельно перечислены в реестре.

Для BPE непосредственный объект обучения — словарь и выученные слияния. Для kNN — содержимое памяти и полученный ответ. Для маршрутизации — обучаемый выбор маршрута. Эти механизмы не объявляются LoRA-обучением. Для нейронных проб отдельно показываются правильные токены при teacher forcing, целый ответ и свободная генерация.
