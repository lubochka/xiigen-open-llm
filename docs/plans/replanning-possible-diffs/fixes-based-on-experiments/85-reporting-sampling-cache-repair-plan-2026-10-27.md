Любой полезный измеренный эффект сохраняется по своей метрике/домену; >5% ухудшения других защищаемых метрик показываются рядом, CPU исключён. Для промпт→домен E2E нужны фактический вызов выбранного trainable recipient и изоляция дообучения/restore, не один constructor receipt.

При долгом разрешённом запуске дождаться terminal status исходного handle, bounded waits ≤60секунд с полезными промежуточными сообщениями. Не перезапускать из-за задержки вывода; не заканчивать раунд словом «жду». При прямом указании пользователя остановиться или перейти к другому ID немедленно выполнить именно его; старую задачу не продолжать. Следующий ID брать из живого индекса, не из исторического номера этой карточки.

Карточки владельцев и полный охват62 записей находятся в [86](86-reporting-sampling-cache-card-coverage-2026-10-27.md). Карта — проверка применимости новых требований, не62 выполненных runtime аудита.
