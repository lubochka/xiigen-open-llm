## 4. Связь с тестами и prompt→domain

Существующий [20-E2E](20-prompt-domain-e2e.md) остаётся единственным планом цепочки prompt→learned selector→конкретный domain handler→результат→restart. FIX-FBC/LFT меняют вычисление в уже выбранном neural handler; они не дают нового domain classifier. Подключать их завершённые native receipts к прежним assertions, без повторного H512 обучения, без нового маршрутизатора и без keyword fallback.

WM02 добавляет ограничение oracle: `deferred` и `wrong_dispatch` — разные исходы; снижение первого вместе с ростом второго не превращать в улучшение маршрутизации. Набор учит одну тему — оркестрацию; положительные классы и отрицательные контроли внутри неё не являются обучением содержанию перевода или документации. Конкретный TRAIN/EXAM назначен прежним20; не менять его по результату WM02 и не выдавать сравнение двух разных наборов за эффект единственного margin-фактора.

Тесты54/55 сохраняют фактическое обучение и приобретённый before; tests восстановления и формата читают уже полученные A/B. Падающий тест сначала классифицируется по действующему контракту: неверный expected работы, устаревший helper или настоящая регрессия. Ослаблять numerical/bitwise/authority/routing проверки ради зелёного результата запрещено. Команды, конечные бюджеты, точные paths и способы restore указаны в самих54/55/17; текущая работа их не исполняет.
