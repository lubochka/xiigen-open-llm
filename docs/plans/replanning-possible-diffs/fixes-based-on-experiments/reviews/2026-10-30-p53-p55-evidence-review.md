## 2. P53: отказ партии оставляет часть записи

Данные: установочный `keep → сохрани`; затем `open file → открой файл` и строка `t-invalid` с `ChosenOutputJson = "{"`. Исправный контроль заменяет вторую строку на `close file → закрой файл`. Панель — эти три источника; постоянный ответ даёт максимум 1/3. Холодно 0/3, после установки 1/3, после исправной партии 3/3.

Точный продуктовый путь: [TranslationMachine.TrainStructuredBatchAsync:89](../../../../../27.TranslationDomain/TranslationMachine.cs) → [ExecutorUnit.TrainOnExample:404](../../../../../27.TranslationDomain/TranslationTrainedUnits.cs) → обычный `GetOrchestratorAsync/RunAsync`. В машине вызов trainer находится на строке112; bookkeeping identities — 114–121; версия и история обновляются лишь на131–144. Executor сначала десериализует JSON409–410, затем пишет exact map415, три KNN записи418–422 и назначенные mappings. Ошибка второй строки оставляет запись первой.

Пять добавленных записей A — три KNN пары, одна exact запись, одна identity. Это **не полезное приобретение от успешной партии**, а побочный эффект отказа. На испорченной партии B сохраняет исходное 1/3 вместо ошибочно приобретённых A2/3; сравнивать это как регрессию переводческого обучения неверно. На законном control обе ветви приобретают два ответа и сохраняют старый.

Измеренный B: [P5301/Program.cs:718–779](../../../../../experiments-v2/RP01-MICRO/P5301/Program.cs) экспортирует state, обучает отдельную `TranslationMachine`, затем импортирует подготовленный checkpoint. Это подтверждает защиту live state от названной ошибки подготовки. Отказ финального `ImportCheckpoint` не вносился. Нельзя распространять доказательство на отмену, concurrent readers, несколько Unit, нехватку памяти или любое исключение.

**Поправки к формулировкам источника:**

- Report:140 утверждает, что сохранённая identity заставит пропустить повторную строку. Текущий код этого не делает: trainer вызывается **до** проверки identity, а проверка только не дублирует запись списка. Из наблюдаемого остатка identity нельзя вывести скрытый skip обучения. Идемпотентность остаётся отдельным контрактом владельца106.
- `StableState` в Program:1016–1030 включает learned containers, version/accuracy/flags, identities и только пять полей history. Он исключает ExportedAtUtc и telemetry history. Поэтому совпал **канонический проверенный состав**, а не все байты полного checkpoint и не доказанный durable bundle.
- `LearningBatchResult.CpuMs` сейчас вычисляется из `Environment.TickCount64` (TranslationMachine:139); это не независимое измерение CPU-time. Не использовать имя поля как доказательство CPU.

Ресурсы A/B: испорченная партия 649856/650320 allocated bytes; исправная 481264/535136, то есть +53872 байта, **+11.193856%**. Wall Train 14/13 мс и 4/6 мс соответственно; один замер не устанавливает причинность или стабильный throughput. Общий прогон2975 мс, peak45 МБ. Прямое исключение для логической целостности объясняет полезность результата; оно не делает ресурсные ухудшения отсутствующими. Новый дополнительный допуск bug/cleanup требует неухудшения качества и скорости native Train; здесь это ещё не доказано.

Исторический бюджет: 14 **попыток строк обучения**, 24 flow обращения против плана9/18. Это не 14 независимых fits. Причины превышений опубликованы; повторять их ради исправления отчёта не назначено.

Для109 выбран меньший будущий кандидат: синтаксическая проверка JSON всех реально назначенных не-held-out строк известных trainers **до первого TrainOnExample**. Это неизмеренная альтернатива, а не результат B. Она адресует именно P53.1; общая транзакция для произвольного сбоя остаётся открытой. Полное копирование state не переносится автоматически с заявлением о приемлемой цене.

## 3. P54: полезное покрытие, дорогой неполный перебор

Три урока: `close user → закрой пользователя`, `user session → сеанс пользователя`, `close → закрой`. У каждого один `ExecutorPhraseMapping`; WordMappings=null. На `close user session` продуктовый [TryComposeFromPhraseMappings:798–857](../../../../../27.TranslationDomain/TranslationTrainedUnits.cs) берёт `close user`, покрывает2/3 и отказывает по0.85. Нельзя подменять «покрытие» правильностью: на восьмисловном краю B покрывает3/8 вместо2/8, но оба отказывают; при девяти словах B возвращается к greedy.

Копия с выключенным фактором сошлась на шести строках, но не доказывает все будущие native ветви.

Численный gate «>5% улучшение без >5% прочих регрессий» не закрыт. Исторически3 урока,26 чтений вместо16:10 ordinary consumer,7 copied greedy,9 copied enumeration.

**Две новые адресные границы исходника:**

1. [EnumerateSegmentations:1048–1083](../../../../../experiments-v2/RP01-MICRO/P5401/Program.cs) сначала делает `Walk(i+1)`, затем ветвится по каждому matching span. Поэтому это не выбор независимых восьми boolean-флагов. При одном значении каждого source span число полных путей удовлетворяет `F(0)=1; F(n)=F(n-1)+sum(F(n-l),l=1..n)`:1,2,5,13,34,89,233,610,1597. Операционный cap256 настоящий, но математическая гарантия полного обхода `2^8` — неверная. На исходной панели cap не достигнут; положительный результат сохраняется.
2. [ReadLearnedMaps:1146–1154](../../../../../experiments-v2/RP01-MICRO/P5401/Program.cs) восстанавливает ordinal из массива `Lessons`, а не только из checkpoint. [ExportCheckpoint:499–503](../../../../../27.TranslationDomain/TranslationTrainedUnits.cs) сортирует phrase map по ключу и ordinal не сохраняет. Нельзя объявить lesson-order tie-break восстановимым из одного этого snapshot. Уникальный лучший путь исходного экзамена от этого не опровергается; равные по покрытию варианты требуют отдельного контракта.

Будущий продуктовый кандидат109 использует точный ограниченный поиск лучшего пути, а не возврат лучшего из первых256. Семантический выбор ролей этим не приобретается. Для детерминированного tie-break выбран canonical source-key order с явной версией; это **предлагаемая адаптация**, не уже измеренный lesson-order вариант. Scope первой интеграции — EN→RU, до8 нормализованных source tokens, без применимого word-map fallback; вне этого scope сохраняется текущий путь. Allocation и Train проверяются отдельно, статус остаётся CONDITIONAL.

## 4. P55: отрицание на единственной различающей строке

Уроки: `I can open the door → Я могу открыть дверь`; `I cannot open the door → Я не могу открыть дверь`; `I never open the door → Я никогда не открываю дверь`. ПанельR1/R3 повторяет первый/третий TRAIN, R4 повторяет второй; **новая строка только R2 `I can't open the door`**. Её gold — «Я не могу открыть дверь». Предел постоянного ответа2/4, в TRAIN1/3.

Текущий [TranslationMemorySourceLaw.Compare:24–41](../../../../../27.TranslationDomain/TranslationMemorySourceLaw.cs) понимает узкий copular regex, включая `the box is not empty`; для R2 возвращает Unknown. [TranslationKnnStore.FindExactWithSourceGuard:268–291](../../../../../27.TranslationDomain/TranslationUnitContracts.cs) снимает только Contradiction. Regex192 разрывает apostrophe, фильтр195–200 удаляет `not/no`, SourceTokens308–314 удаляет короткий остаток `t`: для запроса `can't` положительный источник `can` получает similarity1.00. Обычный consumer ошибается именно здесь.

Измеренный [PolarityFieldLawB:111–212](../../../../../experiments-v2/RP01-MICRO/P5501/Program.cs) — закрытый английский словарь contractions и признаков simple/always negation. Разные однозначные классы дают veto; два отрицательных признака возвращают старый закон. Это rule-based admission **к реально выученным кандидатам**, не обучение модели отрицанию. Правильность A3/4 → B4/4, ложные принятия1→0; coverage в определении copied reader не меняется. Нельзя считать холодный low-confidence bootstrap доказанным уверенным ложным принятием.

Memory-only1/4 →4/4 обходит exact-source перехват, поэтому это отдельный компонентный показатель, не три дополнительных исправления обычного consumer. Полный native A воспроизведён; [BuildReader:1635–1649](../../../../../experiments-v2/RP01-MICRO/P5501/Program.cs) показывает, что B — copied store/executor. Native B и его fresh-load ещё нужны.

## 5. Новый ограниченный опыт полноты обхода

[PHRASE-COVERAGE-CAP-01](../../experimets/cards/PHRASE-COVERAGE-CAP-01.md), предложенный Q128, — **NOT_RUN**. Нативно обучаются28 уникальных contiguous spans суффикса positions1..7 фразы `Brave red birds build warm nests beside rivers` и один prefix0..1. WordMappings отсутствуют. Ни длинный EXAM, ни короткий `Brave red birds` не входят в TRAIN.

После проверки именно29 phrase keys и отсутствия иных alternatives полный DFS имеет на длинной строке `F(7)+F(6)=610+233=843` листа; короткая имеет7.
