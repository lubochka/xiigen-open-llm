4. [Rank:378–388](C:/Projects/llm_mvp_core/18.CapabilityTraining/KnnCandidatePrinciples.cs:378) переводит exception Evaluate в `PRINCIPLE_EVALUATION_FAILED`. Null, отказ и non-finite Value дают нулевой вклад без перераспределения доли. Finite Value ограничивается диапазоном [-1,1]; конечный score дополнительно проверяется.

При N>0 математическая поправка равна `0.20 × Σ(weight_i × clamp(value_i,-1,1))/N`, где допущенные `weight_i∈[0,1]`; отказ даёт ноль. Поэтому её модуль не превышает 0,20, а разность поправок — 0,40. Это аналитическая граница с обычным округлением double, не измерение качества или ресурсов. При N=0 берётся исходный NativeScore без дополнительного сложения. Конечность native score проверяется до callback, конечность final — после. Тест `GrowingTheSetOfRulesDoesNotCreateAHiddenBudget` проверяет N=1/2/3/5 и пределы с точностью десяти десятичных знаков [840–872](C:/Projects/llm_mvp_core/Tests/KnnDomainPrincipleLearningTests.cs:840). Недостижимую через допустимые публичные значения ветвь `INVALID_FINAL_SCORE` нельзя выдавать за пройденный отрицательный runtime-контроль.

**Что закрытым не объявляется:** объект внешнего callback остаётся живым и может менять скрытое состояние или возвращаемую оценку. [Контракт:49–66](C:/Projects/llm_mvp_core/18.CapabilityTraining/KnnCandidatePrinciples.cs:49) прямо отделяет требуемую чистоту от фактически обеспеченных ограничений. Предупреждение рядом с `Principle` [88–98](C:/Projects/llm_mvp_core/18.CapabilityTraining/KnnCandidatePrinciples.cs:88) объясняет, почему для решений надо читать соседний frozen Descriptor. Это честная граница интерфейса, не полная изоляция произвольного кода.

**Тестовый source evidence:** [488–535](C:/Projects/llm_mvp_core/Tests/KnnDomainPrincipleLearningTests.cs:488) проверяет недоступность массива, отказ записи через IList и изменение исходного массива; [541–584](C:/Projects/llm_mvp_core/Tests/KnnDomainPrincipleLearningTests.cs:541) меняет паспорт после Create на HE/Infinity и проверяет сохранённые RU/1.0 и scores; [590–635](C:/Projects/llm_mvp_core/Tests/KnnDomainPrincipleLearningTests.cs:590) меняет четыре caller-owned таблицы; [640–709](C:/Projects/llm_mvp_core/Tests/KnnDomainPrincipleLearningTests.cs:640) проверяет NaN, frozen weight и exception.
