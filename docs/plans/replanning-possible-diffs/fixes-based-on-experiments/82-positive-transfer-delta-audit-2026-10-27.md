## 2. Математика и новая граница диагностического прибора

Пусть E — обученный BPE. Из `Decode(E(p+r)) = p+r` не следует `E(p+r) = E(p) || E(r)`. На p=a,r=b после merge(a,b) левая последовательность имеет один токен; next-token target справа от prompt отсутствует. Раздельная последовательность содержит два токена: response ID на позиции1 оценивается logit позиции0. Этот контрпример подтверждён P07.

Новый статический риск относится **к самому измерителю**, а не к числам ASCII опыта: `P0701/Program.cs:585–606` вычисляет длину токена через `UTF8.GetByteCount(tokenizer.Decode([id]))`. [BpeTokenizer.cs:139–143](../../../../01.Tokenizer/BpeTokenizer.cs) сначала объединяет байты токенов и только затем декодирует UTF-8. Отдельный byte token русского/ивритского символа может быть неполной UTF-8 последовательностью; U+FFFD имеет другую байтовую длину. Поэтому длины отдельно декодированных строк не являются длинами исходных токенов.

Для нового общего test helper длину брать из canonical `Vocab` Base64 → byte[], сохранённого тем же tokenizer snapshot (`BpeTokenizer.cs:560–575`), а исходные response spans — из независимых UTF-8 bytes входа. Не выводить gold из ответа проверяемого reader. **RU/HE перенос этого прибора ещё не измерен**; ASCII результат P07 сохраняется. План83 задаёт защитные RU/HE случаи внутри той же однажды обученной BPE fixture, без выдачи их за состоявшийся положительный опыт или новое качество перевода.

## 3. P06: инвариантность не является улучшением предложенной замены

Основания: commit`b6e688bf383`, [report P0601](../../../../experiments-v2/RP01-MICRO/P0601/results/attempt-0001/report.md), [исходник DpoTrainer](../../../../11.DPO/DpoTrainer.cs):1240–1247. Оба плеча используют одну узкую экспериментальную копию шага; это не доказательство полного native StepVector parity.

`VectorSignal(v)=Clamp(1+count(|v_i|>1e-6)/60,1,2)`. Для `[-1,+1]` и `[+1,-1]` оба count=2, scale=1,0333333. Совпали веса/optimizer/RNG; ответы2/4→2/4,51 Forward всего с тремя отдельными контрольными. Реальные обновления были; предметного выигрыша B над A нет.

Норма также одинакова: L1=2,L2=√2 у обоих векторов. Поэтому замена count на норму **этот опыт не различит**; чувствительность к величине ещё требует своей факторной пары и измеренного полезного выигрыша. Знаковое/координатное обучение — отдельная непроверенная архитектурная гипотеза. Она не получает приоритет готового переноса только из наличия формулы или найденной инвариантности.
