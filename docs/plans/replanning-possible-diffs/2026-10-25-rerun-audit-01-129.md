## Как читать решения

| Статус | Что делать |
|---|---|
| RETAIN | Сохранить узкий измеренный результат. Обязательного повтора исходной постановки не найдено; это не универсальный product PASS |
| SUPERSEDED | Старая незакрытая/дефектная постановка имеет позднюю замену. Использовать указанную generation, не запускать старую заново |
| REANALYZE | Исправить вывод/учёт по существующему raw, curve или логам.0новых Train/Step; это не просьба переобучить модель |
| REDESIGN | Исходная цель осталась открытой из-за постановки. Сначала исправить фактор/qualification/бюджет, затем отдельное назначение запуска; прежний сценарий не повторять |
| RERUN_REQUIRED | Валидной замены нет, исходный опыт потерян/невалиден и его надо заново выполнить после конкретного ремонта. Для текущих129таких безусловных полных повторов не найдено |
| INCOMPLETE | Сначала проверить реальный процесс/сохранённые плечи и завершить только отсутствующее. Нельзя автоматически считать отсутствие отчёта отсутствием обучения; текущая сверка не назначает таких relaunch |

Любое полезное улучшение считается успехом соответствующей оси/темы при действительном обучающем пути. Ресурсная parity на приобретённом навыке не требует роста точности. Нулевой terminal-ответ нельзя прикрывать margin; отрицательная гипотеза на валидном наборе, малая панель, один seed и необходимость native интеграции сами по себе не требуют повторить опыт. Чужая runtime-панель/свободная генерация — новая цель, а не «пересчёт безTrain».
