## Что требуется для учебной валидности, без подмены механизма

Для заявленного N63C retention правильного ответа before=S1 должен подтвердить полный T1 response E=true,23targets. C>0/E=false — только частичный показатель, M>0 при C=0 — preference score без освоенного ответа. Для «DPO приобрёл» нужен !E0&&E1; если correct response приобретена общей SFT preparation, нельзя приписать её одному DPO. Сама DPO→SFT цепь сохраняется; A/B отличаются только stale/corrected SFT.Response. Reference, compatible H512/V629/qv8/tokenizer, source/masks/config/состояние до split одинаковы; EXAM не используется для выбора checkpoint. H16/H32 partial snapshots не подставляются по имени.

Реальный незакрытый design predicate: нет предъявленного совместимого checkpoint **вместе с** full-response before panel, pinned producer/source/runtime receipt, optimizer/RNG или явным common reset contract, и заранее окончательно назначенными costs/ceilings нового corrected design. Эти поля обязан закрыть автор; исполнитель не ищет модель и не увеличивает шаги/LR. Нынешний документ исправляет ошибочную постановку/статус и перечисляет точные недостающие входы, не выдаёт будущую CLI или успех за существующие.
