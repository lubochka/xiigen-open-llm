## Конфликты и точные решения

| Конфликт из вложений | Применённое решение |
|---|---|
| Старые helper README назначают другой host/result-root и запрет записи в текущую папку | В №02/03 указаны точные canonical пути и источник конфликта. Исторические helper-инструкции не являются вторым work order. Текущее прямое поручение и write scope имеют приоритет |
| Исполнитель вынужден выбирать Python, host или способ обхода PowerShell | Карточки назначают конкретный runtime, файлы и полную команду; доступность и прошлые ошибки обозначены отдельно. Без самостоятельного поиска SDK/установки, третьего каталога и перезапуска завершённого опыта |
| Продуктовые OperationResult/comment/test/publication правила переносятся в опыт | В каждой карточке и её промптах явно разрешён минимальный изолированный host с throw/try-catch/void/DTO. Продуктовая цепочка и изменение AGENTS/skills не требуются. Это не расширяет текущие права записи |
| «Если поручена регистрация» оставляет полезный результат без кандидата | При обычном завершении запись до 120 слов в [required-changes.md](required-changes.md) обязательна без нового поручения. Немедленный переход/stop выше оформления |
| Fixed-order время/CPU/whole-process peak получают local_success | Эти числа — измеренные наблюдения с неустановленной причинностью. Они не названы ни доказанным выигрышем, ни отсутствующим измерением. Сырые числа сохранены |
| compare.py разрешает причинный verdict без final state/moments/loss/logits equality | Для эквивалентной оптимизации карточка требует раздельного содержательного verdict по этим уже записанным данным; прежний comparison.json не переписывается. Для quality-фактора равенство конечных ответов не является условием |
| Равенство 0→0 подменяет доказательство обученности | Вердикты resource gain, numerical equivalence и positive learner signal разделены. Слабый NLL сдвиг, частичный exact и отсутствие проверки названы прямо |
| Успех BPE объявляет безопасность alias для всех будущих callers | Уточнена статическая проверка текущих Train/CountPairs/MergeAll/ApplyMerges/Encode callers; blanket гарантии будущим consumers нет |
| После «переходи» исполнитель дописывает старые отчёты/реестры | Немедленный переход/stop выше любых нижних требований. Ни регистрация кандидата, ни readback, skills, hashes или review не оправдывают продолжение |
| Индекс всё ещё отправляет на уже выполненные №02/03 | Сохранённые результаты отражены в строках 02/03. Следующий ещё не выполненный пункт — №04 N62-R1; P-карточки не задают вторую очередь |
