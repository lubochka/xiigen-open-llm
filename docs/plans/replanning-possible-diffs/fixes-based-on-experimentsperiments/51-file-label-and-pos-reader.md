## FIX-FSR — статическое поле не требует null guard своего типа

Три статических учебных случая приобретены, два unseen collision случая не улучшились. Цена label9:85,000→3,329,632 байта и 9.88→916.02ms; время одной пары, но реальное добавление Roslyn binding нельзя скрыть.

Точка изменения: [FileActionKnn.cs:22–38](../../../../12.SemanticCompiler/Prediction/FileActionKnn.cs), `ActionLabelGenerator.Label`, вычисление hasMemberAccess. Разрешить member через Roslyn semantic model и исключать **только подтверждённый IFieldSymbol.IsStatic**. Не считать статическими все выражения с заглавной буквы, неизвестные symbols, instance fields, properties или method calls. Не менять FeatureVector, k, tie order и labels прочих ветвей.

Математическое/семантическое основание: у доступа к статическому полю нет экземпляра-получателя, который надо проверять на null. Это исправление целевого учебного label. Оно не различает примеры с одинаковым AST frequency vector: если f(x)=f(y), любой тот же детерминированный kNN reader возвращает одинаковое предсказание. Поэтому оставшуюся Q-CS ошибку нельзя обещать исправить этим фактором.

Конфликт с прежними FIX-KHC/NG/NKU: все касаются того же файла, но KHC владеет reuse parse, NG — смыслом null guard, NKU — do-while. Для этой пары сохранить их уже принятый общий baseline одинаковым в A/B; diff FSR изменяет только предикат доступа к static field. Если исходная сигнатура после KHC получила root overload, выполнить semantic binding на том же root/compilation, не откатывать KHC и не включать три улучшения в одну FSR дельту. Shared-parse сам по себе не подтверждает экономию стоимости нового binding.

Тест `FileStaticReceiverTransferTests.CaptureLearning`: frozen fixture → common fit6 (один раз A) →common11Predict → на каждом arm восстановить память назначенными 6pairs через native Train и 11Predict →Train9 (те же 6+3static) и 11Predict. Это **5Train/36presentations/55Predict** на пару. Native Save/Load здесь нет; materialized features/labels common сохраняются как входы, не как притворный checkpoint. B читает common A и не повторяет producer. Labeler применяется к 9TRAIN/arm, EXAM gold не вычисляется labeler. Capture сохраняет resolved symbols, labels, vectors, raw predictions и затраты разметки отдельно от fit/read.

Compare: unchanged6labels/features,3target corrections,7→10/11, обеим collision predictions показать правду; порог не повышать до 11/11 и не выкидывать Q-CS. Guard `ActionLabelGeneratorReturnsAddNullCheckForMemberAccessWithoutGuard` в [E13E14FeatureFlagTests.cs](../../../../Tests/E13E14FeatureFlagTests.cs) обязан остаться ADD_NULL_CHECK для instance string.Length. Ещё два безобучающих guards в [ExperimentsV2Tests.cs](../../../../Tests/ExperimentsV2Tests.cs): `ActionLabelGenerator_FeatureVector_HasCorrectLength`, `ActionLabelGenerator_LabelIsDeterministic`. Сохранить expected, никаких широких changes к compiler tests. Если исторический test буквально ожидал null guard от разрешённого static field, исправить только этот expected по независимой семантике и сохранить instance negative control.

В E2E это downstream learner C# после выбранного предметного binding. Ни число static accesses, ни label ADD_METHOD не являются выбором домена. Включение во весь compiler остаётся отдельным решением о цене semantic binding.
