## Попробовать поиск

Из этого каталога:

```bash
python query.py "почему book зависит от контекста"
python query.py "AdamW история" --stage optimizer
python query.py "BPE" --outcome resource_gain
python query.py "E06" --json
python query.py "gradient" --sources
```

Поиск возвращает объяснение, результат, ограничение и ссылки вместе. Это навигационный RAG с готовым лексическим извлечением: он не требует сервера, embeddings или модели. `chunks.jsonl` можно подключить к другому поиску; проверка первоисточника остаётся обязательной.

**Как читать цифры:** рост точности, удержание старого ответа и уменьшение выделений памяти — разные результаты. Запись `passed=true` не заменяет определения метрики. В реестре сохранены и положительные наблюдения внутри неуспешных итоговых запусков, и ограничения положительных панелей.
