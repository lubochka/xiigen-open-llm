## Роли данных и старые RAG не возвращают прежний режим исполнения

[N35-RAG](<C:/Users/lubao/Documents/xiigen/llm mvp/design to code session/replanning/possibleDifs/35-RAG-CANONICAL-LEARNING-LOOP-VS-RP01-2026-10-16.md>) действительно отражает старую последовательность accepted parent → новая пара → оценка → откат. Адресно прочитаны первичные [MECH:37–54](<C:/Users/lubao/Documents/xiigen/llm mvp/design to code session/09.09.26WorkLeft-MECH-01-mechanism-validation.md:37>) и [RESEARCH03:11–45](<C:/Users/lubao/Documents/xiigen/llm mvp/design to code session/09.09.26WorkLeft-RESEARCH-03-dpo-algorithm-conformance.md:11>). Они являются историческими требованиями и прямо не заявляют исполнение модели.

Пользователь позднее прямо разрешил simulation и накопительный BATCH500 ради скорости; затем текущую работу ограничил исследованием. Поэтому отсутствие внешнего автора, экзамена после каждой пары или старого порога95% **не является само по себе нарушением текущего задания**. Качество синтетического материала проверяется по смыслу/разнообразию/точным bytes; название источника не доказывает хорошую или плохую DPO-пару. Метку simulation и существующие оценённые данные не переименовываем.

Новый RAG-вопрос полезен в узкой форме: есть ли воспроизводимая связь «ошибка пользователя → новая информация → нужное изменяемое состояние → обычный ответ» и как действует принятие/откат. Но отсутствие такого свидетельства в batch-опыте не доказывает, что соответствующего кода вообще нет. Сохранение и публикация исследовательских артефактов также не равны продвижению неуспешных весов в обслуживаемую модель.

Гипотеза «проверять после каждой пары и откатывать — значит качество лучше» требует отдельного опыта. Если по одним и тем же ответам многократно выбирать, какие обновления оставить, эта панель становится частью выбора модели. Для честной финальной оценки нужна отдельная неиспользованная панель; слово blind у судьи не устраняет адаптацию к уже использованному экзамену. Это замечание к будущему дизайну, не новый обязательный gate и не разрешение запуска.
