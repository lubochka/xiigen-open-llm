# Preflight: чистая поверхность ввода Codex

Идентификатор работы: CODEX-CLEAN-INPUT-SURFACE-RECOVERY-22.

Цель этого среза: найти или подготовить чистую локальную поверхность Codex app/chat и сам контрол ввода, не отправляя промпт.

Границы:
- Не отправлять промпт.
- Не вводить секреты, токены, пароли, приватные фразы или пользовательские данные.
- Не фиксировать приватный контент в скриншотах.
- Если чистую поверхность нельзя изолировать, остановить попытку и записать blocker.
- Не редактировать продуктовый код, governance, skills или plan-файлы.
- Не заявлять готовность Codex dual-path или product readiness.

Безопасные действия:
1. Осмотреть доступные локальные окна/процессы только для поиска Codex app/chat.
2. Если найдено окно Codex, проверить, видна ли чистая поверхность ввода без приватного содержимого.
3. Если поверхность чистая и контрол ввода найден, сделать безопасный скриншот, на котором нет секретов и приватного текста.
4. Записать `clean_surface_verified=true`, `input_control_found=true`, `prompt_submitted=false` только при наличии чистого экрана и найденного контрола ввода.
5. Если Codex окно, чистая поверхность или контрол ввода не найдены, записать точный blocker.

Ожидаемый результат этого среза: evidence packet только для preflight. PASS означает только найденную чистую поверхность/контрол ввода, а не полную готовность Codex.
