# XIIGen · Ловушка перевода — файлы проекта

## Готовая игра (главное)
- **index.html** — готовая игра, один самодостаточный файл. Открывается двойным щелчком в любом браузере, работает офлайн. Это имя нужно для itch.io.
- **translation-game.html** — побайтово идентичная копия index.html (на случай, если на хостинге удобнее это имя).

> Авторитетный источник — именно эти два HTML-файла. Всё игровое содержимое, стили и логика встроены внутрь.

### Что внутри игры
Режимы на одном DPO-ядре: Быстрый раунд, Ловушка дня (+ ссылка-челлендж `?daily=`), Классическая викторина, фокус-режимы по типам ошибок, 🧩 Собери перевод, 🔍 Найди ловушку, 🃏 Память ловушек, 📜 Пословицы и цитаты, 🎲 авто Микс-сессия. Геймификация: XP/уровни, путь мастерства, полосы навыков, бейджи, рекорды, тосты. Плюс озвучка (TTS), блокнот ошибок, экспорт в Anki, картинка результата (canvas), профиль ученика, онбординг, персонаж-тьютор.

### Перед публикацией
В начале `<script>` есть блок с заглушками — подставь реальные ссылки:
```
const XG = { site:"https://xiigen.com", play:"https://play.xiigen.com", utm:"..." };
```

## Данные
- **game-pairs.json** — 1849 очищенных DPO-пар (chosen/rejected) со схемой `{id,dir,src,ok,bad,type,why}`. Источник всех заданий.
- **curated_ru.py** — модуль с 44 курированными парами, у которых разбор написан вручную на живом русском (пул по умолчанию в игре).
- **anki-deck.txt** — все 1849 пар в формате импорта Anki (таб-разделитель).

## Сборка (как делалось ядро)
- **build_dataset.py** — превращает сырые прогоны переводчика в `game-pairs.json`.
- **build_v2.py**, **build_v3.py**, **game_template.html** — ранние сборщики/шаблон базовой версии.

> Важно: эти скрипты строят БАЗОВУЮ версию. Все последующие режимы и геймификация добавлялись инкрементально прямо в `index.html`, поэтому скрипты НЕ воспроизводят текущую полную игру — авторитетен сам `index.html`.

## Курированные пословицы
14 общеизвестных (public-domain) пословиц/идиом EN→RU встроены прямо в игру массивом `const PROVERBS` (поля `src, phon, wfw, ok, bad, source, rule`). Расширяется дописыванием объектов.
