## Corrected UML Reading Used Here

- User prompt -> split prompt into domains.
- Domain translation is repeated for every chosen domain.
- Scheme planning turns the request into b1 ... bn and matching transformation prompts.
- Domain processing is an array: n units in parallel, one per sub-task or domain piece.
- Applying fbi to bi is also an array: n units in parallel, producing R1 ... Rn.
- Result translation is also an array: n units, each sees all R1 ... Rn but translates its own result back to user language.
- Arbiter selector is placed beside result translation, before final formatting. It sees all R1 ... Rn and chooses the needed reviewers.
- Arbiter units review the domain results and can send selected pieces back through the reprocessing loop.
- Formatter receives only approved translated results and folds them into one user-likable answer.

## Node Training Meaning

1. User prompt: receives the raw human request or raw document line. Produces the subject being handled.
2. Domain splitter: receives the subject. Produces domain labels such as identity access, email verification, onboarding questionnaire, chat delivery, safety, operations, events, analytics, audit, mobile, tenant, and personalization.
3. Domain translator array: receives one domain label and the matching source text. Produces that domain's own clear work language.
4. Scheme planner: receives domain-language material. Produces b1 ... bn, the ordered and parallel pieces of work.
5. Domain processor array: receives each planned piece. Produces the detailed requirement for that piece.
6. Domain applier array: receives each detailed requirement plus the needed transformation. Produces R1 ... Rn, the domain results.
7. Result translator array: receives all R1 ... Rn. Produces user-language result fragments, one per result, while keeping awareness of the whole set.
8. Arbiter selector: receives all R1 ... Rn. Produces the list of reviewers needed for the current result set.
9. Arbiter units: receive the chosen review task. Produce pass, concern, or reprocess instructions.
10. Formatter: receives approved result fragments. Produces one final answer in a useful human shape.
