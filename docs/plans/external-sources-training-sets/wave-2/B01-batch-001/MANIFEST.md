## Key teaching points

  1. UI lexicon has 22 terms; "navigation" is NOT one of them
  2. "prototype" IS in the UI lexicon in B01 (contrast: gap term in B32)
  3. UI routes to 1.1; DOCUMENT to 2.1; IMPLEMENT to 3.1; ARCHITECTURE to 4.1
  4. Sub-phase hierarchy for SubPhaseId selection: UI > ARCHITECTURE > IMPLEMENT > DOCUMENT
  5. IMPLEMENT present → feature_addition; otherwise → documentation
  6. "write user stories" → DOCUMENT+IMPLEMENT (both fire)
  7. DOCUMENT routes independently — never suppressed when UI is also present
  8. "design" + structural noun fires ARCHITECTURE; "design" + UI noun fires only UI
  9. Three v6 corruption types: v6-01 (UI missed/false positive), v6-02 (FallbackUsed suppressed), v6-03 (multi-branch collapse)
  10. EM-9 guard: Layer 2 Node 01 input must be SelectedLogicalTransition; four fields prohibited in RoutingDecision
  11. FallbackUsed: true only when a registered candidate flow was proposed and rejected
  12. Knowledge-edge path fires when zero predicate terms match; context inference is prohibited
  13. "user experience" longform does NOT fire UI — only "ux" fires UI
  14. "sidebar" is NOT in the UI lexicon; gap vocabulary → knowledge-edge
  15. Gap vocabulary does NOT suppress valid UI matches in the same request
