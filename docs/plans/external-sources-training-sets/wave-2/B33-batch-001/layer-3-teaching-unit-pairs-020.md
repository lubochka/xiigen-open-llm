## TU-020 — "orchestrate" vs "architect" vs "build" teaching unit

**Teaching goal**: Clarify the three-way boundary between "orchestrate" (gap), "architect" (ARCHITECTURE), and "build" (IMPLEMENT) in AI agent context.

**Rule 1**: "orchestrate the agent workflows" → gap. "orchestrate" = AI operational verb. It describes AI-level task coordination, not software design or code construction. Gap-ai-agent-adapt-001.

**Rule 2**: "architect the orchestration layer" → ARCHITECTURE. "architect" = design verb + "layer" = structural noun → ARCHITECTURE fires. "orchestration" as noun in object position does not convert the design verb to a gap.

**Rule 3**: "build the orchestration service" → IMPLEMENT. "build" = code verb + "service" = software artifact → IMPLEMENT fires. "orchestration" as noun does not suppress the code verb.

**Rule 4**: "orchestrate via API" → API_CONTRACT. "via API" pattern → API_CONTRACT fires. The AI orchestration verb does not prevent API_CONTRACT from firing on the integration pattern.

**Rule 5**: "design the orchestration architecture" → ARCHITECTURE. "design" = design verb + "architecture" = structural noun → ARCHITECTURE. "orchestration" is AI context only.

**Rule 6**: Common error: "orchestrate the system" → ARCHITECTURE. This is WRONG. "orchestrate" ≠ "architect". Only design verbs (architect, design) fire ARCHITECTURE.

**Summary**:
- "orchestrate" (verb) → gap
- "architect/design" + structural noun → ARCHITECTURE
- "build/implement" + software artifact → IMPLEMENT
- "via API" with any verb → API_CONTRACT
