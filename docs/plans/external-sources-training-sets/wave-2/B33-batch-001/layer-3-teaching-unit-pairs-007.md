## TU-007 — ARCHITECTURE in AI context: design verbs + structural nouns required

**Teaching goal**: ARCHITECTURE fires only on design verbs + structural nouns, even in AI context.

**ARCHITECTURE trigger pattern**: design/architect/plan/spec + architecture/system/platform/layer/infrastructure/topology/pattern

**"orchestrate" does NOT fire ARCHITECTURE**:
- "Orchestrate the agent workflows" → gap ("orchestrate" is AI vocabulary, not a design verb)
- "Design the agent orchestration layer" → ARCHITECTURE ("design" + structural noun "layer")

**Examples in AI context**:

| Request | Predicate | Reason |
|---------|-----------|--------|
| "Design the multi-agent platform" | ARCHITECTURE | design + platform (structural noun) |
| "Architect the agent coordination layer" | ARCHITECTURE | architect + layer (structural noun) |
| "Plan the agent infrastructure" | ARCHITECTURE → 3.5 | plan + infrastructure |

- "Agent platform architecture" → 3.1 (application-level)
- "Agent cloud deployment topology" → 3.5 (infrastructure)
