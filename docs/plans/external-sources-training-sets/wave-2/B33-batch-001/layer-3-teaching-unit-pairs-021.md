## TU-021 — "adapt vs build" agent boundary teaching unit

**Teaching goal**: Teach the primary verb determination rule through "adapt" vs "build" contrasts.

**Rule 1**: "adapt the agent" → gap. "adapt" = AI adaptation vocabulary → gap-ai-agent-adapt-001. The object ("the agent") is the same in all cases below; only the verb differs.

**Rule 2**: "build the agent" → IMPLEMENT. "build" = code verb → IMPLEMENT fires. Same object, different predicate outcome.

**Rule 3**: Primary verb determines routing in compound sentences. "adapt the agent rather than build a new one" → gap. "adapt" is the primary action. "build" appears in "rather than" negative clause → does not fire.

**Rule 4**: "build a new agent instead of adapting the existing one" → IMPLEMENT. "build" is the primary action. "adapting" in "instead of" clause → does not fire. Primary verb wins.

**Rule 5**: "evolve the agent" → gap. "evolve" = AI capability evolution vocabulary → gap-ai-agent-adapt-001. Same rule as "adapt".

**Rule 6**: "improve the agent's reasoning" → gap. "improve" in AI behavior context = AI quality vocabulary → gap. "improve the agent service response time" → IMPLEMENT (performance optimization = code context).

**Summary**: The primary action verb in a sentence determines routing. Subordinate clause verbs (especially in negative or "instead of" constructions) do not fire predicates. "adapt"/"evolve" always gap; "build"/"implement" always IMPLEMENT.
