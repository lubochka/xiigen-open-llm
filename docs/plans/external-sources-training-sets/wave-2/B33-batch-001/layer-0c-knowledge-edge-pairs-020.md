## KE-020-001 — Edge: "orchestrate" (AI verb) vs "architect the orchestration layer"

"orchestrate the agents" → gap ("orchestrate" = AI operational verb → gap)
"architect the agent orchestration layer" → ARCHITECTURE ("architect" = design verb + "layer" = structural noun → ARCHITECTURE)
Teaching: "orchestrate" (verb form, AI operational) → gap. "architect" (design verb) + structural noun → ARCHITECTURE. These are different verbs with different predicate mappings.

## KE-020-002 — Edge: "orchestration" as noun does not gap-ify code verbs

"build the orchestration service" → IMPLEMENT (code verb fires; "orchestration service" = software artifact)
"implement the orchestration layer" → IMPLEMENT (code verb fires; "layer" used as software component noun)
"design the orchestration architecture" → ARCHITECTURE (design verb + "architecture" = structural noun)
Teaching: "orchestration" as noun in code-artifact phrases does not suppress predicates.

## KE-020-003 — Edge: "AI orchestration" vs "API orchestration"

"orchestrate AI workflows" → gap (AI operational verb → gap)
"orchestrate workflows via the orchestration API" → ["API_CONTRACT"] ("via API" pattern → API_CONTRACT fires)
"build the AI workflow orchestration engine" → IMPLEMENT ("build" fires; "engine" = software artifact)

## KE-020-004 — Edge: "orchestrate" is NOT "architect" despite similar meaning

Common confusion: "orchestrate the system" → ARCHITECTURE (incorrect)
Correct: "orchestrate the system" → gap (AI operational vocabulary; "orchestrate" is not a design verb)
Design verb required: "architect", "design", "plan", "spec" + structural noun → ARCHITECTURE.

## KE-020-005 — Edge: "agent workflow" as noun vs "orchestrate agent workflows" as action

"agent workflow orchestration" (noun phrase, no verb) → gap (no predicate fires without code verb)
"orchestrate agent workflows" (verb form, AI context) → gap
"implement the agent workflow orchestration module" → IMPLEMENT (code verb + "module" = software artifact)
