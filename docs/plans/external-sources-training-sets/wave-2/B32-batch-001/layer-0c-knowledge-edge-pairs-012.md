## B32-0C-012-001 — B32 knowledge edge summary

**Purpose:** Consolidated reference of all B32 knowledge edges taught in this batch.

### Knowledge Edge 1: "prototype" requires action verb
- "prototype" alone → gap-vibe-coding-prototype-001 → knowledge_edge
- "prototype" + action verb → IMPLEMENT fires + gap warning

### Knowledge Edge 2: "dashboard" not in UI lexicon
- "dashboard" → gap-vibe-coding-dashboard-001 → does NOT fire UI
- UI fires on: screen, page, interface, component, form, layout, button, input, widget, modal
- "panel", "view", "sidebar" also not in UI lexicon

### Knowledge Edge 3: Style qualifiers never suppress predicates
- All B32 gap vocabulary → gap warnings only
- Action predicates fire unconditionally regardless of surrounding style vocabulary
- This applies to: vibe, quick-and-dirty, throwaway, rough-cut, hack together, nothing fancy, etc.

### Knowledge Edge 4: B32 DomainId = "software-development"
- B32 vibe coding → DomainId: "software-development"
- B36/B37 project management → DomainId: "project-management"
- Never "vibe-coding" or other invented DomainId

### Knowledge Edge 5: "spike" and gap vocabulary do not fire predicates
- spike, hack, demo, throwaway, cobble, throw together → gap warnings only
- They never fire IMPLEMENT, UI, ARCHITECTURE, or any other predicate

### Knowledge Edge 6: "vibe" in all forms → gap-vibe-coding-style-001
- vibe, vibe code, vibe coding → all gap
- "code" root within "vibe code" → IMPLEMENT fires (root match)
- "vibe" itself → no predicate

### Knowledge Edge 7: "coding" fires IMPLEMENT via "code" root match
- "coding" (gerund) matches "code" root → IMPLEMENT fires
- "exploratory coding" → IMPLEMENT fires + gap warning for "exploratory"

### Knowledge Edge 8: SCHEDULE_CAPABILITY_LEARNING fires once per request when predicates = []
- Multiple gap IDs → single SCHEDULE_CAPABILITY_LEARNING emission
- DomainId determines learning pipeline destination

### Knowledge Edge 9: v6 corruptions to avoid
- v6-01: Never invent VIBE_CODING predicate
- v6-02: Never suppress predicates due to style framing
- v6-03: Never use DomainId "project-management" for B32

### Knowledge Edge 10: Mixed-signal principle
- Predicates and gap warnings are computed independently
- Combined in output without interference
- Gap warnings carry through all layers as metadata
