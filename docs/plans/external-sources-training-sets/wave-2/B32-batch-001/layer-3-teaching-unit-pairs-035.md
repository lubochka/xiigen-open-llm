## B32-L3-035-001 — Teaching: informal action phrases and their gap IDs

**Teaching unit:** Informal verbs that map to gap-vibe-coding-hack-001

"Whip up", "throw together", "bang out", "knock out", "cobble together", "hack together" → gap-vibe-coding-hack-001.

These differ from "lean", "pragmatic", "expedient" (which are adjectives → gap-vibe-coding-style-001).

Informal action phrases → hack-001 (action framing).
Style adjectives → style-001 (quality-bar framing).

## B32-L3-035-002 — Teaching: "implementation" noun form fires IMPLEMENT

**Teaching unit:** IMPLEMENT fires from "implementation" as noun

"Whip up an implementation" → IMPLEMENT fires because "implementation" is in the IMPLEMENT noun lexicon.

Noun forms that trigger IMPLEMENT: implementation, build, codebase contribution.
The predicate fires from the noun object, not just from the verb.

## B32-L3-035-003 — Teaching: "screen" fires UI; "dashboard" fires gap only

**Teaching unit:** Screen vs dashboard distinction

"settings screen" → UI fires (screen → UI predicate).
"dashboard" → gap-vibe-coding-dashboard-001; UI does NOT fire.

When both "dashboard" and "screen" appear: dashboard adds gap ID; screen fires UI. Both effects apply independently.

---

## B32-L3-035-004 — Teaching: gap ID accuracy is required

**Teaching unit:** Gap ID must match actual vocabulary

"Whip up" → gap-vibe-coding-hack-001 (not style-001).
"Lean" → gap-vibe-coding-style-001 (not hack-001).
"Spike" → gap-vibe-coding-spike-001 (not style-001).

Using the wrong gap ID is a corruption. The gap scanner must use the precise mapping, not a default fallback.
