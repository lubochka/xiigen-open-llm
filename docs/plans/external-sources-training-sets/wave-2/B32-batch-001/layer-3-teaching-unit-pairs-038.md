## B32-L3-038-001 — Teaching: informal IMPLEMENT phrases and object context

**Teaching unit:** "hack together", "cobble together" context sensitivity

"Hack together [a specific software artifact]" → IMPLEMENT fires.
"Hack together [something vague]" → no predicate fires.

Specific software artifacts: module, service, handler, endpoint, feature, component, implementation.
Vague objects: something, it, a thing.

---

## B32-L3-038-002 — Teaching: "implementation" noun fires IMPLEMENT

**Teaching unit:** IMPLEMENT fires from "implementation" as noun

When the object of a hack phrase is "implementation", IMPLEMENT fires:
- "bang out an implementation" → IMPLEMENT
- "knock out the implementation" → IMPLEMENT
- "whip up an implementation" → IMPLEMENT

The noun "implementation" is in the IMPLEMENT lexicon.

## B32-L3-038-003 — Teaching: hack-001 vs style-001

**Teaching unit:** Two main gap ID families for informal vocabulary

**gap-vibe-coding-hack-001:** Action phrases that imply rushed execution.
- hack, hack together, cobble together, throw together, bang out, knock out, whip up, kludge together

**gap-vibe-coding-style-001:** Quality-bar adjectives and attitude phrases.
- lean, pragmatic, expedient, barebones, stripped-down, no-frills, agile (informal), iterative
- just get it working, clean up later, wing it, good enough, minimum viable

Never use style-001 for hack phrases. Never use hack-001 for style adjectives.

---

## B32-L3-038-004 — Teaching: ContributionFlag = true for any active flow

**Teaching unit:** ContributionFlag rules

ContributionFlag = true when any predicate fires (any factory creates any flow).
ContributionFlag = false when predicates = [] (knowledge_edge).

This applies regardless of gap vocabulary presence. Gap vocabulary alone does not make ContributionFlag = true.
