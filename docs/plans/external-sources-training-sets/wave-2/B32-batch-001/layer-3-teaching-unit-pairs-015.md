## B32-L3-015-001 — "quick win" is scope vocabulary, not action vocabulary

**Teaching unit:** "Quick win" describes the scope and value of the desired outcome (small, fast-to-implement, high-value). It does not describe what technical action to perform.

**"Win" is not in IMPLEMENT lexicon:** IMPLEMENT fires on: implement, build, create, write, code. "Win" is none of these.

**Core rule:**
```
"quick win" alone → gap-vibe-coding-style-001 → zero predicates → knowledge_edge
"quick win" + action verb → predicate fires + gap warning
```

## B32-L3-015-002 — Examples: quick win with different action verbs

**Predicate-firing:**

| Request | Action verb | Predicate |
|---|---|---|
| "Build a quick win" | build | IMPLEMENT |
| "Implement a quick win" | implement | IMPLEMENT |
| "Document this quick win" | document | DOCUMENT |
| "Test this quick win" | test | TEST |
| "Design a quick win" | design | ARCHITECTURE |

**Zero-predicate:**

| Request | Why zero predicates |
|---|---|
| "A quick win" | No action verb |
| "Quick win for the team" | "for the team" is context, not action |
| "Something as a quick win" | No action verb |

## B32-L3-015-003 — "quick" alone does not produce a gap ID

**Distinction:** "quick win" as a compound phrase is registered in B32. "quick" as a standalone adjective is not.

- "quick win" → gap-vibe-coding-style-001
- "quick prototype" → "prototype" alone → gap-vibe-coding-prototype-001 (from "prototype", not from "quick")
- "quickly implement" → "implement" fires IMPLEMENT; "quickly" is just an adverb modifier (no gap)

**The gap vocabulary list is precise.** Only registered terms (or their roots) produce gap IDs.
