## TU-008 — "design [curriculum/training]" vs "design [system/architecture]"

**Rule**: "design" fires ARCHITECTURE only with structural/software artifact nouns. Curriculum/content design → gap.

**Structural nouns → ARCHITECTURE fires**:
- system, architecture, platform, layer, service, infrastructure, schema, topology

**Content/curriculum nouns → gap**:
- training program, curriculum, course, learning path, workshop, bootcamp, skills matrix (as content)

**Examples**:

| "design a [noun]" | Predicate |
|-------------------|-----------|
| design a training program | [] gap |
| design a system | ARCHITECTURE |
| design a curriculum | [] gap |
| design a platform | ARCHITECTURE |
| design a workshop | [] gap |
| design a microservices architecture | ARCHITECTURE |
| design a learning path | [] gap |
| design a service layer | ARCHITECTURE |

**Mnemonic**: Ask "Is this a blueprint for a software system?" If yes → ARCHITECTURE. If it's a blueprint for human learning content → gap.
