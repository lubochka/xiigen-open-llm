## Формат ответа

Только один SELECT с единственным столбцом n; не включать INSERT/DDL, Markdown или комментарии.

## Оси новых сценариев

- **данные:** NULL и повторы; только NULL; ноль/отрицательные; пустой вход
- **ошибка:** включение NULL; удаление дубликатов; NULL как значение; исключение 0

## Что не смешивать

- JOIN
- guarded UPDATE
- GROUP BY
- window aggregate
- SQL injection как дополнительная тема

### CODE-SQL-COUNT.REF.01 / base

Семейство: `ref.sql.count.duplicate-null.01`.

**Условие:**

```text
Авторская симуляция. T-SQL / SQL Server 2019, ANSI_NULLS ON. Перед возвращённым SELECT в этом же одном T-SQL batch на той же connection выполняется setup:
DECLARE @T TABLE (v int NULL); INSERT INTO @T(v) VALUES (7),(NULL),(7);
Напиши один SELECT: n — число строк, в которых v не NULL; каждое повторение учитывается, числовой 0 учитывается. Должна быть ровно одна итоговая строка, в том числе n=0 для пустого набора. Ответ — только SELECT.
```

**Предпочтительный ответ:**

```text
SELECT COUNT(v) AS n FROM @T;
```

**Правдоподобный ошибочный ответ:**

```text
SELECT COUNT(DISTINCT v) AS n FROM @T;
```

**Доказательство различия:** Оба вхождения 7 должны учитываться, DISTINCT удаляет повтор.

**Контрпример / граница:** expected n=2; rejected n=1.

### CODE-SQL-COUNT.REF.04 / base

Семейство: `ref.sql.count.null-to-zero.01`.

**Условие:**

```text
Авторская симуляция. T-SQL / SQL Server 2019, ANSI_NULLS ON. Перед возвращённым SELECT в этом же одном T-SQL batch на той же connection выполняется setup:
```

**Предпочтительный ответ:**

```text

```
