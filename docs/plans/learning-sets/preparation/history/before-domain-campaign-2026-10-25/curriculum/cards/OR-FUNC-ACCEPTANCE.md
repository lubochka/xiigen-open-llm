## 5. Оси генерации и содержательная проверка

- **boundary:** inclusive; exclusive; empty_condition; explicit_permission.
- **expected_outcome:** accept; reject; show_defined_result.
- **error:** boundary_inversion; invented_side_effect; unobservable_result.

В первой партии должны присутствовать все релевантные состояния из этих осей и близкие контроли с противоположным действием. Не требуется механическое равенство всех комбинаций; фактическое распределение классов записать в отчёте. Если целый класс отсутствует, не объявлять pilot содержательно полным.

- Then проверяется наблюдением и сохраняет единственную границу из prompt.
- Given/when не меняются между альтернативами; не добавлен незаказанный эффект.
- Один решающий дефект; выбранный ответ следует из видимого prompt, а не из скрытых метаданных.
- Есть близкий контроль с обратным решением; нельзя выигрывать постоянным ожиданием, отказом или одним классом.
- Контрпример не выдан за новую измеренную строку и остаётся в семье исходного сценария.
- Набор не подменяет обучение роутингу предметным ответом и наоборот.

Не смешивать:

- Не обучать написанию кода или SQL, дизайну экрана либо выбору runtime-роута.
- Не смешивать критерии нескольких требований в одну пару.

Невалидны два одинаково допустимых ответа, потеря решающего контекста, альтернативы с разными заданиями и отрицательный ответ с несколькими независимыми дефектами. Сохранить причину карантина; новая версия получает новый ID и `derived_from`.

### Пример 1: OR-FUNC-ACCEPTANCE-REF-01

Семейство: `v3-ref.or-func-acceptance.f01`.

**Вход:**

```text
Симуляция. В форме разрешены от 1 до 5 вложений включительно. Рассматривается только количество, все файлы допустимы. Запиши один критерий для пяти вложений в JSON given, when, then; не добавляй другие функции.
```

**Предпочтительный ответ:**

```json
{
  "given": "Выбрано ровно 5 допустимых вложений",
  "when": "Пользователь отправляет форму",
  "then": "Форма принимает 5 вложений"
}
```

**Правдоподобный ошибочный ответ:**

```json
{
  "given": "Выбрано ровно 5 допустимых вложений",
  "when": "Пользователь отправляет форму",
  "then": "Форма отклоняет 5 вложений"
}
```

**Различающий факт:** Пять входит в явно заданную включительную границу.

**Контрпример / граница:** Если верхняя граница исключительная или разрешено не более 4, отклонение ровно 5 становится правильным.
