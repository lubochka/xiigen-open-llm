### DOC-CS-CANCEL.REF.01

Общее семейство источника: `v3.ref.cs.cancel.direct-delegate`.

**Условие:**

```text
Авторская симуляция. C# 10 / .NET 6; using System; using System.Threading; using System.Threading.Tasks. Метод внутри класса: Task<int> Forward(CancellationToken ct, Func<CancellationToken, Task<int>> read) => read(ct); Делегат read записывает точные аргументы, возвращает заранее созданный Task и не бросает синхронно. Опиши, какой token передан, сколько вызовов и что возвращает wrapper. Не утверждай физическую остановку хранилища.
```

**Предпочтительный ответ:**

```text
read вызывается один раз с исходным ct; возвращается тот же Task<int>. Сам wrapper не проверяет отмену и не перехватывает ошибку.
```

**Правдоподобный ошибочный ответ:**

```text
read вызывается один раз с CancellationToken.None; возвращается тот же Task<int>. Сам wrapper не проверяет отмену и не перехватывает ошибку.
```

**Почему различаются:** Смысловая ошибка — подмена конкретного token при передаче зависимости; сама передача не доказывает отмену на сервере.

**Контрпример:** Активный token a из CancellationTokenSource отличается от None; spy должен получить a. Возвращённый Task должен быть ReferenceEquals заданному Task.

### DOC-CS-CANCEL.REF.02

Общее семейство источника: `v3.ref.cs.cancel.identifier-and-token`.

**Условие:**

```text
Авторская симуляция. C# 10 / .NET 6; using System; using System.Threading; using System.Threading.Tasks. Метод внутри класса: Task<string> Fetch(int id, CancellationToken ct, Func<int, CancellationToken, Task<string>> read) => read(id, ct); Делегат read записывает точные аргументы, возвращает заранее созданный Task и не бросает синхронно. **Предпочтительный ответ:**
```

**Правдоподобный ошибочный ответ:**


**Почему различаются:** Смысловая ошибка — подмена конкретного token при передаче зависимости; сама передача не доказывает отмену на сервере.

**Контрпример:** id=7, ct — уже отменённый token a. Spy не бросает ошибку, записывает аргументы, возвращает заданный Task. Ожидание: (7,a), один вызов.

### DOC-CS-CANCEL.REF.04

Общее семейство источника: `v3.ref.cs.cancel.conditional-forward`.

**Условие:**

```text
Авторская симуляция. C# 10 / .NET 6; using System; using System.Threading; using System.Threading.Tasks. ```text
```

**Контрпример:** enabled=true и ct=a: spy получает a; enabled=false и отменённый a: calls=0, результат 0.
