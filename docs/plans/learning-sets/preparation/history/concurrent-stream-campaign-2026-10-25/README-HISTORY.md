# Снимок параллельного поручения по потокам

Эти десять файлов сохранены без изменения содержания из `llm_plan3@daacc32d1f3f51d6b64dfa9264102ec9cfc7836c` («learning sets update»). Коммит появился, пока готовился пакет D1000 по видимому в этой сессии поручению «1000 пар на каждый домен».

Это разные единицы квоты: отдельное поручение по 192 потокам задаёт 192000/192008, D1000 по 21 домену — 21000. Ни одну цель нельзя автоматически выдавать за другую или за уже созданные данные. Явно выбранный пользователем существующий request/кампания сохраняет приоритет. Новая D1000 не засчитывает старые партии автоматически и не заставляет их начинать заново.

Файлы здесь — историческое доказательство, не новый entrypoint. Их относительные ссылки и старые абсолютные пути отражают состояние того коммита. Для текущего D1000 использовать [реестр](../../campaign/registry.json), для отдельного поручения по потокам — [его контракт](../../27-CAMPAIGN-CONTINUATION-CONTRACT.md). Корень **новых** наборов по последнему уточнению пользователя — `C:/Projects/llm_mvp_core/learning-sets`; сохранённые старые request используют собственные фактические paths.
