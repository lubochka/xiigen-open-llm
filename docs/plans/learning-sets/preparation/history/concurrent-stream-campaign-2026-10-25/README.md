Ниже пример первого потока исходной кампании. При уже назначенном ID или начатой попытке продолжайте её; эта команда не сбрасывает очередь. Команда работает из любой текущей папки:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "C:/Users/lubao/Documents/xiigen/llm mvp/learning-sets/preparation/tools/create_sets.ps1" -Stream TR07-OMISSION/ru-en -Run M001 -Count 10
```

Обёртка находит Python 3 через `py -3` либо `python` и инструмент относительно `$PSScriptRoot`. Инструмент использует родительский каталог `preparation`, то есть указанный выше `learning-sets`. Готовые команды в `commands.md` вызывают обнаруженный абсолютный `python_executable`; исполнителю не нужно искать runtime повторно. Готовый промпт: `C:/Users/lubao/Documents/xiigen/llm mvp/learning-sets/TR07-OMISSION/ru-en/M001/prompt.md`. Рядом находятся точный request, команды завершения и состояние. `prepare` не вызывает модель и не создаёт готовые пары. Существующий run продолжается через `resume`; удалять или перезаписывать его нельзя.

Генератор использует фактически выбранную китайскую модель Kiro; помощник наследует её. Если точное имя не видно, записывается `unknown`. Обязательные checksum, фиксированный alias модели, подписанные квитанции и production CI для создания кандидатов не требуются. Точность задания, реальные источники, одна тема и разделение семейств остаются требованиями к содержанию. `finish` подтверждает создание структурно корректного draft, а не качество обучения или независимую приёмку: [контракт](17-CURRENT-PREPARATION-CONTRACT.md), [роли](10-CODEX-AND-CHINESE-ROLES.md), [граница будущего импорта](10-NATIVE-CONTRACT-BOUNDARY.md).
