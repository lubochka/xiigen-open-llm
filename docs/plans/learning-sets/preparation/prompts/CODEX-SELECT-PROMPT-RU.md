# Выбор материала перед генерацией

> **Неактивно в CREATE_ONLY.** Этот сохранённый промпт относится к отдельно порученной поздней процедуре. Текущий генератор не открывает этот цикл после draft: выполнить finish и перейти к следующему потоку по [MASTER](MASTER-PROMPT-RU.md). Старые пути ниже не являются командами запуска.

Исполнитель роли выбора — CODEX с Astra 6 ultracode. Это назначение пользователя для отдельного этапа выбора; не переключай модель китайского генератора и не выдавай текущую сессию за этот CODEX-вызов. При фактическом выполнении укажи запрошенную и наблюдаемую модели; если identity не раскрыта, не объявляй соответствие подтверждённым. Прочитай request, предметную карточку и назначенные RAG-фрагменты. Назови одну обучаемую границу, проверь полноту learner-visible условия, версию/диалект, правдоподобие отрицательного ответа, состав классов и назначенные семьи. Убедись, что данные относятся к текущему ID и не являются копиями публичного reference для скрытого EXAM.

Результат — содержательно выбранный материал и краткая запись в отчёте попытки. Отдельные profile receipts и checksum для новой дорожки не требуются; нельзя выдумывать модель, независимого проверяющего или выполненное обучение. При недостаточном условии исправить prompt новой версией до генерации, сохраняя предыдущий вариант. Следовать [17](../17-CURRENT-PREPARATION-CONTRACT.md), [MASTER](MASTER-PROMPT-RU.md) и [runbook](../18-BATCH-RUNBOOK.md).

При NEXT/новом ID немедленно перейти; не продолжать предыдущую задачу. При STOP прекратить действия. Живой процесс ожидается документированным wait по одному handle, без дубля и частого polling.
