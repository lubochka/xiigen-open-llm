### CODE-CS-NULL.REF.01 / base

Семейство: `ref.cs.null-fallback.literal.01`.

**Условие:**

```text
Авторская симуляция. C# 10 / .NET 6, nullable enabled. Напиши внутри класса метод string Label(string? s). Только при null вернуть "(нет)"; при "", " " и любом другом значении вернуть точное s без изменений. Ответ — только полное объявление метода.
```

**Предпочтительный ответ:**

```text
string Label(string? s) => s ?? "(нет)";
```

**Правдоподобный ошибочный ответ:**

```text
string Label(string? s) => string.IsNullOrEmpty(s) ? "(нет)" : s;
```

**Доказательство различия:** Rejected компилируется, но подменяет пустую строку fallback; chosen следует null-only контракту.

**Контрпример / граница:** s="": chosen возвращает "", rejected — "(нет)".

### CODE-CS-NULL.REF.02 / base

Семейство: `ref.cs.null-fallback.parameter.01`.

**Условие:**

```text
Авторская симуляция. C# 10 / .NET 6, nullable enabled. Напиши метод string Pick(string? value, string fallback), где fallback гарантированно не-null. Верни fallback только если value=null. Пустая и пробельная строки являются значениями и сохраняются. Ответ — только объявление метода.
```

**Предпочтительный ответ:**

```text
string Pick(string? value, string fallback) => value ?? fallback;
```

**Правдоподобный ошибочный ответ:**

```text
string Pick(string? value, string fallback) => value is null || value == " " ? fallback : value;
```

**Доказательство различия:** Единственное дополнительное условие rejected ошибочно заменяет строку из одного пробела.

**Контрпример / граница:** Pick(" ","guest"): expected=" "; rejected="guest".

### CODE-CS-NULL.REF.03 / base

Семейство: `ref.cs.null-fallback.preserve-spaces.01`.

**Условие:**

```text
Авторская симуляция. C# 10 / .NET 6, nullable enabled. Напиши string Keep(string? s): при null вернуть "default", иначе вернуть строку полностью, включая краевые пробелы. Keep(" A ") должен сохранить все три символа. Ответ — только объявление метода.
```

**Предпочтительный ответ:**

```text
string Keep(string? s) => s is null ? "default" : s;
```

**Правдоподобный ошибочный ответ:**

```text
string Keep(string? s) => s is null ? "default" : s.Trim();
```

**Доказательство различия:** Вторая ветвь rejected удаляет символы, хотя контракт требует точное сохранение.

**Контрпример / граница:** Keep(" A "): expected=" A ", rejected="A".

### CODE-CS-NULL.REF.04 / base

Семейство: `ref.cs.null-fallback.empty-default.01`.

**Условие:**

```text
Авторская симуляция. C# 10 / .NET 6, nullable enabled. Напиши string Value(string? s), заменяющий null на "". Любое не-null значение, в том числе " ", вернуть без изменений. Ответ — только полное объявление метода.
```

**Предпочтительный ответ:**

```text

```

**Правдоподобный ошибочный ответ:**


**Доказательство различия:** Rejected заменяет пробельные строки; отличие на whitespace, а не на null или empty.

**Контрпример / граница:** Value(" "): expected длина 1; rejected длина 0.
