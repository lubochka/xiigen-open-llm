### OR-CLIENT-RUN-STATE-REF-01 / base

Семейство: `OR-CLIENT-RUN-STATE-RF01`.

**Условие:**

```text
В интерфейсе активен run C11. API вернул 202 и {run_id:C11,state:running}; по контракту 202 означает принято в обработку, результат ещё не готов. Допустимые ui_state: in_progress, result. Верни JSON ui_state, active_run.
```

**Предпочтительный ответ:**

```text
{"ui_state":"in_progress","active_run":"C11"}
```

**Правдоподобный ошибочный ответ:**

```text
{"ui_state":"result","active_run":"C11"}
```

**Доказательство различия:** Подтверждение приёма сообщает только выполнение; готового результата в ответе нет.

**Контрпример / граница:** Если для C11 пришло terminal_success с итоговым объектом, ui_state=result становится правильным.
