**Prompt**

```text
Авторская симуляция для подготовки DPO. Среда: C# 10 / .NET 6; nullable enabled. System импортирован. Напиши тело decimal Round2(decimal x): два знака, midpoint от нуля. 1.005m→1.01m; -1.005m→-1.01m.

```text

```text
