**Generator instruction (English):** Map a confirmed event for the active run to its UI state. Accepted, completed-empty and completed-failed are distinct. A stale run cannot finish the active run. ## Три образца авторинга

Это открытые **REFERENCE** из [authoring-examples.json](../authoring-examples.json), а не новые строки корпуса. В квоту входят **0** этих примеров. Не копировать их, не подменять только имя/число и не помещать производные в закрытый EXAM. Объяснения и проверки ниже относятся к автору, не к ответу ученика.

### 1. `AUTHORING.OR-CLIENT-RUN-STATE-REF-01`

**Prompt ученика:**

````text
В интерфейсе активен run C11. API вернул 202 и {run_id:C11,state:running}; по контракту 202 означает принято в обработку, результат ещё не готов. Допустимые ui_state: in_progress, result. Верни JSON ui_state, active_run.
````

**Chosen — предпочтительный полный ответ:**

````text
{"ui_state":"in_progress","active_run":"C11"}
````

**Rejected — близкий ответ с заданной ошибкой:**

````text
{"ui_state":"result","active_run":"C11"}
````

**Simple check (English):** Read state=running for C11. The prompt defines 202 as accepted, so the UI is in_progress.

**Bad authoring trap:** Treating acceptance, empty success or a different run as the active run's final result.

**Correction:** Keep the full visible contract; compare the one causal difference before writing the row.

### 2. `AUTHORING.OR-CLIENT-RUN-STATE-REF-02`

**Prompt ученика:**

````text
В интерфейсе активен run C12. Пришло {run_id:C12,state:terminal_success,items:[]}. Контракт поиска разрешает ноль совпадений; это завершённый успешный запрос. Допустимые ui_state: empty_result, error. Верни JSON.
````

**Chosen — предпочтительный полный ответ:**


**Rejected — близкий ответ с заданной ошибкой:**

````text

````

**Simple check (English):** Read terminal_success and the allowed empty result. Zero items gives empty_result, not error.

**Bad authoring trap:** Treating acceptance, empty success or a different run as the active run's final result.

**Correction:** Keep the full visible contract; compare the one causal difference before writing the row.
