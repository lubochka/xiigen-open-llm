# Краткий порядок применения проектных skills к CREATE_ONLY

Это прикладная выжимка для автора назначенной партии; она не вводит новую цепочку approval/review и не требует читать все большие skills перед каждой десяткой. Текущее поручение пользователя CREATE_ONLY имеет приоритет над производственными правилами проекта.

| Проектный skill | Что применить здесь |
|---|---|
| architect-behavior-classifier | Сначала назвать фактическую учебную задачу и контракт ответа; не менять домен на соседний по словам в prompt |
| phase-planning | Одна маленькая цель, точные вход/выход, заданные пути, count, следующий шаг и граница текущего этапа |
| plan-review | Автор подготовки сверяет отсутствие противоречий квот/путей/примеров; это не отдельный reviewer каждой создаваемой партии |
| generated-code-review | Для runner проверить владение, повторный вызов и сохранность уже созданного; для code-пары мысленно пройти различающий вход |
| prompt-patch-authoring | Небольшой самодостаточный prompt: правило → положительный/отрицательный пример → простая проверка → конкретная команда |
| human-communication GLOSSARY | Различать домен, тему, профиль, семейство и класс; русский статус без выдуманной модели, измерения и фиктивного DONE |
| dpo-triple-format | Полные prompt/chosen/rejected для одного входа; одна содержательная причина предпочтения; служебное объяснение вне learner text |
| parallel-execution-coordinator | Уникальный владелец, точный token, общая матрица и один живой handle; фактическое ожидание, без дублей и takeover по времени |

Исходники: [docs/skills в llm_mvp_core](https://github.com/lubochka/llm_mvp_core/tree/b917116b1b85f25df9a9e69a114cae29c336ba6b/docs/skills). Это workflow-референс, не источник автоматически допущенных учебных строк. Рабочие команды и ограничения текущего этапа: [контракт](../17-CURRENT-PREPARATION-CONTRACT.md), [параллельная работа](../28-PARALLEL-GENERATION-AND-QUALITY.md).

Reason internally in English; do not expose private reasoning. Самопроверка — конкретный короткий факт: какая буква, какая ветка, какое событие или ограничение отличает ответы. В отчёте достаточно результата, числа строк, пути, остатка, следующего ID и известного блокера. Доказательство обучения не подменять предположением.
