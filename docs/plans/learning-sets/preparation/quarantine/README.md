# Сохранённые прежние reference-примеры

Эти файлы сохраняют исходное содержание публичных авторских опор, для которых найдено неоднозначное условие. Они не являются отрицательными результатами обучения и не допускаются в принятый корпус автоматически.

| Файл | Исходный ID | Причина | Активная версия |
|---|---|---|---|
| translation-legacy-v1.jsonl | TR08-REF-02 | שלום без контекста допускал приветствие/прощание | TR08-REF-02-v2 |
| translation-legacy-v1.jsonl | TR08-REF-05 | book без контекста не исключал глагол | TR08-REF-05-v2 |
| orchestration-legacy-v1.jsonl | OR-ROUTE-01-REF-012 | Мобильность приложения не была указана | OR-ROUTE-01-REF-012-v2 |

Активные версии находятся в прежних `domains/*/reference-examples.jsonl`, сохраняют семью и связь derived_from. Сам карантин и известные семейства тоже учитываются в запрете публичного материала для закрытого DEV/EXAM. Другие старые карточки, эксперименты и файлы результатов не удалены.

## SQL-GUARD: неполное условие изменения

`sql-guard-underdefined-v1.jsonl` сохраняет четыре исходные полные reference-строки CODE-SQL-GUARD. Их prompt задавал WHERE, но скрывал требуемое `Available := Available - @qty`. Активные `.v2` явно задают это в условии; origin и leakage groups сохранены. Старые строки не допускаются к обучению/DEV/EXAM.
