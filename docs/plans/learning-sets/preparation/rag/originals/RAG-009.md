## 1. Какой запрос решает эта работа

Пользователь хочет **не просто план и не просто код**, а **систему, которую разные AI-инструменты (Claude Code, Cursor, GitHub Copilot, Cline и т.д.) могут сразу потреблять** для систематической реализации XIIGen на C#/.NET 9.

Конкретные цели, поставленные в этой сессии:
- Создать **Skill Library** — набор контекстных файлов (CLAUDE.md, .cursorrules, copilot-instructions.md, .clinerules), которые любой AI-ассистент сможет загрузить и сразу понимать архитектуру, DNA-паттерны, 38 skills и правила реализации.
- Получить **готовые к копированию phased prompts** (PROMPTS.md) — 10 последовательных фаз, начиная от scaffold и заканчивая client + advanced flows. Каждая фаза — самостоятельный промпт, который другой AI может выполнить.
- Получить **интерактивный демо-интерфейс** (React), показывающий, как будет выглядеть работа с flows и skills в будущем.
- Упаковать всё так, чтобы можно было продолжать реализацию в следующей сессии без потери контекста.

Это не "напиши мне код", а "сделай так, чтобы я (или другой AI) мог дальше строить XIIGen эффективно и без постоянного повторения контекста".

## 2. Технический дизайн и ключевые решения

### Главный паттерн сессии: "AI-Consumable Implementation Assets"

Вместо того чтобы генерировать огромный объём кода в одной сессии (что неэффективно), команда сделала ставку на **мета-оркестрацию**:

1. **Skill Library как "операционная система для AI"**
   - Один `context/interfaces.cs` — единая правда про все модели, enums, DataProcessResult, fabrics.
   - Отдельные .md-файлы под конкретные инструменты (Claude Projects, Cursor, Copilot, Cline).
   - Skills Index — карта всех 38+ навыков с фазами, зависимостями и ключевыми классами.

2. **10-фазная цепочка промптов (PROMPTS.md)**
   - Фазы построены строго инкрементально (каждая следующая опирается на предыдущую).
   - Каждая фаза содержит: что делать, какие интерфейсы использовать, как проверять DNA, какие тесты писать.
   - Цель — любой другой AI (даже более слабый) мог взять промпт и выполнить фазу без знания всей истории.

3. **Re-use существующих артефактов**
   - Architecture.docx (19 компонентов MicroserviceBase)
   - DataBase_Fabric.docx (generic IDatabaseProvider + dynamic documents + filter by non-empty)
   - Ранее созданные merged-документы (XIIGEN_ENHANCED_ARCHITECTURE_V2, skills inventory и т.д.)

4. **Дополнительный деливерабл — живой демо-чат**
   - React-приложение с тремя вкладками (Chat / Flows / Skills).
   - Имитирует выполнение flow по шагам + визуализацию DAG.
   - Нужно для того, чтобы пользователь мог "продать" идею и протестировать UX-концепцию до реальной реализации.

### Связь с Genie DNA
- Вся библиотека построена вокруг `DataProcessResult<T>`, dynamic documents, generic fabrics.
- В промптах явно прописано правило "MACHINE vs FREEDOM".
- Skills пронумерованы и сгруппированы по 10 фазам с чёткими зависимостями.

## 3. Этапы реализации (как это было сделано в сессии)

### Фаза 0 — Анализ и синтез входов (внутри сессии)
- Прочитаны: Architecture.docx (19 компонентов), DataBase_Fabric.docx, несколько версий skills inventory и enhanced architecture.
- Сформирован единый Master Plan V3.0 (28–38 skills).
- Выделены 3 основных пути реализации и выбран оптимальный.

### Фаза 1 — Создание Skill Library (multi-tool context)
- `context/interfaces.cs` — каноническая копия всех интерфейсов и моделей.
- CLAUDE.md + .cursorrules + copilot-instructions.md + .clinerules — адаптированные версии под каждый инструмент.
- Skills Index (карта 38 skills по 10 фазам + зависимости + ключевые классы).

### Фаза 2 — PROMPTS.md — 10-фазная цепочка (самый важный артефакт)
Согласно `XIIGEN_SKILLS_INVENTORY_V2.md` (28 skills по 6 слоям с dependency tree) и `XIIGEN_ENHANCED_ARCHITECTURE_V2.md` (6 architectural layers + 8 advanced skills):

- Phase 0–1: Foundation (generic-core-interfaces + object-processor) — MicroserviceBase на 19 компонентов, DataProcessResult<T>, dynamic documents
- Phase 2–3: Infrastructure (elasticsearch-database-service, redis-queue-service, cache-service, ai-provider-services)
- Phase 4–5: Core Flow Engine (api-gateway, flow-orchestrator, figma-parser, ai-processing, ai-review, feedback)
- Phase 6–7: Advanced Services (ai-context-service, flow-visualization, code-generator, dynamic-deployment, documentation-generator и др.)
- Phase 8–9: Supporting + Deployment (auth, permissions, logger, k8s-deployment, react-native-client)
- Phase 10: Packaging + multi-tool Skill Library + handover

Каждая фаза — отдельный большой промпт, готовый к копированию, с явными ссылками на DNA-паттерны и конкретные интерфейсы из context/interfaces.cs.

Каждая фаза — отдельный большой промпт, готовый к копированию.

### Фаза 3 — Демо-интерфейс (React)
- Три вкладки: Chat (натуральный язык → intent), Flows (живой просмотр выполнения DAG), Skills (каталог с поиском).
- Симуляция выполнения flow по шагам с реалистичными данными.
- Мини-визуализация React Flow.

### Фаза 4 — Упаковка и handover
- Полный архив v14 skills implementation (112 файлов).
- Все артефакты сделаны downloadable.
- Сессия явно подготовлена к продолжению ("Your move! Tell me which path you'd like to start with").
