# RAG доступен из llm_plan3

В этой поставке сохранены 57 прежних выдержок и добавлен RAG-DATA-001. Из main перенесены 28 выбранных полных файлов; [карта переноса](transfer-map.json) указывает исходный commit, путь и короткую локальную копию. Все 58 выдержок, manifest, поиск и эти оригиналы доступны в плановой ветке рядом с карточками. Поэтому генератору достаточно checkout llm_plan3.

Из каталога preparation выполнить `python rag/search.py --query "automation ожидание" --show`. Для конкретного источника — `python rag/search.py --id RAG-DATA-001 --show`. Поиск не вызывает модель, не запускает исходные команды и не является обучением. `--verify` необязателен.

RAG-DATA-001 фиксирует исторический пример ошибочного отклонения разрешённого состояния. Использование в новом пакете — проверять обе стороны DPO и оставлять ничью, когда предпочтение не обосновано. Упомянутый в оригинале regex не проверяет runtime и не переносится в oracle.

Источники только xiigen-planning main/llm_plan3. При добавлении сначала прочитать выбранный фрагмент, записать смысл, ограничения и локатор, затем добавить одну запись/выдержку и синхронизировать плановый sources.lock. Полные originals читаются адресно; они не загружаются автоматически в prompt. Скрытые DEV/EXAM не помещаются в этот общий материал для генератора.
