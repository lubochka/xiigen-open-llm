# Источники восьми предметных микротем

## Назначение и статус

Карта связывает новые карточки с уже сохранёнными материалами проекта. Состав целей и `source_refs` взят из [software-control-flow-and-query.json](https://github.com/lubochka/xiigen-planning/blob/llm_plan3/llm%20mvp/learning-sets/preparation/curriculum/additions/software-control-flow-and-query.json) и [automation-window-coverage.json](https://github.com/lubochka/xiigen-planning/blob/llm_plan3/llm%20mvp/learning-sets/preparation/curriculum/additions/automation-window-coverage.json). Обзор остальных предметных областей — в [LIBRARY-NAVIGATOR-RU.md](https://github.com/lubochka/xiigen-planning/blob/llm_plan3/llm%20mvp/learning-sets/preparation/prompts/LIBRARY-NAVIGATOR-RU.md). После назначения stream исполнитель использует готовый промпт этого stream; карта не назначает следующую задачу.

**Текущая фаза — `CREATE_ONLY`. Статус пакетов — `REFERENCE_ONLY_NOT_GENERATED_NOT_TRAINED`.** Публичные reference rows — авторские симуляции и образцы формы, а не output китайской модели. Ожидаемые ответы и oracle не являются наблюдёнными результатами: выполнение новых симуляций, китайская генерация, оценка качества и обучение имеют статус `NOT_RUN`; обучение не измерялось. Эта карта фиксирует происхождение материала, не проводит review пар и не вводит checksum или review-gate.

Роли остаются заданными: **CODEX с Astra 6 ultracode** выбирает материал и оценивает качество на соответствующем последующем этапе; **внешняя китайская модель через Kiro** создаёт назначенные DPO. В Kiro сохраняется выбранная по умолчанию модель, без override. Исторический источник подтверждает методику, тему или проектное решение в названных строках; он не подтверждает успешный запуск новой симуляции либо поведение текущего production-кода.
