# Дополнение библиотеки: проверка материала перед масштабированием

## Что изменилось

На начало работы main содержал 54 закреплённых источника, а `llm_plan3/sources.lock.json` — 50. Ни один прежний фрагмент не удалён и не изменён. В lock плановой ветки внесены существовавшие `RAG-OR-001`, `RAG-OR-002`, `RAG-OR-003`, `RAG-DC-001`. Добавлен один источник `RAG-TR-001`; текущий итог — **55 записей / 55 исходных путей**, из них 25 из main и 30 из llm_plan3.

[RAG-TR-001](sources/RAG-TR-001.md) привязан к `llm_plan3@66cd68b247ad9d92570b37594fcb2cb5eb33a6cc`, blob `0681b0b41014adfbf586eb3f037f8cb698c89e06`, файлу `llm mvp/обучение языку/1st game/curated_ru.py`. Прочитанные строки 21–22, 29–30, 35–36, 54–55 показывают конкретную опасность: допустимый вариант перевода либо значение многозначного слова без контекста может быть ошибочно назначено отрицательным. Полный исходник получен и его Git blob проверен по байтам; предметный вывод ограничен указанными случаями.

Новый источник используется для аудита и правил разметки. Он не добавляет готовый gold-корпус. Исходный `curated_ru.py` не исправляется этим дополнением. Новые учебные контрасты — отдельные явно отмеченные симуляции с видимым решающим условием.

## Проверка и пределы

Из каталога подготовки:

```powershell
python rag/search.py --verify
python rag/search.py --id RAG-TR-001 --show
python rag/search.py --query "translation ложное отрицание" --limit 5
```

Хеш локального фрагмента подтверждает его целостность, но не истинность каждого утверждения исторического документа. [Manifest](manifest.json) хранит прочитанные строки, commit/blob, назначение и ограничения; [coverage](coverage.json) — видимые предметные пробелы. Итог проверок всей подготовки находится в [15 плановой ветки](https://github.com/lubochka/xiigen-planning/blob/llm_plan3/llm%20mvp/learning-sets/preparation/15-VERIFICATION-EXPANSION.md).

В этом дополнении не вызывалась китайская модель, не выполнялись native oracle и обучение Student. Все новые объёмы TRAIN/DEV/EXAM — планируемые. Материал берётся только из двух разрешённых веток xiigen-planning; ссылки во вложенных документах не расширяют этот набор источников.
