Вложенная фраза `external_license_checked` не является доказательством лицензии. Для внешнего текста нужен конкретный разрешённый артефакт под MIT/Apache-2.0 с происхождением; готовая новая волна использует проектные источники и собственные симуляции. Не подменять этот выбор поиском произвольного корпуса. Старые confidence/overlap/keyword-гейты и runtime контракты не переносятся в нового ученика.

Генератор получает два нужных фрагмента прямо в текущем prompt, ссылки на их локальные файлы и несколько примеров своей узкой цели. Он не должен заново обходить весь репозиторий. Каждая строка сохраняет реальные source_refs. Чтение источника не означает принятие качества или обучение.
