# Проверка общего индекса, очередей и команд

Дата: 25.10.2026. Проверяется подготовка DPO; генерация китайской моделью, native oracle новых программ и обучение не выполнялись.

## Воспроизводимое обновление

Из корня пакета:

```powershell
python tools/refresh_indexes.py --write
python tools/refresh_indexes.py --check
```

Первый вызов обновляет только каталоги, распределение квот, reference-индекс и отделённые блоки переходов/команд карточек. Он не вызывает модель, не запускает обучение, не меняет production и не удаляет старые эксперименты. Второй строит ожидаемые файлы в памяти и проверяет, что повторное обновление ничего не изменит.

Источники: `domains/*/topic-index.json`, четыре действующих curriculum pack, [refresh-config.json](../curriculum/refresh-config.json). В конфигурации сохранены порядок прежних 119 objective-потоков, прежние first_run ID и исторические команды. Новые objective записи импортируются один раз; обновлённые действующие записи не заменяются молча архивной копией из additions.

Результат последнего `--check`: **changed_files=0**. Динамическая проверка не зависит от прежнего фиксированного количества карточек в историческом verify_preparation.py.

## Проверенные связи

- Все 169 stream ID и назначенные каталоги первой партии уникальны.
- Все next_stream_id совпадают со следующим элементом единого списка; END есть только у последнего действующего потока.
- Curriculum-подмножество равно первым 129 потокам полной очереди; его локальный null не заменяет full-queue NEXT.
- Для всех 124 карточек канонический generated-блок содержит точную команду каждого назначенного потока и его следующий ID.
- В generation-queue у покрытого parent `command=null`, перечислены replacement_stream_ids; parent отсутствует в действующей очереди и не добавляет второй бюджет.
- Пути новых запусков имеют вид `C:/x/ls/<objective-or-topic>/<profile>/<run>`. Поэтому два objective одного parent больше не делят одинаковую выходную папку. Прежние каталоги сохранены в legacy полях; существующий процесс не переносится и не перезапускается этой сменой назначения.
- Общий бюджет сохраняется: сумма распределений и остатков равна 129 000. Квоты парных/классовых групп целые; пилот не превышает свою долю.
- `sets.validate_rows(..., allow_reference=True)` для всех 764 активных reference-строк вернул пустой список структурных ошибок. Это проверка подготовки, не утверждение о независимой предметной приёмке или качестве обучения.

## Исправление доступного ученику контекста раскладки

Независимый просмотр выявил, что имя layout-fixture-v1 и поля metadata не передают саму карту Student, который получает только prompt/chosen/rejected. Исправлены 6 TR08-LAYOUT и 6 родительских TR08-REF. В prompt добавлены фактическая/предполагаемая раскладки и полная таблица соответствий, одинаковая для обоих контрфактических классов новой цели.

Прежние 12 строк полностью сохранены в [quarantine/layout-fixture-context-v1.jsonl](../quarantine/layout-fixture-context-v1.jsonl). Содержимое каждой проверено побайтовым сравнением с исходной опубликованной копией. Активные строки получили новую версию pair_id и derived_from; family/origin/leakage и число активных строк сохранены. Это исправление самодостаточности учебного условия, не измеренный выигрыш обучения.
