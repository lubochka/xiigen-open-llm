## Проверенные согласования

- В верхних действующих блоках 00, README, 01, 16 и MASTER совпадают 119 карточек, 162 потока, 728 reference и 57 RAG. 119 objective/profile-потоков заменяют 86 parent/profile-сочетаний; 43 оставшихся дают полный порядок 162. Родительский и objective-бюджеты не складываются.
- Очередь `execution-queue.json` объявлена канонической. У шести новых карточек переходы согласованы по ID: TR02-COREFERENCE → TR05-MODALITY → OR-ARCH-DECOMPOSE → OR-QA-REVIEWER-COVERAGE → DOC-SQL-SAVEPOINT → CODE-SQL-SAVEPOINT → DOC-CS-03/base. Прямой NEXT/ID пользователя выше очереди; прежнюю работу после него продолжать запрещено. Исторические цитаты STOP не отменяют текущее задание.
- Selection/review отделены от генератора: текущая китайская модель Kiro без override генерирует после фактического CODEX selection данного request. Сборка пакета и сохранение имеющегося draft как NOT_SELECTED разрешены до selection. PENDING-профиль не выдумывается; отсутствие selection не называется живым процессом.
- Публичные примеры явно обозначены авторскими reference, а TRAIN/DEV/EXAM и B1 — назначениями будущего материала. Не заявлены выполненные Chinese-вызовы, принятый учебный корпус, обученные веса или измеренное улучшение.
- В обеих SQL-карточках явно назначены SQL Server 2019, новое соединение/процесс на полный candidate, setup до BEGIN, исходный @@TRANCOUNT=0. Внешняя BEGIN/ROLLBACK-обёртка прямо запрещена. Ожидаемый trace отделён от фактического native evidence; отсутствие runtime оставляет ORACLE_PENDING, а exit 0 не означает корректность.
- Ожидание длительной реально запущенной работы использует один сохранённый handle и native wait/resume до terminal. Отдельно запрещены дубль запуска, busy polling, новый монитор вместо ожидания и завершение хода сообщением «жду». STOP/NEXT сохраняют приоритет.
- Активный `main/.../rag/CONFLICTS.md` и новые карточки изолируют противоречивые B26 S2/S4/S5 и исторические panel/threshold/model IDs. Новое решение split опирается на достаточную learner-visible policy, QA — на требуемую способность отдельного шага. Synthetic QA reviewer_id не заменяет фактическую authority CODEX.
