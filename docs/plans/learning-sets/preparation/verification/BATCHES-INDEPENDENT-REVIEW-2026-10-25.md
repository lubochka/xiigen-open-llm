# Независимая проверка утилиты подготовки партий

Дата: 25.10.2026. Проверяющий — отдельная роль от автора `batches.py`. Объём: [batches.py](../tools/batches.py), [check_batches.py](../tools/check_batches.py), вызываемые `sets.py` функции чтения/записи, схемы, source catalog и проверки родства; также промпты [генератора](../prompts/BATCH-GENERATE-PROMPT-RU.md) и [reviewer](../prompts/BATCH-REVIEW-PROMPT-RU.md). Production-код и полный прежний аудит не входили в проверку.

## Найденный блокирующий дефект

`evidence_errors` разрешал для любого `docs.*` verdict вида `source_grounded` при `depends_on_execution=false`, даже когда назначенная микроцель прямо требовала `review_requirements.kind=executable_oracle`.

Воспроизведение использовало `DOC-CS-SNAPSHOT`, его назначенный `RAG-027` и evidence со статусом completed, `kind=source_grounded`, `depends_on_execution=false`. Исполняемый oracle не предоставлялся. До исправления функция вернула пустой список ошибок. RAG-027 содержит методику авторинга, а не результат выполнения этого C# fixture. Следовательно, такой путь мог допустить поведенческую пару без требуемой проверки её результата.

Автор исправил функцию: она читает назначенную микроцель по `metadata.learning_objective_id` и требует `execution`, если её контракт — `executable_oracle`. Неисполняемые документационные факты сохранили допустимый отдельный путь `source_grounded`.

**Повторная проверка тем же независимым reviewer:** точный прежний probe теперь возвращает `OBJECTIVE_REQUIRES_EXECUTABLE_ORACLE`. Finding закрыт. Это проверка ветви допуска данных; C# fixture и обучение при ней не выполнялись.

## Другие проверенные границы

| Область | Наблюдаемое поведение в проверенном коде |
|---|---|
| Blind A/B | Позиции выбираются случайно. В reviewer-пакет не попадают `rationale`, `error_tag`, private key и исходные chosen/rejected-метки. Source/lineage контекст сохраняется для проверки происхождения. |
| Незавершённый review | Шаблон PENDING, неполные checks, неправильный winner, tie/neither и отсутствие предметного evidence не дают принять пакет. |
| Независимость | Одинаковый заявленный `generation_session_id`/reviewer session отклоняется; reviewer обязан заявить отдельную сессию или human. Это проверка декларации, не аутентификация человека/провайдера. |
| Изменение данных после blind | Private key хранит точные исходные записи; текущие данные и восстановленный A/B-пакет сравниваются по содержимому. Изменённый draft не наследует прежний review. |
| Родословная | Проверяются назначенные family, origin, leakage groups, общий split, дополнительные переданные корпуса и публичные семьи held-out. Поиск скрытого смыслового родства остаётся задачей содержательного review. |
| Повторный run | Существующий каталог отклоняется; файлы создаются через exclusive write. Blind, acceptance и export требуют новой версии пути, старые результаты не перезаписываются. |
| Экспорт | Выход ученика содержит только `prompt/chosen/rejected`. Полные данные сохраняются в provenance sidecar. Статус — обменный формат, `native_import_verified=false`, обучение NOT_RUN. |
| Внешнее исполнение | `batches.py` не вызывает модели, провайдерские API, trainer или shell. `check_batches.py` вызывает только локальный Python CLI на временных fixture. Учебные команды внутри prompt не исполняются утилитой. |
| Инструментальные проверки | Синтетические reviewer/teacher записи тестового скрипта явно обозначены fixture; их успешный проход не объявляется независимым смысловым review или обучением. |

## Практические ограничения результата

Проверка формы review не доказывает, что его автор правдиво проверил смысл, запустил oracle или не видел ключ. Утилита прямо обозначает declared evidence и не заявляет аутентификацию. Для реальных пар требуется фактический отдельный reviewer и наблюдаемые предметные результаты; заполнение всех полей `true` само по себе не заменяет эту работу.

Родство обнаруживается по предоставленным origin/groups, известным публичным опорам и точным дубликатам. Незаявленный скрытый парафраз и корпус, который не передан через `--against`, автоматически не проверены. Это ограничение раскрыто в командах и export status.

Выполнены чтение указанного кода и адресное воспроизведение обнаруженного дефекта до/после исправления. Независимый reviewer не повторял весь набор инструментальных проверок автора и не приписывает его счётчик себе. После исправления **в проверенном узком объёме других блокирующих дефектов не найдено**. Китайская генерация, предметные native runtimes и обучение в этой проверке не запускались.
