# Очередь D1000: 217 назначений в трёх пулах

**24 × 1000 = 24 000 кандидатных пар.** Автоматический порядок внутри каждого пула определяется `allocations.order` в [реестре](campaign/registry.json). Прямой NEXT выше порядка. Старые IDs A001–A192 сохранены; новые A193–A217 добавлены.

Следующий ID в таблице означает следующую долю после выполнения текущей квоты. Пока у текущей доли есть остаток, `next` назначает следующую её партию. Временная занятость другого владельца может отложить долю; явный NEXT сохраняет раннюю работу и не возвращает к ней без явного выбора.
