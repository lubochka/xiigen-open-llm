# Обозначения и термины

[Главный индекс](README.md) · [Темы, утверждения и формулы](TOPIC-INDEX.md) · [Источник](SOURCE.md)

Словарь относится к уже обработанному материалу: **PDF 1–800, основной текст и приложения — печатные с. 1–764 / PDF 37–800**. Размерности приведены в соглашении книги: токены занимают строки, признаки — столбцы. Сведения о последующих главах не подставлены вместо ещё не прочитанных определений.

## Представление токенов и последовательностей

| Обозначение | Размерность / тип | Значение | Источник |
|---|---|---|---|
| $\mathcal V$; $v\in\mathcal V$ | Конечное множество; его элемент | Словарь; токен (vocabulary; token). | [1.1, PDF 38–39](source/0037-0043-ch01-embeddings-and-sinusoidal.md#definition-1-1) |
| $\iota$ | $\mathcal V\to\{1,\ldots,\lvert\mathcal V\rvert\}$ | Биекция, задающая целочисленный индекс токена. | [1.1](source/0037-0043-ch01-embeddings-and-sinusoidal.md#definition-1-1) |
| $e_{\iota(v)}$ | $\mathbb R^{\lvert\mathcal V\rvert}$ | One-hot: стандартный базисный вектор; для выбора строки таблицы используется его транспонирование. | [1.1–1.2](source/0037-0043-ch01-embeddings-and-sinusoidal.md#definition-1-2) |
| $n$ | Положительное целое | Длина последовательности (sequence length). | [1.5, PDF 40](source/0037-0043-ch01-embeddings-and-sinusoidal.md#definition-1-5) |
| $d=d_{\mathrm{model}}$ | Положительное целое | Размерность представления модели (model dimension). | [1.5](source/0037-0043-ch01-embeddings-and-sinusoidal.md#definition-1-5) |
| $t_i$ | Элемент $\mathcal V$ | Токен на позиции $i$; идентичность токена и номер позиции — разные объекты. | [1.5](source/0037-0043-ch01-embeddings-and-sinusoidal.md#definition-1-5) |
| $E$; $E(v)$ | $\mathcal V\to\mathbb R^d$; строка $1\times d$ | Отображение embedding и исходное представление токена. | [1.2, PDF 39](source/0037-0043-ch01-embeddings-and-sinusoidal.md#definition-1-2) |
| $W_E$ | $\mathbb R^{\lvert\mathcal V\rvert\times d}$ | Обучаемая таблица: $E(v)=e_{\iota(v)}^\top W_E$. | [1.2](source/0037-0043-ch01-embeddings-and-sinusoidal.md#definition-1-2) |
| $X^{(0)}$; $X$ | $\mathbb R^{n\times d}$ | Матрица исходных скрытых состояний; строка $i$ равна $E(t_i)$. $X$ применяется, когда индекс слоя не нужен. | [1.5](source/0037-0043-ch01-embeddings-and-sinusoidal.md#definition-1-5) |
| $x_i$ | $\mathbb R^{1\times d}$ | Строка $i$ матрицы $X$. | [1.6, PDF 40](source/0037-0043-ch01-embeddings-and-sinusoidal.md#definition-1-6) |
| $M$ | $\mathbb R^{d\times d}$ | Билинейный оператор из весов query/key; в книге назван *attention matrix*. В общем случае несимметричен. | [1.6](source/0037-0043-ch01-embeddings-and-sinusoidal.md#definition-1-6) |
| $L$; $L_{ij}$ | $\mathbb R^{n\times n}$; скаляр | Матрица score: $L=XMX^\top$; парная оценка $x_iMx_j^\top$. | [1.6](source/0037-0043-ch01-embeddings-and-sinusoidal.md#definition-1-6) |
| $q_i,k_j$; $W_Q,W_K$ | Строки длины $d_k$; матрицы $d\times d_k$ | Query и key: $q_i=x_iW_Q$, $k_j=x_jW_K$ для строки текущего входа головы. В первом аддитивном слое $x_i=E(t_i)+p_i$. | [2.1, PDF 66–67](source/0064-0075-ch02-single-head-and-scores.md#definition-2-1) |

**Не путать $M$ с весами после softmax.** $M$ имеет размер $d\times d$ и действует между признаками. Матрица весов после построчного softmax имеет размер $n\times n$ и действует между позициями. Определение [2.6](source/0064-0075-ch02-single-head-and-scores.md#definition-2-6) теперь задаёт $A=\operatorname{softmax}(L)$; определение [2.4](source/0064-0075-ch02-single-head-and-scores.md#definition-2-4) включает масштаб $1/\sqrt{d_k}$ в $L$. [Определение 1.6](source/0037-0043-ch01-embeddings-and-sinusoidal.md#definition-1-6), [доказательство 1.8](source/0037-0043-ch01-embeddings-and-sinusoidal.md#pdf-0042).

## Порядок и позиционное кодирование

| Обозначение | Размерность / тип | Значение | Источник |
|---|---|---|---|
| $\sigma$; $\sigma_{ij}$ | Перестановка; транспозиция | Перестановка позиций; обмен позиций $i,j$. Индексная конвенция исходной теоремы 1.8 разобрана отдельно. | [1.8](source/0037-0043-ch01-embeddings-and-sinusoidal.md#theorem-1-8), [H2](source/0044-0050-ch01-trainable-and-statistical-position.md#hypotheses-h1-h3) |
| $\Pi$ | $\mathbb R^{n\times n}$ | **Обозначение этого словаря** для матрицы перестановки: $X'=\Pi X$. В заметке 02 для той же роли используется $P$. | [Матричное разъяснение](notes/02-order-and-sinusoidal-encoding.md) |
| $\mathrm{PE}$; $\mathrm{PE}_i$ | $n\times d$; строка $1\times d$ | Фиксированная синусоидальная позиционная матрица и её строка. | [1.9, PDF 42](source/0037-0043-ch01-embeddings-and-sinusoidal.md#definition-1-9) |
| $\omega_k$ | Положительное число | Частота $10000^{-2k/d}$; пары координат индексируются $k=0,\ldots,d/2-1$. | [1.9](source/0037-0043-ch01-embeddings-and-sinusoidal.md#definition-1-9) |
| $R(\theta)$ | $2\times2$ для одной синусоидальной пары | Матрица вращения; пара $(\sin,\cos)$ получается как $R(-\omega_k i)(0,1)^\top$. | [1.10(i), PDF 43](source/0037-0043-ch01-embeddings-and-sinusoidal.md#proposition-1-10) |
| $X_{\mathrm{pos}}$ | $\mathbb R^{n\times d}$ | Позиционно дополненное представление $X^{(0)}+\mathrm{PE}$. | [1.9](source/0037-0043-ch01-embeddings-and-sinusoidal.md#definition-1-9) |
| $P$; $p_i$ | $n\times d$; строка $1\times d$ | **Обучаемая позиционная матрица** и её строка; вход $X^{(0)}+P$. | [§1.3.3, PDF 44](source/0044-0050-ch01-trainable-and-statistical-position.md#section-1-3-3) |
| $P^*$; $p_i^*$ | Те же размерности | Минимизатор рассматриваемой потери и его строка. Звёздочка не означает доказанную сходимость оптимизатора. | [1.11–1.12](source/0044-0050-ch01-trainable-and-statistical-position.md#lemma-1-11) |
| $\varepsilon,\delta$ | Скаляр; направление из $\mathbb R^d$ | Параметр и направление антисимметричного возмущения $p_i\pm\varepsilon\delta$. В 1.10(ii) символ $\delta$ используется иначе — для сдвига позиции. | [1.11](source/0044-0050-ch01-trainable-and-statistical-position.md#lemma-1-11), [1.10](source/0037-0043-ch01-embeddings-and-sinusoidal.md#proposition-1-10) |
| $r$; $A,B$ | Ранг факторизации; $n\times r$, $d\times r$ | Упомянутая факторизация $P=AB^\top$ с $r(n+d)$ хранимыми параметрами. Полное построение MDS доступно в [1.19 и алгоритме 1](source/0051-0063-ch01-geometry-normalisation-and-residuals.md#proposition-1-19). | [§1.3.5, PDF 49](source/0044-0050-ch01-trainable-and-statistical-position.md#section-1-3-5) |

**Разные значения $P$.** Матрица перестановки квадратная, $n\times n$, и умножает $X$ слева. Позиционная матрица имеет размер $n\times d$ и добавляется к $X$. Для совместного обсуждения удобно писать перестановку как $\Pi$; это явное редакционное переименование, не изменение транскрипции. В §1.4 буква $P$ дополнительно обозначает проектор размерности $d\times d$ на нулевое среднее; он описан ниже.

## Статистика, loss и геометрия распределений

| Обозначение | Размерность / тип | Значение | Источник |
|---|---|---|---|
| $\mathcal D$ | Корпус / распределение последовательностей | Данные длины $n$, по которым определяется статистика позиций. | [PDF 44](source/0044-0050-ch01-trainable-and-statistical-position.md#pdf-0044) |
| $\mu_i$; $\mu_i(v)$ | Распределение на $\mathcal V$; число из $[0,1]$ | Вероятность встретить токен $v$ на позиции $i$. | [PDF 49](source/0044-0050-ch01-trainable-and-statistical-position.md#pdf-0049) |
| $\bar e_i$ | Вектор из $\mathbb R^d$ | Средний embedding позиции, $\mathbb E_{v\sim\mu_i}[E(v)]$. Это не one-hot $e_{\iota(v)}$. | [PDF 44](source/0044-0050-ch01-trainable-and-statistical-position.md#pdf-0044) |
| $\mathcal L(P)$ | Скалярная функция | Loss, рассматриваемая как функция обучаемых позиций; отличать от матрицы score $L$. | [1.11–1.12](source/0044-0050-ch01-trainable-and-statistical-position.md#lemma-1-11) |
| $\nabla_{p_i}\mathcal L$ | Градиент по вектору позиции | Используется в равенстве (1.1) и условии (1.2). | [(1.1)](source/0044-0050-ch01-trainable-and-statistical-position.md#equation-1-1), [(1.2)](source/0044-0050-ch01-trainable-and-statistical-position.md#equation-1-2) |
| $c_k$; $\gamma_k$ | Скалярные коэффициенты | $c_k$ собран из производных по score; $\gamma_k=\mathbb E[c_k]$. Вводятся внутри **эвристики**, не доказанного общего градиентного тождества. | [1.14, PDF 47](source/0044-0050-ch01-trainable-and-statistical-position.md#pdf-0047) |
| $\Phi$ | $\Delta^{\lvert\mathcal V\rvert-1}\to S^{\lvert\mathcal V\rvert-1}$ | Покомпонентный квадратный корень распределения; образ лежит на неотрицательной части единичной сферы. | [1.17](source/0044-0050-ch01-trainable-and-statistical-position.md#lemma-1-17) |
| $d_H$ | Метрика; диапазон $[0,\sqrt2]$ | Расстояние Хеллингера в **ненормированной** конвенции книги; длина евклидовой хорды между $\Phi(\mu)$ и $\Phi(\nu)$. | [PDF 50, 1.17](source/0044-0050-ch01-trainable-and-statistical-position.md#lemma-1-17) |
| $d_{\mathrm{FR}}$ | Метрика | Авторская формула Фишера–Рао: $2\arccos\sum_v\sqrt{\mu(v)\nu(v)}$; численно не равна $d_H$. | [1.18](source/0044-0050-ch01-trainable-and-statistical-position.md#remark-1-18) |

**Масштаб $d_H$.** Если код применяет $H=d_H/\sqrt2$, он получает другую нормировку с диапазоном $[0,1]$. Это требует пересчёта численных порогов. По формулам книги $d_{\mathrm{FR}}=4\arcsin(d_H/2)$; вывод связи приведён в [заметке 04](notes/04-statistical-position-and-hellinger.md).
