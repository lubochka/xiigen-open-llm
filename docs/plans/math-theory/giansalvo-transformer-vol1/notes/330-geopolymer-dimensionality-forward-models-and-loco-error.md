# 330. GPC: размерность, качество прямого прогноза и смысл ошибки LOCO

## Вопрос

Что измерено у прогнозных моделей и почему хорошая случайная cross-validation не закрывает риск нового режима?

**При исключении целого химического режима ошибка заметно больше. Это аргумент проверять сдвиг распределения отдельно от случайного разбиения.** Числа ниже сообщены книгой; эксперименты здесь не воспроизводились. [Размерность и прогнозы](../source/0754-0757-ch18-geopolymer-screening-sufficiency-and-results.md#result-0756-design-space-dimensionality), [LOCO](../source/0754-0757-ch18-geopolymer-screening-sufficiency-and-results.md#result-0757-loco-validation).

| Измерение | Результат источника |
|---|---|
| Доля стандартизированной дисперсии, 5 / 6 главных компонент | 93.4% / 96.7% |
| Participation-ratio dimension / entropy effective rank | 3.17 / 4.49 |
| Медиана локальной размерности при 10 / 30 соседях | 3.01 / 2.14 |
| Число прототипов / silhouette score | 3 / 0.595 |
| ExtraTrees, прочность, случайная cross-validation | $R^2=0.951\pm0.018$, RMSE $2.48\pm0.38$ MPa |
| Ridge, прочность | $R^2=0.790\pm0.040$ |
| Прототипные регрессоры, прочность | $R^2\in[0.65,0.66]$ |
| ElasticNet, CO$_2$ | $R^2=0.9999\pm0.0001$ |
| ExtraTrees, leave-one-cluster-out | RMSE $\approx14.20$ MPa |

Книга выбирает гибрид: ExtraTrees для прочности, ElasticNet для CO$_2$. Прототипы остаются во входном фильтре обратного проектирования. Здесь не продемонстрировано превосходство прототипного регрессора над обычными табличными моделями.

## Что означает множитель 5.7

Из показанных средних $14.20/2.48\approx5.73$. Это отношение двух агрегированных RMSE:

$$
\mathrm{RMSE}=\sqrt{\frac1m\sum_{i=1}^{m}(f(x_i)-y_i)^2}.
$$

Оно не говорит, что прогноз любой новой смеси ошибётся в шесть раз, что значение прочности будет в шесть раз неправильным или что каждый принятый F3 кандидат обязательно имеет меньшую ошибку. Текст PDF 757 переходит к такой индивидуальной интерпретации без необходимых данных.

Низкий эффективный ранг ковариации показывает концентрацию вариации; он сам по себе не доказывает геометрию всего нелинейного многообразия, покрытие тремя центрами или переносимость на новые химические режимы. Книга сообщает, что покрытие проверено, но не даёт здесь радиуса и вычислительного протокола.

Для содержательного повторения понадобятся исходные split-ы, способ получения кластеров без утечки тестовых данных, неопределённость LOCO-оценки и измеренные ответы для новых кандидатов. Особенно следует уточнить, какая часть CO$_2$ измерена, а какая вычислена из состава: очень высокий $R^2$ не различает эти случаи.
