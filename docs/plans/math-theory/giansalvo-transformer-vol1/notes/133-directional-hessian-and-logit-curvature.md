# 133. Directional Hessian: ориентация логитов и скорость затухания кривизны

[Индекс](../README.md) · [Setup](../source/0417-0424-ch12-sharpness-mixed-regimes-and-hessian.md#pdf-0421) · [Theorem 12.4](../source/0417-0424-ch12-sharpness-mixed-regimes-and-hessian.md#theorem-12-4) · [(12.15)–(12.16)](../source/0417-0424-ch12-sharpness-mixed-regimes-and-hessian.md#equation-12-15)

## Какая конфигурация нужна доказательству

Loss в источнике задан точно:

$$
\mathcal L_L(L)=\lVert\operatorname{softmax}_{\mathrm{row}}(L)-\mathbf1e_c^\top\rVert_F^2.
$$

Target означает: каждая строка направляет массу в столбец $c$. Соответствующие насыщенные логиты имеют вид $L^*=m\mathbf1e_c^\top$, $m\to\infty$. В setup и Theorem 12.4 напечатана транспонированная форма $m e_c\mathbf1^\top$. Она прибавляет константу ко всей строке $c$ и оставляет остальные строки постоянными; row-softmax для неё **равномерен во всех строках при любом $m$**. Поэтому утверждение при буквально напечатанном $L^*$ неверно.

Последующий вывод вероятностей $S_c=1/(1+(n-1)u)$, $S_k=u/(1+(n-1)u)$ с $u=e^{-m}$ относится к правильной столбцовой конфигурации. В английском исходнике транспонирование сохранено; здесь исправленная конфигурация обозначена отдельно.

## Что подтверждается алгеброй

Для нужной строки положим $q_j=e^{\ell_j-\ell_c}$ при $j\ne c$. Вблизи directional saturation loss имеет ведущую часть

$$
\mathcal L_{\mathrm{row}}=(\textstyle\sum_{j\ne c}q_j)^2+\sum_{j\ne c}q_j^2+O(q^3).
$$

При одинаковых нетаргетных логитах $q_j=u$ её Hessian действительно даёт напечатанную матрицу $A_n^{(0)}$: diagonal target $4n(n-1)$, target–other $-4n$, other diagonal $2(n+2)$, other off-diagonal $2$, с общим множителем $u^2$.

Её spectrum (12.16) согласуется с этой матрицей:

| Подпространство | Собственное значение ведущей матрицы | Кратность |
|---|---:|---:|
| Константа всей строки | $0$ | 1 |
| Изменения нетаргетных логитов с суммой 0 | $2(n+1)$ | $n-2$ |
| Target против среднего остальных | $4n^2$ | 1 |

При $n=2$ средняя строка таблицы отсутствует, поэтому наименьшее ненулевое значение равно $16$, а не $6$. При $n=1$ нет ненулевого gauge-free spectrum вообще. Формулы, подставляющие $2(n+1)$ как минимум, требуют $n\ge3$.

## Gauge, асимптотика и смысл «резкости»

Нулевая мода возникает из точной инвариантности softmax к прибавлению константы в строку. У всего $L$ таких мод $n$. Сравнивать наименьшие собственные значения можно только после явного исключения этого ядра.

Результат $A_n=u^2A_n^{(0)}+O(u^3)$ является асимптотическим. В пределе $u=0$ все значения Hessian исчезают; речь идёт о малых положительных $u$, а не о ненулевой кривизне в конечной точке «бесконечных логитов».

Слово sharpness здесь используется в двух смыслах: распределение становится почти детерминированным, но squared-loss по логитам становится **плоским**. Ошибка attention по норме имеет порядок $e^{-m}$, её квадрат и Hessian — порядок $e^{-2m}$. Последний абзац PDF 424 приписывает норме тот же exponent, что Hessian; это смешение нормы с её квадратом.

Это вычисление не доказывает Theorem 12.2 для распределённых supports и не даёт числа шагов обучения. Оно точно описывает локальную кривизну конкретного squared-loss при конкретной симметричной directional-конфигурации.
