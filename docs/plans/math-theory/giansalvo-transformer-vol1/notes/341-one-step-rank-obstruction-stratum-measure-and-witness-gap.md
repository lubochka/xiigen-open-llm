# 341. Generic rank obstruction: локальное утверждение, мера и недостающее свидетельство

## Вопрос

Следует ли из Lemma 19.6, что ранг сохраняется на любой глубине?

**Источник сам ограничивает результат одним слоем. Кроме этого, его доказательству нужны точная мера на rank-r входах и свидетельство вне плохого множества в каждой рассматриваемой routing cell.**

Источник: [Lemma 19.6](../source/0771-0773-ch19-symmetry-rank-and-bilinear-span.md#lemma-19-6), [доказательство и Remark 19.7](../source/0771-0773-ch19-symmetry-rank-and-bilinear-span.md#pdf-0773).

## Полезная часть математической идеи

На области с фиксированным top-$k$ набором, корректно определённой LayerNorm и аналитической активацией GeLU entries выхода и его minors аналитичны. Если один нужный minor не тождественно нулевой на связной области, его нули образуют исключительное множество. Это обычный способ доказывать generic rank через ненулевой minor.

Здесь нужно различать три объекта: все возможные пары $u,v$ в Lemma 19.8; реально присутствующие строки одного $X$; пары, разрешённые конкретной routing cell. Полнота bilinear span для произвольных $u,v$ не предоставляет автоматически требуемое свидетельство при фиксированных rank, LayerNorm и top-$k$ constraints.

## Мера на входах заданного ранга

При $r<\min(n,d)$ множество матриц rank $r$ имеет нулевую Lebesgue measure в полном пространстве $\mathbb R^{n\times d}$. Поэтому “Lebesgue-a.e. input X with rank(X)=r” без уточнения может стать пустым по смыслу: любое исключение внутри этого слоя уже имеет нулевую ambient measure.

Содержательная версия требует меры на rank-$r$ manifold/локальных координатах и доказательства, что соответствующий minor не тождественно нулевой **на нём** в каждой допустимой области. Source этого перехода не раскрывает. Его утверждение сохраняется как авторская Lemma с данной границей доказательства, а не как готовая гарантия для реализации.

## Один шаг и обученная глубокая сеть

Даже корректная generic one-step формулировка не даёт нижней границы на наименьшее сингулярное число. Оно может быть положительным, но очень малым; numerical rank тогда падает по выбранному порогу. При композиции ухудшаются conditioning и распределение входов. Generic случайные параметры не эквивалентны параметрам после обучения.

Remark 19.7 прямо различает one-step obstruction и deep-stack behaviour. Ненулевые положительные gates также сами по себе не гарантируют сохранение span произвольной суммы: cancellation и constraints требуют отдельной проверки. Для Xiigen полезен исследуемый механизм bilinear features; обещание неограниченного rank preservation из этих страниц не следует.
