# 193. Динамические переменные INCRT: покрытие существующих голов и наблюдаемость спроса задачи

[Индекс библиотеки](../README.md) · [Источник и политика](../SOURCE.md)

## Точное чтение определений

В (15.2) $\mu_\ell(t)$ — эмпирическая мера **текущих голов**, каждая имеет вес $1/H_\ell(t)$. В (15.3) $\mathcal D_\ell(t)$ — отдельное множество dictionary atoms. Поэтому (15.4) равна

$$
\rho_\ell(t)=\frac1{H_\ell(t)}
\sum_{h=1}^{H_\ell(t)}
\min_{a\in\mathcal D_\ell(t)}\|\sigma_h^{(\ell)}(t)-a\|^2.
$$

Это средняя ошибка представления существующих head signatures словарём. Она может быть положительной: при одной сигнатуре 0 и $D=\{2\}$ значение равно 4. Она равна нулю, если словарь содержит все текущие сигнатуры. Нельзя утверждать, что определение главы 15 тождественно нулевое: в отличие от подстановки тех же голов в качестве центров, здесь словарь задан отдельно. [Формулы 15.2–15.4](../source/0547-0550-ch15-dynamic-variables-and-controller-introduction.md#equation-15-2).

Нужны $H_\ell(t)\ge1$, непустой словарь и определённая норма/метрика. Для разнородных координат signature результат зависит от их масштаба.

## Что текущая head measure не наблюдает

Пусть все существующие головы имеют сигнатуру 0, словарь равен $\{0\}$, а нужная задаче операция имеет сигнатуру 1. Тогда $\rho=0$ не меняется от наличия неудовлетворённого требования: точки 1 нет в мере. Следовательно, малое значение (15.4) само по себе не доказывает coverage **потребностей задачи**. Для этого требуется независимая мера требуемых операций, residual candidates, intervention evidence или явная связь текущих голов с целевым спросом.

Это различие особенно важно при изменении числа голов. Возьмём сигнатуры $\{0,2\}$ и $D=\{0\}$: $\rho=2$. Добавление дубликата в точке 0 даёт $\rho=4/3$, хотя расстояния обеих старых голов до словаря не улучшились. Удаление единственной головы в точке 2 даёт $\rho=0$, скрывая её отсутствие из измеряемой популяции. Crowding и marginal-value проверки могут отклонять такие действия; пример показывает, почему одна $\rho$ недостаточна.

Для сопоставления checkpoint полезно дополнительно считать ошибку на фиксированном reference population или наборе task demands. Это редакторское предложение по измерению, не подмена авторского определения.

## Residual amplification — не residual approximation error

(15.5) задаёт

$$
\Gamma_{\mathrm{res}}=\frac{\|R_\ell(X_t)\|}{\|X_t\|+\epsilon}.
$$

Это относительная **норма фактически внесённого residual update**. Без дополнительной модели она не равна величине недостающей directional information. Для скалярного residual block $Y=X+R(X)$, $X=1$, target $Y^\star=11$ выбор $R(1)=10$ даёт нулевой squared loss и большой ratio. Выбор $R(1)=0$ даёт ratio 0 и loss 50 при нормировке $\frac12(Y-Y^\star)^2$. Поэтому высокая или низкая норма update не определяет underfitting. [Формула 15.5](../source/0547-0550-ch15-dynamic-variables-and-controller-introduction.md#equation-15-5).

Также эта $\Gamma_{\mathrm{res}}$ не должна автоматически отождествляться с прежней энергией skew residual, полученной после геометрического покрытия eigenplanes: одинаковый символ не устанавливает равенство разных функционалов.

## Marginal value и controller state

(15.6) — signed difference loss при controlled ablation. Она зависит от checkpoint, evaluation window, определения удаления и того, какие параметры при этом фиксированы. Differentiable proxy — другое измерение, пока не установлено соответствие точной абляции. [Формула 15.6](../source/0547-0550-ch15-dynamic-variables-and-controller-introduction.md#equation-15-6).

Tables 15.1–15.2 назначают этим величинам роли в controller. Для реализации следует сохранять определение каждого observable вместе с его reference distribution; слова «detects», «protects» и «prevents» в таблицах обозначают предполагаемую роль контроля, а не доказанную достаточность одного скаляра.
