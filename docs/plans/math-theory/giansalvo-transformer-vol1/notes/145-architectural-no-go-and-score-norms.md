# 145. Архитектурные ограничения: точные остатки и проверка числового примера

[Индекс](../README.md)


## Четыре корректные задачи аппроксимации матрицы

[Theorems 12.34–12.37, (12.49)–(12.52)](../source/0446-0450-ch12-orientation-gaps-and-architecture-no-go.md#theorem-12-34) дают точные относительные квадраты ошибок **в пространстве параметрической матрицы** при $B\ne0$:

| Ограничение на $M$ | Оптимальная аппроксимация | $\min\|M-B\|_F^2/\|B\|_F^2$ |
|---|---|---|
| $M=M^\top$ | $B_T+B_S$ | $\delta_A$ |
| $\operatorname{tr}M=0$ | $B-B_T$ | $\delta_T$ |
| $\operatorname{rank}M\le r$ | Truncated SVD | $\sum_{k>r}\sigma_k(B)^2/\sum_k\sigma_k(B)^2$ |
| $M=cI$ | $B_T$ | $1-\delta_T$ |

Первые, вторые и четвёртые результаты следуют из ортогональной проекции. Для ранга используется Eckart–Young; при равных граничных сингулярных значениях минимизирующая матрица может быть неединственной, но значение ошибки определено.

## Почему это не та же численная ошибка в scores

В формулах минимизируется $\|M-B\|_F$, хотя текст называет её score-level residual. При $A=X+P$ фактическая score-ошибка равна $\|A(M-B)A^\top\|_F$. Для полного столбцового ранга:

$$
\sigma_{\min}(A)^2\|D\|_F
\le\|ADA^\top\|_F
\le\sigma_{\max}(A)^2\|D\|_F,
\quad D=M-B.
$$

Точное совпадение относительных норм обеспечивается, например, $A^\top A=c^2I$, но не произвольной геометрией входов. При плохой обусловленности параметрически крупная ошибка может быть слабо видна в scores. При неполном ранге $A$ часть ошибки вообще невидима, и запрет точной score-realisation уже нельзя выводить из отсутствия $B$ в классе матриц без дополнительной идентифицируемости. Это согласуется с [141](141-oriented-tasks-and-score-identifiability.md).

## Example 12.38 не соответствует напечатанным матрицам

[Исходный пример и таблица](../source/0446-0450-ch12-orientation-gaps-and-architecture-no-go.md#example-12-38) утверждают $\|B_T\|_F^2=0.20$, $\|B_S\|_F^2=0.50$, $\|B_A\|_F^2=0.30$ и rank $B=2$. Но в напечатанной $B_S$ восемь ненулевых элементов $\pm\sqrt{2.5}/4$, поэтому

$$
\|B_S\|_F^2=8\cdot\frac{2.5}{16}=1.25,
\qquad \|B\|_F^2=0.20+1.25+0.30=1.75.
$$

Прямой расчёт именно этих матриц даёт rank 4 и сингулярные значения приблизительно

$$
0.912570385,\ 0.912570385,\ 0.205463604,\ 0.205463604.
$$

| Класс | Значение в source table | Значение для напечатанной матрицы |
|---|---:|---:|
| Symmetric | 0.300 | $0.30/1.75\approx0.171429$ |
| Traceless | 0.200 | $0.20/1.75\approx0.114286$ |
| Rank ≤1 | 0.500 | $\approx0.524123$ |
| Rank ≤2 | 0.000 | $\approx0.048246$ |
| Scalar | 0.800 | $1-0.20/1.75\approx0.885714$ |

Это редакторская проверка обычной линейной алгебры, не новые экспериментальные данные. Нельзя заменить матрицу или её коэффициенты так, чтобы подогнать результат к авторской таблице: неизвестно, какую версию примера автор намеревался напечатать. Ошибка примера не опровергает четыре общие задачи аппроксимации, но лишает конкретный пример заявленной численной верификации.

## Как использовать результат в проекте

Если для малой задачи действительно задана целевая билинейная $B$, можно заранее вычислить недостижимую долю при ограничении архитектуры и сравнить её с фактическим score-остатком. Для обычной выходной задачи сначала нужно показать, что целевой score и его gauge определены, а ограничение на $M$ соответствует реализованной модели. Из Frobenius-остатка нельзя напрямую объявлять процент ошибки классификации или обязательное число примеров обучения.
