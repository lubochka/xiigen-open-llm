## §5. Гейт-дисциплина и закрытие флагов

### Единственный GO-гейт

Программа M5 объявляет РОВНО один гейт исполнения: `$PIN_FINAL_MAIN`. Декларативно (M5, строка 334): «**Единственный GO-гейт = «когда A+B финализированы».** Люба даёт GO на финализацию и НАЗЫВАЕТ вершину». Литерал `PIN_FINAL_MAIN` встречается в M5 19 раз (матрица §3: 0,0,9,10,19). Тезис неподвижности `main` до GO — «все три трека делят общую кодовую базу (финализированную main) ДО начала любого» (M5, строка 264). Никакого движения `main` без GO не декларируется.

### Три-трек блок (M5 §7) — только чтение

Три-трек проверка синхронности состоит из трёх видов операций, все — только чтение:

- `ls-remote` — **7 вхождений** в M5 (свежие вершины перед сверкой);
- `merge-base --is-ancestor` — **ровно 3** (по одной проверке предка на каждый из трёх треков синхронности; это утверждение-предикат, ничего не меняющее);
- хост-пины — фиксированные вершины `orchestrator-extensions` пяти хост-репозиториев (каждая стоит 2× в M5, см. §3).

Мутирующих глаголов в блоке НЕТ: `grep -cE "git (fetch|pull|merge|push|checkout|switch|reset|cherry-pick)"` по M5 = **0**. Дословный тезис: «все три трека делят общую кодовую базу (финализированную main) ДО начала любого» переноса — то есть синхронность проверяется чтением, а не изменением.
