- **Эталон** = записанный ответ **платной** модели (исполнитель кодекса). Это экзамен. Он уже существует как продукт её работы — его никто не извлекает руками.

- **Точность меряется по эталону автоматически** — сравнение ответа ученика с записанным ответом платной модели.
- **Порог назван тобой**: 95% и выше = приблизились достаточно.
