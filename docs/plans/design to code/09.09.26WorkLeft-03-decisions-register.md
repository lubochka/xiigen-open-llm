Exact match даёт reuse и 0 teacher calls. Любой mismatch, corrupt, v1 или partial даёт fail-closed, 0 teacher calls и запрет молчаливой перегенерации.

До обучения должен быть загружен latest compatible checkpoint с диска и создана incremental/resume session; fresh start запрещён при наличии compatible checkpoint. После успешного продолжения child checkpoint публикуется атомарно, его manifest несёт точную parent lineage: parent checkpoint manifest path, parent step, parent weights SHA-256 и byte length, плюс exact sealed DPO manifest/hash, а успех признаётся только после reopen/readback.

Артефакты вне канона не продолжаются и не пересоздаются: точные байты импортируются в канонические каталоги, проверяются hash/manifest, затем отдельно review, commit и push. Другая ветка, другой диск или side-cache остаются доказательством существования, но не каноном.

Уже существующие primitives `RepositoryOwnedTrainingArtifactLayout` — единственный владелец canonical DPO/model layout, включая `/checkpoints/<six-digit-step>/`; `RepositoryOwnedDpoDatasetResolver`; `RepositoryOwnedDpoDatasetRequestIdentity`; `RepositoryOwnedModelCheckpointLoader`; `RetainedCheckpointBackedIncrementalTrainingSessionFactory`; `RepositoryOwnedIncrementalTrainingCheckpointPublisher` являются зависимостями, а не задачей на повторное создание. Незакрытые code gaps: live DesignConversion transaction wiring before first teacher call и live training completion -> atomic child checkpoint publication. Честная граница решения: пока не было реального teacher call, production DPO, training run или новых weights; это правка программы и правила приёмки.
