## 5. Representation / kNN / projection interventions

1. **Domain mapping:** oracle-domain and predicted-domain arms with same solver/input; record confusion, abstention, mixed labels, wrong-domain harm and an independent ground-truth labeling policy. A Development intent classifier (CODE_Q/PLAN/etc.) alone is not the seven-domain mapper.
2. **Typed features and tokens:** raw input, canonical text, TeachingVector, BPE encoded sequence, typed ResultProjection and learned embeddings are separate contracts. Lock semantic-critical tokens/punctuation/ordering, lossless serialization, allowed Unicode/RTL and versioned source→vector→consumer mapping. A 60-dimensional local-vocabulary TeachingVector in R04 cannot be presumed comparable to a corpus-trained BPE/HNSW space.
3. **Exact neighbor baseline:** exact search is the retrieval oracle **only for its selected metric/corpus**, not an oracle of answer truth. Compare with ANN under same corpus/eligibility/metric and record returned sets and recall; HNSW efSearch is not k or semantic admissibility.
4. **k/radius policy:** pre-register k_domain = f(domain, eligible-neighbor density, distance distribution/margin, prediction uncertainty, admissibility and all-in cost). Determine whether f is fixed heuristic or actually learned, where update state resides and which result consumer aggregates/reranks multiple hits. Compare fixed/exact top-1, fixed-k, adaptive-k **same representation**, and learned rerank **same eligible pool**; add separate geometry/index changes, never vary everything at once. In current cited KnnLogicalUnit, first-hit TOutput means larger k might alter ANN retrieval or evidence but does not prove multiple-result output learning.
5. **LoRA→typed vector crosswalk:** parameter keys/digest and adapter loading → which layer/activation/log-prob or score changes → decoder/output features and domain invariants → typed target ResultProjection vector schema / version / ordinary consumer. Existing LoRA A/B adapter parameterization is **not** tokenizer, codebook or source→target projection. Proposed learned projector needs its own source space, target typed space, objective, update owner, decoder validity and cross-version/exact law assessment. LoRA gain in C# explanation does not imply improved DTC vectors or Graph links.

**Edge falsifiers:** negative/NULL lost in canonicalization; k>1 but downstream consumes only neighbor[0]; changed codebook paired with stale HNSW index; query-dependent nonmetric distance used with ANN pruning without recall check; Hebrew token normalization changes meaning; learned decoder changes only familiar-family prose style but not correctness; wrong projection maps multi-result IDs onto one hash.
