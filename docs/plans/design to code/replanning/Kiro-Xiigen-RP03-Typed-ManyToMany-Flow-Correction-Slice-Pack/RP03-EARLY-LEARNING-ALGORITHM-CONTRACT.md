## 3. Deterministic + learned algorithm, no hidden deterministic semantic authority
Step F0: enumerate a bounded set of possible transforms (identity, safe typed projection, null-preserving projection, fan-out, fan-in, bounded ReturnLoop or refusal) from actual graph edges and next-port requirements. Calculate legal mask from immutable domain law, typing/nullability, tenant, provenance, side-effect permission, cancellation, version, TTL, resource limit and final arbiter. If no legal transform exists, ABSTAIN; if one exists, use it with F0, do not manufacture a learning gain.
Step F1: **only among admissible choices** use proven existing L2 authority or a small versioned relation policy if a source/code investigation establishes a real training owner. Candidate implementation, not a mandatory new subsystem:
    s_d(x,t)=w_global·phi(x,t) + w_domain(d,law,port)·phi(x,t) - lambda_cost*budget_cost(t)
    t_star=argmax_{t in lawful(x)} s_d(x,t)
Features can include typed-port compatibility, RP02 embedding_space_id/domain tag, kNN relevance, correction trace and observed branch cost; never treat BPE IDs, LoRA weights, semantic vectors or TOutput objects as interchangeable token spaces. RP02 owns the domain-dependent k/encoder; RP03 consumes its versioned passport without overwriting it.
On independent, lawful actual downstream feedback of a better legal t+ over t- (not a guessed counterfactual), one candidate small pairwise ranker update is:
    delta_phi=phi(x,t+)-phi(x,t-)
    w_new=clip(w_old + eta*(1-sigmoid(w_old·delta_phi))*delta_phi)
Persist with unique feedback ID, bounded eta/gradient, rollback and one writer. If feedback is TIE/UNKNOWN, no valid second candidate exists, law changed, or final outcome is unobserved, do NOT update. This pairwise transform learner is not automatically Student text-generation DPO.
The targeted scientific comparison is F0 versus **F1 with a real changed Flow policy and frozen Unit**. A law guard fixing an illegal path is a correctness repair, not evidence of improved learned Flow. Do not claim F1 exists just because an edge was chosen or its ID changed.
