## GOOD / BAD / EDGE / восстановление

**GOOD:** найден W reader и семантический feature producer; trial runner вызывает общий scorer, live accepted tuple остаётся тем же. Нет writer — указан конкретный owner и минимальная вставка. Это даёт исполнимый patch, а не утверждает уже существующее обучение.

**BAD:** `IsLearned=true` назван W; law_version якобы взят из пустого Metadata; IDs использованы как one-hot признаки; новый Candidate опубликован под old live ID. Причина: ложный recipient, утечка identity или обход serving.

**EDGE:** feature version не совпадает, domain mixed/unknown, одна legal route, no accepted parent, no signal. Возврати конкретный FEATURE_GAP/NO_RECIPIENT/NO_SIGNAL. Строительство scorer не ждёт всех экзаменов; no-signal запрещает UPDATE, не source work.

**Recovery:** открой первый отсутствующий producer/writer/reader, найди его реального owner; если реализуемого shared reader нет, опиши один minimal adapter. Не отвечай «нужно всё перепроектировать». **Falsifier:** показанная цепочка не содержит фактического численного reader или feature source — recipient claim не подтверждён.
