1. С одинаковым corrected code приготовь isolated C0=W0 и T=Wtrial на одних inputs/candidate sets, одинаковых domain/law/phi/token/index/kNN/graph/Unit/arbiter/budget. Отсутствующий ordinary trust у W0 не исправлять флагом; сравнение допустимо в ОДИНАКОВОЙ разрешённой trial composition.
2. F0 проверяет type/schema/domain/tenant/rights/TTL/version/effect/cycle. F1 читает конкретный W snapshot и scores только lawful варианты. Опубликуй numeric score difference, `rank_changed` отдельно; прежний top1 не опровергает интеграцию reader.

4. Получи конечный output trial composition и передай независимому 03B examiner. Если отсутствует target invocation, верни L3_EXECUTED_TARGET_NOT_INVOKED и исправь только local adapter. Не называй изолированную композицию ordinary user path.

## ADOPT — отдельное разрешённое действие

5. 8. Для production C0/T использовать только действительно допустимые состояния. Если W0 никогда не был accepted, не выдавать trial C0 за ordinary baseline: paired science остаётся trial; ordinary T adoption измеряется отдельно в 03C.

## GOOD / BAD / EDGE / falsifier

**GOOD:** trial W меняет scores, реальный typed next Unit читает правильный source-associated payload; examiner получает actual output. После scoped acceptance обычный Host действительно читает этот accepted state. Даже если top1 не сменился, reader integration может быть доказана; quality gain оценивается отдельно.

**BAD:** требовать accepted registration до BUILD и тем самым замыкать exam→adopt→exam; OrderedTargets или TargetsExecuted=false назвать результатом пользователя; fake trusted W0; сравнить lab C0 latency с ordinary T. Почему: цикл зависимостей, фиктивный consumer или несопоставимые arms.

**EDGE:** ref истёк после ranking, mixed domain/version, foreign tenant, partial fan-in, cancellation, rejected new tuple. Recheck F0, no effect, safe parent/abstain. **Recovery:** first missing resolver/port/publisher owner; narrow adapter/rollback, не graph rewrite. **Falsifier:** hash W не совпал с actual reader; target не вызван; C0/T отличаются kNN; acceptance отсутствует при USER_ADOPTED=true.
