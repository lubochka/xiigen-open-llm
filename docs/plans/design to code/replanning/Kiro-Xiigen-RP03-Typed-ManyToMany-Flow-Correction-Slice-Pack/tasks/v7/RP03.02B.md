## Минимальная проверка и восстановление

Переиспользуй имеющийся finite/formula-sign, once-only и F0 denial proof **только для реально изменённых рисков**. Один численный контрпример выше достаточен для демонстрации отсутствия rank-flip gate, но не доказывает domain quality. Никаких новых stochastic-output unit-test матриц, fixed counts, coverage targets, blanket Windows runs.

При нулевом/неожиданном delta проверь g, eta/lambda, bounds и actual reader version; не повышай шаг ради отчёта. При несовместимом snapshot сохрани parent, исправь точный version producer. Falsifier: нет реального numeric reader, событие применилось повторно, phi содержит ответ, live state изменён без admission или заявленный update не совпадает с формулой.
