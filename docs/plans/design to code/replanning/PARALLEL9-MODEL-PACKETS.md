Не создавать новый продакшен-корпус. **Приёмка:** все baseline предметы имеют содержательную строку, extras не потеряны, each preference защищает meaningful expectation, нет утечки/forced correctness/sibling wait. **Будущий опыт:** law-sensitive semantic quality, mapping and downstream error attribution, source-family transfer, representation distortion, latency и full memory; thresholds до наблюдений. NOT_MEASURED пока runtime не выполнен.

**Декомпозиция:** A — passports/mapping; B — preference/representation/holdout. Child только один структурно отдельный предмет со своим source subset, common, passport output, good/bad/edge, acceptance и return-only. Не дробить механически на семь новых обязательных model calls.

## 7. Правила сравнения гибридных алгоритмов

Это design of future experiments, не утверждение результатов. Для конкретного механизма выбирать минимальный достаточный contrast; не требовать всю матрицу перед первым уроком. Там, где варианты реально исполнимы и сопоставимы: deterministic baseline; learned-only comparator; fixed hybrid; domain-adaptive hybrid. Нереализуемый baseline отметить и выбрать доступный контроль, а не строить четыре системы. No-update должен получать сопоставимую память/контекст, иначе retrieval gain смешается с parameter learning.

Dynamic kNN contract включает hard domain/law eligibility, meaning-preserving feature extraction, normalization, score/metric family, k/radius/stopping policy, neighbor use/aggregation, uncertainty/abstain и compatible index version. Query-dependent score не гарантирует свойства metric; exact reference для него может потребовать отдельной bounded оценки существующих candidates, не автоматического reuse cosine backend. Best path — лучшая **исследованная** lawful альтернатива при fixed budget, не доказанный глобальный optimum.

DPO examination должна сохранять same conditioning и различие chosen/rejected до objective. LoRA examination должна назвать adapted matrix/frozen base/parameter owner/consumer и отдельно semantic output representation. Ни API name, ни rank, ни положительное изменение weights сами по себе не доказывают полезность. Public methodological references: Rafailov et al., Direct Preference Optimization, https://arxiv.org/abs/2305.18290 ; Hu et al., LoRA, https://arxiv.org/abs/2106.09685 . Эти работы задают термины, но не доказывают conformance или PC-fit XIIGEN. Проектные one-pair/no-repeat/Chinese-authorship правила не заменяются общим учебником.

Пакет принят как инструкция лишь если model может начать без соседа, знает свой next action, не теряет область программы, имеет реальный источник/consumer и различающий способ оценки результата. Публикация этого документа не выполнение R01–R25 и не положительный learning experiment.
