2. **ILearningFlow** deterministic: typed Input/OutputRef port compatibility, version/lifetime, hard law. Trainable: correction/relationship weights. Proof: freeze Unit and solver, change only Flow, see better downstream input and user utility.
3. **ILearningOrchestrator** deterministic: rights, DAG dependencies, bounded deadlines/cancel/scheduling/resource accounting. Trainable: route preference/stopping.
