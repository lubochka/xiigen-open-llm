## 4. Concrete domain examples for model orientation (NOT real sealed case rows)
**C# source law**. GOOD: correctly distinguish nullable x?.ToString() from an additional ?? "n/a" fallback, preserve declared return type and project language version. BAD: say null-propagation by itself turns null into zero — false method semantics; why: similarity to another coalescing example is not type-law. EDGE: unknown nullable context / another project version / one matching neighbor only. Correct response: qualify, route by source/version, abstain when no lawful evidence. Required exam: unseen method families, exact domain/intent mapping and final method docs, not test-file count.

**English→Russian semantics**. GOOD: "Do not delete backups unless export succeeded" remains a negative prohibition with condition and explicit subject/action, accepting idiomatic Russian variants. BAD: reversal into an instruction TO delete backups, even if cosine is high; why: negation reverses operational meaning. EDGE: Cyrillic/Unicode, modal ambiguity, mixed language, numbers and negation scope. Correct response: keep raw Unicode and permissible variants; refuse false law-grounded neighbor, no regex removing all non-Latin tokens. Required exam: independent source families for polarity, condition, number and actionable intent.

**SQL query/documentation**. GOOD: distinguish right predicate in LEFT JOIN ... ON from same predicate in WHERE; unmatched left rows/NULL and 3-valued conditions, dialect version and duplicate/cardinality semantics. BAD: claim they are equivalent because the tokens and table names match. EDGE: IS NULL predicate, right duplicates, unknown dialect/DDL. Correct response: qualify actual schema or abstain. Required exam: new unseen schemas, lawful output and query path; SQL stages after first C# or translation effect, but MUST happen before multi-domain generality claims.

These are OPEN ILLUSTRATIONS, not suitable as future SEALED_CERT. Independently source and legally admit real families; freeze TRAIN/OP_DEV/SEALED_CERT by original project/source version rather than paraphrased row; no train/cert or author/evaluator leakage.
