```text
raw x + source permissions/tenant/schema/version

```

Let `E_d(q)` be **retrieval eligible** (source rights/tenant/domain/index schema/license/split), and `A_d(z)` be **action admissible** (hard law, typed semantics, preconditions, arbiter). A permitted rejected/negative example may be retrieved as a *warning* but must not be executed as a good output. A high cosine similarity or dynamic k cannot bypass the arbiter. Hypothetical formula, NOT implemented: `s_d(q,z)=sum_j w_j(d,q)*sim_j(phi_j(q),phi_j(z))-lambda_d(q)*lawRisk_d(q,z)`; `sum(w)=1`, explicit calibrated feature spaces. `k_d(q)=clip(g_d(ambiguity,density,margin,lawRisk,latencyBudget),1,min(Kmax,|E_d(q)|))`; if `|E_d|=0`, ABSTAIN. Approximate HNSW candidates and a nonmetric learned reranker are separate stages. A LoRA update `W+BA` changes named layers but does NOT itself emit semantic token IDs; any token transposition requires actual encoder/projection/codebook and recipient.
