## Real deterministic + learned algorithm chain
Input/context → multi-axis subject/intent/direction/dialect/version with UNKNOWN/MIXED → versioned typed φ_d of syntax/operator, POS, morphology, dependency/coreference, polarity and SQL NULL/join semantics → candidate pool restricted by tenant/rights/source/domain/schema → exact/ANN search → only *established* hard domain law/arbiter veto → calibrated learned ranker w_d and conditional k_d(context, risk, confidence, density, PC budget) → lawful typed user output → separately authorized feedback → once journal/checkpoint/restart → independent source-disjoint exam. Ambiguous grammar requires posterior alternatives, not an invented global gender prohibition. k=0/k=1/deterministic-only may be superior.

**Roles preserved:** ILearningUnit = typed domain+vector schema and many→many output (RP02 contracts only); ILearningFlow = separately learned unit correction (RP03); ILearningOrchestrator = budgeted async input/output (RP04); ILearningDynamicGraph = learned higher-order pattern relations (RP04). RP02 does not implement all four as preconditions.

**DPO distinction:** RP01 Student response-conditional reference-policy objective and genuine LoRA gradient with same prompt and approved Chinese Teacher authoring BOTH final chosen/rejected; independent exact-pair judge. RP02 lawful retrieval ranking preference (q,z+,z-) with learned w_d and pairwise ranking objective is NOT Student DPO; forbidden candidates remain runtime veto/warning, never a served positive. LoRA matrices are not automatically domain semantic tokens: a verified encoder/projector/codebook/cold reader is required.
