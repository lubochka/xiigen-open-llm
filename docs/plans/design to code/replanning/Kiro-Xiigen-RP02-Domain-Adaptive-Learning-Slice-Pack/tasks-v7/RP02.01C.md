BAD: flatten LoRA matrices into a vector and call each position a token; parameter space has no demonstrated linguistic coordinate mapping. EDGE: quantization/dequantization, unknown activation type, same-width reordered vocabulary, NaN/Inf, zero/no-information vector, old persisted index, projection fitted on hidden answers or absent adapter. Use the declared compatible transform, honest UNKNOWN, refusal or exact missing owner. Do not claim every generic caller is broken from one helper.
