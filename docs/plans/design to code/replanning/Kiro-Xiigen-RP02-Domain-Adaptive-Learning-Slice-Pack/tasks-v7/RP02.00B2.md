## Copy-ready prompt

Define meaning units to retain: polarity/negation scope, modal and temporal conditions, named entities/numbers/placeholders, dependency/POS role and agreement conditioned on the same referent. A grammatical gender label is not evidence of a person's gender or a global sentence-wide rule. For ambiguous context retain multiple legitimate referents/outputs and explicit UNKNOWN rather than force a label.

Create families for negative instructions, coreference/role continuation, multi-clause scope, quotations/register, Unicode/NFC/NFD/ё, mixed scripts and out-of-domain input. When source disambiguates a referent, specify the supported dependency; otherwise grade appropriate uncertainty. Predicted posterior probabilities are model outputs to calibrate, not human ground truth copied into the test answer.

Split TRAIN/OP_DEV/SEALED by original document/author/discourse provenance before any tokenization fitting, projection/calibration or teacher call. Near-duplicate translations/paraphrases stay in the same family. Public examples in this card are never SEALED. Give 01D the public feature/rule schema; give the independent curator restricted hidden material. Store only digest/authorized locator in planning.

Preregister per-family semantic correctness, critical polarity/condition errors, known-referent correctness, false hard veto, warranted abstention and answered coverage. BLEU or exact string match alone cannot decide meaning. Record examiner/rubric version and actual invocation when performed; curation does not claim Astra has already graded a model.

## GOOD / BAD / EDGE with why

GOOD: `Do not send until approved` → `Не отправляйте до одобрения`; both NOT and the approval condition survive. BAD: `Отправьте до одобрения`; fluent but reversed permission.

GOOD: `Книга лежала на столе; он был тяжёлым` allows `он` to refer to masculine `стол`. BAD: a feminine noun somewhere earlier makes every masculine pronoun impossible. The rule ignores referent identity.

EDGE: multiple possible antecedents, reported speech or changed speaker. Accept compatible alternatives/qualified uncertainty, not a false single reference. EDGE: aliases/reference IDs are renamed but relationships unchanged; labels should remain invariant. EDGE: failed tokenizer/Latin-only normalization in one caller must not be generalized to all RU pathways; bind the actual path and preserve unsupported status.
