## 3. Hybrid algorithm boundaries to implement and study
`x + (tenant, source rights, domain law version, intended output type)`
→ deterministic eligibility `E_d(q,z)` (source/license/tenant/role/version/scheme) and no-leak guard
→ domain mapper `M(x)=(subject,intent,language,stack/dialect,version,uncertainty)`, optionally learned
→ domain law-preserving semantic IR `phi_d(x)` and versioned codec/index, **not** arbitrary identical-width vectors
→ eligible positive/examples and separate hard-negative or warning roles
→ exact/ANN candidate search, with recall and ANN error distinguished from quality
→ typed legitimate multi-neighbour solver/fusion, **not** generic string concatenation or averaging arbitrary `TOutput`
→ optional fixed-k learned ranker; optional separately learned adaptive `k(q), radius(q), budget(q), abstain(q)`
→ hard-law arbiter `A_d` with veto authority, typed ordinary answer and provenance
→ consented novel pair/feedback, an authorized named trainable state update and checkpoint
→ sealed independent examination, cold reload, next bulk or rollback.

## 4. Independent domain-law examinations — illustrate then freeze lawful sources
**C# documentation / code:** project + C# language-version family, nullable context, method overload, output type, error/cancel handling. GOOD: `s?.Length` can be nullable while `s?.Length ?? 0` provides fallback zero; state actual input context. BAD: assert both are always zero on null because token strings look alike — critical semantics wrong. EDGE: overload nullable annotation mismatch, unknown compilation target ⇒ qualify/abstain. Train/dev/CERT split by **repository/method family**, not random paraphrases.

**EN→RU:** polarity/negation, modality, quantities, numbers, direction, person, preservation of names, Cyrillic forms and legitimate translations. GOOD: “Do not delete this file” → “Не удаляйте этот файл” (one acceptable context-dependent rendering). BAD: “Удалите этот файл” reverses hard prohibition, even with fluent style. EDGE: “may”, “must not”, double negation, negation scope, abbreviations, morphology and Unicode canonical equivalents; allow multiple lawful translations and human adjudication. Split by original source/text family.

**SQL third staged domain:** schema/dialect/NULL semantics, outer JOIN filter placement, aggregate/granularity, cardinality and access rights. GOOD: LEFT JOIN `a LEFT JOIN b ON a.id=b.a_id AND b.active=1` can retain unmatched `a` rows; BAD: replacing it blindly with `WHERE b.active=1` may discard unmatched rows. EDGE: predicate nullability, dialect differences, duplicates, group by, unsafe query changes ⇒ version and rubric or abstain. Source schema + query family split; stage *after* first 1–2-domain E2 signal, not a precondition for W1.

Every exam passport: `domain_id`, `law_id`, `source_sha`, `license/consent`, `family_id`, `stack/version`, `allowed_output_variants`, `critical_forbidden`, `abstain_expected`, `raw_examples` and `TRAIN/OP_DEV/SEALED_CERT` with unrelated families; CERT sealed before treatment. Proposed example ≠ observed data. Cross-domain compound/unknown cases belong to a future or separate staged diagnostic; do not quietly broaden W1.
