# RP02 · Functional examination and traceability · revision 7.3

**2026-10-15 · proposed protocol, not measured results.** Stable filename retained. The scientific question is whether the combined deterministic and learned mechanism solves unfamiliar domain tasks more accurately or at lower complete cost. Internal coverage does not answer that question. [Execution contract](RP02-V7.2-LEARN-FIRST-RUNBOOK.md) and [effective context](RP02-EFFECTIVE-CONTEXT.md) define rights, roles and minimal integrity checks.

## One independent experiment, with honest evidence levels

Before intervention, curator fixes the domain law, evaluation input distribution, unit of independence, TRAIN/OP_DEV versus SEALED families, ordinary endpoint, eligible corpus, candidate type, feature/index/tokenizer/decoder versions, control θ0, trial θ1, hardware, budget, stopping rule and acceptance policy. C0 and T share corrected code, data and inference configuration; only the declared trainable state differs. `T−C0` estimates this learning intervention. Optional historical P yields `C0−P` engineering change only when lawful and runnable. An unavailable P does not block C0/T.

Do not force an output flip to call the update real. Report separately update, state consumption, output/path change, quality, cost and promotion. Unchanged correct answers with measured lower resource use can support efficiency **only with a preregistered quality non-inferiority condition**. A nonsignificant quality difference is not proof of equivalence. One public demo is PILOT_ONLY; it cannot establish stable generalization. Tiny samples show raw counts and uncertainty, not invented confidence or universal N.

### Blinding and dataset access

Curator keeps a restricted `opaque_arm_id → P/C0/T + checkpoint` map. Judge receives opaque randomly assigned labels, randomized answer order, the frozen question/rubric and source-authorized evidence; it does not see arm names, optimizer status or the author's preferred result. Lock grades before unblinding. Record requested `astra 6 ultracode`, actual model ID, prompt/rubric digests, invocation ID and disagreements. Pair judge and final-output examiner are separate invocations. Rechecking a small role/order-swapped public control can detect judge instability; it does not replace domain oracles.

Public examples in tasks are never SEALED. Split by independent source/project/schema/discourse family, not strings or renamed variables. Fit vocabularies, normalizers, codebooks, calibration and learned hyperparameters on TRAIN/OP_DEV only. SEALED answers, embeddings, references and near-duplicate families must not enter training, retrieval or teacher context. During a legitimate retrieval evaluation, distinguish permitted question-provided evidence from hidden solution material. A heldout panel repeatedly used to choose checkpoints becomes OP_DEV; reserve fresh confirmatory families and preregister bounded looks. Do not keep modifying the grader until a candidate passes.

### Experimental factors: no hidden confounding

C01 changes mapper only. C02 changes representation plus its required index rebuild as one declared representation intervention; scorer features common to both must remain meaningful. C03 changes θ only. C04 changes search policy only, distinguishing retrieval effort from consumed k. C05 changes search backend only. C06 changes typed reducer only. C07 changes contextual next-step adapter only. Each may be engineering evidence without a learner update; do not relabel all A/B differences as learning.

C08 **learning interaction**: fixed retrieval architecture/eligible datastore and fixed compatible representation; cells use Student parent/updated adapter × ranker θ0/θ1. Compute `Y11−Y10−Y01+Y00` per domain with family-level uncertainty. Student OFF means parent adapter, **not no Student**. kNN learning OFF means θ0, **not removing access guards or the whole datastore**. Component-removal D-only/L-only/hybrid ablation is a separate experiment on the same lawful questions, not the same estimand. If LoRA changes the coordinate encoder, either use a fixed external representation for this experiment or declare representation/index a coupled intervention; never mix incompatible indexes to preserve a false four-cell claim. Missing real arms allow protocol preparation, not invented measurement.

## Metrics, sample size, stopping and bulk logic

Record eligible family/case denominators; law-correct, critical semantic errors, unsupported assertions, false hard veto, justified/unjustified abstention, domain-axis confusion, rank-preference accuracy and, when observable, AST/POS/referent accuracy. Report answered-case quality **and answer coverage** so abstaining on everything cannot win. Path regret is relative to the preregistered finite set of legal measured paths; if no oracle/alternative execution exists, mark PATH_REGRET_NOT_IDENTIFIED, not global best path.

Before confirmatory claims, fill practical gain δ, allowed non-inferiority margin ε, critical-error rule, max independent families/looks, seed/repetition policy and resource ceiling. Pilot defaults are exploratory: use the available independent families, show counts and mark PILOT_ONLY; no fake significance. Choose confirmatory sample size from domain variability and the desired precision/power before seeing treatment results. Use paired family-level estimates; repeated cases/paraphrases are nested observations, not new families. Freeze multiple-comparison/stopping decisions before C01–C08 selection. Wide intervals → INCONCLUSIVE.

For B1 compare parent and challenger on the **same new-family** panel plus retained old-domain panel. B2 uses new authorized lessons, not replay of B1 under a renamed ID. Longitudinal B0/B1/B2 curves alone confound curriculum changes; keep paired control comparisons per bulk. Promotion uses the preregistered operational decision; final generalization claims use fresh confirmatory families. Retention and domain-specific critical regressions are visible even when the aggregate improves.

Whole-PC cost includes end-to-end wall and CPU, measured total peak RAM/VRAM, base/reference model, tokenizer/parser/feature extraction, probe/recall/rerank/arbiter/decoder, optimizer and activations, index build/rebuild/load, trial+parent checkpoints, journal/cache/disk, failed calls and external Chinese/CODEX tokens/time/cost. Report local inference/training feasibility separately from external author/judge dependency. Do not sum nonconcurrent component peaks as measured total peak. Separate cold/warm and one-time/amortized costs; tiny-N p95 is descriptive and unstable. Accuracy/time-per-bulk improvement is not proven by a small adapter file.
