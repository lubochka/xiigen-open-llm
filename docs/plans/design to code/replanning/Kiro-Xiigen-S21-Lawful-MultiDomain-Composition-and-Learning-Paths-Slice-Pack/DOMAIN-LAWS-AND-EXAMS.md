# S21 real-law domain exam, examples and immutable splits

## At least one genuine multi-domain request
Primary composed family: C# .NET DTO/API + named SQL dialect/schema → Russian or English user documentation. Additional independent family: Angular client + C# API contract → SQL persistence or EN↔RU localized error messages. Scope source/target as separate subjects; no C# paraphrases masquerading as domain breadth.

| Scenario | Law (source must be frozen) | GOOD final path | BAD plausible alternative | EDGE / abstain |
|---|---|---|---|---|
| C# DTO → SQL Server → RU | C# nullability, actual SQL Server dialect and API contract, translation negation | Nullable DTO remains nullable SQL and RU "необязательное поле" | SQL field silently NOT NULL then RU reports required | Dialect/version/schema missing |
| C# → PostgreSQL query → API | Declared PostgreSQL edition, parameters, DTO types | LIMIT and lawfully parameterized query | SQL Server TOP or string interpolation injection | Mixed dialect artifacts |
| Angular form → C# API | Versioned Angular and C# API schema, frontend validation not proof of backend authority | Consistent optional form and API nullability | Frontend coerces null to required field | Contract mismatch and two valid UX options |
| EN→RU after code change | Original named law wording, placeholders and negation | Preserve "must not cache" and {field} tokens | Fluent "следует кэшировать" changes obligation | Ambiguous source sentence |
| Figma → HTML/CSS → localized UI (future) | Rights to design, responsive/source target, visual difference protocol | Typed layout token and corresponding locale are lawful | Model imagines screenshot measurement or loses spacing semantics | Source image inaccessible or rights absent |

## Three different evidence lanes
TRAIN: source-family identifiers selected before rephrasing, law licenses verified, approved one-pair recipients only. OP_DEV: iterative route/parameter/algorithm choice; never reuse as untouched confirmation. CERT: independent untouched scenario families sealed before outcome observation, with blind judge and predeclared utility rubric. Law editions/dialects/tenant IDs and project state version travel with all three.

## Functional grading, not simple coverage
At every stage grade law+version fit, typed port, referenced origin, dependencies and legal action; at final result grade whether *all* constraints hold (joint success, not averaged fluent prose). Report per-domain, per-stage, worst-domain, multi-hop cross-stage contradiction, refusal calibration, corrected no-update vs isolated learned treatment, and all-resource cost. Good deterministic solution counts as success; learned but unlawful solution fails. Proposed mini panels only screen candidate mechanisms and cannot prove a 95% population claim. N, source provenance, confidence interval, judge identity and untouched-family evidence required for any generalization.

## Negative memory is not illegal execution
retrieval_eligible depends on source rights, split, representation, version and conditioning; action_admissible depends on law/type/permission. An authorized negative warning may be consulted to avoid a bad path; executing its wrong action as positive is forbidden. Mixed source-tenant or law mismatches are explicit blocks, not low scores.
