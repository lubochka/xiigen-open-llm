2. **Проверить информативность и законность.** Два same-x FULL_CLEAN_OBSERVED typed outcomes, genuine independently justified preference. UNOBSERVED/CANCELLED/DENIED, TIE, both-bad, неизвестный attribution либо нулевой feature difference не превращать в обучающий negative. Плохой с точки зрения hard law маршрут не исполнять ради пары. 3. **Зафиксировать причинный контекст.** Одинаковые graph topology/legal pool, law/schema/representation versions; RP02 tokenizer/vector/kNN/LoRA projection, RP03 Unit/Flow, E3 и Student frozen. 4. **Определить контекстное предпочтение.** Учитывать задачу x совместно с ordered motif, а не только global frequency motif. Для linear score простая concatenation `[c(x),a(motif)]` сокращает c(x) в same-x pairwise margin. ## 4. GOOD / BAD / EDGE с причинами

**GOOD numerical receipt:** для illustrative joint `psi+=(1,0), psi-=(0,1), theta=(0,0), eta=.1` без regularization один step даёт `(0.05,-0.05)`. Это только пример знака, не реальные измерения или заданные hyperparameters. В execution экспортировать собственные values, data-gradient и actual owner.

**GOOD structural:** два законных typed ordered motifs решают одну задачу; различается качество/полная цена по заранее заданной rubric; U меняет preference, cold selected target реально возвращает lawful typed result. **BAD:** добавить edges, отсортировать refs, переключить flags либо поменять NOT_ACTIVATED на OK. Почему: отсутствует требуемый learned ordered state/reader.

**GOOD contextual:** одни и те же два allowed motifs уместнее в разных входных контекстах; joint features допускают такой разворот. **BAD:** разные choices достигнуты только запретом одного motif law mask. Это guard correctness, не learned contextual preference. Если оба motifs равноценны, TIE; никакого произвольного chosen/rejected.

**GOOD domain law:** non-null-required operation защищена precondition; nullable SQL parameter preparation не считается автоматически нарушением. EN→RU coreference связывает согласование с референтом, не ближайшим словом. Source/version обязателен.

**EDGE:** один lawful motif → NO_VALID_PAIR; stale graph coordinate/law → compatibility decision; nonfinite gradient → no mutation; interrupted checkpoint → quarantine U/restore coherent parent; повтор signal → reconcile original journal. Неизвестный reader → STATE_CHANGED_NOT_USED; E3 не блокируется. Отмена wrapper не разрешает повтор optimizer/effect. No retuning sealed T и no retry-until-green.
