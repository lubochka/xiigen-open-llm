## 6. Minimum checks versus actual scientific study
Engineering checks: correct typed associations, no permission bypass, deterministic DAG/cancel/timeouts, no hidden side effects, snapshot checksum/cold reload/rollback, branch budget accounting and invalid pair rejection.
