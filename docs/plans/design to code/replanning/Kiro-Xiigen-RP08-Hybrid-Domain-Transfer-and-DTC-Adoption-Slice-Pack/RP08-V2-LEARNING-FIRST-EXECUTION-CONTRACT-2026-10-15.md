## Four irreducible learning roles
ILearningUnit: domain+vector+requested typed many→many results preserving input/output source identity. Deterministic typed and law admission; learning through existing ILearningMachine, never a fictional Unit.Train().
ILearningFlow: identity-preserving correction/conditional relationships between Units. Static typed checking is not a learned Flow correction; freeze Unit when measuring Flow state.
ILearningOrchestrator: bounded lawful async candidates, dependencies, cancellation, branch cost and D-15 admission. Learned route policy must choose among structurally distinct permitted paths, not just flag configurations.
ILearningDynamicGraph: higher-order directed 2/3 relations and versioned motif preference. A graph schema or motif count is not a learned state; transfer must work on unseen structural family.
Domain IR/token/vector coordinate schema must remain distinct from Student BPE IDs/masks and actual LoRA parameter groups; positive retrieval memory and negative/warning memory have different effects. Rights/split/version eligibility is before retrieval; hard law/type/authority eligibility is before effects, not converted to a weak cosine penalty.
