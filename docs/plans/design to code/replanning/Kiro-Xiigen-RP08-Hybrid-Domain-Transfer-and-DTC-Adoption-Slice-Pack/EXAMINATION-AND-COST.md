# RP08 examination plan — scientific ability, not green Windows tests

## Causal contract
For each named domain family, freeze before learning: source rights/version, domain law rubric, domain+intent mapping authority, legal candidate universe, budget, baseline exact-state, allowed outputs, independent evaluator calibration, TRAIN/OP_DEV/sealed CERT *grouped by source family*, hardware/process-tree identity and measured starting cost. Sealed CERT never enters teacher prompt, retrieval, DPO memory, feature selection or threshold tuning. Disagreeing judges report uncertainty. Pre-register minimum useful improvement, critical-violation upper bound, acceptable retention delta and cost envelope; do not invent N/threshold here.

**O** historic algorithm (optional); **N** current **corrected identical pipeline without learnable update**; **U** identical corrected pipeline with **one** versioned authorised changed learner state. Compare `U−N` for learning and separately `N−O` for deterministic repair; P/parent and C0/no-update mean the same freeze concept in upstream slice nomenclature, but keep exact IDs. No Student accepted parent? use a lawful pinned cold-start if already authorised, else `NOT_READY` for Student contrast; domain/source-only lanes continue.

| Card | Single changed factor; everything else frozen | Falsifier |
|---|---|---|
| H00 | ordinary old vs corrected N (not a learning claim) | no observed consumer delta or new unintended failure |

| H08 (optional) | legal hybrid N vs one combined accepted state, **after** isolated H01–H07 evidence | claimed synergy disappears in cross-domain holdout or PC cost dominates |

**Outcome columns**: `domain/subject/intent/version_accuracy`, calibrated UNKNOWN/MIXED, hard-law-violation rate, source-grounded task correctness, typed many-to-many association, chosen lawful path vs *best of enumerated permitted under same resources* regret, helpful abstentions, multi-viewport DTC semantic+visual result with independent judge, p50/p95 elapsed, user-visible task completion, retention after next bulk and absolute worst domain. Exact query/vector quality or internal DPO reward alone are not end-task accuracy.

**Total cost**: time from user request/lesson search/teacher/judge/training and evaluation to first useful accepted ordinary output; CPU peak, process-tree RAM/VRAM, persistent parent+trial+reference+optimizer+index+cache, disk peak/snapshot/restore, all parallel/cancelled/failed branches, reindex/ANN rebuild, network/external provider cost, pending/unknown charges. Record MEASURED/ESTIMATED/UNKNOWN per field, do not count one worker's memory as whole PC. Same quality but materially higher full resource burden can be a scientific failure.

**Bulk-to-bulk**: each B1, B2 … contains *new* unique authorised lessons; one pair ID one admitted application, no hidden replay after rollback. Keep frozen old-domain anchor and new families across A0→A1→A2, compare retained ability, learning/teaching wall time and cost per accepted improvement. Negative/ambiguous results are valid, no post-hoc retuning of CERT. 95% owner aspiration is not a default empirical threshold or "run until PASS" instruction.

**Verdicts** separately `NOT_MEASURED|INVALID_EVIDENCE|INCONCLUSIVE|REGRESS|IMPROVE`; mechanism `SOURCE_ONLY|IMPLEMENTED_NOT_USED|USED`; selected consumer `NOT_OBSERVED|COLD_USED|ADOPTED`; review `NOT_PERFORMED|NEEDS_FIX|PASS`. Only actual logs/data can populate measured numbers; document plans never set these to IMPROVE.
