## Полный prompt для executor (CODEX)
Ты чинящий только доказанный deterministic training seam исследователь. Сначала из кода зафиксируй exact target mask: только response tokens (shift by one), `chosen != rejected`, no prompt reward, branch gradients opposite signs, reference not changing. Проведи одну дешёвую finite difference/directional derivative consistency check на tiny synthetic logits/LoRA, сравни с analytic dL/dθ, допуск float32 объяви до результата, проверяй zero/NaN. На 8–32 разных коротких admitted TRAIN-парах, при необходимости собственных `ASTRA_SYNTHETIC_DEV` с фактическим actor receipt, создай pinned read-only policy/ref baseline from permitted checkpoint и tiny experiment new unique run ID. Freeze `TRAIN`, `heldout families`, same prompt/decoding config, 1–3 short update checkpoints (actual updates, not pair count). Выполни несколько коротких обновлений **без trainer rewrite** и сохрани `stepVectorTiming`, AdamW settings, tensors unchanged/changed, gradient signs/norms, train pair log-odds, masked chosen logP, finite-difference difference, top-k/top1 gap on SAME prompt, greedy vs sampled output, fresh full reload. Ищи tiny overfit на TRAIN как diagnostic, а затем отдельный heldout; quality на TRAIN не равна generalization.

GOOD example: C# `int y=x++; Write(y)` chosen `writes old value` versus rejected `writes incremented value`; actual numeric contrast and chosen probability observed. BAD example: negative answer содержит `WRONG` и модель учит служебный токен вместо закона; BAD: changed adapters alone = pass. EDGE: chosen and rejected tokenize to identical IDs, mask zero length, response truncated at context; require reject/RECORD not silent commit. EDGE: LoRA B=0 initially: check A gradient initial zeros could be expected, B nonzero, later A update; don't misclassify without source-based math. EDGE: unstable loss/nonfinite -> safe rollback and record issued/completed, stop not infinite retries. EDGE: new dataset cannot be admitted by pinned existing CLI -> one smallest authorized adapter/fixture through current owner, no bypass of permission/custody.
