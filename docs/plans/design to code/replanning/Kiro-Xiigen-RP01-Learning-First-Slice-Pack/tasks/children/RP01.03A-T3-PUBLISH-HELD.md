## GOOD / BAD / EDGE

GOOD: published weights SHA равен held Trial; optimizer entry count не увеличился; следующий owner cold verifier. Почему: публикация не создаёт нового смешанного опыта.

BAD: после positive verdict запустить train-and-hold ещё раз. Почему: новый эффект и другие веса уже не оценены. Remedy: publish-held над original bundle.

BAD: заполнить scientific-verdict из code fixture или изменить gain threshold. Почему: hashes не дают научного результата. Remedy: настоящий независимый T2, без bypass.

EDGE: parent изменился другим owner→не продвигать stale Trial; raw answer отсутствует/preview-only→KEEP_HELD; publication call оборвался→прочитать actual canonical manifest/journal через owner, не повторять optimizer; состояние already published→проверить exact identity, не выдумывать second successful publication. Refusal code `CODE_DOCUMENTATION_SCIENTIFIC_POLICY_OR_VERDICT_INVALID` требует найти конкретный binding/authority gap, не заменить expected hash observed значением автоматически.
