## GOOD / BAD / EDGE

GOOD: existing parent/descriptor согласованы; scorer unchanged; новый intent отсутствует. T0 завершён без model allocation/generation. WHY: входы проверены без повторного обучения.

GOOD: прежние frozen inputs сохранены, неполный C0 до canonical attempt допустим; T0 выдаёт только недостающую revalidation и передаёт T1 recovery. WHY: не теряется baseline и не создаётся новый опыт.

BAD: seeded модель объявлена загруженным parent или A/B slots удалены ради base-only reader. WHY: подмена persisted state. Remedy: actual descriptor/codec/import owner.

BAD: held уже есть, новая версия плана требует второй T1. WHY: duplicate optimizer. Remedy: held → T2; source compatibility отдельно.

BAD: command resume запущен «для read-only проверки». WHY: возможен первый optimizer. Remedy: status/metadata reads в 00B/T0, effect только у T1.

EDGE: rank/targets/topology mismatch → typed refusal; denied private metadata → BLOCKED_EXACT; kNN/decoder semantic drift → confounded evidence, не DPO gain; caller cancellation/partial write → existing owner; невидимое состояние PC → UNKNOWN, не READY по README.
