### 1. Смысловой vector/token — до настройки количества соседей

Сопоставить actual tokens/features/distances/выбранное решение для `a-b`/`b-a`, `x<y`/`x<=y`, null/empty, отрицания и перестановки actor/recipient. Не утверждать коллизию, пока не получены actual vectors. Count/hash representation, теряющая порядок/роль, не исправляется одним k>1. Указать state/schema owner и один versioned feature change при подтверждённом дефекте.

Предлагаемые содержательные координаты — **не готовый runtime API**: domain/intent/version, ordered spans, AST/POS role, entity/referent/dependency links, type/nullability/scope, negation/modality, context constraints и provenance. Неуверенная POS/coreference остаётся soft evidence. Смена semantic schema требует совместимого encoder/index/cache, а не просто равной dimension. Стоимость reindex входит в сравнение.

### 2. Законы домена и положительные/отрицательные соседи

C#: синтаксическая допустимость продолжения, scope/type/nullability/control flow. Неполный prefix не равен ошибочной завершённой программе. При задаче **объяснить ошибочный код** его ошибочность не причина отбросить input: правильный ответ должен объяснять ошибку.

ENRU: согласование именно связанных слов/объекта, negation, dependency, смысловые роли. «Книга…стол…он» не запрещает masculine; «Анна…Мария…она» требует обработки неоднозначности. SQL: NULL/UNKNOWN; ON против WHERE при LEFT JOIN; dialect/version. Это разные законы, не один cosine threshold.

Сначала domain/version/role-appropriate pool. Positive neighbour может поддерживать решение; negative/warning сохраняет полезную информацию о неудаче, но не возвращается как правильный ответ. Применимый hard law/право нельзя компенсировать высоким similarity. Final arbiter authority сохраняется. При пустом/недостаточном pool — честное abstain/fallback, не unconditional hits[0].

Learned metric/reranker использует semantic/structural/evidence/risk features; dynamic k/radius/skip учитывает ambiguity, sufficiency и budget. Назвать реально изменяемые параметры и TRAIN/DEV signal; произвольная формула без обученного состояния — fixed baseline. Threshold0.50 из старого опыта не универсальный optimum. «Оптимальный k» означает лучший наблюдённый в конкретном domain/task/budget, а не доказанный глобальный максимум.

### 3. Минимальный причинный и экономический опыт

Простой диагностический дизайн: две уже сохранённые Student версии B0/C500 × две frozen политики fixed/adaptive. A=(B0,fixed), B=(C500,fixed), C=(B0,adaptive), D=(C500,adaptive). **Четыре inference arms, не четыре обучения.** Для сравнения policy зафиксировать domain mapper, semantic representation, candidate universe, code/decoder, budget и applicable laws. Если один из этих факторов меняется, это отдельный contrast с указанным confound, не прежний policy-only вывод. Записать, на каких TRAIN/DEV данных обучалась adaptive policy; sealed не выбирает k.

На одной шкале считать Student effect B−A, policy effect C−A, interaction D−B−C+A и реальные ошибки/затраты. Эти contrasts описывают данный опыт, не обещают synergy. Smaller matched contrast допустим, если входов для полного2×2 нет; отсутствующий effect NOT_MEASURED. Не заводить новую обязательную матрицу всех комбинаций всех доменов.

Метрики по вопросу: mapping confusion и mixed/OOD handling; lawful candidate recall; ошибочно принятые outputs; k distribution/abstention; quality/time; path success/cost. При retrieval miss сопоставить exact и ANN на том же pool, чтобы не приписать индексную ошибку learner. «Лучший путь» сравнивать среди реально перечисленных допустимых путей с общей ценой/качеством; report limited regret, не global optimum. Если fixed deterministic путь лучше по полезности/стоимости — оставить его, не объявлять rejected только по происхождению.

### 5. LoRA, projection и PC-компактность

Tokenizer формирует последовательность; semantic projection — договор отображения typed features/result в нужное vector space; LoRA меняет конкретные model matrices. Для каждого отдельно input/output meaning, dimension/version, learned state и consumer. Совпавшая dimension не доказывает смысловую совместимость; не требовать exact обратимость lossy projection, если codec этого не обещает. Исследовать сохранение роли/порядка/negation и качество реального downstream выбора.

PC footprint: base/runtime, encoders, optimizer, adapters, index/graph, caches, checkpoints и одновременные processes. Маленькая LoRA не означает маленькую систему. Отдельно расходы S/A/J/E и Chinese model при её будущем включении; current inner loop безQwen не делает весь development полностью offline. Нулевой gain → cost-per-gain UNDEFINED. Faster inferior path не называется успехом без указанного quality tradeoff.
