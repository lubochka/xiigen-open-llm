## Два разных результата, не один общий манифест

**A. Доступ только по роли. Не передавать этот packet S/A/J, Teacher или training RAG; публично только разрешённые hashes/метаданные.

Без SEALED inputs, answers, rubric, private paths или полного exam manifest. Selector выбирает урок, не экзамен.

## Последовательность без невозможного условия

1. До воздействия на Student определить independent families, научный вопрос, rubric, критические нарушения и правило агрегации пяти повторов. По возможности заморозить design до authoring; Teacher/selector не получают закрытого содержания ни при каком порядке.
2. Не требовать окончательный PairId/parent SHA **до существования пары и B0**. Early design/scorer commitment и final run binding — разные операции. После S/A/J и при необходимости B0, T0 связывает уже замороженные criteria с настоящими run/parent/dataset/PairId. Содержание экзамена от этого не меняется.
3. Для текущего first-root route соблюдать реализованные familyCount=12, repeatCount=5, minimumCorrectFamilyGain=2, maximumTrialCritical=0, maximumNewCritical=0. Источник значений — actual policy, не новый порог автора плана. Scorer aggregation взять из закреплённого protocol/scorer; не выдумывать после ответов правило 3/5 или «лучший из пяти».
4. Source-family split делается по исходному проекту/структуре/происхождению, не только по text hash. Перефразировки/переименования одного AST или перевод того же задания остаются одной семьёй. Проверить train/holdout contamination у уполномоченного exam owner; передать наружу только допустимый результат проверки.
5. Основное сравнение C0 vs Trial: один corrected code/runtime, parent vs разрешённый Student update, fixed reference/tokenizer/domain vectors/kNN/arbiter/decoder/compute. P старой реализации — только дополнительный реально существующий diagnostic arm, не обязательная третья генерация. T0 не генерирует C0: текущий train-and-hold уже делает required capture.
6. Заморозить научные показатели: correctness по законам/полноте, critical errors, lawful abstention и фактический solution-path выбор, parent/trial latency N/p50/p95, ресурсы машины и all-stage costs. Отделить fixed first-policy acceptance от broader evidence of generalization. Небольшой N не даёт автоматической statistical significance.
7. SQL и EN→RU независимые exams отправить соответствующим RP02 владельцам **параллельно**; их подготовка не условие первого C# T1. Отсутствующий consumer=NOT_RUNNABLE, не прохождение toy score.

## Конкретные публичные иллюстрации — НЕ SEALED cases

C# задача: объяснить `static int Count(string? s) => s?.Length ?? 7;` при s=null. GOOD: 7, потому что ?. даёт nullable result, ?? выбирает fallback. BAD: 0 или обязательный NullReferenceException; это разные семантические ошибки. В настоящем holdout нужны другие независимые источники, не переименование Count.

SQL: требуется сохранить всех клиентов и присоединить только оплаченные заказы. GOOD: predicate по заказу в LEFT JOIN ON сохраняет unmatched clients. BAD: такой же predicate в WHERE незаметно убирает unmatched rows. Зафиксировать SQL dialect/NULL semantics и допустимые альтернативные решения; сравнить реальный результат на независимых данных, не текст query.

RU: «Книга лежала на столе. Он был деревянным». GOOD: masculine согласование относится к столу. BAD: запретить «он» из-за ранее упомянутой книги. EDGE: «Анна подошла к Марии. Она улыбнулась» без контекста неоднозначно — не принуждать одно gold-coreference решение.

## Ошибки и восстановление

- Уже готовая Chinese pair до final policy: не уничтожать её только ради порядка документов; доказать независимость exam и ранний неизменный scorer, затем final binding до C0/optimizer. Если независимость не доказана, конкретный scientific blocker.
- Trial уже виден scorer-автору: не оформлять новый protocol как preexisting; закрытый compromised exam не доказывает heldout gain.
- Family hashes различны, но один origin: объединить до freeze; после эффекта INVALID_EVIDENCE/ограниченный claim, не перестройка denominator.
- Code/dialect/representation drift: новая явно versioned experiment branch, не смешение внутри C0→Trial.
- Нет actual examiner/model grant: protocol может быть описан, но exam NOT_PERFORMED; не выдумывать Astra verdict.

## Выход и проверка

Два раздельных handoff с audience, content class, allowed paths, hashes, actual source spans и receipt owner. Private packet содержит frozen family/rubric/aggregation/criteria/arms/budget; TRAIN packet не содержит private inputs/gold/rubric. Отдельно `design_frozen`, `final_run_binding_complete`, `effect_already_present`, `contamination_verdict`, `domains_ready_or_NOT_RUNNABLE`, `new_product_tests=0`, `model_calls=NONE`.

Проверка карточки: T0 может собрать policy без круговой зависимости PairId; S/A/J не видят экзамен; T2 применяет правило, существовавшее до эффекта. STOP после своего precommit/reuse handoff, не генерировать ответы Student.
