## Как проверять функциональность, не coverage

Domain confusion/macro per-domain accuracy и unknown/abstention отдельно от downstream task success. Measure как ошибка domain влияет на выбранный путь и законы; representation — law-distinguishing collisions, typed decode/association validity, downstream retrieval/ranking/task accuracy; learned projection — правильность **семантически декодированного/потреблённого** результата, не только cosine. Снять latency и resident state/reindex footprint. Ни high routing confidence, ни same-shape tensors не доказывают соответствие домену.
