task_id, task_status, current_unquoted_user_intent, current_task, not_the_task, claimed_scope, evidence_scope, P_head, K_head, changed_files_and_sha_or_NONE, source_read_depth_by_file, visited_WorkLeft_RAG_MDs_NDJSON_and_primary, unread_paths_and_owner, skill_file_read_receipts, domain_subject_law_edition_rights, taskIntent, deterministic_hard_laws, learned_owner_and_mutable_state_ids, input_output_many_to_many, feedback_actor_and_consent, CODEX_selector_receipt_or_NOT_RUN, Chinese_both_sides_receipt_or_NOT_RUN, separate_exact_pair_judgment_or_NOT_RUN, parent_pair_trial_reference_and_optimizer_RNG_journal, true_step_count_or_NOT_MEASURED, no_repeat_status, ordinary_caller_consumed_state, P_C0_T1_T2_arms_actually_run, frozen_family_panel_identity, quality_law_utility_retention_ci_and_falsifier, kNN_used_neighbor_vs_retrieved_list, full_PC_stage_and_peak_resource_cost_or_NOT_MEASURED, crash_recovery_or_NOT_RUN, cold_readback_or_NOT_RUN, native_boundary_check_if_affected, independent_Astra_candidate_review_or_NOT_PERFORMED, one_minimal_next_action_and_owner.

Separate documentary acceptance from code behavior and measured learning:
- DOC_VALID = task file + evidence route + GOOD/BAD/EDGE + falsifier coherent.
- MECHANISM_USED = current real caller did use the behavior, not only method existence.
- RECOVERY_OBSERVED = isolated interrupted path really recovered correct accepted state.
- STATE_CHANGED = exact intended trainable recipient and at-most-one Step with full proof.
- SCIENCE_EXAMINED = independent frozen panel + uncertainty + all PC costs.
- COLD_ORDINARY_ADOPTED = new process host consumed accepted checkpoint.
- INDEPENDENT_REVIEWED = different actual reviewer with exact candidate SHA; author review is SELF_CHECK.

Never derive the latter six from DOC_VALID. If evidence is absent write NOT_MEASURED/NOT_RUN/INTEGRATION_OPEN. A reviewer must compare received values with exact GitHub paths/candidate SHA; if candidate changed, request new review.
