## 2. Четыре роли и DPO role boundary

Unit: domain/input-vector/output contract и typed many→many associations. Flow: отношения/коррекция между Unit. Orchestrator: допустимое асинхронное сочетание/порядок/бюджет. DynamicGraph: отношения паттернов высших порядков и перенос. Train остаётся у actual ILearningMachine; не четыре новых trainer. Имя interface, IsLearned и checkpoint filename сами не доказывают mutable recipient или ordinary consumer.

CODEX с запрошенной Astra-конфигурацией выбирает разрешённый lesson и отдельно оценивает exact pair/context. Разрешённая внешняя открытая китайская модель авторствует обе final sides; слабый Student output — возможный context, не обязательный rejected. Reference policy, pair judge, runtime arbiter и post-update evaluator различаются. TIE/BOTH_BAD/UNJUDGEABLE не forced preference. Никакие такие model calls первоначальным R07 или RCOR не выполнялись.

## 5. Four-role causal chain — исправленный порядок

Request → domain/intent/representation → lawful candidate pool → конкретная learned selection/correction → сохранённые typed input/output/target associations → actual selected Flow/solver execution → observation/weakness → CODEX selects permitted lesson → Chinese author обеих exact sides → separate CODEX pair judgment → admitted update **того же semantic recipient** → isolated candidate utility/retention/cost examination → authorized accept/retain/recover → selected-state publication/registration → next ordinary request → сопоставимое bulk observation.

Для document-model E1 L2/L3 Graph не обязателен; для route/graph preference objective/state принадлежат selector/relation, не несвязанному generation model. Candidate selection, payload association, state load, update and independent quality each have distinct proof.

## 6. Credit assignment и измерение

Будущие различающие вмешательства: frozen Units/changed Flow (и обратный диагностический контроль); frozen Flow/changed selector; fixed candidate pool/changed learned authority; fixed selector/changed domain eligibility; fixed primitives/changed higher-order relations; parent no-update/candidate при comparable memory/context/compute; same selected state через isolated evaluator и ordinary caller.

Не менять одновременно tokenizer/pool/k/selector/objective/Flow и приписывать reward одному. Для kNN отдельно ranking, k/radius и actual neighbor composition; first-hit Output при большем k не fusion. Для LoRA отдельно actual allowed keys/freeze и source→target semantic projection. Для комбинации deterministic+learning использовать сопоставимые arms с одним обязательным law/security envelope; runtime effects и стоимость всех branches не скрывать.

Bulk — новые allowed lessons, stable anchor и independent source families, а не replay и не сравнение средних разных сложностей. Effect/retention/uncertainty/sample/budget заранее. Отрицательный/неопределённый результат не насильно превращать в improvement; actual PC fit NOT_MEASURED.

## 7. Two-combination walkthrough

A: Unit U1→U2 → Flow F-A → authority A → L3 X. B: U1→U3 → F-B → authority B → L3 Y. Unit предлагает typed alternatives; Flow исправляет отношения; Orchestrator планирует async dependencies/budget/cancellation; Graph связывает паттерны высшего порядка. Lawful authority не может выбрать запрещённый кандидат.

При reorder результатов `verify(B)` не разрешает `send(A)`; fan-in сохраняет реальные input associations, не позиции завершения. Две равнохорошие комбинации допускают TIE; происхождение deterministic не причина rejected. Неизвестный payload/state consumer не заполнять placeholder-объектом ради successful flow.

## 8. Edge cases

Stale checkpoint/registry/version; одинаковая форма с другим semantic codebook; mixed/unknown domain; partial/cancelled async output; fan-in с конфликтующим evidence; L2 target без допустимой L3 association; equally good candidates; evaluator загрузил child, ordinary caller оставил parent; document checkpoint ошибочно используется routing/kNN policy; preload без training lineage; missing OutputRefs payload/lifetime; UNKNOWN update outcome; пустая preference/contrast lost; full footprint за budget несмотря на малый adapter.
