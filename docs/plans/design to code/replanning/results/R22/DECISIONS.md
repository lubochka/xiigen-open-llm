## Отклонённые подмены

Новый trainer вместо минимального existing seam; обучение всех четырёх ролей до первого урока; глобальная смена tokenizer перед E1; ручной k как learned policy; Graph registry как transfer; coverage/Windows на каждый урок как efficacy; выбор рубрики после ответа; повтор пары до significance; всем детям вся библиотека; запись только новой книги при stale results; model alias как independent invocation. Эти пути не приняты. Реальное новое evidence может изменить предметное решение только с exact source/consumer receipt и сохранением истории.

**Что ещё не принято:** конкретный runtime profile/host/grants/weights/installed keys/families/resource allocation и independent review. Здесь опубликован исправленный проект экспериментов; ни алгоритмы, ни размерность пространства, ни «лучший k», ни качество обучения не объявлены доказанными.
