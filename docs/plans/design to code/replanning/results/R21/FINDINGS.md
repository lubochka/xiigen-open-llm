## Human role, exact pair и semantic recipient

**External approved open Chinese model authors BOTH final chosen and final rejected** for the same exact task/context. **CODEX on GPT-6 Astra UltraCode performs human lesson/case selection and preference, and in a SEPARATE step checks exact frozen DPO-pair quality.** Student weak answer — context only; post-update evaluator and independent architect are distinct roles. R21-R2 не вызывал эти модели.

DOCUMENT_EXAMPLE C#: для одного x с `s?.Length` preferred explanation сохраняет null-conditional смысл, meaningful near-miss утверждает zero. `s?.Length ?? 0` — ДРУГОЙ x, не подходящая замена rejected. Translation: same x «Do not send before approval», preferred meaning сохраняет запрет, near-miss его теряет. Реальные final bytes позже создаёт разрешённый author, не этот документ. TIE/BOTH_BAD/UNJUDGEABLE/reversed preference/rights unknown/changed bytes не ведут к forced update. Правильный deterministic answer может быть chosen.

DPO pair validity, actual parameter update и Student utility различны. Для E1 берётся response-conditional policy/reference objective и соответствующий backward R18; DPO reference не внешний judge/no-update control. Нулевая initial margin при policy=reference не подтверждённый bug. Train-ready unit recipient не превращается в graph target из-за whole-path оценки.

## Scientific examination — спроектировано, не выполнено

**Сравнения:** N corrected no-update → U same corrected pipeline trained; O optional old-pipeline только для отдельного code-repair вопроса. D/L/H — deterministic-only/learned-only/hybrid при одинаковых разрешённых facts/tools/resources и hard-law guards. Representation, mapper, learned rerank, k/radius, multi-neighbor-use, LoRA/projector, Flow, async policy и Graph получают отдельные declared interventions, не один смешанный winner claim.

**Метрики:** predicted-domain mapping отдельно от oracle diagnostics; ambiguity/OOD/abstention с явным знаменателем; grounded task accuracy и critical laws; typed many→many associations; correction of Flow; valid/efficient path и полная стоимость всех branches; Graph new-composition transfer; pair admission отдельно от downstream Student gain; worst-domain/retention; time-to-useful-gain; RAM/VRAM/disk/learning/inference/reindex/snapshot и external costs. NOT_MEASURED не 0. Best path — лучший среди реально рассмотренных lawful budget-bound candidates, не global optimum.

**Серии:** новые уроки объединяются в отчётные bulks; accepted IDs не replay. На одной registered panel сравниваются A0/Aprev/current и N/U контроли; смена curriculum/panel/rubric версионируется и требует сопоставления обеих версий либо раздельного ряда. Reused OP_DEV не sealed CERT. Family grouping нужна для uncertainty, а не число перефразировок. Operational noise-aware one-pair policy не заменяется обязательной significance каждого микрошагa. Научное подтверждение mastery/95%/hybrid gain отдельно от operational accept/rollback.

**Feedback:** consent/rights/quarantine → new allowed weakness family → exact author/judge → one authorised update → OP_DEV/old-domain retention → accepted state или restore → ordinary consumer after restart. Конфликт feedback с source law разрешается предметно. Unknown update после crash требует reconcile journal, не повторить тренировку.
