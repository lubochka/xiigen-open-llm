## Three independent splits (seal before first observed T)
TRAIN: lawfully teachable source families only; admitted human/teacher context allowed.
OP_DEV: separately tagged diagnostic families for causal mistakes and examples; not certification.
SEALED_CERT: held-out untouched source-family lineages, never exposed to teacher, Builder, patch/tuning, subjective choice or repeated prompt selection. Independent review controls unblinding. Holdout contamination invalidates certification, not merely a warning.

## Early compact panel proposal (not fabricated measurement)
2 subjects × 6 source families/subject × 2 task variants/family = 24 cases. Freeze source-lineage and independence; include explicit OOD/conflict/unknown strata and 1–2 near-miss mutation types by subject. If not enough legally usable families, use what exists, record N by stratum and uncertainty, and do not claim statistical power. Optional EN↔RU sentinel only if real consumer reachable; no presumed translation update.

## Falsification
S19 is not a success if subject accuracy increases but wrong-law answer rate or worst-domain lawful answer utility worsens, if only mock memory is measured, or if an adapter hash changes without ordinary consumer selection. Wrong-domain retrieval rate is based on **used evidence**, not returned-hit count.
