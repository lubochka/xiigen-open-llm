**Дата:** 2026-10-19. **Исторический донор:** [PrepareToGPL@31346d8](https://github.com/lubochka/llm_mvp_core/tree/31346d8928be4469b01aaf313780e8f950ff91e2). **Сравниваемая ветка:** [codex/dpo-implementation@6d36492](https://github.com/lubochka/llm_mvp_core/tree/6d36492714ebc1b9ae5f31a5a1da00673f524d83). ## Ключевое решение

Первые пробы должны вернуть сохранённую обученную память и доказать цепочку **старый checkpoint → законная миграция → trained Unit → обычный Flow → новый смысловой запрос**. Не начинать с ещё 500 DPO пар. Архивный перевод был гибридным: exact/phrase/word mappings, semantic tokenizer, kNN и learned verifier. Нейронный Student RP01 — другой получатель обучения; изменение LoRA весов не означает повторение прежнего успеха гибридной памяти.
