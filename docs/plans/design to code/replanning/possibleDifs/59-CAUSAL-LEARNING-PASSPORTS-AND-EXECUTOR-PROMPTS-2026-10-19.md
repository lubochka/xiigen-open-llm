## Общий протокол кратких опытов

Установить **получателя обучения** (конкретный Unit, сохранённые параметры/словарь/веса), **producer** разрешённого учебного сигнала, **consumer** (ordinary Flow, не проверяющая обёртка), **предметный домен**, не смешивая их. До выполнения закрыть независимые TEST case IDs и рубрику. Создать четыре состояния: A0=current initial before, A1=current после того же числа допущенных уроков, B0=same immutable initial before intervention, B1=один изменённый фактор + те же уроки/updates. Состояния A0/B0 обязаны совпадать по фактической исходной модели и memory state. Контроль без урока, invalid negative и cold restore — раздельные инструменты, не факторы, незаметно смешанные с основной A/B. Замерить own output на том же реальном маршруте, wrong accepted/all, coverage, correct/all + опасные семантические ошибки и ресурсы; показать delta по **всем** полезным показателям, а также ухудшения. Рост точности НЕ нужен для локального успеха на других измерениях, но отсутствие на exam собственной реакции получателя запрещает claim learning quality.

Небольшая реализация = один bounded native .NET harness, 2–4 TRAIN урока, 4–8 свежих EXAM, локально и только по утверждённым данным. Любой synthetic/example ниже — DESIGN FIXTURE, пока не утверждён как настоящий источник; не считать демонстрацию измеренной успешностью.

**Hypothesis:** positional source-first → target-first mapping for reordered sentence adds unsupported chosen WordMapping, which the learner writes to memory and later reuses for a new sentence; removing only unsupported fallback reduces harmful learned associations. **A intervention:** original builder all mappings. **B:** leave explicit/verified/marker mappings unchanged, suppress ONLY positional first-eligible-source→first-target fallback; not change source tokenizer, target text, rejected, admission, KNN, scorer, memory priority, threshold or grammar rules.

**Candidate 2 TRAIN examples** (illustrative, independently validate grammatical/source/target correctness and safety first): source «Книгу я читал», chosen «I read the book»; source «Письмо она отправила», chosen «She sent the letter». Training rejected sides are independently certified near-misses or source-verified omitted markers; if not available mark BLOCKED_INPUT rather than fabricating negatives. Train only Executor recipient, leave semantic/verifier untouched, using allowed typed batch; record individual actual generated WordMappings and memory checkpoint SHA.

**Fresh EXAM families**, separate from training source sentences, intent: «Книгу он взял» and «Письмо я прочитал», each paired with a related negative-control source where first-source token is already subject and alignment is unambiguous. Gold must be independently approved before outputs and define preserve agent/object, action, target language. Same lexical anchors are intentional transfer probes, NOT unseen-word generalization. Record exact/phrase/wordmap/knn/fallback chosen route, own translation, score and wrong substitutions. **Important:** if exact/phrase path bypasses affected wordmap or there are fewer than two usable mappings, this run is informative about reachability but **NO_CONTRAST** for claimed ordinary quality, not a positive result. Check cold checkpoint by fresh load and same exam.

**Success:** any useful measured improvement in wrong associations, coverage, CPU, RAM, cost/time or retained correct meanings counts per metric/domain; show negatives. Do not claim neural DPO improved. **Falsifier:** generated pseudo-mapping never written to state, never selected, or changed TEST behavior not attributable to the single mapping.
