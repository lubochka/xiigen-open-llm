# Сопоставление приложенных правил с поручением от 20 октября 2026

Это сопоставление инструкций, а не результат обучения. Полностью прочитаны приложенные `experiment-data-integrity-SKILL.md`, `plan-review-SKILL.md`, `plan-self-validation-SKILL.md`, `code-examination-SKILL.md`, `human-language-gate-SKILL.md`, `promptops-cycle-SKILL.md`, `TEACHING-MEASUREMENT-GUIDANCE-v6.md`.

| Источник | Сохраняемое полезное требование | Конфликт и решение для этого поручения |
|---|---|---|
| `experiment-data-integrity-SKILL.md` | Исторический результат относится к версии алгоритма; после исправления не выдавать его за актуальный | Требование заново запускать тестовый набор не превращает документный аудит в запуск; помечать исторический результат и необходимый будущий опыт |
| `plan-review-SKILL.md` | Проверять соответствие цели, фактические пути, измеримый результат и отсутствие пропущенных зависимостей | Общий полный тестовый прогон и обязательное новое личное согласование каждого документа не применяются; достаточно уже данного поручения и конкретной границы работ |
| `plan-self-validation-SKILL.md` | У исполнителя должны быть перечислены все входы, файлы и команды; план сам проверяет полноту | Проверка числа всех продуктовых тестов не нужна для маленькой экспериментальной копии; она не измеряет обучение |
| `code-examination-SKILL.md` | Читать механизм вместе с callers/consumers, формулировать гипотезу до подгонки под тест | Наличие готового теста не доказывает учебную причинность; требуется writer → learned state → reader |
| `human-language-gate-SKILL.md` | Расшифровывать обозначения; объяснять ожидаемый и фактический эффект по-человечески | Стабильные идентификаторы карточек сохраняются для адресности, но сопровождаются смысловым названием |
| `promptops-cycle-SKILL.md` | Один меняемый фактор; измеренный baseline; не повторять опыт без нового основания | Порог прироста точности 0,20 и автоматический merge отменяются новым поручением. Любое полезное измеренное улучшение — успех по этому показателю и домену; перенос в основной код решает пользователь |
| `TEACHING-MEASUREMENT-GUIDANCE-v6.md` | Разделять orchestration DPO/capability DPO, structural pass/quality, реальные ресурсы, накопительное состояние; проверять raw outputs | Требование непадения accuracy для успеха не применяется. Улучшение времени или памяти остаётся успехом по своей оси при явном показе ухудшений. Исторический V309 не является текущим baseline |

## Приоритет текущего поручения

1. Разблокировать настоящий обучающийся механизм или его доказанную зависимость (данные, восстановление, использование выученного).
2. Устранить неоднозначности карточки до передачи исполнителю: точные данные, копируемые файлы, один фактор, host, команды и пределы работы.
3. Применять релевантные присланные обновления без наследования чужой цепочки CI и продуктовых исправлений.
4. Прочие проверки отложить; связи с обучением нельзя имитировать добавлением формальных уроков.

Ни один из этих навыков не даёт разрешения менять защищённый каталог `llm_mvp_core/docs/plans/replanning-possible-diffs` в данной сессии. Исправленные паспорта и рекомендации добавляются в `xiigen-planning/.../possibleDifs`.
