## Разрешение реальных противоречий

1. **Protected output vs запрет пользователя:** все исходные126 карточек и общая методика могут ссылаться на protected results. Для работы нынешнего поручения применяется только назначенный `possibleDifs/.../results`. Исходные карточки не правятся.
2. **Старое PENDING vs новое явное разрешение:** выполнять действующую верхнюю политику20.10. Историческое «все личные допуски PENDING» в нижней части README — исторический срез, не актуальный запрет. Если выбранный input доступен, исполнитель готовит его сам.
3. **Общий словарь вариантов vs готовая команда:** `<ID>` — шаблон, не команда. Регистр честно сохраняет `REFERENCE_FAMILY_SELECT_EXACT_RECIPE`; новая N-KU-01 выделена отдельно. Неполный N60 source-copy manifest не превращается в READY-host.
4. **Прогресс по метрике vs promotion:** снижение false rejects вместе с ростом false accepts — успех по первой метрике, а не автоматическое решение внедрить. Пользователь выбирает перенос. Улучшение resource cost не требует accuracy и не доказывает её сохранность, если она не измерена.
5. **Имена CpuMs/PeakRamMb vs физическая величина:** в конкретном `TranslationMachine.TrainStructuredBatchAsync` CpuMs заполняется TickCount64 elapsed, PeakRamMb — моментным `GC.GetTotalMemory`. Показывать их под фактическим смыслом; независимый Process.TotalProcessorTime/working-set требует отдельного честного измерителя. Исправление подписи не является ускорением обучения.

## Текст overlay для каждого переиспользуемого шаблона

> Выполни только выбранный маленький опыт на заранее назначенной экспериментальной копии механизма и том же замороженном материале. Укажи конкретные writer/update/state/reader и реальный learning consumer либо доказанную зависимость результата обучения. Для actual learning сохрани A0/A1/B0/B1; для restore/consumer допустим один доказанно обученный state без декоративного Train. Любое измеренное улучшение полезного показателя — успех по этому показателю и домену; рост точности не обязателен; остальные изменения, включая ухудшения, покажи рядом. Основной код и продуктовые тесты не меняй. После измерения передай пользователю raw outputs и точный кандидат переноса; пользователь решает, переносить ли его. Назначенные пути, input bytes, seed/N/A, бюджет и конфликтная ветвь решения являются частью паспорта. В этой сессии protected каталог не изменяется.

Данный текст не выдаётся за исправление17 защищённых файлов/секций: это append-only правило переиспользования в разрешённом пакете. Ни один исторический шаблон не становится самостоятельным runtime поручением по одному его наличию.
