## Что обязательно прочесть вместе с назначенной карточкой

- [Договор](05-executor-contract.md) назначает outputs, host-owned claims, model и report и разрешает конфликт записи в protected для каждого pending ID.
- [Уточнение](experiments/EXECUTION-CONFLICT-OVERLAY.md) сохраняет исторический разбор R2/R1 literal; R2 и E-OPT уже завершены и исключены из запуска; точный LF-03 overlay см. в final827 readback. Для активных факторов действует одна внешняя chain, не дублирование внутренних команд.
- [Tensor-договор](learning/TENSOR-LEARNING-EXECUTION-CONTRACT.md) — часть двух новых карточек: точные короткие пути, Student, одна исходная пара, source-copy composition, команда после подготовки и четырёх-forward TRAIN-панель.
- Для NG01 использовать [существующий промпт](https://github.com/lubochka/llm_mvp_core/blob/66947785d1318f7cbbc88118f3156cdc75001e16/docs/plans/replanning-possible-diffs/experimets/prompts/NG01-executor.md) плюс общие правила этого дополнения. Canonical ID — NG01; текущий внутренний host указан в root05. Любая запись в protected required-changes из старого recipe отменена прямым запретом пользователя.

Слово «документирован» не означает существующий и проверенный runner. Подготовка ровно описанной экспериментальной копии входит в будущую задачу исполнителя; новый host/данные/модель самостоятельно не выбираются. Конкретный отказ подготовки не превращается в нулевое качество и не блокирует чужие независимые опыты.
