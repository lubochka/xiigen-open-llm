Машинная квитанция: [documentation-validation.json](evidence/documentation-validation.json). Это структурная проверка документации, не оценка качества обучения и не полный научный PASS для всех старых гипотез. Содержательные пределы перечислены в [источниках](03-sources-and-scope.md).

Файлы публикуются добавлением нового каталога и отдельного указателя. Используется актуальный родительский commit planning с проверкой ожидаемого HEAD, без force-update и без изменения старых файлов. Изменения core, появившиеся во время исследования, внесены другой сессией и учтены как поздняя delta; защищённая папка нашим аудитом не изменяется.

Итоговая стадия четырёх новых опытов: **DESIGN_REVIEWED_NOT_IMPLEMENTED_NOT_RUN**. Рецепты закончены для последующей реализации изолированных опытов; исполнимые host, доступность конкретного Windows SDK/DLL/B0 и измеренный эффект пока не подтверждены. Документ не назначает новый запуск, product adoption или полную цепочку тестов.

При прямом указании «следующий» нельзя продолжать оформление или проверку предыдущего опыта; при «стоп» работа прекращается, кроме необходимой остановки своего работающего процесса. Незавершённые результаты сохраняются. Любое полезное измеренное улучшение остаётся успехом по своей метрике и домену, с ухудшениями рядом; решение о внедрении принадлежит пользователю.
