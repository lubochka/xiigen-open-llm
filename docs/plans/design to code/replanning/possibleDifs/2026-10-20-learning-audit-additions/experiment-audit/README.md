## Что означает машинный scan

Scanner читает тела документов, выделяет P-подслучаи, профильные секции и адресные ссылки. Отдельные признаки фиксируют наличие текста успеха, default-модели, русского report-template, обучения, запрета перезаписи, незаполненного паспорта и буквальной команды запуска. Отсутствие найденной команды в 126 карточках означает только отсутствие команды **в этом теле**: внешний короткий рецепт может существовать. Это не автоматическое заключение, что 126 опытов запрещены или неисполнимы.

Результаты машинного поиска отделены от ручной проверки policy, общих повторяющихся блоков, P01, P86-алиасов, специальных lifecycle-контрактов и полного BPE scaffold. Причинная связь каждой из 470 гипотез и качество каждого исторического результата не считаются проверенными одной инвентаризацией. Профили SQL, C#, EN→RU, RU→EN, морфология и Unit/Flow не объединяются в один domain-success.

Source SHA взяты из Git tree. Локальный инструмент материализации добавлял конечный LF; после учета только этой операции 295 документов совпали исходным Git blob, ещё два — с восстановлением CRLF. Для четырёх индексных текстов исходная смешанная форма переноса строк не восстановлена: их локальные тексты не называются побитовой копией. Все 135 карточек совпали с исходным blob после учета добавленного LF. Этот нюанс не означает изменения защищённого репозитория. Данные нормализации сохранены в CSV.
