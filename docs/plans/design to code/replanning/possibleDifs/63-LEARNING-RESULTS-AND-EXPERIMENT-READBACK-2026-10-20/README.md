## Какие выводы о текущей реализации скорректированы

- **DPO:** знак производной и дробная response mask уже присутствуют; exact-путь использует response-only mask и сумму log-probabilities. Legacy-путь имеет другую reduction. Старое общее утверждение «DPO objective сломан» не описывает весь текущий код. [Источник и границы](02-CURRENT-NEURAL-LEARNING.md).
- **LoRA:** обучаемый адаптер подключён к forward по формуле base + alpha/r × B(A(dropout(x))). Наличие этой формулы само по себе не доказывает предметный навык; частичное улучшение NLL всё равно является полезным учебным сдвигом. [Разбор](02-CURRENT-NEURAL-LEARNING.md).
- **Unit / восстановление:** текущий trainer передаёт один и тот же упорядоченный KNN-корпус в live Unit и manifest; loader восстанавливает именно этот корпус. Старый top3-versus-flatten256 restore-пробел нельзя объявлять нынешним отсутствующим механизмом. Ограничение top3 выбора replay — другой участок. [Точная карта получателей и состояния](03A-CURRENT-KNN-UNIT-RESTORE-MAP.md).
- **Соседние ветки:** полезные исторические метрики сохранены, даже если старый `passed=false` определялся порогом другого показателя. Одинаковые Git blobs в нескольких ветках не считаются независимыми повторами. Точная цепочка конкретного «неудачного matrix → успешного KNN» не выдумана при отсутствии её первичного доказательства. [Историческая сверка](03-HISTORICAL-KNN-AND-UNITS.md).
