## Human finding

RP01 cannot be judged as a failed reproduction of an earlier «learning algorithm» until the *recipient of each lesson* and the *actual consumer of its state* are matched. Earlier positive reports concerned different mechanisms: source/AST structural kNN, contextual POS dictionary, exact source/phrase/word maps, learned verifier, limited replay in a bigram learner, and also **actual neural training** in the `DesignToCode` branch. Their existence is not interchangeable evidence of improved free-language generation.

RP01's main frozen route uses a small **random B0**, exact segmented DPO preference material, q/v-only LoRA, 50 updates per 500-pair domain, full private state readback and **direct TextGenerator**. The C# and EN→RU free semantic results reported in [RP01 recovery](../Kiro-Xiigen-RP01-Learning-First-Slice-Pack/RP01-2026-10-16-LEARNING-RECOVERY-AND-CODE-AUDIT.md) remained **0/3→0/3 and 0/4→0/4**. Changed 16 LoRA tensors ≠ learned skill. This is a strong *recipient-mismatch hypothesis*, not proof of one particular broken math operation.

**New N33 contribution:** trace two distinct measurement contracts that may change the apparent outcome *without any change to learned state*. One concerns macro-averaging of independent Unit heldouts versus actual request accuracy. The other concerns a max-output-length field participating in evaluation identity but not imposed in the RP01 raw-generation consumer. Detailed source proofs and falsifiers: [N33 direct source finding](33-NOVEL-UNIT-SCORE-AND-STUDENT-LENGTH-PARITY-2026-10-16.md); [small discriminating experiments and executor instructions](33-MICRO-RECIPIENT-AND-METRIC-QUALITY-EXPERIMENT-2026-10-16.md). No claim that these are the cause of frozen 0/3 or 0/4.

## Decisions and requested actual quality evidence

1. **No new Main500 / Windows CI.** First select ONE named recipient and ordinary consumer; one mini-case should move a learned state and a real answer, not only pass assertions.
2. **Keep causal comparisons separated:** neural Student vs Unit memory, then a genuine combined hybrid only if each recipient is trainable and consumed. Use same source, history, judges, decoding, prompt and source-family split.
3. **Domain-aware features, not indiscriminate fixes:** code AST ≠ natural-language word order; C# compiler validity ≠ correct documentation; morphological structure ≠ all-domain semantic geometry.
4. **A valid experiment reports:** unchanged or changed user-visible answer, source-law correctness, false accept/reject, abstention/coverage, prior-law retention after new lesson, cold-restore parity, cost. Pair margin and raw Unit accuracy are secondary signals.
5. **Evidence and review:** architect checks exact call path; code reviewer independently checks method signatures and counterexamples; plan reviewer verifies negative controls and unchanged denominators; prompt engineer freezes lawful DPO pair framing; human-communication reviewer explains one verified finding vs unmeasured causal prediction. No fictitious CODEX/Astra calls or executed native tests.
