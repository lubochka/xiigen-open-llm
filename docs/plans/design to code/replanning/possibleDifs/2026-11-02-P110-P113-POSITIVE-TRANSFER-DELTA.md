Это статический вывод из кода, не выполненный отрицательный тест; будущий контроль описан в 130.
- P111: измерена экспериментальная адресация, а не неисправность `LearningEventScheduler`. Его очередь не выбирает Unit. Дополнение 131 связывает feedback с identity фактического ответа, не с одинаковым prompt. Состояние соседнего владельца проверяется до restore; object identity и совпавший ответ не объявляются полной проверкой tokenizer/index bytes. Новый публичный SHA API не выдан за доказанное улучшение.
- P112: [MaterialLedgerVerifier:60–64](C:/Projects/llm_mvp_core/experiments-v2/RP01-MICRO/P11201/src/MaterialLedgerVerifier.cs:60) доверяет предъявленным ContentHash/NormalizedContentHash и не пересчитывает их из actual Content. В :137–146 overlap только считается: честный A с пересечением принят намеренно. Следовательно, копия verifier ещё не обеспечивает admission guard. В :39–42 выбирается первая семья normalized digest; неоднозначность конкретного frozen pool не доказана, а отказ при неоднозначном будущем source — предложенный контроль.
- P112, продуктовая граница: `BuildKnnTrainingCorpus` и projector получают TRAIN, но не EXAM/FamilyId. Guard только у KNN Train слишком поздний для защиты всего обучения: BuildTeachingStack и DPO уже выполнены. План 132 ставит проверку trusted owned material до них, сохраняет corpus-v1 и не запрещает legacy Train без оценки. Отсутствие lineage означает отсутствие доказанной независимой оценки.
- P113: энергии пересчитаны по обученному BPE; внутренние HNSW-векторы напрямую не измерены. Согласие reducer с 32 обычными ответами по соседу/confidence — отдельное свидетельство. Short доля 0,552381→0,5 (−9,48%), ответы 4/4→4/4; ухудшение геометрической метрики не выдаётся за доказанный вред ответу. Raw и регистрация в Program.cs дают 5 arithmetic entries: 1 preflight + 2 политики × 2 вида, тогда как report называет 6. Это расхождение документа и ведомости сохранено без перезапуска.
- P113, применимость: обычный продуктовый trainer вызывает `TransformerEmbeddingKnnLogicalUnit<string>`, который не имеет двух половин text/predicate. Изменить его по формуле generic Unit было бы другим экспериментом. Writer, query и restore должны иметь одну policy identity; query-only переход к новому масштабу против прежнего индекса не допускается. Нет native loader — нет утверждения о native восстановлении.
