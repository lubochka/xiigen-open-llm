# 04 — Индекс 125 семейств экспериментальных карточек

> **Проверка актуальности перед публикацией:** основной индекс 125/470 закреплён на `bf9b543e149ef197da85a767821d98c9b67916d2`, но текущие правила дополнительно сверены с `de4ef0f14172dada4daf142a4c66ba19e96bb6d4`. Общий PENDING и запрет зависимых loader/restore/consumer-проверок уже сняты внешним обновлением; E1/E2 уже получили новые малые рецепты. Не считать эти прежние недостатки текущими или исправленными авторами этого аудита. Полная сверка: [06-LIVE-CORE-DELTA.md](06-LIVE-CORE-DELTA.md).

Проверяемый core: `bf9b543e149ef197da85a767821d98c9b67916d2`. Исторические карточки — источник подслучаев, **не активная очередь из 125 запусков**. Ссылки на них и малые рецепты закреплены этим commit.

В таблице ниже 125 семейств и суммарно470 подслучаев. Это документное сопоставление и предварительная семейная классификация. **470 извлечённых A/B-постановок не означают470 независимых текущих code reviews, выполненных опытов или готовых runtime-паспортов.** Точная учебная связь, применимость домена и current caller проверяются для выбранного подслучая перед его выполнением.

«Обновление» означает наличие в семье вопросов о настоящем writer/Train. «Зависимость результата» требует точной цепочки обучения→состояние→loader/reader согласно п.4 пользователя. «Выбрать подслучай» предупреждает, что семья смешивает разные уровни и контроли. «Последняя очередь» не должна задерживать учебную работу без установленного causal caller.

Для каждой выбранной карточки нужен маленький однофакторный опыт по предметному домену. При оценке изменения самого обучения показываются A0/A1/B0/B1 и собственные ответы на одном frozen EXAM. При ресурсном сравнении настоящих updates дополнительные Generate не обязательны; качество без измерения неизвестно. Для сохранности или использования обученного результата допустим один доказанно обученный state и одинаковый материал до/после точечного исправления loader/restore/consumer, без декоративного Train. Любой полезный измеренный выигрыш — успех по его показателю, без обязательного роста accuracy; остальные изменения и потери рядом. Во всех случаях нужен конкретный native путь и source fix; обучение и присланные обновления идут первыми. Детали и поправки — в [01-EXPERIMENT-COVERAGE-AND-CORRECTIONS.md](01-EXPERIMENT-COVERAGE-AND-CORRECTIONS.md). Полный машинный перечень — [coverage.tsv](coverage.tsv), [coverage.json](coverage.json); дословные 470 A/B — [subcase-ledger.tsv](subcase-ledger.tsv).
