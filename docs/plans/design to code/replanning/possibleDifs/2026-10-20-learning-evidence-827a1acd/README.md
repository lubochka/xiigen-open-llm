Правило успеха сохранено буквально: **любое измеренное улучшение полезного показателя считается успехом по показателю и домену; рост точности не обязателен; ухудшения показываются рядом.** Отдельно указывается причинная уверенность. Одна A→B пара может дать полезное изменение времени, не устанавливая устойчивую причинную скорость. Отсутствие такого доказательства не стирает измеренный результат.

Эти результаты относятся к разным learners и не превращаются в один универсальный вердикт об обучении.
