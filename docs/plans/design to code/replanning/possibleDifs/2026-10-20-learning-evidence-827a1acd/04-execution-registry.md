## Переход и остановка

После обычного завершения — один русский отчёт и, при любом полезном измеренном результате, кандидат по назначенному пути. Потом переход по NEXT только в порученной программе. При техническом блокере сохранить частичные данные, записать короткий статус и перейти по NEXT; при поручении одного ID завершить его. Отсутствие host означает реализацию только явно назначенного экспериментального состава, не поиск другого опыта.

**«Следующий» немедленно прекращает любые действия по прежнему опыту: report, hashes, review, Git, retry, исправления. «Остановить всё» прекращает всю работу.** Незавершённый отчёт не оправдывает продолжение. Старые результаты/claims не удаляются. Запрет повторения указанного пользователем инцидента входит в каждую новую карточку и prompt, а также общий контракт.
