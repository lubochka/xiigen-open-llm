## 2. Независимый вопрос, ещё НЕ закрытый

**Могут ли CURRENT и GOLD выдавать разные ответы при идентичном содержимом checkpoint solely из-за policy-veto и разных последовательностей consumer?** Для одного KNN вызова по исходникам ответ: правила действительно различаются; для **обычного** Flow и semantic quality это **пока не измерено**. N55 позволяет выбрать краткий differentiating probe, а не переписывать целую learning stack.

**Инвариант восстановления:** GOLD historical positive → сохраняем данные/learning carrier → cold restore → нужный Unit → обычный Flow → независимая семантическая проверка. Нельзя «чинить» прежние успешные DPO/KNN опыты добавлением фиксированного правила, если требовалась обучаемая память.
