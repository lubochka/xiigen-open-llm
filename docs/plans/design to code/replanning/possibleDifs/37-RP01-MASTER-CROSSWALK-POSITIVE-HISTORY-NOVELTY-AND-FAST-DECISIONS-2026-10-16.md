## 1. Сначала различить четыре носителя обученного состояния

1. **Нейронный RP01:** 500 C# + 500 ENRU simulation DPO → frozen reference → AdamW → q/v LoRA → checkpoint → Student генерация. Реально изменились 16 LoRA tensors; независимый free answer 0/3→0/3 и 0/4→0/4. B0 random 629-token/4-layer/hidden512, исходный языковой навык не доказан. См. [RP01 recovery](../Kiro-Xiigen-RP01-Learning-First-Slice-Pack/RP01-2026-10-16-LEARNING-RECOVERY-AND-CODE-AUDIT.md).
2. **Structured Translation LearningMachine:** train-ready example распределён по SemanticTokenizerUnit, ExecutorUnit, QualityVerifierUnit; состояния — signature corrections, exact source, phrase/word map, KNN store, verifier. Rejected label/diagnostics влияют на producer, но это НЕ тождественно нейронному gradient DPO. См. [N16 Unit](16-INDEPENDENT-TRANSLATION-UNIT-AND-KNN-LEARNING-GAPS-2026-10-16.md).
3. **Generic learned KNN / domain routing / semantic compiler:** размеченная память, векторы, HNSW, learned labels и порядок кандидатов. Наличие класса или training receipt ≠ вызов в ordinary product и ≠ улучшение текстовой генерации.
4. **Детерминистические гибридные законы и graph/routing:** могут улучшать safety, выбор контекста и реакцию на отрицание; даже 4 wrong accepted→0 на 6 open cases не превращается в нейронное обучение. Проверяется отдельно coverage/abstain и достижимость learned owner.

[WorkLeft RAG index](../../09.09.26WorkLeft-RAG-MASTER-INDEX.md) — карта документов и решений, не акт исполнения; [WorkLeft guide](../../09.09.26WorkLeft-RAG-00-usage-guide.md) требует проверять фактическое использование, one-pair/rollback, saved state и качество отдельно.

## 4. Приоритет следующего короткого цикла без Windows CI

**RUN N0 (neural, independent):** before/after same frozen C#/RU free outputs, valid schema, same decoder, B0 vs after 100 steps, no new learning. Если 0/3 и 0/4 — status NO_OBSERVED_GAIN, не глобальный приговор.

**RUN N1 (neural, target one fault):** 8–32 admitted pairs diagnostic response mask + numerical gradient then tiny supervised warmup vs direct DPO. Не запускать 500 опять пока не установлен capacity/gradient.

**RUN U1 (structured RU_EN new N37):** M0 source history guard, M1 Unit learned update, M2 independent new-family final answer. Только один semantic admission factor.

**RUN K1 (historical):** выбираем один положительный learned donor (E09/E25/E22/E40), сверяем earliest primary receipt, actual State/Train method, integration diff и reachable current consumer; один matched test, без переноса всей матрицы.

**RUN G1 (GraphRAG/domain):** только если ordinary route вызывает graph seeding, проверять empty-seed false-evidence, law/abstain отдельно от Neural.

Human communication: сообщать «какую конкретную способность приобрёл», а не сколько UNIT tests GREEN. Каждый опыт возвращает fixed case ids, state/recipient, one-factor delta, false positives/abstains, source SHA и status NATIVE_RUN/NOT_RUN. No speculative bulk, no Windows CI requirement for exploratory native learning comparison.
