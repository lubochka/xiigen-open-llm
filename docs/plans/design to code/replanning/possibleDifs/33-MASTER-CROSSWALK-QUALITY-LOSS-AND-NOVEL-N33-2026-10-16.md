## 1. Приоритетный результат — не путать «вес сдвинулся» с «ученик научился»

Существующий [RP01 recovery audit](../Kiro-Xiigen-RP01-Learning-First-Slice-Pack/RP01-2026-10-16-LEARNING-RECOVERY-AND-CODE-AUDIT.md) и [N31](31-INTEGRATED-POSSIBLE-DIFFS-NEW-HYPOTHESES-AND-PRIORITY-2026-10-16.md) фиксируют **C#500 0/3→0/3**, **ENRU500 0/4→0/4** при изменившихся LoRA/optimizer. Не следует из этих маленьких holdouts вывод «DPO математически сломан»: [независимое адресное чтение exact DPO gradient](https://github.com/lubochka/llm_mvp_core/blob/codex/dpo-implementation/docs/plans/replanning-possible-diffs/41-current-dpo-gradient-chain-source-review.md) не обнаружило очевидного обрыва q/v градиента. Важно, что [RP01 pipeline](../Kiro-Xiigen-RP01-Learning-First-Slice-Pack/RP01-CURRENT-CODE-MAP.md) — Student DPO/LoRA/Generate, а положительные E09/E13B/E26/E43 — **иные recipients**. Успех полезной памяти не заменяет требуемого neural learning; нейронное изменение не подтверждает правильного learned Unit.

## 4. Самый дешёвый порядок проверки после текущих документов

1. **P0, actual product causal chain:** frozen RP01 input→which Student/Unit→changed state→cold restore→ordinary free answer→blind law judge. До результата не запускать новый 500-парный цикл. [Active recovery](../Kiro-Xiigen-RP01-Learning-First-Slice-Pack/README.md).
2. **P0, короткий N33 validity probe:** проверить на native E44/E45, что интервенции различают только вес или порядок **готовых true pairs**. Убедиться в ложных переходах/неодинаковых pair multiset перед измерением semantic gain. [Work order](33-MICRO-E44-E45-FACTORIAL-QUALITY-PILOT-2026-10-16.md).
3. **P1, правдивость исторических positives:** отдельно E09 AST, E26 POS, E13B memory, E43 replay; source-family-disjoint heldout плюс реальный consumer, не суммировать сырые top1 разных получателей.
4. **P1, neural learnability:** tiny true pairs, proper reference gradient, SFT-prerequisite, rank/decoder, then domain-specific lawful DPO with authorized teacher/judge. Нельзя заменять настоящие pairs synthetic proxy JSON.
5. **P2, after empirical signal:** broader domain coverage, variant gates, replay/forgetting, PC latency/peak memory; security/integrity release gates отдельно, без Windows run как обязательного предварительного исследования.
