Ссылки на родительские семейства RAG разрешались по фактическим paths; переиспользованный исследовательский вывод помечен как исторический. Весь R01–R25, все родительские каталоги и каждый старый файл заново полностью не исследовались. Такое обещание не требуется для двух локализованных новых гипотез и не даётся.

## Как воспроизвести именно приложенные проверки

Проверки не требуют изменения core и записывают результаты рядом с собой либо по `--output`. Для скриптов, читающих core, нужен локальный checkout на указанном commit с настоящими исходными blobs. Иная версия отвергается по Git SHA. Если путь содержит пробелы, заключите его в кавычки.

```bash
python3 evidence/argument_ordinal_probe.py
python3 evidence/verifier_marker_probe.py --core-root /path/to/llm_mvp_core
python3 evidence/recount_historical_panel.py --core-root /path/to/llm_mvp_core
```

Первая проверка использует явно условные векторы и не разбирает C#. Вторая воспроизводит выбранные ветви для простых кириллических fixtures и не является полным tokenizer/builder/runtime. Третья сверяет архивную арифметику и frozen accepted-фразы; не удостоверяет заново DLL/PDB или всю историю запуска. Их JSON явно содержат эти границы.

Проверены результаты: old/new ordinal distance0/0.3; у marker четыре source-equivalent ячейки2/4,2/4,2/4,4/4; у архиваA0→0,B0→19,C0→13. Первые два ряда не публикуются как native прирост качества. Последний относится к уже сохранённым native ответам.

Git LFS payload `translation-memory-ingress-01/comparison.json` не получен: доступен только указатель. Его нельзя считать перечитанным JSON. Для этого успеха прочитан report со всеми 24 ответами и отдельный evidence-validation, что прямо обозначено в главе4.

## Граница публикации

В разрешённом `possibleDifs` добавляется отдельная папка этой работы и краткая ссылка в общем README. Существующие разделы README сохраняются побайтно. Запись выполняется от актуального parent commit без force и с проверкой ожидаемого HEAD; при конкурирующей записи требуется новая основа, а не перезапись чужого результата. SHA итогового commit и проверка readback сообщаются в ответе пользователю.

Защищённый core остаётся источником. Поэтому формулировка покрытия новых гипотез — «добавлены внешние маленькие карточки с доказанным пробелом в текущем каталоге», а не «мы изменили защищённые эксперименты и теперь гарантируем их все».
