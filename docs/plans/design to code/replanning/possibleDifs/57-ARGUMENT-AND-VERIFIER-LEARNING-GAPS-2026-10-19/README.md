# Где ещё теряется учебный сигнал и что действительно проверяют малые опыты

19 октября 2026. Это дополнение к прежнему `possibleDifs`: две новые узкие гипотезы по исходному коду, проверка их покрытия в действующих экспериментах и уточнение двух старых проверочных панелей. Исправлений продукта и новых native запусков обучения в этом пакете нет.

**Главный вывод:** действующая методика малых опытов уже содержит корректное сравнение до/после и явно различает нейронный Student, память Unit и доставку ответа. Но полноту всех работающих экспериментов подтвердить нельзя. Два найденных здесь условия не представлены отдельными проверками, а часть уже описанных опытов ожидает конкретного маленького runner или подключённого получателя ответа.

Новые кодовые гипотезы не доказывают причину отрицательного нейронного RP01. Для структурного KNN прослежено наследование того же существенного кода из `language_translate`; наличие этого дефекта нельзя называть новой ошибкой слияния. Для перевода история и границы проверены в отдельной главе. Оба результата относятся к своим получателям обучения.

**Сохранённые успехи подтверждены отдельно:** EN→RU Executor 0/24→19/24, восстановление тех же 19/24 в новом процессе, доставка частей урока 11/24→19/24. По первому набору заново пересчитаны 144 сохранённые записи. Это реальные результаты памяти; подробные доказательства и границы — в [главе4](04-history-and-mechanism-crosswalk.md).

## Что проверено в старом каталоге

В pinned core найдено **125 карточек и 470 именованных подслучаев**: 468 числовых и два буквенных. Все имеют адрес в новой карте. Это проверка адресуемости. Содержательно проверены все 18 документов активного малого набора, наиболее близкие старые карточки и первичные участки кода новых находок. Не заявляется новый полный причинный аудит каждого исторического подслучая.

На основном снимке прежние 492 Markdown в `possibleDifs` получены целиком, сверены с Git blob SHA и проиндексированы для проверки новизны. Это не 492 новых исследования первоисточников. Весь исходный снимок содержит 790 файлов, включая evidence/scripts; не все эти вспомогательные файлы выполнялись или перечитывались. Перед публикацией дополнительно сверены 13 новых Markdown других авторов до planning `9a07709b…`; они не дублируют две точные находки. Подробности — в главе6.

## Приоритет для RP01

Для вопроса **«обучаются ли нейронные веса так, чтобы улучшался собственный ответ?»** ближайшая проверка остаётся [два нейронных урока](<https://github.com/lubochka/llm_mvp_core/blob/eb05219c27663835ce927c7bf97cf1274c07cddb/docs/plans/replanning-possible-diffs/experimets/2026-10-19-small-learning-probes/04-documentation-neural.md>). Она использует существующие trainer и C# evaluator, но требует отдельного двухстрочного admission/dispatch: штатные режимы сейчас рассчитаны на 1 или 500 пар. Бюджет основного контроля — 2 обновления и 8 собственных ответов при доказанном общем baseline; иначе 16 ответов. Успех памяти KNN/проверяющего не закрывает этот вопрос и не является обязательной предварительной стадией.

**Роли неизменны:** CODEX с запрошенной `astra 6 ultracode` выбирает учебную задачу в роли человека. Разрешённая внешняя открытая китайская модель создаёт обе окончательные стороны DPO. Отдельный CODEX с той же запрошенной моделью оценивает качество точной неизменённой пары. Проверка ответа Student — отдельная роль. Условные примеры в карточках не являются фактически вызванной китайской моделью; metadata реальных вызовов здесь не выдумываются.

Документы и evidence добавляются только в разрешённый planning-каталог. Защищённый `llm_mvp_core/docs/plans/replanning-possible-diffs` остаётся источником чтения. Поэтому новые карточки из этого дополнения физически не добавлены туда; утверждать обратное было бы неверно.
