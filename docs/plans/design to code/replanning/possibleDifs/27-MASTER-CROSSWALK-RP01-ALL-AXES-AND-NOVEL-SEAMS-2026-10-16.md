## Суть архитектурного разрыва

**RP01 проверил обновление LoRA neural Student, но исторические положительные результаты часто использовали совсем других получателей обучения.** Единица сравнения — не «DPO» или «KNN» по названию, а вся цепочка `goal/quality → chosen/rejected/source identity → vector/token ID → actual learner → checkpoint → route → ordinary consumer → independent judge`.

Три нельзя смешивать: (A) изменение LoRA при исходной не обученной B0; (B) обучаемая дискретная Unit/KNN/correction память и hybrid deterministic laws; (C) validator, который может ложно объявить успех или провал. Позже найденное улучшение алгоритма в KNN нельзя объявлять несуществующим только из-за раннего negative Matrix/NG-ram run.

Одновременно сохранить реальный ordinary output. **Эксперимент не запущен;** подробный [work order](27-MICRO-N27-LEARNING-QUALITY-PILOT-AND-WORK-ORDER-2026-10-16.md).
3. **State:** отдельно N27-A no-train heldout batch before/after и N27-B cached vs disk checkpoint после simulated failed save. Не изменять учебные данные/weights при тестировании одного фактора.
4. **Synthesis:** только `source→learner→checkpoint→consumer→CODEX law judge` с source-family split и real callable evidence разрешает заключить `IMPROVE/REGRESS/NO_GAIN/INCONCLUSIVE`. Классический Matrix E07 нельзя выкинуть из KNN по unpaired E07/E09 метрикам. Домены сравнивать отдельно.

## Обязательные роли DPO и честность границы

**CODEX, запрошенная модель `astra 6 ultracode`, выполняет роль человека в выборе урока.** Допущенная **внешняя открытая китайская модель** производит **обе окончательные DPO стороны — `chosen` и `rejected`**. **Отдельный CODEX с `astra 6 ultracode` оценивает качество ровно этой неизменённой пары**, в том числе отсутствие корректной предпочтительной стороны. Ни Student, ни deterministic dataset builder, ни наш source-audit не подменяют эти назначения. При отсутствии реальных вызовов ставить `NOT_RUN`, а не выдумывать accept/quality.

В этой сессии применены целевые чтения skills архитектора, планирования, plan/code review, prompt engineering, human communication и experiment/claim verification; **полное чтение всех RAG документов, полный археологический поиск по каждому refs, независимое CODEX ревью, native C# и real-model quality не выполнялись**. Новые доказательства касаются именно source paths N27; причинная связь с neural Student RP01 требует отдельного эксперимента.
