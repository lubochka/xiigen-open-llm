### Один критерий для любого «успешного обучения»

Проверять: `dataset/semantic-law + actor provenance + pretraining state + tokenization and response mask + mutated recipient + actual restore + ordinary routing + independent semantic gold`. Указать *кто учился*: LoRA neural policy, KNN memory, Unit rule, classifier, deterministic guard. Показать separate baseline/endline, exact vs source-disjoint, per-domain quality, coverage, confidence, memory/time. Proxy с высоким accuracy, F1 или latency не складывается с другим proxy в глобальное «процент качества».

## Доменная граница: отобрать функции, а не внедрять всё повсюду

| Домен | Потенциально необходимое поведение | Опасная ложная глобализация |
| --- | --- | --- |
| C# code analysis | Roslyn AST ancestor/sibling/scope; identifier & type, nullability, overload, ordering, compile/run verified expected | Назначать AST code-specific scoring EN→RU лексической фразе |
| EN→RU / RU→EN | word order, subject/object roles, negation, aspect, referent, gender across clauses; uncertainty | Механически запрещать «не» или все gender alternates без source gold |
| SQL | operator type `IS NULL` vs `= NULL`, JOIN-ON/WHERE difference, precedence, alias scope, version/dialect | Считать близость одних и тех же таблиц соблюдением join law |
| Code-documentation | task intent describe vs fix vs generate; runtime verified expected behavior, source spans and AST | Генерировать «правильный» ответ через hardcoded regex, затем приписывать его нейронным весам |
| Cross-domain memory | data/feature/consumer/encoder/checkpoint SHA, role predicate, correct law retention, reliable abstention | Переносить единый kNN top-k и confidence floor между всеми доменами |

## Исполнение и границы расследования

**Контракт ролей, строго:**
- **CODEX + model astra 6 ultracode** осуществляет роль человека: выбирает/одобряет вопросы/критерии/обучающие пары, обосновывает выбранное доменное правило.
- **Внешняя открытая китайская модель** (только реально вызванная, законно используемая с подтвержденными provider/model/license receipts) генерирует *обе* стороны DPO — `chosen` и `rejected`. Детерминистический Python/C#/Astra synthetic можно использовать для диагностики, но нельзя маркировать внешним teacher.
- **Другой независимый прогон CODEX + astra 6 ultracode** слепо проверяет точные пары и, отдельно, конечные ответы системы по заранее согласованному gold; не исходный автор отрицательной стороны.

**Приоритет по причинной близости RP01:** P0 neural cold B0 and train-eval exposure; P0 correctness of model-visible contrast/mask/gradient; P1 learning-policy target/domain law and ordinary generation; затем memory/Unit/Replay специфические оси по фактическому owner.
