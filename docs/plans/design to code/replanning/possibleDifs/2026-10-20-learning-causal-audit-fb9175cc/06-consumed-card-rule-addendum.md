## Уточнение паспорта №08 N63-INGRESS-LENGTH

> **Правило успеха этого сохранённого опыта.** Любое измеренное улучшение полезного показателя считается успехом по этому показателю и домену; рост точности для этого не обязателен. Рядом показываются изменения остальных показателей, включая ухудшения. Для №08 сохранены полезные admission/update и NLL изменения на коротких C# уроках; их нельзя обнулить из-за отсутствия роста response exact. Одновременно 0 правильных response-токенов и 0 точных ответов до и после не доказывают усвоение задания: исходный learning verdict и `MEASURED_REQUIRES_METRIC_REVIEW` не переименовываются. A отказал без updates, B выполнил два: разницу wall/CPU/allocations не называть ускорением одинаковой работы. Это уточнение трактовки уже сохранённых результатов, без нового запуска, диагностики, отчётного цикла или правки production. Старые raw/claims сохранить. Модель читающего исполнителя — default текущей сессии; пояснение по-русски. При «следующий» немедленно прекратить прошлый report/review/hash/Git/retry и перейти к уже назначенному NEXT; при «остановить всё» немедленно остановиться. Одиночное поручение №08 заканчивается END; current next unconsumed общей программы — №10 N63-CORRECTION-COLLISION.
