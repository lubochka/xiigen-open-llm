## Для человека: главное отличие

У системы есть **разные обучаемые получатели**. RP01 Student обновляет нейронные параметры LoRA; переводческий `ExecutorUnit` сохраняет и извлекает обученную память; domain kNN хранит структурное сходство; `Flow` выбирает конечный ответ. Эти результаты нельзя складывать как «один способ обучения». **Домен** — предмет изучения (перевод, программирование, документация, оркестрация), EN→RU и RU→EN — профили одного домена, Unit/Flow — архитектурные получатели, не отдельные домены. Это следует применять ко всем P-карточкам.

**Наблюдения из сохранённых результатов, не из нашего запуска:**
- [RP01 recovery/code audit](../Kiro-Xiigen-RP01-Learning-First-Slice-Pack/RP01-2026-10-16-LEARNING-RECOVERY-AND-CODE-AUDIT.md): C#500 (25 семьи ×20), 50 DPO updates, изменение 16 LoRA tensors, свободный ответ 0/3→0/3; ENRU500 50 updates, свободный ответ 0/4→0/4. В просмотренном формате **не обнаружено полного per-run паспорта с точным model artifact/initial checkpoint hash, exact skill-load list, исполнимой командой и датой human approval**. Ряд карт относит эти сведения к общей методике. Это **GATE_NOT_READY** до per-run заполнения, а не дефект научной гипотезы.
- Некоторые protected cards ссылаются на `C:/Users/lubao/Documents/...` (см. [N56-02](56-02-PROTECTED-EXPERIMENT-COVERAGE-AND-QUALITY-AUDIT-2026-10-19.md)): эти пути не портируемы для удалённого исполнителя. Внешние пакеты используют GitHub URL + pin.
- Исторический [N57 package](57-ARGUMENT-AND-VERIFIER-LEARNING-GAPS-2026-10-19/README.md) уже нашёл ArgSyntax ordinal и повреждение кириллического suffix; **не приписывать это N58 как новые открытия**.
- Реальный статус: **SAMPLED_METHOD_REVIEW**, **GLOBAL_SEMANTIC_COVERAGE_OPEN**, **NO_NATIVE_EXECUTION_THIS_REVIEW**, **NO_REVIEWER_SIGNOFF**. `31 names missing` из N56-02 означает лишь literal index gap, не отсутствие 31 эксперимента.
