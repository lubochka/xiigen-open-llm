## Очерёдность реальных действий

**Gate 0 — оценка:** понять false-positive N45 и зафиксировать семантическую рубрику до экспериментов. **Gate 1 — восстановление:** old translation checkpoint4→6, уже исправленный phrase ingress и cold state, old R1/R2 context, E09/E26 learned features. **Gate 2 — новый навык:** одно законное изменение state, затем unseen answer через обычный consumer; для neural до DPO проверить base/warm ability и свободный ответ. **Gate 3 — сохранение и расширение:** E43 replay, E22 per-class routing, навыки на нескольких подлинных доменах. Для каждого этапа отличать `CODE_CONFIRMED` / `HISTORICAL_RECEIPT` / `HYPOTHESIS` / `NATIVE_NOT_RUN`.

**Наши новые узкие кандидаты — только K44-01/K44-02**, проверенные небольшим source-equivalent proxy (5/5); полноценный peer dedup и native quality ещё открыты.
