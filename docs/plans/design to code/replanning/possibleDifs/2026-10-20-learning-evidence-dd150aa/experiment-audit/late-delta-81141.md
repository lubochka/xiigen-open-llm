## L3. ATTN: настоящее обучение предусмотрено, валидный минимальный набор ещё не обеспечен

[Механизм L22–36](https://github.com/lubochka/llm_mvp_core/blob/81141d57b847bc050881c2fabba8302ac18c0f8a/docs/plans/replanning-possible-diffs/experimets/cards/ATTN-TRANSPOSE-STRIDES-01.md#L22-L36) находится внутри native forward/backward/SFT update. Поэтому это допустимая гипотеза стоимости обучения, не внешний benchmark массива. A/B меняет только rank4 axes1↔2 integer addressing; предусмотрены parameter write, losses, state/moments и logits parity. Успех allocations/time не требует роста accuracy.

Однако [L86–103](https://github.com/lubochka/llm_mvp_core/blob/81141d57b847bc050881c2fabba8302ac18c0f8a/docs/plans/replanning-possible-diffs/experimets/cards/ATTN-TRANSPOSE-STRIDES-01.md#L86-L103) задают холодный hidden64 Student, новую LoRA stream и ровно4 updates/arm без проверенного ненулевого результата; [prompt L42](https://github.com/lubochka/llm_mvp_core/blob/81141d57b847bc050881c2fabba8302ac18c0f8a/docs/plans/replanning-possible-diffs/experimets/prompts/ATTN-TRANSPOSE-STRIDES-01-executor.md#L42) запрещает дополнительную подготовку. Нельзя обещать валидность по п15 заранее и нельзя молча запускать400/1000steps как fallback. Новый hidden16 restore donor с другой topology не является совместимым готовым state для hidden64/rank4 этого рецепта.

**Добавочная коррекция:** до назначения исполнения автор фиксирует совместимый общий B0 с доказанными положительными TRAIN anchors либо заранее оплаченный preparer и весь бюджет preparation+updates+reads; EXAM для адаптации не используется. Пока этого нет — `PREPARATION_REQUIRED_FOR_LEARNING_PANEL`, при сохранении ценности cost-гипотезы. Это не команда повторить законченный frozen-transpose опыт или №08. При будущем фактическом0/0 ресурсный gain сохраняется отдельным кандидатом, а панель обучения помечается невалидной по правилу пользователя.
