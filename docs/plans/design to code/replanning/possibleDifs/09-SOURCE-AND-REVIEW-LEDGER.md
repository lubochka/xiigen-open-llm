## Governance gap
RP01 можно считать технически исполненным по count updates, artifacts, tests, но это не тождественно обучению новой функции. Governance должен запрещать `WEIGHTS_CHANGED`/ `MARGIN_INCREASED` → `LEARNING_GAIN`; RAG pointers → implementation claims; early experimental PASS→present RP01 gain; deterministic law guard→neural gain; restored private checkpoint→adopted user model. Для закрытия требуется pinned real Student→consumer new-family semantic outcome и independent review.
