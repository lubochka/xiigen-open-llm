A. Для каждого старого успешного прогона взять source SHA, raw train/test IDs, train/update mutation, evaluation input/rubric, recipient и frozen output; отделить hard-coded rule, retrieval memory, learned unit и LoRA.

Если production consumer не вызывает успешный модуль, фиксировать MISSING_INVOCATION; если вызывает другой алгоритм — TRANSFORMATION_DIFF; если метрика несопоставима — MEASUREMENT_DIFF; если изменяется состояние, но не результат — LEARNING_NOT_ADOPTED.
