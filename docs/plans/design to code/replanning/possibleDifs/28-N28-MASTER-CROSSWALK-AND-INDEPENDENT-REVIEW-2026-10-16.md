## 1. Что действительно сравниваем

RP01 нейронный путь — `CodeDocumentationSimulationDpoExperiment → exact material → DpoTrainer/AdamW → LoRA q/v → TextGenerator`. Ранний успешно наблюдаемый гибридный путь — `semantic/domain parsing → trainable corrections, KNN, phrase/exact/word maps → routed Executor → learned law verifier → ordinary consumer`. Кроме того, были реальные старые neural DPO training checkpoints, source archives и экспериментальные bigram/replay/AST routines. **Ни один** из этих механизмов не заменяет доказательство улучшения свободного ответа *того же Student*.

[RP01 learning recovery (исходные результаты)](../Kiro-Xiigen-RP01-Learning-First-Slice-Pack/RP01-2026-10-16-LEARNING-RECOVERY-AND-CODE-AUDIT.md): C#500 = 25 semantic families, 50 updates, free 0/3→0/3; ENRU500 = 20 families, ещё 50 updates, free 0/4→0/4. Факт изменения 16 LoRA tensors **не** равен росту correctness. Наборы маленькие; запрет выводить статистическую «нулевую способность обучаться» по 3–4 задачам. Повторного native запуска здесь нет.

## 3. Почему конкретно N28 — дополнение, а не переименование findings

**N21-01** уже заметил, что SemanticTokenizer self-label записывается bootstrap законом, иногда под `|PAIR:id`, поэтому не переносится. **N28-A** начинается *после* независимого исправления этого недостатка: даже если корректный Pattern обучился, downstream Executor *обучает свои ключи по отдельному не скорректированному tokenizer*, а inference читает corrected keys. Оба дефекта должны быть независимыми условиями экспериментальной матрицы.

**N26 metric** уже установил RU_EN-only coverage при batches без heldout; **N28-B** относится к batches **с** heldout и обученному реальному Flow: negative-only samples для Verifier, Eval parser без learned state и hardcoded language. Одноклассовая оценка может показать ложный SUCCESS даже когда final user answer ухудшается.

## 4. Самый быстрый следующий шаг и пределы доказательства

Вместо 500 новых DPO и Windows CI: [один причинный MICRO-N28](28-MICRO-N28-CAUSAL-AB-EXPERIMENT-2026-10-16.md) плюс [источниковая case matrix](28-MICRO-N28-CASE-MATRIX.json). Прежде чем запускать — утвердить genuine Pattern correction и source-disjoint gold, зафиксировать 12 вопросов, провести префлайт key divergence. Изолировать сначала индексный фактор, затем отдельно метрику. Получить raw per-case correct/incorrect/abstain/selected-neighbour, а не только percentage/green labels.

**Статусы, которые нельзя подменять:** `KEY_DRIFT_CONFIRMED` ≠ `QUALITY_GAIN_PROVEN`; `MODEL_STATE_CHANGED` ≠ `LEARNING_VALIDATED`; `HISTORICAL_PASSED` ≠ `MATCHED_REPLICATION`; `TRAIN_READY` ≠ `INDEPENDENT_GOLD_APPROVED`; `UNIT_ACCURACY` ≠ `ORDINARY_CONSUMER_CORRECTNESS`.
