## Сначала вернуть полезную цепочку обучения

Приоритетная очередь [главы 0](00-LOCAL-WIKI-RECOVERY-FIRST.md): настоящий `Prompt/Chosen/Rejected` до получателя; нужные policy/reference при continuation; использование learned state обычным ответом; потерянный сценарий `ClientServerBusinessFlow`; новая обратная связь при выборе следующего урока; проверка сохранения и загрузки. Для уже известных различий сохранены ссылки на первоначальных владельцев из 49-пакетов.

Для донорского воспроизведения пересчитаны исторические CodeTrace019 **49/50** и CodeTrace064 **46/50**, а также два узких run 50/50. У CodeTrace гораздо больше разных текстов; один chosen и один rejected на 100 строк в QueryPlanning134 ограничивают силу его 50/50. Все эти числа — архивное DPO preference, их нельзя приравнять к новой свободной генерации. [Первичные receipts и разнообразие](evidence/donor-receipts.json), [разбор](01-NEW-CURRICULUM-FEEDBACK-GAP.md).

Current содержит полезные исправления реального LoRA forward, знака DPO derivative, сохранённого графа и autograd операций. Они сохраняются при адресном восстановлении. [Проверенные места и ограничения](03-MECHANISM-COVERAGE-AND-KEPT-FIXES.md).
