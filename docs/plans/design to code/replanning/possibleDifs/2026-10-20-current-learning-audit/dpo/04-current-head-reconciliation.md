## Защищённая библиотека экспериментов

В `experimets/cards/P01...P125` лежат исторические варианты. В `experimets/2026-10-19-small-learning-probes/` лежит активная малая очередь. В обеих уже присутствуют требования любого полезного улучшения, показанных ухудшений и фактического участия в обучении. Нельзя выдавать добавление этих правил в наши документы за исправление отсутствующего глобального правила.

[Активная D04](https://github.com/lubochka/llm_mvp_core/blob/bf9b543e149ef197da85a767821d98c9b67916d2/docs/plans/replanning-possible-diffs/experimets/2026-10-19-small-learning-probes/04-documentation-neural.md) честно отмечает незаполненные native host, B0/optimizer/RNG и один выбранный factor. Это конкретные технические зависимости, а не доказательство уже проведённого плохого эксперимента. Новый cache factor определён отдельно, потому что два разных урока по одному разу в исходной D04 не создают повторов reference score. Необходимая запись для сводного crosswalk: `LC-REF-CACHE → protected direct experiment absent → possibleDifs supplementary design → native not executed`.
