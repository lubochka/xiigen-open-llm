## Проверять отдельно каждое звено

Полная учебная цепь: **исходный опыт/обратная связь → содержательный урок → адресат и materialization → update памяти или параметров → сохранённое состояние → восстановление → штатное чтение → полезный результат**. DPO-loss, число затронутых Units и успешная запись checkpoint относятся к разным звеньям. Они не взаимозаменяемы с предметной правильностью ответа.

## Что значит «скрытый детерминизм» в этом аудите

Расстояние, tokenizer и optimizer неизбежно содержат фиксированные вычисления. Дефект возникает, когда заданная вручную семантическая развилка выдаётся за выученную способность или когда изменяемая learned memory не доходит до настоящего consumer. Поэтому критерий — не наличие слова `if`, а проверяемая зависимость **урок → изменённое state → результат**. Неправильный labeler особенно важен: reader действительно обучается, но усваивает ошибочный target. Именно эту ситуацию проверяет новый static-field контрпример.

## Доменная граница

AST path, ancestor kind и sibling position полезны для C# next-node/file-action целей, но не задают готовый язык признаков перевода. Для обычного предложения важны последовательность, агент/получатель, отрицание, tense и контекст; словоизменение/роль может потеряться при bag/normalization. Это уже описанные семьи, а не вновь доказанный универсальный эффект. Routing уроки принадлежат оркестрации даже при разных предметных входах. Перенос любой функции требует совпадающих semantic target, данных и читателя; совпадения имени эксперимента недостаточно.

## Неразрешённые вопросы

Источники позволяют составить проверяемые причинные кандидаты, но не ранжировать все причины деградации по величине эффекта. Нет единой контролируемой пары «исторический успешный RP01 state против текущего с одним изменением» для всего тракта. Не все исторические donor states сохранены/аттестованы; соседняя ветка с исходником не равна готовому trained snapshot. Для неполученных данных записано `unknown`, а не нулевой результат. Исполнитель новых карточек не должен самостоятельно восстанавливать отсутствующий исторический эксперимент или бесконечно расширять поиск.
