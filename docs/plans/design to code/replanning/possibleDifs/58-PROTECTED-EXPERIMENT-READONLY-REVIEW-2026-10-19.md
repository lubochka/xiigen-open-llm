## 3. Неочевидный дефект готовности карточек к запуску: паспорт ссылается на общий приказ, но не является полным

**Проверка выборки конкретных файлов (не универсальное утверждение обо всех 125):** [P125](https://github.com/lubochka/llm_mvp_core/blob/eb05219c27663835ce927c7bf97cf1274c07cddb/docs/plans/replanning-possible-diffs/experimets/cards/P125-executor-memory-learning.md), [P51](https://github.com/lubochka/llm_mvp_core/blob/eb05219c27663835ce927c7bf97cf1274c07cddb/docs/plans/replanning-possible-diffs/experimets/cards/P51-translation-context.md), [P57](https://github.com/lubochka/llm_mvp_core/blob/eb05219c27663835ce927c7bf97cf1274c07cddb/docs/plans/replanning-possible-diffs/experimets/cards/P57-semantic-measurement.md), [P02](https://github.com/lubochka/llm_mvp_core/blob/eb05219c27663835ce927c7bf97cf1274c07cddb/docs/plans/replanning-possible-diffs/experimets/cards/P02-warm-base.md):

1. У каждой есть полезные критерии A/B, domain profiles и заключительный **обобщённый prompt** вида «выбери PNN, один подслучай и профиль, сохрани hashes». Это архитектурно ценный **design**, но сам по себе **не полный исполнимый паспорт** по последней методике 01: в теле выбранных P02/P51/P57/P125 нет буквального полного исходного поручения, заранее закреплённой роли/идентификатора модели исполнителя и reviewer, точных файлов TRAIN/EXAM вместе с SHA и содержимым, поимённо подгружаемых skills, полного human approval версии. Эти детали местами есть в **соседних small probes и saved receipts**, однако самоисполняемость конкретной карточки без выбора источников пока не подтверждена.
2. Часть P-карточек «Прямые источники» использует **абсолютные Windows-пути** `C:/Users/lubao/Documents/...` или `C:/Projects/llm_mvp_core/...`. Такие относительные к авторскому компьютеру ссылки в GitHub не являются переносимым воспроизводимым первоисточником. До approval заменить (ТОЛЬКО в shadow packet или будущей разрешенной версии, защищённый файл не трогать) их pinned HTTPS repo URL/commit/path/source SHA. Не считать число ссылок доказательством фактического чтения и проверки источника.
3. Нельзя переносить разрешение «P125 запускали 18 октября» на **новое** упражнение или «G55 был когда-то разрешён» на новую серию. У `03-translation.md` отзыв G55 явный. Новые N58 карточки помечены `PENDING` и содержат будущие промпты в теле; они не активные команды.
4. До/после разрешено сравнивать **только на одной frozen panel EXAM**, причём считать и предметную точность, и coverage/abstain/critical errors. Заменять после обучения метрику на coverage, while before was measured accuracy, **невалидно**. Read-only offline пересчёт verdict — это улучшение инструмента, не улучшение обученности. 2 урока / 4 EXAM — дешевый различающий пилот, не статистическая гарантия.
5. Статус каждого подслучая должен быть из `NOT_DESIGNED / DESIGN_ONLY / SOURCE_CONFIRMED / COMPONENT_NATIVE / LEARN_NATIVE / USER_FLOW_NATIVE / COLD_VERIFIED / CONFLICT / NOT_RECONSTRUCTABLE / INAPPLICABLE`, а не один PASS. Для каждого указывать реальную model identity, recipient, baseline, data hashes, one factor, controls, output reason, model/Unit/Flow depth, memory/time/effort.

## 4. Незаполненная часть требования «все детали»

При ограничении READ_ONLY защищённого каталога и текущем частичном прочтении **невозможно добросовестно выдать ALL_FOUND_DETAILS_COVERED**: 125 карточек не равны всему рекурсивному RAG, исторические ветки не прочитаны полностью и нет единого machine-readable crosswalk с текущим `possibleDifs` HEAD до каждого PNN.subcase и каждого original experiment source hash.

**При следующем авторизованном пакетном аудите (не автоматически в этой сессии)**: собрать file manifest *рекурсивно* и hash каждой source и эксперимента; из каждого hypothesis извлечь precise code contract и актуальность HEAD; нормализовать causal claim, а не имя файла; для всех 470 строк создать соответствие `claim→protected P.subcase→full self-contained passport→native result→domain-specific baseline/control→independent reviewer verdict`; незамкнутые связи классифицировать MISSING_NOT_DUPLICATED и **создать shadow packet только в possibleDifs**. Отдельно пройти документы из родительских и соседних направлений repo, не делать вид, что snapshot закрывает все RAG links.
