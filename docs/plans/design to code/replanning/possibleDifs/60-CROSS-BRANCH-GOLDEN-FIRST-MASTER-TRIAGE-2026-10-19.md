## Новые N60 исследования и почему они отдельны
[N60-B composite hypotheses](60-COMPOSITE-CAUSAL-HYPOTHESES-VERIFIER-PHRASE-SKILL-DRIFT-2026-10-19.md) связывает исходники неверного negative Verifier lesson с реально выученным rule и связывает полезный phrase learning с verified accepted edge errors. [N60-C microcards](60-TWO-LEARNING-MICROEXPERIMENT-CARDS-AND-PROMPTS-2026-10-19.md) задаёт две маленькие альтернативы обучения только в том же настоящем learner/caller, никакого абстрактного posthoc semantic gate. [N60-A protected cards check](60-INDEPENDENT-125-CARD-COMPLIANCE-AND-VALIDITY-2026-10-19.md) подтверждает 125 карточек по текстовому правилу, но не 470 подслучаев научно.

**Приоритет:** P0 восстановить actual donor learned state/owner для задач, где уже доказано полезное изменение (например восьмиурочный Translator; Orchestration v1 прежде чем его отбросить); P1 выяснить точный source→DPO loss текущих Wiki domains; P2 не увеличивать RP01 500-step/Windows gates пока 2–8-lesson microlearning с реальным ordinary output не отличит недостаточную языковую базу от отсутствующего learned Unit bridge.

**Обязательный verdict:** для каждой новой гипотезы SOURCE_VERIFIED vs HISTORICAL_RECEIPT vs CAUSAL_NATIVE_MEASURED vs UNPROVEN/NOT_APPLICABLE. Любое измеренное улучшение полезной оси в заданной теме — успех этой оси, хотя иные оси могут деградировать. Самостоятельный cold/score-only без реального обновления не ставить в learning queue и не тратить токены; весь core protected остаётся неизменным.
