**Основные результаты:** структура маршрутов согласована; 50 записей нельзя называть 50 готовыми экспериментами. Полезный показатель не отвергается из-за другой регрессии: N60-E1 меньше ошибочно отвергает правильный перевод, но больше ошибочно принимает неправильный. Неполные N63 цели не закрываются исходным 0→0; позднейшие probes содержат частичное удержание с регрессиями и ограничениями происхождения. WIKI-MARGIN постоянного ответа не показывает различения входов.

Наличие обязательного текста во всех 188 документах не удостоверяет каждую постановку или поведение будущего исполнителя. Здесь полностью проверена структура, адресно — смысл указанных рецептов, подробно — сохранённые показатели. Полный смысловой аудит всех 171 карточек не заявляется.
