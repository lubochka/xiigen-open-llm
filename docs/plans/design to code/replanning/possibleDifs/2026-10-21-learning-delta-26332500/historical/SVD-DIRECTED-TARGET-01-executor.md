## Единственный фактор, данные и учебный gate

A читает source·source, B — source·target. Native PPMI, vocab500, rank30, PowerIters10, Random42, deflation и tie-breaking одинаковы. Source factors A/B должны совпадать. Дополнительный массив target честно учитывать в памяти B; диагностику измерять отдельно. Не чинить одновременно clamp, tokenizer, нормализацию, self-mask, rank или smoothing.

Одна тема — оркестрация, ID0 receive,1 validate,2 persist,3 wait_input,4 wait_result. TRAIN-before: 300 троек +300 четвёрок (600); after: before +400 повторов [0,1,2]+300 троек+300 четвёрок (2400). EXAM строго пять пар [0→1,1→2,2→0,3→3,4→4], одинаковых до/после. Один self-loop даёт нулевую PPMI, поэтому оба before-контроля обязательны.

Четыре native SVD fit и два bigram fit, 20 A/B query +10 bigram query. Оба before self-контроля в каждом плече должны иметь правильные ответы из положительных counts/PPMI. Постоянный ответ0 даёт аналитические 1/5 (directed1/3, self0/2), его показать отдельно. After хотя бы одно A/B должно приобрести новый правильный directed ответ; иначе учебная цель OPEN. 0→0 правильных невалидно. Matrix reconstruction/асимметрия объясняют механизм, но без обучения не являются полезным учебным опытом. Нормы Фробениуса считать после fit/eval из saved factors B при доказанном source-parity, без дополнительного fit и без бесплатного target-массива в A.

Любое измеренное улучшение полезной метрики — успех по этой оси и теме, точность расти не обязана; все регрессии показать рядом. Ресурсный успех на уже обученном состоянии сохранить отдельно, даже если directed-learning вопрос остался OPEN. Для времени сохранить наблюдаемую полезную дельту, устойчивость/причинность отдельно неизвестны. Старый +5% accuracy/ABANDON не применять.
