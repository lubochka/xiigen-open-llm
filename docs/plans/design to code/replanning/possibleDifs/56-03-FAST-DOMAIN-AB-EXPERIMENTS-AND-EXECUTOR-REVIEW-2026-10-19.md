## Общее правило для всех карточек

Опираться на [защищённую методику малого опыта](https://github.com/lubochka/llm_mvp_core/blob/eb05219c27663835ce927c7bf97cf1274c07cddb/docs/plans/replanning-possible-diffs/experimets/2026-10-19-small-learning-probes/01-method-and-report.md), [измерения](https://github.com/lubochka/llm_mvp_core/blob/eb05219c27663835ce927c7bf97cf1274c07cddb/docs/plans/replanning-possible-diffs/experimets/03-metrics-and-reporting.md), [предметные профили](https://github.com/lubochka/llm_mvp_core/blob/eb05219c27663835ce927c7bf97cf1274c07cddb/docs/plans/replanning-possible-diffs/85-domain-protocols.md). Не заменять настоящие outputs toy/mock/proxy. Группа **A0/A1** — control before/after, **B0/B1** — intervention before/after. Default **2 учебных примера + 4 новых экзамена** (не обязательная квота эффективности), при необходимом доказательстве вернуть frozen 24-case P125 как дополнительную **отдельную** панель. Единственный фактор и фиксированные TRAIN/TEST, tokenizer, seed, optimizer, learned state, legal authority, rubric, consumer. Обязательное report: correct/4 (или n) до/после для обоих плеч, errors per case, quality/coverage/retention, latency+time per actual update, RAM/VRAM, checkpoint size, total/trainable tensors+layers или N/A, executed Unit/Flow depth, confidence, stop/admission, version/SHA. Не смешивать improvement in scorer с learner improvement. Если updates=0, пометить **CONTROL/MEASUREMENT**, не \`learning\`. Exact surface equality vs independent semantic answer — два показателя, не один.

**Порядок не привязан к Windows CI:** сначала restore исторического положительного recipient и 2+4 native controlled case; расширять только при обнаруженном сигнале и конкретной неопределённости. Не запускать многократно full 500 DPO и Windows workflow в роли gate проверки нового learning-law. FAIL/error/checkpoint blocked — сохранить как измеренный блокер, не подменять пустым B0 и не менять gold.

## EXP N56-01 — EN→RU: positive Executor memory и phrase-mapping contribution [M / U]

**Источник:** сохранённые [P125 native receipts](https://github.com/lubochka/llm_mvp_core/blob/eb05219c27663835ce927c7bf97cf1274c07cddb/docs/plans/replanning-possible-diffs/experimets/results/2026-10-18/P125-enru-memory-01/report.md) и [ingress native result](https://github.com/lubochka/llm_mvp_core/blob/eb05219c27663835ce927c7bf97cf1274c07cddb/docs/plans/replanning-possible-diffs/experimets/results/2026-10-18/translation-memory-ingress-01/report.md). **Уже выполненный исторический** 0/24→19/24 и 11/24→19/24 — benchmark, **не новый результат**.

**Получатель:** конкретный \`TranslationMachine.TrainStructuredBatchAsync → ExecutorUnit.TrainOnExample → TrainedTranslationAdapter → TranslationRoutingFlow\`. **A:** стандартный accepted lesson без дополнительных \`PhraseMappings\`; **B:** идентичный lesson + только разрешённые исходным schema \`PhraseMappings\` (WordMappings, topology, datasets, flow остаются теми же). 2 admitted contrast урока: \`validate the file → проверь файл\`, \`delete the cache → удали кэш\`; точные structured JSON брать из принятого native P125 fixture, не выдумывать поля. **4 EXAM:** \`validate the cache\`, \`delete the file\`, \`do not delete the file\`, \`validate a file\`; первые два — композиция, третий — **negation safety**, четвёртый — near/article. Source-disjoint coverage ≠ новая грамматическая family; не делать обещаний об идеальном результате.

**До/после:** четыре состояния одного freshly duplicated checkpoint; результаты каждого EXAM, selected \`-exact-source/-phrase-map/-wordmap/-knn/-fallback\` и итоговый adapter после verifier. Отдельно post-train cold restore 4 raw outputs и 24-case if feasible. **Failure:** B меняет только phrase map, но не получает quality gain; отсутствие изменений или ложный accept \`do not\` — честный outcome, не адаптация gold. **Почему полезно:** у системы был реальный memory gain, он является быстрым положительным якорем.

## EXP N56-02 — EN→RU: Translation k5 first-eligible и раннее перехватывание [C/U → M conditional]

**Предметная цель:** перевод, не абстрактное kNN; **владелец:** \`ExecutorUnit.TrySelectKnnCandidate\` и \`TrainedTranslationAdapter\`, а не generic \`KnnLogicalUnit\`. **Гипотеза:** полезная функция kNN не влияет на ordinary answer, если раньше сработала word/phrase map; при вызове kNN первый подходящий из пяти может быть семантически хуже других. Источники [N56-01](56-01-TRANSLATION-KNN-CONSUMER-NEW-CAUSAL-SEAMS-2026-10-19.md); protected P107 generic k3 — лишь общий принцип.

**A:** current frozen index + current selector. **B:** тот же index, набор top5, source-law, verifier и *только* альтернативный законный selection predicate, разработанный на заранее утверждённых без TEST-gold semantic obligations (polarity, actor, object). Не добавлять новые уроки одновременно. 4 EXAM: \`the box is open\`, \`the box is not open\`, \`the door is closed\`, \`the door is not closed\`; валидны только если frozen index содержит контрастные реально обученные кандидаты и фактический route находит хотя бы два допустимых предложения. Отдельные POS word-order cases — лишь при реально выученном vocabulary. **A0/A1/B0/B1:** без обучения идентичны внутри каждого плеча, запись \`updates=0\`; если потребуется эффект от 2 новых lessons — **вторая** изолированная M-карточка на двух clones, не этот selector-only опыт. \`k=5\` есть реальный запрос, не всегда пять результатов.

**Контроли:** все пять соседей равноценны; first eligible единственный; exact/wordmap перехват (mark NOT_REACHABLE); novelty same-source family. **Метрика:** real final semantic accuracy and wrong-accepted/coverage, rank/score/provenance selected neighbour, latency, memory. **GOOD:** «кандидат изменился у действительного kNN call, correct/4 1→2, без других правок». **BAD:** «больше пяти соседей/больше score — значит модель научилась переводить» или «kNN неверен, потому что RP01 Student C# 0/3».

## Review rubric: reject bad experiments, not real negative results

| Gate | PASS | NEEDS_FIX |
|---|---|---|
| Source and positive gold | Pinned donor/recipient/checkpoint and real measured historical evidence where claimed | Branch exists or PASS label presented as proof of learned ordinary answers |
| Experiment isolation | One independent factor, paired A0/A1/B0/B1, same EXAM and heldout source family, explicit negative and edge | Changed tokenizer+LoRA+kNN+rubric together or samples tailored after seeing outcome |
| Domain and recipient | Topic, task/profile, actual Unit/Flow/neural and ordinary consumer named separately | C# AST rules generalized to RU verbs; kNN proxy declared translation learning |
| Correct measurement | Four frozen raw answers per arm, real updates, quality/coverage/critical errors, time and RAM, layers/depth, checkpoint | Margin/weights/CI PASS substituted for semantic correctness; percentages without denominators |
| Evidence honesty | Source/measured/design/hypothesis/missing consumer labeled, failing cases preserved | Native run fabricated from JS or mock; failure silently repaired by weakening gold |
| Publication scope | New docs + later sanctioned receipts only in planning \`possibleDifs\`; protected core untouched | Any write to \`docs/plans/replanning-possible-diffs/**\` or retroactive edit of original run |
