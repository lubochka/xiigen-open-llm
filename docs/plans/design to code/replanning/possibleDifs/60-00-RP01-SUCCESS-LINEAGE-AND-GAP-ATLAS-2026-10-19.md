## 0. Значения слов

**Домен** = предметная тема обучения (перевод, программирование, документация, оркестрация). EN→RU = профиль перевода, C# AST = признаки задачи программирования, LoRA/kNN = механизм, Unit/Flow = получатель/потребитель, не домены. Нельзя смешивать успешное изменение обучаемой памяти с обучением q/v LoRA Student. Использован канонический [human-communication-GLOSSARY](https://github.com/lubochka/llm_mvp_core/blob/f50b710a5eaa6a8f0468b07d5b2510342a1de7ba/docs/skills/human-communication-GLOSSARY.md).

**M** — измеренный historical/native результат на конкретной панели; **C** — прямая цитата реализации/сигнатура; **H** — гипотеза для причинной A/B; **X** — невалидная подмена процесса обучения frozen inference-only проверкой. Утверждать «причину деградации RP01 доказали» можно лишь при native A/B на реальном Student / названной memory Unit с одинаковой обучающей работой и end-user outputs. Измеренная польза по ЛЮБОЙ полезной метрике считается локальным успехом; не обязательно accuracy; другие ухудшения показываются обязательно.

## 2. Подтверждённая исходниками цепь current memory learning

Current [TranslationMachine.TrainStructuredBatchAsync](https://github.com/lubochka/llm_mvp_core/blob/f50b710a5eaa6a8f0468b07d5b2510342a1de7ba/27.TranslationDomain/TranslationMachine.cs#L88-L147) → unit-id dispatch и TrainOnExample → [ExecutorUnit.TrainOnExample](https://github.com/lubochka/llm_mvp_core/blob/f50b710a5eaa6a8f0468b07d5b2510342a1de7ba/27.TranslationDomain/TranslationTrainedUnits.cs#L396-L464) сохраняет exact/phrase/word/KNN → [TrainedTranslationAdapter](https://github.com/lubochka/llm_mvp_core/blob/f50b710a5eaa6a8f0468b07d5b2510342a1de7ba/27.TranslationDomain/TranslationDirectionAdapters.cs#L114-L140) читает семантическую Unit и Executor и вызывает verifier → GetOrchestratorAsync().RunAsync ordinary output. Этот путь имеет положительный исторический native proof P125.

Отдельный [generic KnnLogicalUnit](https://github.com/lubochka/llm_mvp_core/blob/f50b710a5eaa6a8f0468b07d5b2510342a1de7ba/21.AgentInfrastructure/Logical/KnnLogicalUnit.cs) обучает BPE320 + hashed bag / predicates, HNSW, default k=3 и возвращает nearest top1; он НЕ равен Roslyn E09 AST kNN. Отдельный [DpoTrainer](https://github.com/lubochka/llm_mvp_core/blob/f50b710a5eaa6a8f0468b07d5b2510342a1de7ba/11.DPO/DpoTrainer.cs) оптимизирует neural модель; изменение весов НЕ показывает, что выученный закон дошёл до Flow. Для объединения нужен конкретный, наблюдаемый caller/trainer/consumer bridge — не предположение по одинаковому названию DPO.

## 4. Отдельное неприкосновенное правило

Ни native implementation, ни training runs, ни файлы protected core не менялись. Документы описывают наблюдаемую source связь, но НЕ утверждают достижение качества или готовность к запуску без отдельного личного APPROVED конкретной версии карточки. Frozen serving-only, scorer-only, zero-train probes получают X=OUT_OF_LEARNING_SCOPE и не выполняются в рамках этой задачи. Любой изменённый полезный показатель — локальный успех (скорость, цена, RAM, точность, удержание, число уроков, покрытие и пр.), одновременно фиксируются любые ухудшения остальных.
