### N16-03 · P0 · Операторы C#/SQL исчезают из exact-memory key

[`NormalizeMapKey`](https://github.com/lubochka/llm_mvp_core/blob/83590a462b2f8aedc9d3ab4cb775193eb9c25ce5/27.TranslationDomain/TranslationTrainedUnits.cs#L1008-L1024) оставляет только буквенно-цифровые символы, `_`, `$` и whitespace. Прямое следствие формулы: `"x != y"`, `"x == y"`, `"x < y"` и `"x > y"` **все становятся `"x y"`**; `"can't"` становится `"cant"`. Это не потеря текста во всём BPE — это коллизия адреса *обучаемой exact memory*. Две законные противоположные `chosen` стороны не могут оставаться самостоятельными записями. **Проверить причинность:** [MICRO-16: operator identity](16-MICRO-OPERATOR-IDENTITY-CAUSAL-EXPERIMENT-2026-10-16.md): одинаковые Units/training records/decoder; меняется только exact keying, оценка применения выученных знаний на matched heldout. Без большого Windows CI.
