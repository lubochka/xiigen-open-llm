# Проверка дополнения перед публикацией

## Что проверено независимо

Три направления исследования выполнялись отдельно: входные данные/units/restore; kNN/соседние ветки/replay; паспорта и сохранённые измерения. Затем рецепты INGRESS-LENGTH-01 и N63-AR-CAP проверены другим направлением по исходным публичным API. Корневые выводы отдельно сверены с повторным расчётом raw. Это source/document review, без нового native запуска и без заявления формальной аттестации внешней моделью.

| Найденное при review | Что исправлено в публикуемой версии |
|---|---|
| INGRESS: дополнительный negative control противоречил условиям Program и создавал новый B0 | Он исключён из назначенного бюджета. Остаётся одна A/B попытка, максимум два updates; отдельный контроль потребует собственного режима, не изменения fixture на месте |
| INGRESS: переданный владельцем CARD_DIR оставлял лишний выбор пути | Полная fixture встроена в shell heredoc; её содержимое совпадает с приложенным JSON. Исходное место исполнения и output назначены |
| INGRESS: описанное чтение status и attempt02 расходились с реальными output/командами | Назван `results/run01/status.json`, команды создания применяются только к отсутствующему каталогу, завершённый run читается без повторного Train, конфликт не перезаписывает прежнее |
| INGRESS: failure после изменения параметров мог записать нулевое количество обученных targets | Сохранены фактический optimizer step и hashes; неизвестные счётчики становятся null/UNKNOWN_AFTER_PARTIAL_FAILURE. Ошибка checkpoint не выдаётся за отсутствие обучения |
| N63: full checkpoint сам не создаёт LoRA topology | Задан порядок: fresh model → ApplySeeded на свежих slots → LoadCheckpoint → new AdamW → portable state import. Cold measurement использует ту же последовательность без ненужного optimizer import |
| N63: перенос moments не равен default per-call lifecycle IncrementalTrainer | Явно назван общий исследовательский контроль; перенос эффекта на reset-moments pipeline не заявляется |
| N63: process peak нельзя сравнивать как независимую память arms | PeakWorkingSet назван cumulative whole-process показателем; отсутствует вывод per-arm RAM gain |
| Корневое правило cost-only могло снова исключить допустимый trained reader | Стоимость обучения требует update; стоимость использования результата требует настоящего consumer обученного state. Декоративные новые уроки не назначаются |
| N-KU: знак timing contrast меняется в обратном порядке | Оставлено наблюдение; причинность JIT/порядка и устойчивый speedup не объявлены |
| Новизна могла прозвучать абсолютной | Указана граница проверенного каталога, соседние общие темы и условная достижимость; старые weighting/replay-admission идеи не названы новыми |

Проверены публичные `IncrementalTrainer`, session factory, `ISessionStorage`, `ApplySeeded`, Save/LoadCheckpoint, `ExportPortableState`/`TryImportPortableState` и stable AdamW bindings. В external host не используется internal CaptureState.Step. Это чтение API; без .NET-компиляции отсутствует основание присваивать READY.

## Техническая проверка документов

До публикации разобраны все JSON, проверены локальные ссылки, парность Markdown code fences и совпадение встроенной ingress fixture с отдельным JSON. Проверены границы 247 pinned line anchors по доступным исходникам. Такая проверка ловит неверный адрес/номер строки и не заменяет смысловое чтение, выполненное для основных причинных цепей и шести пакетов measured evidence.

Машинный каталог сохраняет 130 записей карточек и 470 P.n. Исторические 128 строк Markdown-таблицы дополнены отдельным late review двух N62-карточек; итоговое число не выдано за 130 готовых проектов. Подсчёт remaining blanket exclusions после late update — 21 карточка/60 мест; три уже исправленных upstream карточки отмечены отдельно.

Повторное чтение protected cache подтвердило Git blob identity 908 файлов базового снимка. LFS pointers не называются полученными payloads. Поздний источник и исключённый из доказательства build.log описаны в [границах источников](02-SOURCES-SKILLS-AND-LIMITS.md). Итоговые hashes публикуемых файлов перечислены в [DELIVERY-MANIFEST.json](DELIVERY-MANIFEST.json); manifest не включает собственный hash.
