## Как проверить этот аудит без новых экспериментов

`measurement-recheck.json` содержит source raw/gold/scoresSHA256, совпадение 24 IDs/order, каждую optimizer step, training loss arrays, unchanged weights/reference и повторно вычисленные counts. Чистая функция assess из retained scorer выполнялась только над существующими raw; никакие Train/Generate/loader не запускались. Для N-KU бинарная функция Correct воспроизведена отдельно над 4state-группами. Отсутствующие LFS summary не заменены придуманными числами: использованы actual raw. Это проверка корректности уже представленных измерений, а не новый самостоятельный proxy-опыт.

Что не подтверждено этим проходом: повторяемость native runtime на текущей машине; байтовое наличие всех прошлых DLL/checkpoints вне Git; statistical generalization; все остальные retained эксперименты; full E2E adoption. Наблюдения не дают автоматического разрешения переносить fixes в production.
