## Что считается доказательством

- **Source-confirmed:** свойство конкретного метода, прочитанного на закреплённой версии. Например, allocation внутри token-loop или marker без A/B identity.
- **Historical measured:** сохранённый native report/JSON с результатом. В этом проходе он прочитан, но не повторён.
- **Hypothesis:** возможное влияние конкретного source-различия на named learning/consumption path. R1/R2 пока именно такие гипотезы.
- **Preparation:** недостающий контракт/host/data materialization. N03 — подготовка корректного сравнения, не самостоятельное доказательство роста качества.
- **Open link:** source→learner либо learned state→reader пока не установлен в заявленном объёме. Это повод изучить его, а не автоматически объявить неприменимость.

Статус строки README, имя метода Train, reference match, hash equality или количество файлов не подменяют доказанное приобретение навыка.

## Журнал существенных решений

1. Зафиксированы planning/core snapshots, каталог 555 источников, текущие code paths и requested skill stack. GitHub-источники читались через доступный connector; репозитории не клонировались с подменой авторизации.
2. После обнаружения применимого ограничения «один активный worker» остальные исследовательские worker были остановлены; дальнейший независимый аудит выполнялся последовательно. Отчёт не выдаёт первоначальное назначение за runtime attestation модели.
3. Отдельно подтверждены первичные данные translation ingress/P125/P25, E25/E22 и RP01 EN→RU. Положительные и отрицательные оси сохранены; новые измерения не приписаны этому проходу.
4. По исходникам выявлены R1/R2 и N03. Не проводились standalone benchmarks или реализация патчей.
5. Во время проверки core перешёл на de4ef. Аудит пересобран: выводы об общей блокировке и отсутствии E1/E2 отозваны как устаревшие;152 изменённых документа перечитаны/сопоставлены по дельте,249 bytes проверены.
6. На de4 найдены 13 адресных оговорок/исторических записей. Перед публикацией обнаружена новая дельта a822,146 документов получены заново,249/249 hashes проверены; реестры 125/470/24, навигация 555 и novelty-поиск пересчитаны. Статус каждой прежней оговорки актуализирован, исправленные строки не объявляются оставшимся дефектом. Новые промпты переведены на faithful experimental copy; защищённая папка без наших изменений.
7. Перед публикацией planning продвинулся доfb9: оба новых пакета сопоставлены,24 Markdown получены и проверены. N03 признан общим с пакетом61; R1/R2 остались отдельными факторами. Уточнено, что StepVector loss/margin — pre-update, а final loss без отдельного Evaluate не измерена.
8. Подготовлены документы в requested possibleDifs, все 125/470 таблицы и поисковый ledger; точный кандидат направлен на отдельное ревью. Итоговое ревью и фактический статус публикации фиксируются отдельно, без предположения успеха заранее.

## Ограничения

Не выполнены новые native runs, вызовы Student/teacher/judge, сборки, tests, benchmarks, изменение весов, продукта или защищённых core docs. Не заявляется полная семантическая аттестация 470 причинных цепей либо полный аудит всего кода и истории 15 ветвей. Точный исторический move «матрица→kNN» не идентифицирован; E07/E09/E22 остаются конкретными уликами с разными представлениями и панелями.

Результат этого прохода — source-backed дополнения, актуальная сверка покрытий/противоречий и малые проверяемые проекты. Любое будущее измеренное полезное улучшение оценивается по своей метрике и предметной теме вместе с ухудшениями; отсутствие нового runtime здесь не превращается в нулевой эффект гипотез.
