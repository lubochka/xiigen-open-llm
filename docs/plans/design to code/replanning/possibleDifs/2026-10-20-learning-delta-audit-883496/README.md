# RP01: первичные результаты, текущие учебные цепи и новое BPE-отличие

**20 октября 2026. Core883496; публикация согласована со свежим planning9d311. NEXT — №05 N62-R2. Сейчас только документация.**

Пакет сохраняет полезные результаты обучения, уточняет их ограничения, сопоставляет22 запрошенные оси с кодом и экспериментами и добавляет **одну новую отдельную гипотезу BPE**. Второй независимо разработанный SKNN-рецепт признан дубликатом уже опубликованного AST и не создаёт повторного запуска. Защищённый core-каталог, продуктовый код и старые эксперименты не изменяются.

## Основные результаты

1. **Исходный RP01 реально обучал LoRA.** Первичные C#/ENRU сводки фиксируют по50 updates, изменение16 adapter tensors при39 неизменных base tensors и восстановление полного состояния. Средний preference margin немного вырос, но собственные ответы остались0/3 и0/4; ухудшения по11/25 и9/20 случаям сохранены. [16: первичные итоги](16-RP01-primary-readback.md).
2. **Четыре полезных результата20 октября сохранены как кандидаты.** N-KU улучшил учебную метку с регрессией нужного совета; frozen transpose/BPE уменьшили выделения памяти внутри обучения; N62-R1 имеет наблюдаемую экономию времени ApplyOptimizer и небольшую экономию выделений при GC0/1/2 по+1. Один порядок A→B не доказывает устойчивый причинный множитель. [02: результаты и кандидаты](02-learning-results-and-candidates.md), [03: N62 raw](03-N62-R1-measurement-erratum.md).
3. **Текущий DPO→Units имеет разные реальные маршруты.** Structured memory учит три Unit, нейронный handoff учит исходную пару. Положительные annotations могут находиться в rejected намеренно; происхождение поля само по себе не доказывает ошибку. [17: код, поля и потребители](17-current-dpo-unit-transfer.md).
4. **Новая гипотеза BPE-REALIZED** отдельно проверяет выбор merge по числу реально исполнимых неперекрывающихся замен. Она меняет цель выбора и не выдаётся за ошибку стандартного BPE. В fixture ожидается выигрыш lambda-профиля и ухудшение комментариев/общего EXAM; это ожидание, не измеренный успех. [08: карточка](08-BPE-REALIZED-MERGE-COUNT-01.md), [09: промпт](09-BPE-REALIZED-MERGE-COUNT-01-executor-prompt.md).
5. **Полный protected Markdown-корпус проверен по хэшам334/334.** Структурно проверены153 карточки;125 P-семейств и470 подслучаев не равны470 готовым hosts. Конфликты и пять дополнений со skills указаны адресно. После обновления HEAD проверены20 новых planning Markdown; SKNN признан дубликатом AST, очередь сохраняет ROPE/AST/NG01. [04: аудит](04-coverage-and-card-conflicts.md), [18: согласование](18-concurrent-reconciliation.md).
