## Приоритеты и точные переходы

1. **P0 — разблокирование обучения:** PARENT-ADOPTION-01. Это техническое принятие/восстановление H16 parent, а не доказательство двух полных правильных ответов.
2. **P1 — измеримость и конфликты:** N63-INGRESS-LENGTH-LEARNED-01 сохраняет частичную token-цель. Затем current маршрут приводит к открытой N63C постановке: исправить назначенный дизайн, не запускать consumed entry. Приоритетный дополнительный вопрос — [несовпадающий обучающий и измерительный carrier N63C](09-n63c-framing.md). Это известная P07-семья, без нового ID.
3. **P2 — прямые учебные факторы и пользовательские обновления:** прежние №13–45 в исходном относительном порядке. У 15 прежних unqualified-рецептов теперь обязательна квалификация before/набора/бюджета; новый заголовок не делает старые два/четыре cold updates достаточными.
4. **P2, уже опубликованные новые cost-факторы:** canonical SILU-SIGMOID-REUSE-01 → HNSW-QUERY-NORM-REUSE-01. Их исходные авторские спецификации сохраняются. Наш SiLU alias не создаёт SD01 или второго опыта.
5. **P3 — чтение выученного результата:** исходные №46 IDENTITY-M1-01 → №47 KN-ROUTER-LEARNED-KEY-01 → новый POS-QUERY-SET-ONCE-01 → END. POS связан с настоящим Train, но его фактор находится в trained Predict, поэтому он последний.

При одном назначенном ID NEXT=END. Current контракт N63C требует ремонта незакрытой цели; нельзя автоматически пропустить её только потому, что прежняя попытка невалидна. Прямой NEXT пользователя или разрешённая независимая работа определяют следующий шаг. **По NEXT немедленно оставить прошлые report/hash/review/Git/build/retry; по STOP остановиться.** Старые артефакты сохраняются. Неизвестный исход не разрешает повтор, новый каталог либо увеличение deadline.
