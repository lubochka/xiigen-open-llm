## Domain-dependent kNN study, not a universal magic function
For each domain freeze permitted features, distance (cosine or domain-specific structured metric if verified), fusion with lexical BM25 and query-conditioned admissibility; adaptive `k(x, domain, density, uncertainty, PC_budget)` is a *hypothesis*. Measure actual neighborhood consumption (not index k) and route gain against k=1/static-k, label-drift, no-memory and vector-space-mismatch arms. Value is improvement of final lawful solution per full-PC cost, not higher isolated similarity. Claim learned weights only if parameters changed and the real consumer used them.

**Target 95%** from WorkLeft remains an owner-defined domain reference goal, not a per-task universal acceptance gate or current measurement.
