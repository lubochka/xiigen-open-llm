## Hybrid deterministic + learnable algorithm details

**Non-negotiable deterministic law / Arbiter:** source/license/tenant/permissions, output type and token/index version, C# AST symbol/scope/type/nullable, Angular version, SQL NULL three-valued logic/dialect, grammatical role/gender/co-reference, DOM reading order, RTL, breakpoint and accessible CTA, privacy and side-effects; law rejection/abstention is NOT trainable away.

**Vector tokenization:** domain passport includes semantic field type, grammar or syntactic role, tree/geometry or AST relations, normalized values, provenance, law/encoder/projection/index versions, stable InputRef and OutputRef, source family and tenant rights. Learner/LoRA parameter update does not itself change tokenizer or guarantee meaningful vector coordinate; changed encoder/projection requires explicit index migration and matched ablation.

**Law-conditioned adaptive kNN:** build valid candidate pool using domain/rights/type/version first, then actually CONSUME multiple selected neighbors; compare exact top1, law-filtered multi, reranked dynamic k(q)=f(domain, density, ambiguity, score_margin, hard_conflicts, PC_budget), and ANN separately. Cosine-nearest text is unsafe if C# signatures, object grammatical gender, SQL truth or mobile layout law disagrees. If Search(q,k) yields 5 and consumer uses hits[0], there is no demonstrated multi-neighbor benefit.

**ILearningUnit:** domain+vector structure+typed many-to-many InputRefs↔OutputRefs, learnable correct candidate association when real reader exists. **ILearningFlow:** typed corrections among Unit outputs/inputs, different credit owner. **ILearningOrchestrator:** bounded asynchronous fan-out/fan-in/cancel/side effects/order/branch budget, learned lawful routing only with mutable state. **ILearningDynamicGraph:** versioned higher-order reusable pattern relationships, test novel compound tasks with lower components frozen. **ILearningMachine/Student:** existing sole optimizer owner; response-DPO objective, kNN ranker, Flow edges and Graph route optimization must not be conflated.
