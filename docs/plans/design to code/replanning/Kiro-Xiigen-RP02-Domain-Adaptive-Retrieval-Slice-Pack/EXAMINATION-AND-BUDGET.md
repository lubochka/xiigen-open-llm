# Scientific examination of RP02 — learning utility, laws, path choice and PC efficiency

## Pre-registration and roles of evidence

Declare experiment id, actual model/memory/index/consumer refs, source-family partition, legal eligibility, law rubrics, treatment factor, baseline, seeds and matched budget BEFORE seeing treatment outcomes. Keep training curriculum separate from development tuning and inaccessible sealed confirmation. If a previously sealed panel influenced fixes it becomes development history, not a fresh untouched exam. No numeric N/time/confidence may be fabricated; unknown is NOT_MEASURED.

Define baselines B0 fixed current production pipeline; B1 same pipeline plus lawful exact eligible candidates; B2 B1 with typed all-neighbor use; L1 B2 with learned reranker; K1 L1 with adaptive k; V1 B2 with altered representation (re-retrieve exact in its own geometry); A1 exact vs ANN with same corpus and coordinate. Compare matched source families and same actual consumer; a two-factor interaction only after isolated effects. Do NOT conflate code repair B0→B2 with trained state L0→L1.

## Questions each experiment MUST answer

| Experiment | Frozen factors, intervention | Observable output + falsifier |
|---|---|---|
| E2-DOMAIN | same raw source families, same solver; predicted vs oracle subject with intent/version separately | domain confusion matrix, multi-domain recall, UNKNOWN false confidence, wrong-law routing, abstain utility; cannot claim accuracy from classifier confidence |
| E2-IR | same solver/rights/corpus, typed IR/semantic projection vs preexisting representation; exact search separately in each geometry | critical operator/negation/null collisions, decoded semantic fidelity, downstream law accuracy, index rebuild/PC cost; same vector length/hash is not benefit |
| E2-POOL | same input and index, eligible legal subset vs unfiltered baseline as a diagnostic only; negative/warning retrieval enabled lawfully | rights/law violations, useful warnings and end-task quality; forbidden actions cannot be accepted even if high similarity |
| E2-FUSION | same exact candidate IDs and k; first hit vs typed all-neighbor consumers | more than one hit changes lawful answer/evidence and improves on independent hard cases; IDs listed as evidence only = FAIL |
| E2-RERANK | SAME exact lawful candidate set, scorer fixed vs newly updated θ | ranking inversion attributable to θ, law-valid answer quality, cold-loaded persistence, same data/solver; static weight edit = NOT_LEARNED |
| E2-K | SAME candidate pool/scorer with fixed k vs query-dependent k/radius under same time budget | quality, covered warning types, latency and chosen neighbor role; improvement must survive case families beyond tuning set |
| E2-ANN | SAME corpus/metric/space, exact retrieval vs independent HNSW candidate set | recall vs exact, end-task law error/time/RAM/reindex; NEVER force ANN to use exact returned IDs |
| E2-HYBRID | deterministic-only, optional lawful learned-only, hybrid; identical allowed facts/tools/rights/resource ceiling | user-level correctness, path validity/relative regret across considered lawful alternatives, total time and PC cost, retention; absent learned-only arm limits general superiority claim |
| E2-FEEDBACK | accepted parent, new lawful feedback/bulk, state update vs no-update; same evaluation families under allowed looks | measured per-bulk change, wrong-domain retention, no replay, cold reload; feedback text alone or adapter hash ≠ improved output |

**Mapping quality is independent of solving quality.** Report predicted-domain and oracle-domain gap. Dynamic kNN can benefit from retrieving a negative *warning* but it may not become positive action memory. An unseen family with exact law contradiction is more informative than another easy paraphrase.

## Measures and denominators

Per-item: family_id, subject true/predicted/mixed/OOD, confidence and abstain, intent/version, source_provenance, law rubric, neighbor candidate IDs + roles, vector-space ids, index type, k(q), actual neighbors used, output refs, final arbiter, correct/incorrect/ambiguous, critical law error, wall-time segments, seed, state IDs, reference. Per family: unique family N, law validity, family-averaged accuracy, macro/worst-domain, confusion, abstain specificity, retention. Report uncertainty paired at family level; do not compute deceptive p95 with tiny N. Retention across original domains is mandatory when adopting a learner. Meaningful effect / noise / stopping / rollback tolerances selected prospectively by authorized owner, not after plot.

Total cost counts input classification and domain scan, pair lesson selection when relevant, external Chinese author both final sides, separate CODEX judgment, denied attempts, actual training/reopen, embedding/projection/index reindex and dual-index migration, all model/branches/feedback evaluations, promotion/rollback, cold ordinary result. Report elapsed wall, overlapping vs sequential components, CPU, whole simultaneous process-tree peak RAM/VRAM, disk model+LoRA+optimizer+index+graph+cache+old/new snapshot and growth. Externally hosted calls still count workflow time/cost, not hidden free PC compute. Fit on real PC is an OBSERVED budget envelope, not the word "compact."

## Bulk and final outcomes

Bulk is a time/order window of NEW distinct lawful lessons/feedbacks, not a DPO optimizer batch nor replay of previous pair IDs. Log proposed/admitted/accepted/rejected/applied/rolled-back/unknown identity and provenance. Compare same corrected code parent/no-update/one candidate under current approved policy; a changed code pipeline must be the SAME on both learned and control arms. Every bulk records per-domain/worst/retention and time-to-useful-gain.

Outcomes:
- IMPROVE = prospective law/quality/resource decision rule met on valid independent evidence, with applicable safeguards and permitted review.
- REGRESS = worse than protected baseline or critical law violation, restore accepted state.
- INCONCLUSIVE = comparable observations exist but precision/effect/coverage insufficient, no invented PASS.
- INVALID_EVIDENCE = leakage, differing inputs/models/space/budgets, misplaced oracle, corrupt state, missing origins.
- NOT_MEASURED = no authorized actual experiment. A green unit/Windows test or higher retrieval score does NOT change this.

For all claims separately report PRODUCT_IMPLEMENTED, LEARNED_STATE_UPDATED, CONSUMER_CHANGED, LAW_VALID, INDEPENDENT_IMPROVEMENT, COLD_ADOPTED, PC_FIT, RUNTIME_RELEASE. These labels are not mutually implied.
