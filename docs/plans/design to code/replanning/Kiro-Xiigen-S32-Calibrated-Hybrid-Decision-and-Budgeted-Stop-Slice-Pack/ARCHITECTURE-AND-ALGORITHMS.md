## Novel seam and falsifier
An ordinary real consumer currently *either* combines heterogeneously scaled scores without validated reliability *or* spends extra branches/answers from confidence independent of measured quality. First PROVE or REJECT by method-level trace. S32 may add one minimal versioned, provenance-bearing reliability envelope to the **existing consumer** with separate code grant; if already calibrated, `REUSE_NO_CHANGE`. Do not add calibration algorithm in S32 if RP11 existing owner can provide it.

Hypothesis H32: in at least one held-out lawful domain, calibrated/qualified evidence causes **lower selective wrong-answer risk at a comparable answered fraction, or higher lawful utility under the same whole-PC budget** than the same no-update pipeline with raw scores. Null: hard laws, existing empirical score, existing RP11 or an always-abstain baseline dominate; no S32 code. The hypothesis is NOT satisfied by lower ECE with zero answers, infinite extra branches, or a changed test fixture.

## Why stop/abstain isn't a blanket heuristic
Three legal decisions: `ANSWER` if final admissible + measured risk within domain-scoped tolerance; `GATHER` only when source/rights/time/PC budget and expected marginal utility permit and an alternate legal branch exists; `ABSTAIN_OR_ASK` if unsupported law, insufficient calibration, wrong-domain/unknown subject, unavailable rights or resource limit. Hard veto occurs BEFORE ranking; model confidence can never make forbidden path eligible. If no validated probability, carry `UNKNOWN/UNCOMPARABLE` and use explicit conservative existing fallback.
