## 3. Scoring and uncertainty
- Per-case primary: source-grounded correct/admissible user result or graded expert score with independent rubric. Domain map: macro/multi-label measures, UNKNOWN/MIXED abstain and calibration only for meaningful probabilities. Hard-law violation rate and fatal law guard precede aggregate reward.
- Retrieval: law-relevant positive evidence, warning discrimination, typed hit association, exact/ANN recall; report change in actual downstream answer.
- Path: lawful completion, quality and bounded regret against enumerated feasible alternatives at equal resource cap; successful deterministic-only path remains a valid winner.
- Time: per-operation end-to-end user elapsed, full teacher/CODEX/evaluator/trainer/reindex wait, p50/p95 only for meaningful N; do not normalize away retries.
- Resource: simultaneous process-tree peak RAM/VRAM, CPU/GPU utilization/cost, disk active+reference+trial+optimizer+rollback/index/graph/cache/temp and transfer; cold/warm separately; remote costs known/unknown and failed/uncertain charges.
- Learning by bulks: genuine unique B1/B2/... authorized pairs with persistent consumed IDs, frozen old families and novel families, report per-domain before/after, catastrophic forgetting, worst old domain, cost per newly correct family.
- Group uncertainty by independent source families (e.g., clustered bootstrap if defensible), show N/family support/disagreements. No invented CI or thresholds after observing T.
