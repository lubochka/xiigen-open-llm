# RP18 — scientifically meaningful examination, not coverage inflation

## Preregister one law-distinguishing claim before data are observed

For C# or EN→RU: hypothesis, primary law/source version, representation target, changed trainable state (or `NONE`), actual producer→method→consumer, nearest alternate lawful routes, family-disjoint OP_DEV/CERT, grader, budget/PC, high-risk negative examples, stop rule, release/rollback owner. An unmeasured hypothesis is `NOT_MEASURED`.

## Matched arms, only when applicable

- `D` lawful deterministic source/arbiter-only baseline.
- `R` existing BM25/kNN/lexical or frozen encoder and *real selected* output.
- `F` fixed explicit projection; same domain/eligible corpus/consumer as R.
- `P` separately authorized learned projector (change only its state, keep upstream Student and candidate corpus frozen).
- `L` project-LoRA Student generator change (do **not** relabel it vector projection).
- `H` selected lawful hybrid path with exact same deterministic hard constraints.
- `N` corrected serving pipeline + frozen parent/no update; `U` **same pipeline** + one admitted unique training event. Legacy old-code `O` is a separate diagnostic, **never** used as N in U−N inference.

Do not compare several changed components and attribute gain to LoRA/transposition. For learned geometry vs index, report candidate-pool change separately from same-pool learned reranking. To claim dynamic k advantage, report which multiple neighbors actually reached the typed solver; RP02 owns the modification.

## Measures & statistics

- Law/domain mapping: correct domain, intent, stack, version, UNKNOWN/MIXED; critical-law violation rate, abstain, calibration, semantic feature/exception retention, true typed many→many association accuracy.
- Vector alignment: dimension/basis agreement, decode/roundtrip where intended, index-state compatibility, positive vs hard-negative separation, recall@k and actual final candidate utility. High cosine or reduced bytes alone = **not** learned outcome.
- Solution route: enumerated lawful feasible paths within a stated budget; user-visible correctness/utility, actual route vs best *among observed alternatives* (do not claim global optimal), path regret, Flow corrections, Graph patterns, canceled async branches.
- Learning: exact pair provenance/admission, one allowed gradient or projector update and actual state delta, N→U family effect, old-law and old-domain retention, negative transfer, per-unique-lesson bulk1→bulk2 trend with uncertainty. One lesson ≠ demonstrated continual learning.
- Efficiency: wall/CPU latency p50/p95, prompt+embedding+query+training and reindex time, all branch/model/reference/evaluator/teacher costs **separately tagged**, peak RAM/VRAM (including baseline/rollback state), disk/checkpoint/index footprint, tokens, energy if measurable, throughput per watt/dollar only with real instrumentation. Target PC profile has to be **observed**; hardware goals are not successful run receipts.

Report n per source family; effect size and CI or honest sparse-data uncertainty; missed panels and unstable outcomes; selection bias and leakage checks. Thresholds/design choices locked before CERT, not post-hoc tuned to green. Same compute and law constraints for arms. Independent exam owner RP09; separate CODEX Astra UltraCode review bound to exact final candidate SHA.

## Guard matrix

**Narrow deterministic checks required where relevant:** schema/type, coordinate IDs/dimensions, source and rights, token-codebook roundtrip, exception polarity, no silent truncation, reproducible pointer/hash, rollback/no-repeat, security/tenant, role provenance, no accidental index mixing. These do NOT make a probabilistic capability “covered”. **Windows/IDE/native** verification only for actual Windows host or protected integration property, never blanket GH Actions prerequisite for offline learning exam. Do not disable existing mandatory repository tests/rules.

## Accept/reject semantics

`IMPROVE` requires an actual ordinary consumer using compatible selected state, preregistered independent lawful improvement with acceptable resource/retention limits, separated cause and lawful permissions. `REGRESS` rollback to parent. `INCONCLUSIVE` keep parent; no forced lesson. `INVALID_EVIDENCE` never score as no improvement. `NO_TRAINING_NEEDED` acceptable if verified deterministic/fixed baseline already satisfies user law. `NOT_MEASURED` for documents, static source or blocked environment; never invent a chart.
