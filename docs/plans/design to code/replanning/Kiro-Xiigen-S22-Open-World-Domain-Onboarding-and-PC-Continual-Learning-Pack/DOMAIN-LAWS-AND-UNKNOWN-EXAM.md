## Exam families frozen BEFORE learning/selection
**TRAIN:** sources legitimately available to Builder/CODEX chooser/Teacher (only under later grants) and permitted memory. **OP_DEV:** repeats allowable for diagnostics, parameter tuning and comparisons; after using it for selection, not final certification. **SEALED_CERT:** disjoint by original source family/time/doc chapter, unavailable to Teacher, selector, index and tuning; open once according to independent RP09 protocol.

- **KNOWN/KNOWN**: normal C#/translation, correct D-04 intent but distinct subjects, adapted project context.
- **UNSEEN/LAWFUL**: novel subject with verified source law and compatible typed representation; expecting provisional routing then lawful output/abstention.
- **UNSEEN/NO_SOURCE**: novel claim with no source/version; expected explicit uncertainty, not confident invented domain.
- **MIXED**: one request contains Go+C# or EN→RU inside C# code comments; preserve segmentation/intent.
- **NEGATIVE/WARNING**: nearest example is misleading; know negative as contraindication, not chosen route.
- **TIE/BOTH_BAD/UNJUDGEABLE**: pair quality cannot be forced; no DPO optimizer call.
- **INDEX/STATE EDGE**: matching vector width but wrong codebook version, adapter project mismatch, cold crash, user revokes consent.
- **RETENTION**: old known-domain lawful outputs after a novel subject lesson.
- **COMPOSITION**: familiar Unit/Flow primitives composed into unseen lawful path, with arbiter authority and bounded budget.

## Domain scoring dimensions and falsification
1. Open-set **false-confident-known assignment rate**, sensitivity to actual new subjects, abstention utility; define denominator and split.
2. Predicate/law preservation + input/output type, version, direction/negation, wrong-dialect incidence.
3. Allowed memory and multi-neighbor *actually consumed*, codebook compatibility, positive/negative/warning semantics.
4. Full route quality: final lawful output, best among *actually enumerated* allowed routes, Graph path regret, time.
5. Incremental DPO T-C0 and older-domain retention; fail if DPO pair invalid or no real updated state.
6. PC feasibility and cold result with true selected state. If deterministic best is correct, prefer it.
No mean-only or sample-count magic; repeated source paraphrases not independent. Audit source citation, uncertain outcomes and head-drift at use time.
