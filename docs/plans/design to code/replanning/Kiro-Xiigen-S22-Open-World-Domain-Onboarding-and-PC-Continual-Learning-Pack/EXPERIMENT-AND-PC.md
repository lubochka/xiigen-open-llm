# S22 — causal experiment/PC protocol (not yet executed)
## Control choices and attribution
- **O**: current historical pipeline diagnostic; may be broken, only a context observation.
- **P**: accepted parent state and its normal user path, record exact version.
- **C0/N**: lawful provisional/mapping/representation fixes **without Student gradient**, same corrected K pipeline, model, index/adaptor versions and evaluation as T.
- **R**: optional existing native kNN multi-neighbor / adaptive-k factor, law and memory pool matched; RP02 owns implementation.
- **X**: optional lawful source→target semantic transposition (RP18), Student unchanged, only if actual consumer uses it.
- **T1**: same corrected pipeline and one truly fresh authorized Chinese-both-sides, CODEX-judged **existing Student/LoRA** update; never a fake T if blocked.
- **T2/BULK2**: optional different unique authorized pairs (no disguised replay), only after already examined bulk and separate grant.
Most useful first baseline: P→C0 with **no model spend**. Legitimate contrast for learning = **T1 − C0** under same repaired pipeline, not O→T. No built-in proof that factor improvements are additive. Deterministic laws, rights, policy, arbiter and tenant isolation apply to every arm.

## Preregistration BEFORE results
Set exact source family/policy, law edition, registered-known/withheld unknown boundary, hardware profile, available arms/rights, sample N per family, main endpoint, false-confidence ceiling, smallest meaningful benefit, null interval/uncertainty rule, trial/stop caps, retention guard, PC budget and cold adoption rule. Require independent scorer blinded to actor/arm; right-bound source corpus. If reviewer/owner hasn't approved values, mark `DESIGN_BINDING_REQUIRED`; do not invent an empirical N, 95% CI, effect or tolerated regression.

## Result table schema (one row per real call/family)
`{runId,arm,sourceFamilyId,split,subjectAndEdition,intentD04,noveltyDecision,passportRef,vectorSpace/codebook,stateId,authorizedLawIds,neighborsRequested/Used,negativeWarningUsed,legalRoutesEnumerated,routeSelected,arbiterResult,studentAnswer,lawScore,abstain,feedbackStatus,wallMs,cpuMs,peakRamMb,peakVramMbIfAvailable,allBranchMs,teacherJudgeCosts,modelStateHash,codeHead,consumerEvidenceId}`.
Separate model performance from retrieval route and state mutation. Missing data = NOT_MEASURED; never 0.

## Outcome
Report known/novel/mixed confusion matrix, novel-subject unlawful answer rate, law utility, domain macro and worst-domain, held-out retention; paired C0/T change if T exists. Compute within task/bulk uncertainty appropriate to stratified family and multiple looks. Whole PC = data/preparation + K training/idle overhead + failed optimizer attempts + every async branch + inference + loading + teacher/judge where relevant; distinguish local vs paid external cost without inventing hardware power usage. p50/p95 time, RAM/VRAM peaks and disk bytes may be recorded on actual PC, not estimated.

**Learning claim requires** exact immutably judged new pair, actual optimizer state change, independent T-C0 effect, selected new state in cold normal user path. No Student call can be inferred from a changed semantic index. Same domain law and copyright restrictions in all experimental arms. A no-op/provisional-only result is still useful when it reduces wrong-confidence and cost.

## Stop rules
Source unverified/privacy conflict → quarantine; D-04/subject confusion → fail-open-set and return RP02; TIE/BOTH_BAD → no update; budget overrun → stop branches/KEEP_PARENT; regression of older domain → reject promotion; no meaningful held-out gain → INCONCLUSIVE/REGRESS without moving metric; absence of actual R/X/T arm → do not claim comparison. No blanket Windows-run/coverage gate on research; do minimal deterministic compatibility/recovery guards when actually editing native code.
