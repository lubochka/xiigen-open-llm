# RP14 — preregistered causal examination, bulk learning and total PC cost

## Decide the scientific question before an intervention
E14-A: Can an authoritative project/domain-law revision be represented, activated, and used by the actual ordinary consumer without false acceptance of old-version answers? E14-B: Does law-version-specific memory/kNN improve correctness and path choice over the **same corrected law-only baseline** at PC-safe cost? E14-C (optional later grant): Does one new Chinese-dual-authored, CODEX-examined, RP01-governed DPO/LoRA Student update improve a **frozen** corrected-law consumer over C0/no-update? E14-D: Do typed Unit/Flow/Orchestrator/Graph interactions genuinely improve feasible route utility rather than just increasing nodes/branches?

## Arms and confounding
- `L`: optional historical old-law diagnostic for migration issues, **not** Student learning baseline.
- `D`: **new approved law**, deterministic-only, no new memory or weight update.
- `M`: same law/caller, approved versioned memory + fixed legal retrieval; track domain token/embedding and k separately if changing them.
- `M_k`: M with only RP02 bounded adaptive k/rerank *when a genuine learned state is observable*, otherwise label fixed heuristic. Freeze eligible candidates if attributing k; separately inspect ANN recall/geometry.
- `N / C0`: corrected pipeline and authorized accepted parent, fixed law+memory+IR+retrieval/route configs, **no Student update**.
- `U`: exact same corrected pipeline and law/rights/corpus/candidates/evaluator/budget as N; **one admitted new Student update** only, if authorized. Compare U−N for learning, NOT U−L.
- `H`: same laws, available alternatives and budget with hybrid Unit→Flow→Orchestrator→Graph; carefully matched small 2×2 ablation when interactions claimed. If route enumeration is incomplete, call best *observed* legal path, not global optimum.

Count *all* launched, cancelled and retry branches, training, index migration, cold state recovery, evaluator, teacher/selector/judge, and caches. Separate shared precomputation versus per-request incremental PC cost; report both amortized and unamortized assumptions. Do not add unrelated peaks into fake simultaneous RAM/VRAM peak.

## Exact experimental hygiene
Freeze preregistered panel/family splits, law authority/version, thresholds determined by owner **before outputs**, index/semantic codebook versions, production caller, rights, CODEX/Teacher identity and budgets. Never expose CERT target to Teacher, preference writer, dynamic k updater, prompt optimizers, tests or selector. One authorized pair may train once; re-evaluate checkpoint without repeating optimizer. Separate first local pilot from confirmatory panel with no cross-family leakage. Report N, family-level paired uncertainty, ties/refusals, critical safety failures, calibration/abstention, old-v1 and unrelated-domain retention.

**Primary:** % law-valid useful ordinary outcomes by source family, route feasible/best-enumerated score and critical violations. **Secondary:** domain/version confusion, typed many-to-many association fidelity, semantic negation/nullable preservation, actual selected multi-hit useful evidence, k range/radius, unknown/OOD handling, bulk B0→B1→B2 benefit/retention. **Cost:** phase wall time, CPU/GPU RAM/VRAM **simultaneous** peaks, disk+rollback+index duplication, teacher/judge/evaluator overhead, total $/tokens if remote; per-request and per-lesson time-to-utility.

Do not set numerical pass thresholds post hoc. If a current approved domain policy defines effect/retention/resource bounds, cite it. Otherwise record `THRESHOLD_OWNER_DECISION_REQUIRED` and run only non-promotional diagnostics until bound; this is a **design bind**, not a promise of gained accuracy. No made-up 95% or “20× savings”.

## Outcome decision table
- `INVALID_EVIDENCE`: leakage, incompatible representations between arms, missing ordinary caller, changed law across U/N, no data rights or untracked spending.
- `NOT_MEASURED`: no actual runner/feedback/Student/PC execution. Planning docs cannot exceed this.
- `INCONCLUSIVE`: uncertainty too high; no licensed conclusion.
- `REGRESS`: worse independent law/retention/cost bound; retain safe parent.
- `NO_TRAINING_NEEDED`: lawful deterministic solution already superior; preserve PC and avoid DPO.
- `IMPROVE`: preregistered meaningful independent gain without critical law/PC harm; still not ADOPTED unless cold ordinary consumer uses promoted exact state.

## Scenario that invalidates false success
Positive kNN example from old law appears semantically closest; v2 answer violates required field. If the evaluator only counts retrieval hit@k or green unit coverage, claim is false. Scientific evidence requires the *actual output* passes v2 law, the v1 output remains valid for v1, and full cost stays within measured budget. A lower Student DPO loss is not enough.
