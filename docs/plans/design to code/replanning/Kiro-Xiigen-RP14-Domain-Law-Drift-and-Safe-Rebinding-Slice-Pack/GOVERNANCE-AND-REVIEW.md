## Exact-review contract
`task_id; candidate SHA/blob set; reviewed changed methods+callers; requirement→implementation map; bounded local runtime/contract integrity; domain law source; frozen independent experiment and result; role/auth provenance; whole PC measurement; regression/rollback; remaining owner/trigger; actual reviewer identity/call evidence; reviewed SHA`.
A review of older SHA cannot be inherited by a rebased final head. If no actual CODEX Astra invocation, `INDEPENDENT_REVIEW_NOT_PERFORMED`. A self-check is not an independent reviewer.

## Five operational verdicts
`SOURCE_TRACED` → `ACTUAL_CONSUMER_USED` → `VERSIONED_STATE_CHANGED` → `INDEPENDENT_GAIN_EXAMINED` → `COLD_ADOPTED`, plus separate `EXACT_SHA_REVIEWED`. Provide positive/negative/edge, falsifier and evidence for each. If code, model or examiner never ran, record `NOT_IMPLEMENTED/NOT_RUN/NOT_MEASURED` without inferred values.

## Explicit regression and stop handling
Law source conflict, insufficient consent, ambiguous mutable state, incompatible representation/codebook, unknown effects, critical law violation, old-version regression, consumer not using new pointer, uncontrolled PC peak, hidden CERT contamination → quarantine/revert to approved lawful version. Unknown result is not an invitation to duplicate training. A correct deterministic answer is not rejected solely because it uses no model.

In concise Russian: what actual semantic seam was changed (or no-change), why it matters for user ability, what source/consumer was read, what *was not* executed, what was measured with N/uncertainty/time/PC or NOT_MEASURED, which exact decision is needed next.
