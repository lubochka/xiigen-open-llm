## Learning experiments / rejected false positives

1. DPO: P accepted parent vs C0 no-update and T one legal new pair on identical corrected pipeline, frozen reference and independent family panel; new SHA/loss change does not imply improvement.
2. Domain representation: raw/BPE-only vs law-aware tokens/vector IR with the **same** solver/index, compatible encoder/decoder/versioned reindex, law collisions and target output measured; LoRA recipient/projection separate from token vocabulary.
3. Query-adaptive kNN: exact eligible pool, fixed metric/k/radius baseline; vary admissible domain k=f(domain,density,top distances,margin,uncertainty,rights,cost), then independent rerank/neighbor aggregation, then ANN recall-vs-exact; top1 consumer with k>1 is **not** fusion.
4. ILearningUnit vs ILearningFlow: freeze Unit outputs and change only typed Flow correction; stable association IDs, reorder and fan-in; measure corrected downstream material result. A learned Unit rank change is a separate arm.
5. Orchestrator: same admissible alternatives/permissions and deterministic fallback, vary learned order/route/stop, count ALL launched + timed-out async compute; compare to bounded best **enumerated** feasible path when small, not claimed global optimum.
6. DynamicGraph: freeze lower roles, require versioned learned higher-order relation update and normal consumer, measure unseen compositions vs flat/static, including degree/order/cost. More edges is not evidence.
7. Hybrid/PC: deterministic-only, learned-only **within hard law** when viable, and hybrid; equal total PC/time budget and same task pool; isolate one factor, only then bounded 2×2 interaction when scientifically justified.
