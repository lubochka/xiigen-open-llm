## Separate algorithm factor studies

1. **Domain map**: oracle vs predicted, known/mixed/new, C# question containing SQL/English, confusion, wrong-domain law critical rate, abstention. Single keyword as domain label is BAD.
2. **Domain-specific semantic token**: versioned domain/intent/type/POS/AST/coreference/morphology/negation/rights/uncertainty/codebook output. Compare learned projection and independent LoRA effects. Gender must follow referent ID, not next closest word; unknown ref -> clarify.
3. **Dynamic law kNN**: common eligible pool; top1 vs real multi-hit aggregation vs law rerank/veto vs adaptive k and exact/ANN recall. Keep lawful negative neighbors as counterevidence but never execute illicit output. Measure calibration, abstention, critical law errors, p95 latency and full PC. A raw hit.score is not confidence of legal correctness.
4. **ILearningUnit many→many**: typed multiple linked outcomes per input set; compare D deterministic legal/type gate, L learned association WITH guard, H hybrid; fixed one-output lookup not evidence of capability.
5. **ILearningFlow**: versioned mutable correction of Unit output→input many-to-many links, actual consumer before/after, rollback; static edge is not trained Flow.
6. **ILearningOrchestrator/DynamicGraph**: async fanout/early stop/cancel and higher-order learned path among unseen pattern compositions, legal action ordering and lost-branch expenses; Task.WhenAll or static graph alone not learning.
7. **LoRA→semantic token transposition**: isolate LoRA Student answer, semantic encoder/codebook/vector output and their interaction on cold real consumer, stale/mismatched projection versions and cross-domain retention. Weight digest change alone does not prove valid typed semantic token.
