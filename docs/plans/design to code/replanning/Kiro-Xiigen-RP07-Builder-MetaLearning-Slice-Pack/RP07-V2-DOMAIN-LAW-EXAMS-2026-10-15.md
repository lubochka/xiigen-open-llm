## DPO law/exam examples, not ready-to-train pairs
- GOOD teaching contrast: for an unambiguous RU referent, chosen keeps same gender/case relationship and rejected makes a subtle grammatical contradiction without unrelated style change. Final BOTH sides must actually be Chinese-teacher-authored under exact immutable context and reviewed by separate CODEX judge.
- BAD contrast: chosen and rejected differ only in punctuation, or rejected is just deliberately garbled, or model is told the held-out answer. No meaningful generalizable law.
- EDGE: both candidate texts valid, ambiguity unresolved, source has no rights, or rejected actually better for a hidden constraint. Return TIE/BOTH_BAD/UNJUDGEABLE and no optimizer admission.
For code: chosen respects original async error behavior and rejected compiles but violates contract (hard negative). For SQL: chosen preserves requested LEFT JOIN results; rejected filters unmatched NULLs. Do not replace pair semantic judge with a compile test.

## Pre-registered verdict algorithm
- VALID_EXPERIMENT = documented rights + immutable roles/pairs + actual update receipt + same starting parent and independent families + honest cost and evaluator; else INVALID or INCONCLUSIVE.
- STUDENT_IMPROVED only if credible paired heldout T over matched C0 with nontrivial useful domain-law performance, no unacceptable regression and uncertainty as pre-specified; negative/no gain is a valid result.
- BUILDER_IMPROVED only if accepted real B1 is loaded cold, improves *future* independent Student learning vs frozen B0 under matched allocation, and gain not explained by more attempts/time/better teacher/prompts or leaked families.
- PC_EFFICIENT only if whole actual PC (not kernel-only) latency, RAM/VRAM, failures, retries, provider costs, restart and retained-learning feasibility meet predeclared constraints.
- CROSS_DOMAIN_TRANSFER only if an unseen law/domain family was excluded from taught/selected material; passing a familiar template is not transfer.
Stop/challenge (independent Astra on final SHA): domain law collision, invalid DPO contrast, C0/T different parents, optimizer unchanged, off-path cold consumer, unit/flow/graph authority attribution, source leakage, hidden expensive branch, builder label obtained from one learner outcome. Each failure must name one minimal next experiment, not “increase coverage”.
