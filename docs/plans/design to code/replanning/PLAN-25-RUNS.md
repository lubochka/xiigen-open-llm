## Сохранённая архитектура и способ её исследовать

| Роль | Deterministic и learned части | Что должно различить examination |
|---|---|---|
| Unit | Domain/input/output schemas и associations ограничивают learned many→many mapping | Смысл и input→result matching, не только shape/hash. |
| Flow | Typed relationships/order ограничивают learned input→output correction | Frozen Units + changed Flow и обратный контроль. |
| Orchestrator | Dependency/permissions/cancellation/budget ограничивают learned async combination choice | Те же candidates/budget; качество, допустимость, цена всех branches. |
| DynamicGraph | Законные typed patterns ограничивают learned higher-order relationships | Unseen compositions familiar primitives, не memorized whole path. |

Actual ILogical*/Machine сопоставляются поведением, не опечатками. Train остаётся у ILearningMachine; Graph=L5 specialization, не шестая ступень/четыре trainers. ORM-43 reasoning node не permanent hollow adapter/вторая machine. Сохраняются TensorCore/shared base/project LoRA, StackDetector-before-normalization, semantic compression, BM25+kNN, positive/negative/warning memory, final arbiter, semantic OrderedPatternIds и mandatory skills вне top-k до предметно разрешённой миграции.

Каждый блок: input/domain → hard admissibility → learned authority/state/signal → output/association → ordinary consumer → intervention/control/falsifier → full cost. Deterministic compute над learned weights не опровергает learning; случайность не доказывает его. Correct deterministic result не negative по происхождению.

**DPO:** разрешённый Chinese author обеих final sides; CODEX/Astra lesson selection и отдельная exact-pair assessment; Student; независимый post-update evaluator. Reference policy не judge. Meaningful negative отвечает той же frozen task; TIE/BOTH_BAD/UNJUDGEABLE не forced preference. Exact pair должна без потери различающего смысла достигать response objective/правильного recipient. Conditional probabilities/masks/EOS/reduction и frozen reference задаются R12; arbitrary similarity не стандартный DPO. Zero cold-start margin не semantic failure.

**Representation/kNN:** raw/canonical/TeachingVector/BPE/trainer tokens — named channels с coordinate meaning/versions, не один float[] stack. Law-sensitive features/forbidden normalization, eligibility, score, k/radius, index и neighbor consumer отдельны. Query-dependent `Σw_j(d,q;θ)φ_j(q,n)` — исследуемое семейство, не заранее лучший metric; exact/ANN backend должен поддерживать выбранный score. k больше при first-hit Output не доказывает aggregation. Warning с ответом не abstention.

**LoRA/связи:** назвать actual adapted matrix, frozen state, source/target representation, objective и ordinary consumer. LoRA не tokenizer/codebook и не semantic projection по одному shape. Solver gain не selector learning; Graph-policy и documentation lesson могут идти разными путями. Best path — лучшая рассмотренная допустимая альтернатива при объявленном budget, не global optimum.
