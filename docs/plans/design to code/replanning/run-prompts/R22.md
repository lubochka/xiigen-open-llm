## Выход и остановка

Один назначенный вопрос/фрагмент → содержательный результат → finite residue и конкретный owner. A–E и C00–C11 — внутреннее разбиение задания, не фактические extra calls. Дополнительный реальный child получает полный §2 contract каталога, exact inputs/skills/examples/examination и return-only scope; count и identity записываются по факту. Нет автоматического R26/30/50-pass loop и нет притворного «ещё раз всё исследовать».

Документная приёмка R22 не равна выполнению эксперимента или достижению качества. Отрицательный валидный опыт может быть полезным; он не закрывает требование улучшить продукт.
