| Обязательство | Что должно быть в задании | Различающий результат / владельцы |

| Orchestrator | Асинхронные combinations, зависимости, cancellation, выбор законного пути и цена всех ветвей | Измеряется качество выбранного feasible path и regret к объявленному bounded reference, не global optimum; R06/R07/R12/R22 |
