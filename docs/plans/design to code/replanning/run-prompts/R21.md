Сопоставлять ILogical*/ILearningMachine по поведению; Train остаётся у существующего owner. Не вводить четыре trainers, шестой уровень или переименование API по опечатке. Curriculum L0–L5 — ступени обучения, не номера архитектурных классов.

Сохранить TensorCore/shared base/project LoRA, StackDetector-before-normalization, semantic compression/order, BM25+kNN, positive/negative/warning memory и final arbiter. Retrieval eligibility по правам/split/пространству не равно admissibility действия: lawful negative/warning memory можно читать как противопоказание; её ошибочное решение нельзя исполнять как chosen. Проверка доменных hard laws не получает скрытого правильного domain ID.

Путь сигнала: разрешённый case → exact Chinese final y+/y− для одного x → отдельное CODEX/Astra judgment → faithful representation → подходящий objective/parameter owner → checkpoint → обычный consumer → независимое наблюдение. Сохранить текущий unit-level train-ready GraphDpoPair (`Level="unit"`, UnitId); path/order/links могут быть контекстом/оценкой, но не самовольным graph-level optimizer payload. Flow/Graph credit assignment требует конкретного получателя, не строки "улучшить граф".

DPO не любое ранжирование пары. Для E1 нужен response-conditional policy/reference log-ratio с response targets и математически соответствующим backward из R18. DPO reference, no-update control и внешний evaluator — разные роли. Нулевой initial margin, когда policy=reference, сам по себе не баг. LoRA адаптирует выбранные матрицы; не является tokenizer или автоматически корректным result→vector converter. Для отдельного projector нужны typed target, loss, keys, consumer и versioned geometry; это не prerequisite E1.

### B2. Отдельные вмешательства вместо смешанного «dynamic algorithm»

**Prompt.** Для выбранного domain опиши deterministic reference, изменяемый learned factor и downstream effect. Сначала зафиксируй law-preserving tokens/IR/encoder-space; не объявляй одинаковые float dimensions совместимостью. В E1 сохрани выбранный R18 faithful segmented-byte-BPE-v2 и exact x/y, не делай новый словарь prerequisite урока. Для отдельного representation опыта сначала определить семантические координаты/утраты и миграцию, затем сравнение при фиксированном solver.

Для kNN раздели: (1) authorised candidate memory (включая marked negative/warning); (2) indexable exact/ANN geometry; (3) domain-conditional rerank; (4) fixed k versus separately learned k/radius; (5) настоящий multi-neighbor consumer; (6) final action admissibility. Candidate score из §9.4 — гипотеза, не optimum. Utility feature может использовать только ранее доступные разрешённые outcomes, не будущий holdout или эффект текущего challenger. Если caller берёт hit[0], увеличение k не доказательство multi-neighbor learning.

Для четырёх ролей заполни producer/input identity → legal edge/port → learned state/owner → signal/objective → selected output/consumer → failure/rollback. Unit: many→many/empty/ambiguous associations; Flow: frozen Units и learned correction; Orchestrator: frozen Units+Flow, async fan-out/fan-in и стоимость отменённых ветвей; Graph: frozen lower levels и новые higher-order motifs. Матричный или детерминированно вычисляемый learned forward остаётся обучаемым механизмом.

**Выход:** по одному first discriminating experiment, не полный перебор domain×layer×k×encoder. **Good:** fixed candidate pool/k/encoder, изменён только reranker, lawful downstream answer сравнен. **Bad:** одновременно новая tokenization, новый corpus, большой k и LoRA, после чего вся дельта названа DPO gain. **Edge:** нет eligible соседей, NaN/zero vector, incompatible index, ошибочный mapper, gold law only in examiner; задан lawful fallback, не oracle. **Приёмка:** улучшение можно отнести к конкретному фактору, а полезные negative memories не исчезают из-за запрета исполнять плохие решения.
