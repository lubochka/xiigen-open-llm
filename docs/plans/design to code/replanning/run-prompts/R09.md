## Подробный prompt

**A — проверить выборку и причины.** Сохрани уже опубликованную R09 выборку первых 30 branch runs и её окно/ограничения; не называй это новым измерением. При новой доступной выборке заранее укажи inclusion/exclusion, completed/in-progress/cancelled, queue/runner/wall time, overlapping jobs и причины повторов. Runner occupation не человеко-часы, не invoice и не будущая экономия. Не выводи затраты по commit/file counts. Раздели native defect, environment, product regression, process overhead и неизвестное.

**B — test-fitting hypothesis.** Для ограниченного числа representative episodes восстанови requirement→implementation→failed assertion→exact test/rubric diff→authorized reason→behavior. Классифицируй legitimate fixture repair, authorized requirement change, unauthorized weakening, oracle fitting или unresolved. RED→GREEN не обвинение. Existing PsecPhysical failure — пример native boundary, не доказательство DPO quality. Без достаточного diff оставить INCONCLUSIVE.

**C — убрать ложные prerequisites.** Для каждого gate выбери KEEP/REUSE/DEFER/REPLACE-AS-LEARNING-EVIDENCE и назови capability, causal dependency, owner и trigger возврата. Provenance/state/no-repeat/rollback остаются; learning acceptance — independent quality evidence; native Windows — только реальный native consumer/milestone. S04 local loop не ждать S05 remote delivery по умолчанию. Full domain matrix/new encoder/новый trainer не обязательные gates первого bounded lesson.

**D — полная стоимость learning.** Установи будущий instrumented ledger: original snapshot/lesson/family; exact pair; tokenizer/domain/index/adapter versions; accepted/rejected/invalid update; teacher/assessor/evaluator/inference/training/reindex/rollback/all branches cost; peak process RAM/VRAM, disk growth, p50/p95 и total wall time. Девять research agents не девять simultaneous GPU trainings. Fair baseline/challenger measurements требуют одинаковой capacity/concurrency policy. Не заявляй PC-fit до declared hardware observations.

## Outputs / acceptance

Пять own carriers: bounded cost evidence с limits; конкретные test-fitting verdicts; gate→dependency→decision→owner map; first-learning cut-set hypotheses; полная resource recipe. Receipts R11/R13/R17/R22/R23. Documentary acceptance: «убрать из critical path» всегда содержит причину и future owner, не deletion; подозрение либо подтверждено exact episode, либо честно unknown.

Future examinations: gain per **unique allowed lesson**, useful-result latency и full cost при сопоставимой семантической точности; bulk accuracy/time/retention без скрытых retries; отдельные domain mapping/DPO utility/kNN/LoRA/path axes. Снижение CI-time не learner improvement. Code/tests/workflows не менять в R09.

**Good:** native gate остаётся для Windows delivery, но не блокирует non-native exact-pair transport correction. **Bad:** 368 минут runner occupation объявлены потерей 368 минут человека; все тесты удалены; regression объявлена успехом ради скорости. **Edge:** overlapping jobs, retry с иной нагрузкой, cached build, partial logs, exception до update, неизвестный outcome, shared GPU interference, evaluation дороже training.
