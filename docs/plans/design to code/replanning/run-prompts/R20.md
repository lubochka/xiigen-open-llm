## B — собрать содержательное назначение, включая обучение

Для действительно собираемого packet вставь полную assigned card и необходимые source/skill contents, exact refs, own checkpoint, current→target mechanism, конкретные шаги/outputs, права/бюджет/stop/return и meaningful good/bad/edge. Сохрани source claim→authority→accepted meaning→consumer; raw historical text не становится текущей командой. Обязательное неизвестное поле может быть `UNRESOLVED` с resolver **в preparation packet**, но исключает именно зависящее от него действие.

Доставь механизмы, а не названия: Unit domain/input-vector/output schema и typed many→many associations; Flow коррекция и связь Units; Orchestrator async lawful paths/order/cancellation/стоимость всех ветвей; Graph higher-order relationships и перенос. ILearningMachine остаётся фактическим training owner, Graph — L5 specialization, не новый trainer. По каждому стыку: law/eligibility, learned state/signal/objective, parameter owner, ordinary consumer, вмешательство и falsifier.

Для будущих опытов сохрани: одинаковый request/domain law у обеих сторон DPO; meaningful rejected, TIE/BOTH_BAD/UNJUDGEABLE без forced preference; разрешённая открытая китайская модель — автор обеих final сторон; CODEX/Astra — отдельно human lesson selection и exact pair judgment; Student и post-update evaluator отдельно. Domain/intent/stack не сливать. Dynamic kNN раскрывает eligibility/features/metric/k/radius/index/neighbor consumption/arbiter; k>1 при first-hit consumer не доказывает learning. LoRA trainable keys и encoder/projection/tokenizer — разные контракты.

**Причинная оценка:** N = frozen no-update parent, U = isolated updated challenger. У них одна исправленная material/token/mask/stop/input-renderer/ordinary-consumer pipeline и сопоставимые evaluation conditions. Legacy L→N — инженерный эффект, не N→U обучение. Frozen family-disjoint panel, blind heldout, domains/worst-domain/retention, accuracy/time/latency, все попытки, teacher/judges и полный PC footprint; bulk — окно новых pair IDs. Rollback/quarantine при неизвестном update outcome; не повторять optimizer. Числа и confidence не придумывать. Valid no-gain — завершённый информативный опыт, не повод подгонять rubric.

**Выход B:** фактический текст собранного packet + source-content manifest + gaps/exclusions + consumer receipt либо честное `CONTENT_NOT_ASSEMBLED` по не собранным назначениям. План обучения не свидетельство улучшения.
