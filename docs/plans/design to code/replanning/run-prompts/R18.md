## Prompt: что обязательно исправлено и должно остаться исполнимым

**A — exact material.** Сохрани segmented-byte-BPE-v2: p=Encode(x), a=Encode(y), concat; immutable raw/context/tokens/masks; response target j получает logits[j−1]. Удали Compact из selected path, не просто подними 480. Strict UTF-8/range/capacity/meaning-or-refusal до effects. Semantic TIE, material contrast lost и initial zero margin различаются. Teacher пишет обе финальные стороны одного x; CODEX/Astra отдельно выбирает case и судит exact pair; не relabel authorship и не forced preference.

**B — objective/recipient.** Conditional response log-probability sum с тем же backward; public average inference API не меняется. Frozen existing VectorSignal, raw/optimized metrics раздельно. Actual installed LoRA keys/RequiresGrad/optimizer membership, frozen base/reference и independent storage, prepared continuation state. Не заказывать второй trainer/freeze. Policy training:true и reference:false требуют явного mode/RNG учета; равные weights не автоматическое доказательство exact margin=0. Zero/identical update не исправлять фиктивной мутацией.

**C — state и настоящий ordinary answer.** Reuse найденный TextGenerator, не повторять generic search. Shared facade предлагается в 14.ContinuousLearning над 09.Inference; wrapper26 и assessment14 вызывают его вниз. Действующая 26→14 не допускает обратную 14→26. Ordinary endpoint/новые carriers — PROPOSED, routing stages не documentation. Structured CodeDocumentationRequest legacy сохраняется; adapter обязан подтвердить corresponding x или отказать.

Сохрани обе допустимые StartService ветки: accepted verified parent; либо clean missing + applicable explicit ColdStartPolicy→воспроизводимый initial baseline. Не создавать fake accepted manifest и не выдавать cold-start permission из наличия метода. Corrupt/incompatible/ambiguous/unavailable никогда не silent cold start. Isolated trial оценивается до promotion; ordinary cold adoption после решения; unknown update только existing recovery/no-repeat. Protected C:\Projects\llm_mvp_core bootstrap сохраняется; отсутствие blanket Windows CI не доказывает Linux portability.

**D — экзамен и стадии вместо кругового G1–G6.** Work order §5 — конкретный C# nullable/control-flow опыт, §6 — разрешённый causal порядок.
