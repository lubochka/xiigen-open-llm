## Подробный prompt

**A — карта значений.** Раздели raw source, canonical representation, TeachingVector, retained BPE retrieval vector, actual trainer tokens/masks, output schema. Для каждого укажи domain/intent/project, shape, coordinate meaning, tokenizer/codebook version, normalization и все consumers. Сохрани StackDetector-before-normalization. Для Unit восстанови many→many: какой input породил каждый result/OutputRef/association; shape equality не заменяет смысл.

**B — предметные потери.** На documentary examples разных семей покажи, что нельзя стирать: negation/числа в переводе; caller/callee, cancellation и порядок в C#; scope/lifecycle в Angular; NULL и bag semantics в SQL; дерево/геометрия/breakpoints в HTML/CSS. Это примеры проектирования, не созданные training data. Исследуй equal-shape incompatible vectors, long distinguishing suffix, Unicode/code indentation и missing domain. Зафиксируй actual tokenizer capacity, не считай 480 символов token budget.

**C — минимальные альтернативы.** Сопоставь reuse existing sharedRootVocab overload/encoder с необходимой миграцией; обозначь compatibility/reindex/consumer changes. Не делай encoder experiment R04:E01 prerequisite первого learning experiment R04:E02. Передай R05 только установленный representation contract/потерю смысла, R06 — ограничения metric/index, R07 — семантику портов. Изменение вектора, хеша или active-count heuristic не learned semantic projection.

## Outputs / examination

Пять carriers: channel/coordinate/consumer map, typed association walkthrough, source-backed losses и falsifiers, current→candidate contract, scoped E01/E02 handoff. Documentary acceptance: один concrete input проходит до ordinary typed result; видно, что сравнивается и какие claims ещё неизвестны. Р04 не принимает DPO objective за R05 и не заявляет новую embedding систему внедрённой.

Future examination: same-domain lawful alternatives и hard negatives; representation A/B при frozen downstream state и compatible exact retrieval; контроль влияния tokenizer на exact chosen/rejected difference; сохранение association; quality/latency/full memory/reindex cost. Отличить semantic quality от character/surface score. Ни одного product coverage suite в этом R04.

**Good:** два канала имеют разные смыслы и законных consumers; меняется только подтверждённый lossy adapter. **Bad:** dimension=768 — значит взаимозаменяемы; «новый encoder сначала для всех». **Edge:** равные vectors при разных outputs, legal normalization, смешанный domain, token overflow, shape-compatible checkpoint с другим codebook, множественные допустимые ответы.
