## False-success challenges
- A clean DTC API DTO or direct LocalCallerAdapter call is not real plugin consumption.
- A V port-map is not an installed editor.
- Trainer loss decreases but cold client loads old adapter: STATE_CHANGED maybe, PRODUCT_ADOPTED false.
- Several neighbors were retrieved but output consumed only first: adaptive multi-neighbor gain false.
- Graph file hash changes without loaded relation/selector/path difference: Graph learning unproved.
- Malformed source/forbidden cross-tenant project/unapproved teacher/OOM/resource cap → fail closed or ABSTAIN, not automatic training.

All three paths preserve separate acceptance status. A valid one-pair E1 does NOT claim full DTC, native IDE or E4 readiness.
