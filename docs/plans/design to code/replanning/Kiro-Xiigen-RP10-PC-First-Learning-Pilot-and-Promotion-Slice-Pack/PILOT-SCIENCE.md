# RP10 evaluation: one real PC pilot, not coverage or cherry-picked learning

## Freeze before T
Choose **one admitted ordinary local user flow** and one domain-law family, then hold out NEW independent source families in TRAIN/OP_DEV/CERT partitions with dedupe by origin, answer and paraphrase family. Freeze `protocolVersion, source/license/tenant rights, domains/lawVersions, cases/negative/warning/OOD, oracle/answer rubrics, evaluator blinding, budget, thresholds, base/parent/selected state, environment, exact code refs, timing method and stop conditions` before looking at T. Keep CERT out of Chinese prompts, RAG, kNN index, engineering fixes or feedback replay. First C# CodeDocumentation; EN→RU next if lawful; additional law families independently when ready.

## Comparison structure
- `P`: accepted parent snapshot on ordinary consumer.
- `C0`: SAME corrected code/inputs/candidate set/consumer/measurement as T but **no trainable update**; captures deterministic fix.
- `T`: same C0 pipeline with exactly ONE authorized new admitted lesson and named recipient state update; pair_id one-time with full journal.
- `A`: after independent decision, cold *ordinary local consumer* reads accepted selected child version; non-adoption is recorded even if T wins.
- Optional `H`: historic uncorrected code, only to attribute deterministic defect (do not compare T only with H). `C0−H` is engineering; `T−C0` is learning.

**Before/after bulk:** later authorized `B1,B2,...` use NEW pair IDs/independent source families; cumulative metrics and retention on old frozen families, not reuse/redo of the same trial. Every failed/interrupted/consumed reservation counts toward full resource and idempotency evidence.

## Primary metrics; set denominators and tolerances before T
1. Exact lawful task success or blind expert grade on CERT, **per domain**; fatal domain-law violation count and source-family N; worst-domain result + UNKNOWN/MIXED calibration.
2. Semantic loss through raw→IR→token→vector→retrieval→answer (contrast negatives that differ by a single *legally material* feature).
3. Retrieval recall of lawful and warning evidence; effective actual multi-hit contribution; dynamic k/metric/rerank vs fixed-k, `k=1`, exact ANN compared with equal eligible pool.
4. Unit association precision for typed many→many; Flow correction contribution with Units frozen; async Orchestrator lawful route quality/time with branches frozen; unseen order-2/3 Graph composition performance.
5. Path utility and `regret = best enumerated feasible comparator utility − chosen utility` at equal resource cap. Do **not** assert theoretical globally optimal path.
6. Quality/time/PC frontier: wall elapsed user result p50/p95 where N supports it; teacher+CODEX+evaluation+trainer+reindex+retry+native wait recorded separately and as total campaign. Whole process-tree RAM/VRAM peaks, CPU/GPU, disk all parent/ref/trial/optimizer/LoRA/index/graph/cache/temp/rollback, cold/warm, unknown currency costs.
7. Retention/fatigue after fresh feedback bulk; false-positive promotions and accepted-state reopen; quality per total PC-hour and per lawful useful new family.

## Falsification and early stop
Abort T and preserve negative evidence on provenance mismatch, CERT contamination, unpermitted data, unknown replay state, incompatible vector/index coordinate versions, hard-law violation, invalid requested type, unacceptable PC cap, evaluation instability or loss-mask corruption. No infinite retrain-to-pass. A valid `REGRESS` closes **that experiment** and keeps P; it does not justify widening teacher budget or erasing the failure.
