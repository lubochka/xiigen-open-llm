**13.10.2026 · NEW RP10 in `replanning`, NOT historical S10/FINAL. STATUS: PUBLISHED EXECUTION DESIGN (DRAFT); PRODUCT / STUDENT / BUILDER NOT CHANGED BY THIS PACK; LEARNING AND PC RESULTS NOT MEASURED; INDEPENDENT CODEX ASTRA ULTRACODE REVIEW NOT PERFORMED.**

## Результат, который нужен человеку

Пользователь обращается к обычному локальному XIIGEN. Система определяет закон предметной области, сохраняет его в типизированном представлении, находит не один «первый» похожий пример, а несколько допустимых и предупреждающих свидетельств, выбирает **лучший из реально перечисленных допустимых маршрутов при заданном бюджете**, применяет комбинацию детерминированных ограничений и обучаемых политик, выдаёт результат. После разрешённого нового отзыва CODEX выбирает подходящий урок, разрешённая внешняя открытая китайская модель создаёт обе финальные стороны DPO, CODEX независимо оценивает эту точную пару; Student обновляется через существующий владеющий механизм. Только отдельно измеренное улучшение на независимых задачах допускает новое состояние в обычный локальный путь. Всё выдерживает холодный перезапуск ПК, соблюдает ресурсные ограничения и допускает откат.

**RP10 отвечает за операционное замыкание ONE PC PILOT → controlled promotion**, а НЕ повторяет механизмы других слайсов. Начальная проверка возможна даже без разрешения на обучение: провести реальный ordinary baseline/C0, найти точный missing seam, измерить реальную стоимость и оставить обучение честно `NOT_RUN`.
