# S29 — preregistered learning exam and whole-PC economics
## Distinguish five actual arms; do not run imaginary arms
| Arm | State, input and effect | What it can prove |
| --- | --- | --- |
| P | accepted ordinary parent, actual normal output | current domain-law and full PC baseline |
| C0 | exact same parent, narrow deterministic law/arbiter repair, NO gradient | engineering gain only |
| H0 | exact same parent, bounded safe private lawful alternative *actually executed*, NO gradient | information from comparison and cost of exploration, NOT learning |
| Tpolicy | one uniquely admitted real path preference updates existing policy/Graph state | route-policy learning only if independent change+ordinary consumer observed |
| Tstudent | a distinct granted exact Chinese-authored pair updates Student/LoRA | Student learning if independently evaluated, NOT graph/route learning |
| T2 | actually new later bulk, new pair and distinct state Step | continual learning and forgetting, only if executed |

Every arm freezes original user request, subject domain/law edition, source family, rights, accepted parent, tokens/index/projector, route candidate pool, context window and PC budget; permitted single factor differences and stochastic repetitions are preregistered. Sealed CERT is separate from TRAIN and OP_DEV by source family and cannot tune k/teacher/policy. If the instrumented real system cannot execute H0, record NOT_RUN; not a mocked source. For comparisons that alter index or LoRA, explicitly mark changed factor and do not credit policy for it.

## Mandatory scientific measures
- Domain: recognized/multi-label/unknown subject mapping vs expert passport; false-confident unknown; macro and worst domain under seven named areas.
- Semantic: law-preserving negation/type/output refs, tokenizer/projection/LoRA semantic compatibility; no accidental vector alias.
- Retrieval: fixed k/top1, multi-used-hit, adaptive k with same frozen neighborhood/index; actual downstream path change and domain-specific relevance.
- Hybrid: required Unit many→many; Flow downstream corrections; Orchestrator async actual completion/cancellation; Graph higher-order legality and route ranking; D-15 arbiter rejection=hard failure.
- Pair admission: valid strict comparable path hard negatives vs illegal veto/tie/both-bad, independent label agreement; Student chosen/rejected roles are separate.
- Learning: actual correct recipient policy or Student changed with parent journal and one Step; parent/C0/T with N and source-family uncertainty; negative transfer/old-domain retention; bulk1→bulk2 true additional information.
- PC: full wall p50/p95, CPU, peak RAM/VRAM/disk/index growth, cold/warm/restore reserve, external evaluator/provider token cost, all branches including cancelled/failed, quality per cost/budget.

Define upfront per-domain meaningful quality threshold, hard-law zero-violation rule, safety and retention bounds, resource cutoff, minimum N and uncertainty procedure; do NOT retrofit thresholds to green results. If C0 beats training, engineering-only path can win. If H0 cost is greater than benefit, do not shadow by default. A valid negative result or no-gradient win is scientifically useful; report INCONCLUSIVE vs REGRESS vs INVALID_EVIDENCE separately.

## Observability and causal attribution
A preference accepted by S28 != policy Step. A policy Step != accepted state. Accepted state != cold ordinary choice. Timestamp/run/source evidence and actual consumer ACK required. The best route comparator is best **actually enumerated/observed lawful** path; do not presume global optimum. No GitHub Windows test pass, pair count, DPO loss or static graph diagram can substitute. 95%+ to frozen oracle remains long-term product goal, not a point estimate for this packet.
