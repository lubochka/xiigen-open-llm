# S27 — Learning-science acceptance, no coverage proxy

## Freeze before seeing treatment effects

Use RP09 independent examiner, not a S27 replacement. Freeze source-law versions, subject vs D-04 intent, tenant/project, eligible candidate universe, TRAIN / OP_DEV / SEALED_CERT separated **by original source family** before paraphrases, same retrieval corpus/index, tokenizer/adapter, solver and inference budget, hardware and Student parent. Teacher/selector never sees sealed answers. A legal data source or near-copy may not cross split. Rubrics and minimum useful gain, maximum worst-domain regression, confidence method and whole-PC limits must be **pre-registered with owner and independent evaluator**; absent exact threshold = INCONCLUSIVE, not PASS.

### Distinct actual arms
- P: cold accepted parent response through existing ordinary consumer.
- C0: same parent, full corrected deterministic law/feedback pipeline, **no new weight update**.
- E: C0 plus S27 evidence classification/handoff only, no Student Step.
- T1: E path plus one genuinely new CODEX-selected, Chinese-both-authored, CODEX-exact-approved pair applied once to existing Student.
- T2: only if second **different approved pair** in new bulk with measured intermediate B1 (no silent replay).

Compare raw feedback vs E classifier on same law-frozen signals; E–C0 isolates evidence handling, T1–C0 isolates *learning after deterministic repair*. Valid negative experiment remains valuable; do not invent missing T1/T2 arms.

### Lawful capability measurements
1. Domain map macro/worst-domain accuracy for subject, language, SQL dialect, stack, intent and law-version; wrong-domain overconfidence, UNKNOWN and MIXED.
2. Representation/token preservation of negation, nullable semantics, side effects, typed input/output associations, rights; compatible vector space and index.
3. Adaptive kNN actual **multiple consumed** eligible hits, dynamic k vs fixed-k, exact vs ANN recall and p95; avoid calling an unused neighbor a win.
4. Unit many→many, Flow learned correction, bounded async Orch, higher-order Graph, deterministic law-arbiter and routing regret versus **best enumerated eligible route under equal PC budget**.
5. CODEX case appropriateness; Chinese exact pair usefulness and invalid/tie rate; actual response-only Student objective/recipient, old-domain retention and independently judged answer.
6. Real user-facing task correctness: C# nullable, SQL LEFT JOIN/NULL, EN→RU negation, Angular binding, DTC multi-viewport, orchestration dependencies, Builder both-bad contrasts; no synthetic-only 100% claims.

### Whole-PC and bulk progression
For each B0/B1/B2 record sample count, domain/source-family, parent/child SHA, number of distinct admitted pair IDs, domain-law errors, macro and worst-domain utility, retention and route regret, median/p95 response latency, teacher/trainer/evaluator + canceled-branch wall times, total wall time, peak RAM/VRAM, CPU/GPU, disk/state, networking/provider and failed-attempt cost; joules only if actually metered. Report Δlawful_accuracy / cumulative elapsed time and Δgain per admitted pair with denominator, uncertainty and control effects. Include no-update savings and failed GPU costs, not just winning branch.

**Falsifiers:** E only blocks lawful examples, T1 improves same-family leakage but harms heldout, law-risk increases, T1 improves only because C0 pipeline differs, new state not selected on cold consumer, adaptive k consumes first hit only, or cost exceeds frozen PC budget. Return REGRESS/INCONCLUSIVE/INVALID_EVIDENCE/NO_TRAIN as observed; keep parent. 95% is a product aspiration, not a threshold to start first informative experiment.

Only focused deterministic tests for schema, law/rights, typed refs, pair authorship hash, no-repeat, rollback and cold loader are relevant safeguards; GitHub Windows Actions/coverage percentage do not establish learned performance. Native host delivery under RP06/S10 has separate integration evidence.
