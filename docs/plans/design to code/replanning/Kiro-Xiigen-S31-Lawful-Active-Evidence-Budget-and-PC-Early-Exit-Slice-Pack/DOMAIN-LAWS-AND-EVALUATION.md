# S31 seven domain-law passports (illustrations, NOT training or sealed exams)
Task INTENT (BUG/PLAN/CODE_Q/ARCH/REFACTOR) and subject DOMAIN (C#/SQL/translation/etc.) must be independently represented. An oracle-known correct domain, the actually mapped domain and controlled ambiguous/wrong domain must be compared. All subjects include edition, data rights, project/tenant, typed outputs, vector version and required legal evidence.

| Subject | Cheap lawful preliminary observation | What must NOT be inferred / STOP veto | Negative or edge |
| --- | --- | --- | --- |
| EN↔RU translation | source scope, referent, quantities, negation and subject terminology | similarity ≠ faithful translation; incomplete negation/grammar demands continue | 'not' reversed or number omitted despite good vector match |
| C# docs | authorized API signature/version, nullable/async and exception semantics | guessed method behavior or old framework edition cannot be authoritative | same API name and changed nullable contract |
| Angular docs | actual edition, lifecycle/reactivity/signals/router documentation | old-version symbols not legal basis for new-version behavior | similar syntax with wrong lifecycle |
| SQL docs | dialect/schema/column types, semantics/transactions | SQL Server syntax mistaken for PostgreSQL, unsafe writes during probe | lexical near-neighbors have opposite dialect law |
| Orchestration | DAG prerequisites, idempotency, cancellation, permissions/deadline | side effects or mandatory fan-in unresolved; cannot cancel invisible writes | late dependency, cheaper forbidden branch |
| Figma/Canva→HTML/CSS | authorized design tree/assets, breakpoints/accessibility hints | one viewport match not adequate responsive/functional/rights evidence | small-screen layout broken, copied asset not licensed |
| DPO Builder | lesson origin, exact x/context, selection/author/judge grants | incomplete provenance, wrong author or sealed exam leakage blocks admission | weak Student output labeled Chinese final rejected |

For each, preregister **GOOD** safe stop, **BAD** erroneous stop, **EDGE** unknown/mixed/novel domain/version and strict **FALSIFIER**. Keep real training inputs, operational tuning/development and SEALED_CERT separated by source family. Sparse kNN, negative/warning memory, exact-vs-ANN, domain-specific token projection and new law editions are mandatory coverage of the *functional experiment*, not GitHub test-count coverage.

Comparison P full accepted ordinary vs C0 safe static no-gradient vs C1 domain-conditioned no-gradient if actual vs T1 existing owner true learned state if separately granted.
