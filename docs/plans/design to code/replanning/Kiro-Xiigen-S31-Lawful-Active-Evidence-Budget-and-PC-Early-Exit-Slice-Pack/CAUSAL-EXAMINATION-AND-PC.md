Use same accepted snapshot, source version/rights, candidate set, budget and run definitions in matched contrast; report any unpaired constraints or confounding. Domain mapping: oracle domain supplied versus actual predicted versus known wrong/mixed domain. Real kNN: k=1/static/adaptive and BM25+semantic, track what the consumer uses not just search index results. Four roles: freeze Unit while changing Flow, freeze Flow while changing Unit, bounded async vs sequential on same alternatives, higher-order unseen graph composition with primitives frozen. Metrics: lawful correctness/N and separate hard-law violations, type n→m association, best **actually enumerated feasible** path/regret (if oracle unknown: NOT_ESTIMABLE), negative discrimination, calibration of continue/stop, p50/p95 and confidence by domain and worst domain; CPU/wall, peak RSS/VRAM, disk, GPU conflicts, checkpoint cold reload, provider calls/tokens and **all** losing/failed/speculative/cancelled branches.
