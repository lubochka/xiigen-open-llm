### Good, bad and edge
- GOOD: code law C# 9 rejects file-scoped namespace, while C# 10 can accept it; old-law alternatives remain available; normal C# consumer changes output or abstains with causal receipt and identical solver.
- BAD: only add `version` label to an output JSON and report dynamic learning success without changing retrieval/selected route/Student state.
- EDGE: same textual request references both C# 9 project and modern C# 10 example, or SQL dialect missing; respond with version-scoped alternatives/abstention, never substitute newer syntax silently.
- NEGATIVE DISCOVERY: eligibility reduces harmful stale examples but costs more and hurts recall; report tradeoff, route to RP02 for controlled refinement, do not manufacture IMPROVE.
