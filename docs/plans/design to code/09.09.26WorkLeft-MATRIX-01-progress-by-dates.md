## Как читать этот файл

**Правило имени вместо номера.** Внутренний номер (строка работ, разрыв механизма, решение владельца, дефолт архитектора) никогда не стоит в этом файле отдельно: сначала человеческое название и цель, номер — в скобках сразу после. Голые номера допустимы только в машинном блоке в самом конце файла. Единый словарь человеческих названий всех номеров — файл `09.09.26WorkLeft-GLOSSARY-human-names.md` в этой же папке.

**Что такое «семейство» и «веха».** Семейство — группа файлов с одной датой в имени (например все файлы `23.08.26WorkLeft-*`), написанных одним раундом проверки; у большинства семейств есть итоговый файл (суффикс «00-ИТОГ»), который читается первым. Веха — одна датированная точка хроники: либо целое семейство, либо одиночный датированный файл (отчёт статуса, список действий). Раунды 25.08, 25.08-B и 25.08-C новых семейств не создавали — они дописаны append-секциями в файлы семейства 24.08; в хронике это отдельные вехи.

**Порядок.** Таблица отсортирована по датам от старейшей вехи (июнь–июль) к свежайшей (25.08). Если в один день есть вехи в разных папках — у каждой папки своя строка.
