Задача \- запуск сервера для обработки Фигма/Канва и подобные в html-css  
Это основные требования с которыми надо сверять написанный  план:  
\!\!\! Начало\!\!\!

1. Пользователь получает html+css и отправляет результат \+ оригинальное дерево \+скрины дизайна в системе \- на сервер (сервер это наш xiigen platform \- его АПИ  
2. Сервер посылает дерево и полученный результат в свою обученную модель \- Ilearning MAchine \- новый под проект в этом проекте у него будет свой АПИ для обработки)  
3. Генерируется картинки  в разных резолюциях с полученным результатом \- Это на сервере нужно спомощью QA AUtomation \-\> загрузка полученого HTML+CSS  в разных резолюциях  
4. Картинки которые получилась и то что должно было бы быть (экспорт из фигмы/канва…) \- отправляются на визуальную проверку \- и принимается результат \- что не так \- с целью достигнуть определенного процента точности и/или достижения максимум цены на пользователя (это варьируется от того какой уровень пользователя \- бесплатный, платный, про…) \- visual of any available AI (claude, open ai, gemini)  
5. Отправляется результат, полученный html и картинки сравнения, для улучшения   
6. Снова идет сравнение \- до получения нужного качества  
7. Результаты сохраняются в специальной базе данных  для обработки для обучения  
8. Локально проект открывает  базу данных, из строит из неё DPO по основным принципам DPO для ILearningMachine где в векторе ДПО будет как внутренняя часть от машины для который этот ДПО пресназначен, так и сорсстроение \- фигма/канва и другие, так и результат. Особенно ванжо качественно создавать в паре негативный ДПО. \-  
   1.  Для того что бы строились правильно ДПО необходимо написать гайды и скилы именно для этой задачи.  
   2. Эти ДПО отображаются пользователю с показателями их полезности  
   3. Пользователь может дать указания архитектоу в сессии до обучить модель и залить новую модель с новыми весами на сервер, что бы улучшить результаты конверсии
