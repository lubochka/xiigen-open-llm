**§9 Публикация.** По канону §9 (репозиторий ядра, канон-ветка `codex/dpo-implementation`): независимый ревьюер → личная read-only проверка архитектора → пробное слияние без записи = 0 конфликтов → коммит с русским телом → push немедленно; исполнителю кода commit — только после приёмки. > «артефакт одного прогона содержит ≥ 3 разных сочетаний единиц для одного и того же входа, исполненных асинхронно СУЩЕСТВУЮЩИМ раннером, с сохранённым журналом маршрута и результатом каждого сочетания (сохранённых артефактов сейчас 0); мутационная чувствительность зафиксирована как исполненная проверка; порог «три» — пол архитектора под слово «несколько» из первоисточника: поднимать при исполнении можно, опускать ниже трёх нельзя без записанного решения (ядро строки сохранено из первой редакции).»

Обвязка исполнения (цитату не подменяет): числа «до/после» — сохранённых артефактов 0 → ≥ 1; в артефакте различимы ссылки трасс всех сочетаний; проверка мутационной чувствительности — сравнением журналов, не словом исполнителя. Мутационная чувствительность НЕ доказывается различием ссылок трассы. Перемер 25.08 по коду раннера: ссылка трассы собирается интерполяцией из трассы запроса, индекса плана и идентификатора комбинации (строка 226 файла раннера), а разбор планов принудительно требует уникальности идентификаторов комбинаций и уникальности состава каждого плана, иначе отказывает с кодом дубликата (строка 462), — значит различие ссылок трассы у разных сочетаний гарантировано конструкцией и появится в любом прогоне. Засчитываются только два сравнения. Первое, положительное: при смене СОСТАВА единиц меняется результат сочетания — полезная нагрузка ответа и ссылка трассы пути, а не только идентификатор. Второе, отрицательный контроль: тот же самый состав, прогнанный ПОВТОРНО отдельным прогоном (внутри одного запроса раннер дубликат состава отвергнет), даёт тот же результат с точностью до идентификаторов — это доказывает, что различие в первом сравнении даёт состав, а не разброс между прогонами. Прогон, где различаются только идентификаторы, — ровно тот фиктивный прогон, который эта строка запрещает засчитывать. — O3
