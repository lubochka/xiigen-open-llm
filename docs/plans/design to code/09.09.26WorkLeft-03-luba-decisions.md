# 09.09.2026 WorkLeft — решения Лубы человеческим языком

Этот файл теперь формулирует решения без внутренней бухгалтерии. Они нужны, чтобы следующий исполнитель не заменил качество модели расширением тестов или повторным прогоном старых пар.

## Открыто первым

Нужно сделать обучение похожим на урок: модель ошиблась на задаче, Qwen пишет одну новую пару, модель пробует эту пару, отдельная модель-проверяющий смотрит стало ли лучше, плохой урок откатывается, хороший сохраняет новые веса.

## Решения

1. Цель — 95% и выше к зафиксированному эталону.
2. Если уже есть 95% и выше до новой пары, новую пару не создаём автоматически.
3. Qwen — источник обучающих пар и судья урока.
4. Платная модель — финальное удостоверение, не источник DPO-пар.
5. Ручной разметчик не нужен.
6. Старые пары можно показывать как контекст, но уже принятые пары не применяются повторно.
7. Равно или неясно — это не улучшение.
