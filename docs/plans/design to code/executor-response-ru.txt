Называй конкретный resolver/path/operation и результат; не своди всё к нехватке знаний модели.

Сначала используй действительно существующий принятый выбор, связанный с этим objective. Иначе CODEX выбирает подходящее допустимое задание содержательно и объясняет выбор; при равнозначности сохраняет исходный порядок curriculum.
