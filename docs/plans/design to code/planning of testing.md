На основании этого плана нужно подготовить программу обучение и тестирования качества, скорости и точности обучения. Для этого нужно иметь возмовность уникально протестировать обучение, на уровне каждого нового design pattern и домейна описаного в заданиях. Для этого надо взять строение design pattern, domain и построить для них тестовые сеты, e2e tests  что бы посмотреть как их комбинация влияет на все эти параметры.  тому же нужно под каждый домейн подбирать KNN  логические функции так же как мы делали с домейнами оркестрации, различного кода и переводов. 
Загрузи в этот раз скилыархитектора и планирования, используй Fable 5 Ultracode  как архитектора и собери список гипотез для каждого нового design pattern, домейн из тейчто мыбудем прорабатывать и способы протестировать. (5 проходов) Не входи в технические детали твоязадача оставаться на уровне исследователя и  сохранять документ именно на человеческом языке!

Тестируемые design patterns: 
1. ILearningUnit \- упрощенная матрица принимает домейн, строение векторов, строение выхода, и по входам выпускает Iquearable of results of requested input type many-\>many  
2. IlearnyngFlow \- это взаимоотношение между юнитами , для коррекции входа в выход   
3. IlearningOrchestrator \- это уже более глубокая модель, позволяющая асинхронно обрабатывать инпут и превращать его в оутпут  
4. ILearningDynamicGraph \- более комплексная модель соотношений различных паттернов разного порядка

Тестируемые домейны: 
1. Перевод с английского на русский и обратно
2. Оркестрация задач по программированию (с общей на под задачи)
3. Перевод дерева figma -> Html+css
4. Документация кода на C#
5. Документация кода на Angular
