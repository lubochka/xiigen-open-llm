# Следующий проход

Начните с `next_review` выбранной карточки и её `source_refs`; затем читайте исторические измерения. Не смешивайте snapshot опыта и commit текущего кода.

1. Новый scope — `additional_examples_round2`; предыдущий `selection_review` остаётся историей.
2. Для KDP проверьте явно подключаемый каталог и новую свежесть HEAD. Не заменяйте панель качества числом тестов и не предполагайте автоматический выбор правил.
3. Для RD/MB восстановление назначенного learned S0 — открытый пункт аудита, отдельный от наличия оптимизации в коде. Старый A/B не является новым ресурсным замером HEAD.
4. Для SEXP и RETENTION сначала установите, перенесён ли именно экспериментальный фактор; соседний ремонт другой ветви не засчитывается переносом.
5. Для P02 сохраняйте distinction между абсолютным margin и изменением между зарегистрированными точками. Не выдумывайте отсутствующее время SFT.
6. Каталог исторический; если нужна новая полная очередь, прочитайте текущий индекс отдельно. Наличие записи не означает положительный результат.

Исходные тексты книги и бинарные checkpoints в пакет не включены. Поиск автономный; чтение полного GitHub-источника требует сети. Новые модельные запуски этим пакетом не разрешаются и не выполняются автоматически.
