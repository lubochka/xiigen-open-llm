# XIIgen: ещё пять экспериментов — автономный навигатор

Откройте `navigator-more.html` двойным щелчком. Интернет для поиска не нужен: основной текст, карточки, формулы, исходники схем и ссылки встроены в один файл. Ссылки на полные первоисточники открываются на GitHub при наличии сети. Внешние библиотеки не загружаются. Формулы показаны в записи LaTeX, Mermaid-схемы можно скопировать; автоматического внешнего рендеринга нет.

## Как читать результаты

KDP уже имеет явно подключаемое API project18 после4599582. Исторические панели по8строк не являются27новыми тестами переноса. RD/MB присутствуют в коде, но назначенная квалификация переноса на восстановленном H64/LoRA остаётся открытой. SEXP и RETENTION max-merge не перенесены в названные основные методы. Ни один из трёх нейронных вычислительных примеров не заявляет прирост точности.

В MB01 новая точная сверка raw показывает allocations13642496→12782336; прежний агрегат860160 байт/6,31% сохранён. У MB01 wall+5,07% в одной паре показан рядом с выигрышем allocations. RD01 и MB01 используют один исторический донор: их проценты не являются измеренным суммарным выигрышем.

В P02 различаются бюджеты4/8 обновлений. Между первым и последним зарегистрированными margin изменения составляют0,0012550415 и0,0012739184; отношение1,01504. Отношение последних абсолютных уровней3,2247 не доказывает3×эффект DPO. Точность2/4не меняется; отдельное времяSFTне измерено.

## Поиск через Python

Нужен Python3, дополнительные пакеты не требуются. `query.py` использует локальный `query_legacy.py` для прежнего алгоритма ранжирования.

```sh
python query.py RETENTION
python query.py KDP01 --selection main --json
python query.py RD01
python query.py MB01
python query.py SEXP01
python query.py P02 --json
python query.py --selection main
python query.py --selection previous_main
```

Это взвешенный поиск по словам и русским/английским соответствиям. Векторной базы, эмбеддингов запросов и генерации ответов нет. JSON-выгрузка сохраняет исторические и новые поля отдельно.
