## Corrected UML Rules

These rules are binding for this batch.

1. The domain processor is not one unit. It is an array of units. Each planned piece can be processed by its own unit.
2. The applier is not one unit. It is an array of units. Each planned piece can be applied by its own unit.
3. The result translator is not one unit. It is an array of units. Each result has its own translation unit, while every translator can see the full result collection for consistency.
4. The arbiter selector is separate from the result translator. It sees the full result collection and chooses which reviewers are needed.
5. The arbiter units run before the final formatter. They can send selected pieces back through the reprocessing loop.
6. The formatter receives only approved translated results and folds them into one user-readable output.
