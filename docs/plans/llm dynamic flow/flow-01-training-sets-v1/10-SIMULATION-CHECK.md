# Flow 01 Training Sets - Simulation Check

## Simulated Run

Input: create the architecture design for user registration and SSO onboarding from the source document.

1. Domain splitter emits identity and access; onboarding and account state; communication delivery; event movement; safety and compliance review; running and reliability; measurement and personalization; client experience; tenant variation; account consistency.
2. Domain translator array turns each selected domain into its own work language while keeping original source lines available.
3. Scheme planner creates the provider path, email path, shared onboarding path, waiting states, recovery cases, event chain, review needs, and final answer sections.
4. Domain processor array processes one planned part per unit, instead of one large all-purpose processor.
5. Applier array creates one result per processed part: account result, verification result, questionnaire result, event result, safety result, operations result, service result, client result.
6. Result translator array turns each result into human language while seeing all results for consistency.
7. Arbiter selector chooses the reviewers before final formatting.
8. Arbiter units pass good results or send selected fragments back for reprocessing.
9. Formatter folds only approved result fragments into one final user-likable architecture answer.

## Expected Missing Parts

- These sets still need more real rejected examples from session corrections. Current rejected examples are derived from source rules and are marked as derived.
- The exact final creation transcript was not found, so the history rows cannot be treated as certain creation rows.
- Arbiter selection is source-derived but still thin; future documents should add richer examples for deciding which arbiters fire.

## Pass Criteria

- All 357 source lines are represented across the node files.
- The array stages remain arrays: domain processor, applier, and result translator.
- Arbiter selector remains separate from result translator.
- Formatter receives approved translated results only.
- No row replaces source text with a shorter summary; every row includes the original source text or clearly marks itself as candidate history or derived review example.
