# Node-05 - Applier Set

## Purpose

Runtime A is one work piece, its transformation instruction, and the processed result from Node-04.
Runtime B is the concrete social-network behavior or outcome.

## Pair 5.1 - Apply onboarding

A: Work piece: onboarding. Transformation instruction: account, profile, suggestions, and feed seeding all complete usable signup. Processed result: identity, profile, recommendation, and feed sources are ready.

B: Action outcome: the new user can sign in, has profile basics, receives suggested connections or interests, and sees starter feed content.

Pair 5.1 - Phrasing B

A: Work piece: make account useful. Transformation instruction: do not stop at authentication. Processed result: onboarding pieces ready.

B: Action outcome: the platform moves the user from empty account to usable social experience.
