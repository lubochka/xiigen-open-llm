# Node-01 - Domain Splitter Set

## Purpose

Runtime A is a human prompt about social-network modules or flows.
Runtime B is the array of social-network domains touched by that prompt.

## Pair 1.1 - Onboarding

A: "Build onboarding where signup creates an account, profile prompts collect basics, suggestions seed connections, and the feed shows starter content."

B: [identity accounts sessions and recovery, rich profile and persona, social graph connections and suggestions, recommendations and experimentation, home following and profile feed]

Pair 1.1 - Phrasing B

A: "A new user should register, complete profile basics, get suggested follows or groups, and see an initial feed."

B: [identity accounts sessions and recovery, rich profile and persona, social graph connections and suggestions, recommendations and experimentation, home following and profile feed]

## Pair 1.2 - Social graph

A: "Support friend requests, follows, blocks, mutes, restricted edges, close friends, lists, and people-you-may-know suggestions."

B: [social graph connections follows blocks lists and suggestions, privacy policy and audience controls]

Pair 1.2 - Phrasing B

A: "Model graph edges for friend, follow, block, muted, and restricted relationships."

B: [social graph connections follows blocks lists and suggestions, privacy policy and audience controls]

## Pair 1.3 - Publish post with media

A: "Let a user upload media, transcode it, create a post, wait for media readiness, publish, and make it feed eligible."

B: [content creation and media pipeline, home following and profile feed, notifications and preferences]

Pair 1.3 - Phrasing B

A: "Posts may include text, images, video, documents, stories, or reels, and media must be processed before final display."

B: [content creation and media pipeline, home following and profile feed]

## Pair 1.4 - Feed request

A: "Build a home feed that generates candidates from graph, groups, pages, interests, filters privacy and blocks, ranks posts, adds ads with spacing, and records impressions."

B: [home following and profile feed, privacy policy and audience controls, recommendations and experimentation, monetization, analytics and metrics]

Pair 1.4 - Phrasing B

A: "The feed should collect candidates, filter them, rank them, diversify them, inject eligible ads, and serve cursors."

B: [home following and profile feed, privacy policy and audience controls, recommendations and experimentation, monetization, analytics and metrics]
