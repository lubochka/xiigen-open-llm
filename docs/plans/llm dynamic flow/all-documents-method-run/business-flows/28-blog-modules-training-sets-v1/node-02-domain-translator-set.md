# Node-02 - Domain Translator Set

## Purpose

Runtime A is one prompt fragment paired with one domain label.
Runtime B is the same request written in that domain's precise working language.

## Pair 2.1 - content model

A: Prompt fragment: "Create posts and pages with fields, relationships, revisions, and publishing state." Domain label: content model.

B: The content model responsibility must be represented as a separate territory in the blog modules flow. It must preserve the user's requested outcome, name the information it depends on, name the visible result it should produce, and expose any approval, waiting, recovery, privacy, or measurement concern that affects the rest of the flow. The fragment asks for: Create posts and pages with fields, relationships, revisions, and publishing state.

Pair 2.1 - Rephrased

A: Domain label: content model. Fragment: "Help me create posts and pages with fields, relationships, revisions, and publishing state."

B: Treat content model as its own responsibility inside blog modules. State what is being requested, what must be known first, what result leaves this territory, and what risk or waiting condition must remain visible to later nodes.
