# Node-01 - Domain Splitter Set

## Purpose

Runtime A is a human prompt about lesson completion, points, learning adaptation, social sharing, peer grading, or privacy.
Runtime B is the array of domains touched by the prompt.

## Pair 1.1 - Complete questionnaire

A: "When a learner finishes a lesson questionnaire, validate the answers, score them, and store the attempt."

B: [questionnaire answer validation and storage, raw score calculation]

Pair 1.1 - Phrasing B

A: "After the user submits all lesson answers, save the attempt and calculate the first score."

B: [questionnaire answer validation and storage, raw score calculation]

## Pair 1.2 - Award points

A: "Give the learner points for completing the questionnaire, correct answers, speed, streaks, and high-quality text responses."

B: [gamification points, streaks, quality rewards]

Pair 1.2 - Phrasing B

A: "Calculate the learner's reward from accuracy, completion, time bonus, streak bonus, and reflection quality."

B: [gamification points, streaks, quality rewards]

## Pair 1.3 - Level up and achievements

A: "If the new point total crosses a threshold, level the user up and unlock any earned achievements."

B: [levels, achievements, notifications]

Pair 1.3 - Phrasing B

A: "Trigger a celebration when the learner reaches a new level or earns a badge."

B: [levels, achievements, notifications]

## Pair 1.4 - Adapt learning plan

B: [adaptive learning-plan adjustment]

Pair 1.4 - Phrasing B

B: [adaptive learning-plan adjustment]

## Pair 1.7 - Peer grading

## Pair 1.8 - Social opt-out

A: "If the learner keeps learning activity private or opts out of sharing answers, skip the social post entirely."

B: [privacy and consent, social branch control]

Pair 1.8 - Phrasing B

A: "Run points and learning updates, but do not create a feed post when the user does not consent to sharing."

B: [privacy and consent, social branch control]

## Pair 1.9 - Prevent point farming

A: "Do not let the client submit point values or submit the same questionnaire repeatedly to farm rewards."

B: [point integrity and anti-farming, duplicate submission control]

Pair 1.9 - Phrasing B

A: "Calculate points on the trusted side, rate-limit completions, and make duplicate submissions return the same result."

B: [point integrity and anti-farming, duplicate submission control]
