## Задача 2 — Запустить Scale 3 для E01 E02 E03 E06

**Scale 3 = подпроекты 00–14, ~55 360 BPE токенов, ~44 288 обучающих пар:**

```
Уже были в Scale 2 (00–08):  ~30 543 токена
Добавляются в Scale 3:
  09.Inference        ~1 898 BPE
  10.LoRA             ~1 173 BPE
  11.DPO              ~2 009 BPE
  12.SearchEngine     ~4 834 BPE
  13.CodeOptimizer    ~6 488 BPE
  14.MachineLearning  ~8 410 BPE
  Новых:             ~24 812 BPE
ИТОГО Scale 3:       ~55 355 BPE токенов
```

**Точная команда для Claude Code:**
```csharp
var runner = new ExperimentRunner(
    projectRoot: @"путь\к\llm_mvp_core",
    outputDir:   @"experiments\results");

runner.Run("E01", scale: 3);
runner.Run("E02", scale: 3);
runner.Run("E03", scale: 3);
runner.Run("E06", scale: 3);
```

**Ожидаемые результаты Scale 3:**

| Эксп. | Scale 2 | Ожидание Scale 3 | Обоснование |
|---|---|---|---|
| E01 | +42.4% | +40–45% | Vocab ~480/500 насыщен, кластеры стабильны |
| E02 | +10.6% | +9–13% | Больше разных паттернов кода, оба направления растут |
| E03 | +11.7% | +10–15% | Тригамма надёжнее на большем корпусе |
| E06 | +50.7% | +45–55% | AST грамматика C# конечна — ~130–150 типов максимум |

**Критерий перехода:** accuracy_delta ≥ 5% → Scale 3 пройден.  
Если результат стабильно выше 5% на Scale 0, 1, 2, 3 — теория считается подтверждённой на всей кодовой базе проекта.

## Что ожидать после Scale 3

**E01 и E06** с высокой вероятностью пройдут — тренд стабильный.

**E02 и E03** — если delta снизится ниже 5%, это не провал теории.  
Это нормальное поведение: при большом корпусе baseline тоже улучшается,  
и относительное улучшение enhanced может немного снизиться.  
При этом абсолютные числа будут выше.
