# P16F backup/share metadata

## Что можно переносить в review package
Можно переносить candidate checkpoint copy, manifest и source manifest с указанными SHA. Это metadata evidence, а не внешняя публикация.

## Что остается приватным или не common-ready
Adaptive/user-owned/unverified material не становится common training. Raw private prompt text в P16F не копировался.
