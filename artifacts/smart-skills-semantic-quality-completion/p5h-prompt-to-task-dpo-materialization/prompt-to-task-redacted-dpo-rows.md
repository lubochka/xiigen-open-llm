# P5H: материализация редактированных DPO-строк для PromptToTask

Фаза создает шесть строк для родительского обзора из P5G-кандидатов со статусом `candidate_for_authoring_review`. Эти строки не являются учебными, не прошли разбиение на обучающую и проверочную части, и не подтверждают семантическое качество.

## P5H-DPO-PTT-001
- Исходный кандидат: `P5G-PTT-FAMILY-001`
- Целевая машина: `PromptToTask`
- Семья источника: `sf-p5g-ptt-accepted-orchestration-patterns-7F8936DA`
- Состояние источника: `local_prompt_archive_inspected_not_analysis_state_done`
- Универсальная граница: PromptToTask извлекает контракт текущей задачи до исполнения; прошлые разборы и их порядок являются свидетельством, а не готовым ответом.
- Выбранный ответ: Сначала превратить просьбу в проверяемый контракт: цель, допустимые контекстные входы, ограничения, ожидаемые артефакты, критерий принятия и следующий безопасный слой работы.
- Отклоняемый близкий промах: Взять пометку успешного разбора как готовый маршрут, повторить порядок действий из прошлого случая и не выделить самостоятельный контракт текущей задачи.
- Тип ошибки отклоняемого ответа: `accepted_archive_label_used_instead_of_task_contract`
- Почему это полезный промах: он похож на рабочее действие, но пропускает извлечение контракта задачи и поэтому учит не идти по поверхностному признаку.
- Удаленная утечка: Удалены частные формулировки, названия источника, имена файлов, номера потоков, локальные продуктовые метки, пути и загруженные материалы.
- Будущая группа для честного разбиения: `ptt_future_train_candidate_accepted_archive_contract`
- Контроли будущей абляции: `exact_prompt_lookup`, `filename_path_title_shortcut`, `keyword_only_classifier`, `source_family_id_shortcut`, `nearest_only_retrieval_only`, `archive_heading_shortcut`
- Готовность к родительскому обзору: `true`, причина: Кандидат принят родительским обзором P5G для материализации; строка остается только для родительского обзора и не является учебной.
