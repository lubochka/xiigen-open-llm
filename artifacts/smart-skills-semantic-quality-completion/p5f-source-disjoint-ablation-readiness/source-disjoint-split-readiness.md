# P5F: готовность независимого разбиения по источникам

Этот артефакт только предлагает роли для будущего обзора. Он не открывает обучение, оценку или утверждение качества.

- `training_allowed=false`
- `eval_allowed=false`
- `semantic_quality_claimed=false`
- ни одна строка не имеет `training_ready=true`

## Выводы по машинам

### PromptToTask

Недостаточно для честного независимого разбиения: есть только две независимые строки. Можно наметить одну строку для обучения и одну резервную проверочную строку, но этого мало для устойчивой проверки и отдельного запаса.

Что еще не готово:

- все строки остаются не готовыми к обучению
- проверки на подсказки еще не запускались
- не хватает ширины независимых семей источников
- не было запуска обучения, оценки и родительского принятия обучающего набора

### OrchestrationReasoning

Достаточно для чернового предложения независимого разбиения: пять строк из пяти семей источников позволяют предложить роли для обучения, проверки и резерва. Это не готовность к обучению.

Что еще не готово:

- все строки остаются не готовыми к обучению
- несколько строк остаются кандидатами из именованных ссылок
- проверки на подсказки еще не запускались
- риск близкого дублирования между строкой о границе фазы и строкой о нескольких ветках должен проверить родительский обзор
- нет доказательств по обучению, оценке, контрольной точке, свежей загрузке и продолжению обучения

## Общие ограничения

- Это не обучающий набор и не проверочный набор.
- Проверки на подсказки и близкие дубли еще не запускались.
- Родительский обзор должен принять или отклонить роли до любого следующего шага.
