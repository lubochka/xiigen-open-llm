# Приборы этой попытки: чем именно делались сборки, прогоны и сравнения

Здесь лежат КОПИИ сценариев, которыми выполнялась работа. Копии, не переносы:
оригиналы продолжали работать во время копирования, чтобы идущий прогон не
сорвался. Смысл этих копий — воспроизводимость: без запускателя прогон
невоспроизводим, а значит улика неполна.

| Файл | Что делает | Откуда скопирован |
|---|---|---|
| `fixkhc_stage.sh` | один этап: условие на нулевую занятость, пересборка, обнаружение, прогон одиннадцати существующих, прогон новой, отпечатки библиотек до и после прогонов | `C:/Users/lubao/AppData/Local/Temp/fixkhc_stage.sh` |
| `full_suite.sh` | полный прогон проекта проверок без пересборки, с условием на занятость и отпечатками библиотек | `C:/Users/lubao/AppData/Local/Temp/full_suite.sh` |
| `wait_build_slot.sh` | очередь на общий каталог сборки по правилу двух нулей подряд, предел десять минут, каждая попытка пишется в журнал очереди | `C:/Users/lubao/AppData/Local/Temp/wait_build_slot.sh` |
| `busy_check.ps1` | прибор занятости: считает чужие сборки И прогоны на общем каталоге, исключая процессы со своим каталогом вывода и собственный процесс | `C:/Users/lubao/AppData/Local/Temp/busy_check.ps1` |
| `parse_trx.py` | разбор файла результатов по узлам разметки: счётчики и строки результата с исходом и сообщением | `C:/Users/lubao/AppData/Local/Temp/parse_trx.py` |
| `trx_sets.py` | сравнение двух прогонов разностью множеств полных имён: регрессии, новые упавшие, исправившиеся, исчезнувшие | `C:/Users/lubao/AppData/Local/Temp/trx_sets.py` |
| `apply_khc_transfer.py` | внесение самого переноса по готовой форме карточки в два названных файла | `C:/Users/lubao/AppData/Local/Temp/apply_khc_transfer.py` |

Числа прогонов считаются перечислением строк результата по схеме, а не полем
«всего»: это поле самоссылочно и охват им не доказывается.
