ЧТО ПРОВЕРЯЕТСЯ И ПОЧЕМУ ИМЕННО ТАК
Требуется доказать, что ни один файл доказательств этой попытки не выпадает
из-под учёта Git из-за правила игнорирования. По правилу проекта код возврата
сам по себе вердиктом НЕ является: решает текст победившего правила. Поэтому
проверка двухчастная.
  Часть первая — фактическое дерево: перечисление реально существующих
  неотслеживаемых игнорируемых путей. Это прямое доказательство.
  Часть вторая — гипотетические пробы: разбор победившего правила для пути в
  каждом подкаталоге. Это доказательство на будущее: оно показывает, что
  новый файл в этих каталогах тоже не будет проигнорирован.
Чтение победившего правила: код возврата 1 при пустом выводе означает, что
подходящего правила игнорирования нет вовсе, то есть путь НЕ игнорируется;
код возврата 0 с правилом, начинающимся с восклицательного знака, означает
явное ПЕРЕ-включение, то есть тоже не игнорируется; код возврата 0 с
правилом без восклицательного знака означает игнорирование и жёсткий отказ.
