## Мутация M1 — вернуть дефект аудита: четыре поля литералами при вычисленном признаке

Что именно менялось (внутри валидатора `DecideComparison`, возврат вердикта): четыре строки
```
LearningValidity: valid ? "VALID_FOR_NAMED_UNIT" : "INVALID_NON_FINITE_STATE_OR_LOSS",
HypothesisStatus: valid ? "NOT_SUPPORTED_IN_VALID_COMPARISON" : "OPEN_COMPARISON_NUMERICALLY_INVALID",
ExitCode: valid ? 0 : 1,
Problems: [.. problems]);
```
заменены на литералы
```
LearningValidity: "VALID_FOR_NAMED_UNIT",
HypothesisStatus: "NOT_SUPPORTED_IN_VALID_COMPARISON",
ExitCode: 0,
Problems: Array.Empty<string>());
```
Признак `NumericallyValid: valid` оставался вычисленным — ровно та конфигурация, которую
описал аудит: признак считается, а поля рядом написаны руками.

Результат (`runs/run-02-mutation-M1-literals/run-02-mutation-M1-literals.trx`, код возврата
прогона 1): всего 7, исполнено 7, **упало 4**, прошло 3. Упали ровно четыре отрицательных
контроля — не-число, плюс бесконечность, минус бесконечность, потеря; каждый на
`Assert.Equal() Failure: Strings differ` (ожидалось `INVALID_NON_FINITE_STATE_OR_LOSS`,
получено литеральное `VALID_FOR_NAMED_UNIT`). Прошли: основной опыт, прежний отрицательный
контроль измерителя и положительный контроль — им литералы не мешают, и так и должно быть.

Вывод: контроли проверяют именно поля, а не только признак. Без связи они краснеют.

## Мутация M2 — выключить бесконечность из предиката

Что именно менялось: строка валидатора
```
if (block.Infinite > 0)
```
заменена на
```
if (false && block.Infinite > 0) // МУТАЦИЯ M2
```
то есть ветка бесконечности стала недостижимой; ветка не-числа и ветка потери не тронуты.

Результат (`runs/run-03-mutation-M2-no-infinity/run-03-mutation-M2-no-infinity.trx`, код
возврата прогона 1): всего 7, исполнено 7, **упало 2**, прошло 5. Упали ровно контроли
«плюс бесконечность» и «минус бесконечность» (на `Assert.False` — валидатор признал
испорченную руку действительной); контроли «не-число» и «потеря», положительный контроль и два
прежних испытания прошли.

Вывод: включение бесконечности в предикат несёт нагрузку — без него обе бесконечности проходят
как действительные, и это ровно то состояние, которое было до починки.
