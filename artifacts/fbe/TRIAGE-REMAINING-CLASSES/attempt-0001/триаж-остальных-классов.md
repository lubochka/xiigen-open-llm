## Решения координатора, применённые с этой партии

1. **«Значительно — более пяти процентов»:** применяю оба чтения и указываю оба числа — пункты и
   относительную долю. Если хотя бы по одному чтению выходит больше пяти процентов — первая
   очередь, второе число рядом.
2. **Молчаливое необучение** квалифицировано координатором как явная логическая ошибка сохранения
   правильного ответа: урок не попал в модель вовсе. Первая очередь по этой ноге.

### Расхождение реестра с живым кодом — восьмой случай этого вида

Единственная строка партии, где колонка состояния прямо утверждает **«Не реализовано»**, — Q22.
Проверка по живому коду говорит иначе, и говорит точно:

| Что проверено | Наблюдение |
|---|---|
| продуктовый адаптер исправлений | `27.TranslationDomain/TranslationCorrectionLearningAdapter.cs`, 324 строки |
| точка входа | `DeliverAsync` на строке 243 |
| обучение памяти | `machine.TrainStructuredBatchAsync(batch, ct)` на строке 276 |
| отвергнутый ответ как обязательное поле | `ActualRejectedAnswer` на строке 63, с комментарием «ДЕЙСТВИТЕЛЬНО выданный ответ, который проверка забраковала» |
| сторож подмены | код ошибки `REJECTED_ANSWER_SUBSTITUTED_BY_SOURCE` на строке 106 и `CORRECTION_REJECTED_ANSWER_REQUIRED` на строке 93 |
| обычный вызывающий вне тестов | **нет**: единственный продуктовый файл, упоминающий адаптер, — он сам |

Поэтому формулировка «Не реализовано» неверна про механизм и верна про продуктовый путь.
Назначенный классом узкий срез и есть этот недостающий обычный вызывающий. Прежние проходы нашли
семь таких расхождений; это восьмое, и оно с оговоркой, а не безоговорочное.
