Проверка действующих атрибутов. Класс порчи — перекодирование переводов строк, поэтому текстовое преобразование обязано быть выключено.
Команда: git check-attr -a -- <путь>

experiments-v2/RP01-MICRO/SEP01/results-01/producer-abs.bin: diff: unset
experiments-v2/RP01-MICRO/SEP01/results-01/producer-abs.bin: merge: lfs
experiments-v2/RP01-MICRO/SEP01/results-01/producer-abs.bin: text: unset
experiments-v2/RP01-MICRO/SEP01/results-01/producer-abs.bin: filter: lfs
experiments-v2/RP01-MICRO/SEP01/results-01/producer-sign.bin: diff: unset
experiments-v2/RP01-MICRO/SEP01/results-01/producer-sign.bin: merge: lfs
experiments-v2/RP01-MICRO/SEP01/results-01/producer-sign.bin: text: unset
experiments-v2/RP01-MICRO/SEP01/results-01/producer-sign.bin: filter: lfs

Правило-источник: .gitattributes:45  ->  *.bin filter=lfs diff=lfs merge=lfs -text
core.autocrlf = false
core.eol =   (пусто = не задано)
Вывод: text=unset означает явное -text, то есть преобразование выключено; повторной порчи при следующей выдаче файла не будет.
