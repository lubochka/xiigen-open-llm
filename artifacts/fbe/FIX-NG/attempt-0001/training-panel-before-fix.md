# Прогон обучения ДО правки — показания

Продуктовый код в этом прогоне равен опубликованной вершине: объект файла
разметчика `ef7a88a3c4c2540569b9ce6f204d8e4750875501`, пустая сверка изменений.
Это тот же объект, который карточка закрепила на своём проверенном срезе.

Прогон: один настоящий вызов продуктового писателя обучения на двенадцати
учебных строках, затем чтение через настоящий продуктовый читатель метки файла.
Журнал прогона целиком — `red-on-published-code-console.log`, машинный отчёт —
`red-before-fix/red-on-published-code.trx`.

## Опоры непустоты, прошедшие на ЭТОМ (старом) состоянии продукта

- то же сравнение величины, записанное обычным оператором `n>0` вместо образца
  `n is >0`, уже даёт совет о проверке на пустое значение;
- то же тело вообще без условия даёт тот же совет;
- вектор признаков целевого запроса побитово равен векторам всех трёх строк его
  собственного учебного семейства.

Эти три опоры доказывают, что урок в данных есть и достижим, а прятало его
ровно распознавание записи через образец, а не отсутствие данных.

## Исход прогона

Упало 3 из 10, прошло 7. Упали ровно три решающие проверки, каждая по существу:
ожидался совет о проверке на пустое значение, фактически выдан совет о методе.
