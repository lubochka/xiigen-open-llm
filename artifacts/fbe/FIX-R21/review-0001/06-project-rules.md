Найдено шесть мест, и все они — не нарушения по существу:
- строки 88, 90, 92: три константы `TrainLoop`, `TrainErrorHandling`, `TrainSimple` идут подряд после одного группового комментария (строки 83–85), который описывает все четыре; это обычная форма группового комментария для набора однотипных констант;
- строки 240, 282, 308: заголовки методов `[Fact]` — комментарий о смысле случая стоит первой строкой тела (242–244, 284–289, 310–314), и это содержательнее, чем комментарий над атрибутом.

## Правило 9 (аббревиатура расшифровывается при первом употреблении)

Файл проверок: поиск `\b(KNN|SHA|TRX|FQN|API|UML|JSON|E13|E14|DPO)\b` дал одно совпадение — строка 6, `FIX-KNN-TIE-01`, это имя переноса (идентификатор), а не употребление аббревиатуры в тексте; предсказатель в тексте называется словами («методный предсказатель», «предсказатель с одним соседом»). Нарушений нет.

Файлы улик (малые нарушения):
- `pre-work-fingerprints.md`, строка 20 («Отпечатки файлов (SHA-256)») и `acceptance-record.md`, строка 16 (заголовок столбца `SHA-256`) — сокращение не расшифровано при первом употреблении (алгоритм безопасного хеширования с длиной 256 бит);
- `run-baseline.sh`, строка 2: «в плане помечена UNRUN» — английская машинная метка без перевода («не запускалась»); в `acceptance-record.md` строка 6 та же мысль передана по-русски («помечена как не запускавшаяся»), так что смысл не теряется;
- `acceptance-record.md`: `.trx` употребляется как расширение файла с пояснением «результат раннера» (строки 73, 92, 190) — расшифровка по существу есть, формально имя формата не раскрыто. Не считаю нарушением.

Доказательство: `grep -noP` по файлу проверок -> `6:KNN`; чтение улик.
