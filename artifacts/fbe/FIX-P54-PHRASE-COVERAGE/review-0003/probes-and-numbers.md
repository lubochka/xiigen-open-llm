## 1. Прибор, который меня чуть не обманул: поиск ссылок на пустой журнал

Первая проба — по отслеживаемым файлам с пропуском двоичных:

```
git grep -n -I 'verification-after-repair' -- .
```

Дала 7 строк в 4 файлах. **Калибровка провалилась:** заголовок нового журнала
(`verification-rerun-working.log`, строка 1) заведомо содержит эту строку, а проба его не показала.
Причина — атрибуты пути:

```
git check-attr text eol diff crlf -- <путь к журналу>
  -> text: unset, diff: unset
.gitattributes:1107  /artifacts/fbe/**/*.log -text -diff
.gitattributes:1122  /artifacts/fbe/**/*.txt -text -diff
```

Git считает такие файлы двоичными, ключ `-I` двоичные пропускает. Правильная проба:

```
git grep -c --text 'verification-after-repair' -- .
```

Итог — 13 упоминаний в 6 файлах (пропущено было 6 из 13, в том числе все пять строк журнала команд):

Дополнительная проба на указатели другими словами:
