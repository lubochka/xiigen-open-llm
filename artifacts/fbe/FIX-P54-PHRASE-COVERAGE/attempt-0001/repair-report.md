## Пункт 1 — возвраты каретки в показаниях: закрыт

- Причина: сериализатор JSON с отступами на Windows ставит `\r\n`; приёмник улик пишет текст как есть
  («нормализацию делает вызывающее испытание»). Число возвратов в файлах (40, 54, 22, 56, 30, 66) равнялось
  числу переносов JSON.

  замена `\r\n` → `\n` перед записью; комментарий про формат теперь говорит и про метку порядка байтов,
  и про возвраты каретки.
- Доказательство: проба `tr -dc '\r' | wc -c` на эталоне с одним возвратом → 1; на шести показаниях после
  прогона → 0, 0, 0, 0, 0, 0. Четыре показания с неизменным содержанием уменьшились ровно на число
