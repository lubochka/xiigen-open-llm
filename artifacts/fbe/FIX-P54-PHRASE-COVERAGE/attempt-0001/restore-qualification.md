## Что доказано

1. **Export → import в чистую машину без переобучения** (`Restore_ExportedStateImportedIntoFreshMachine_AnswersFourOfFourWithoutRetraining`).
   Три урока (`R54-t01/t02/t03`, `SourceId r54-native-acceptance-v1`, у каждого ровно одно
   PhraseMapping и ни одного однословного) учатся одной партией на исходной машине. Чистая машина ДО
   загрузки: 0 из 4 — все четыре строки дают `[EN_RU:BOOTSTRAP] …`. После `ExportCheckpoint()` →
   `ImportCheckpoint()` в ту же чистую машину: **4 из 4, 0 потерянных**:
   `close user session → закрой сеанс пользователя`, `close user → закрой пользователя`,
   `user session → сеанс пользователя`, `close → закрой`.
2. **Дисковый путь** (`Restore_SavedCheckpointFileLoadedFresh_AnswersFourOfFourWithoutRetraining`).
   `SaveCheckpointAsync` во временный файл (4 805 байт) → `LoadCheckpointAsync` в полностью новую машину:
   **4 из 4**, тот же набор ответов. Файл удалён после проверки.
3. **Путь фразовый, а не ассоциативная память — на копиях ЗАГРУЖЕННОГО состояния**
   (`Restore_CopiesOfLoadedStateWithoutThePhrase_TurnThePanelRedWhileTheLiveStateHolds`). Копии
   строятся из `ExportCheckpoint()` уже загруженной машины (не исходной обученной), каждая грузится в
   отдельную новую машину; живое загруженное состояние не трогается:
   - без фразы `close`: главная строка → `закрой пользователя` (не золото), панель **3 из 4**;
   - с заменой перевода `user session` → `СЕАНСЗАМЕНА`: главная строка → `закрой СЕАНСЗАМЕНА`
     (содержит замену, не содержит `сеанс пользователя`);
   - с пустой фразовой памятью: главная строка → `закрой пользователя` (не золото);
   - живое загруженное состояние после построения копий: по-прежнему **4 из 4**.

## Как доказана краснота

Утверждение восстановления — «правильных ровно 4 из 4». На копии загруженного состояния без выученной
фразы `close` та же панель даёт 3 из 4, и главная строка не равна золоту; проверка прямо утверждает
`Count(Correct) < 4` и `NotEqual(ExamTarget, …)` на этой копии — то есть утверждение «4 из 4»
на ней ложно, проверка восстановления на таком состоянии краснеет. Живое состояние при этом не портится
(4 из 4 после копий). Чувствительность проверена без нового обучения: только копии записи контрольной точки.

## Чего восстановление не доказывает

Не доказывает качество перевода на живых данных, семантическую правильность равных по покрытию
разбиений, совместимость старых файлов контрольных точек других версий, поведение вне области
(>8 слов, другие направления, строки с однословными переводами) и чистоту полного регрессионного набора.
