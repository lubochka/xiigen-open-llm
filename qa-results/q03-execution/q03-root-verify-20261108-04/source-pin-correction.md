# Поправка к закреплению исходников этого прогона

Исходный файл закрепления был перезаписан мной по ошибке при починке хвостовых
пробелов: я подставил отпечатки файлов в их текущем состоянии, а не в том, в
котором этот прогон на самом деле выполнялся. Это была порча доказательства, а
не вопрос форматирования.

Восстановленные значения взяты из вывода проверки разбора, сделанной перед
запуском этого прогона: оболочка приёмки `83543cb306674d10...`, общий модуль
`6df164f1393315a4...` — версия уже с починкой обхода дерева процессов, но ещё
без комментария с измеренным запасом точности.

Ограничение названо прямо: после перезаписи эти значения нельзя пересчитать из
самих файлов, потому что файлы с тех пор изменились. Они восстановлены по записи
сессии, а не подтверждены повторно. Принятым прогоном этот прогон не является;
он доказывает только то, что починка обхода дерева закрыла упавший случай и
вернула счётчик сборок к 17.
